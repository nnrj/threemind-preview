# AI Debug Reports

[中文](README_CN.md) | [English](README.md)

This directory receives generated experiment reports from the ThreeMind
Experiment and Debug Workbench. Each report preserves the selected run,
validated commands, observed result payloads, and any external analysis.

Reports are **generated, unreviewed research artifacts**. They are not Core
output and do not establish semantic understanding, agency, or consciousness.
The selected persistence backend holds the canonical structured audit record.
