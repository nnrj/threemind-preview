# E44：从零语言外设共同发育与连续内部活动

2026-10-04，结果查看前登记。[总计划及原话](../../../docs/zh/plans/language-development.md)。Core 固定 continuous-memory/2 普通默认；不改动力学、死亡、旧感官或旧证据。

## 校准与正式材料

先用独立名字「壬、癸、子、丑」及四个可观测几何对象的常规名称「红球、蓝盒、绿柱、黄块」校准。正式名字「甲、乙、丁、戊」不参与对应训练或外设选型。几何对象不是海洋生态，也不宣称具备主动操作能力；这是语言及视觉共同经历的教学装置。完整教学保留短句「甲是红球。」等，反转组只反转对应。

A 阶段比较原文本感官、既有从零模型整句 L2 向量、新增独立协议的逐字符因果特征输入。新协议固定 NFKC、20 ms 字符步距、种子接线；因果 Transformer 不读取将来字符，每个字符完整 UTF-8 到达后才输出。可比较稠密 L1 与最大绝对值四路稀疏 L1，单帧总量1。它们是显式感官候选，不是现有映射的静默升级。训练句与短提示逐帧的总量、重叠、区别均保存。不同文本长度有不同总量，不能把跨长度效果全归于顺序。

从零输入 Transformer 使用同一独立语料学习字节序列，不含正式名字和对象的对应答案。先训练输入再阶段性固定，随后 Core 从经历学习；输出 Transformer 从真实活动过程学习表达。所谓共同发育首先指两种外设学习和 Core 可塑学习交替进行，不宣称可微端到端联合优化。

校准阶段每句12次连续重复（句间隔0.5秒），随后8次同项间隔2秒、8次4秒、8次8秒、8次16秒，最后共同复习；固定普通强度1。按校准材料的目标响应可区分性、相反对应的变化选择最多两种路线：保留原文本作为参照，即使不是赢家。未测到唤起也继续完成一个受限的从零表达训练，不能用新门槛无限推迟用户要求的尝试。正式输入/输出配置在接触正式结果前写入选择文件。

输出训练包含单对象/词、背景、不同输入幅度、复习前后和无新语言阶段；只使用校准名字的关系样本。原始完整活动仍保留；新增无已知通道碰撞的时序特征，将未登记通道放入独立剩余桶并计数，不能静默删掉背景或陌生节点。训练/验证按完整经历来源划分，不将相邻窗口随机拆分冒充泛化。

## 正式验证

三个接线/模型种子11、37、53，分别报告，不能称为三个不同生物学大脑。普通、相反对应、关闭可塑性、未教学四条件；保持背景、时间和候选动作规则一致。普通强度、上述先密后疏的重复。保持额外强刺激规则，但强度1不借用其额外巩固；额外易化仍关闭。

提示「名字」与「名字是」分别测试，从相同检查点的独立副本发出，强度0.5和1；不回写教学实例。教学结束、60秒、300秒检查保持，主观察提示后完整2秒过程，并列0–0.5、0.5–1、1–2秒，不事后择优某个窗口作为唯一结果。报告原始目标活动、普通与反转同时正确率、文字、空白/学习关闭差异。所有测试名称对应对输出器严格不可见；解码只读活动和当前句内已生成字节，不读问题、答案、上一个窗口文本或跨窗口缓存。

若出现可重复的经历差异，再做局部传导静默、匹配静默、持久状态/过程交换。至少先做同源正常/关闭传播的短期观察以定位内部传导对活动与文字的贡献；这种研究干预不得成为运行默认。不把全局清空当作唯一归因。

## 连续联想与独白

在每次教学后及延迟阶段记录连续窗口，不能把独立分叉拼成连续独白。无语言而有背景与全部外部输入停止分开；记录在途外部帧直到真正结束。使用 E43 已有840秒真实宿主/采集进程遥测的原始等时重放，无模型答案、不循环、不拉伸、不虚构当前实例实时遥测。本轮单个生命历程必须在录制覆盖范围内。若需更长只可另登记实测或模拟背景。

保留全部匿名活动，记录激活上升、再入、实际传导。输出可能是词、短句、乱码或空；全存，译文不回灌。用相同轨迹比较训练早期/后期输出器，以及完整/置零/交换/时间打乱特征，不能凭流畅或目标词出现宣布内部思考。对背景可译成熟词的问题，报告无教学背景的误译率，不靠删除原始活动纠正。

## 工程、预算与分支规则

原协议、旧状态及 Core 源码保持不变。新外设/读出/训练工具提供 Python 和 CLI；既有 API 可接收编译好的普通刺激，实验笔记、结果、轨迹与浏览器可读的连续译文存入新项目。观测器只做一次固定输入下的无干预验证，相关代码变化才重验；不重复大包哈希。

继承总计划1536实例/分支、4小时计算、6/8GiB证据预算及账户35%基线的+8/+12点限制。先记录校准和至少一组真实从零共同训练；明确缺口阻止后续组合/社会阶段时如实标为未启动，完成当前证据和报告后交用户讨论。新规则或更多校准选择必须在执行前附加登记；失败、资源停止与阴性区分。
