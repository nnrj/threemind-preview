# continuous-memory/3：自动保持与回收的实现验证

[English](report.en.md) · [事前范围](protocol.md) · [结果](results.json) · [计划与公式](../../../docs/zh/plans/memory-retention-v3.md)

2026-10-08。本批是内核工程与结构机制检查，没有训练感官外设或进行形色答题，也不是 E66 旧个体的继续。每个探针从独立空内核开始；原实验、旧个体与运行服务未改。

## 已交付与默认

新增独立身份 `threemind.continuous-memory/3`、状态 `/3` 和假设标识，Python 参考实现与 Rust 原生实现共用配置/状态契约。未指定版本的新建默认采用 /3；保存的项目默认、旧意识、显式旧配置及历史协议保留原身份。精确旧版行为应选择旧 kernel_id；新版 `legacy-stability` 只是公式对照。

用户明确选择统一支持度自动模式，故 `node_retention_mode=automatic` 为默认。支持度 S 表示局部使用形成的保留余量，其半衰期 H_node 记录保持尺度；没有另增语义重要性分数。实际活动越充分，保持通常越久。无活动、无活跃入出边且 S<0.006 才回收。自动模式不读取手动阈值/等待参数。

手动实验保留：`prune_support`（节点回收支持度阈值）>0 时优先使用旧阈值和触达年龄；=0 时使用正值 `dead_node_retention_us`（死节点保持时间，默认 80 秒）。真实触达重置孤立等待，重新连接取消等待。`retain_nodes=false`、`dormant_traces_enabled=false`、`revival_enabled=false`；休眠关闭联动关闭复活，重开不自动恢复复活。UI/API/CLI 使用同一配置，模式下无效参数在界面禁用。

连接权重及自动节点支持度采用可学习的半衰期。初版 Hmin=30 秒、Hmax=30 天；闲置每模拟秒 H 减少 0.125 秒；有效活动按时间剂量学习 H 和权重。不存在默认永久固化标志或旧稳定度额外加分。强刺激产生局部显著性和可恢复疲劳；可选能量账本开启时另记实际消耗。所有时间都是模拟时间，没有人类时间换算。

## 结构测量

按[固定脚本](verify.py)执行。保持探针显式关闭传播和抑制，以分开被动遗忘与循环自强化；两通道幅度 0.8，重复组每 250 ms 输入一次、持续 120 秒。无外围模型，因此以下均不代表答题正确率。

| 条件 | 0.1 秒平均边权重 | 30 秒 | 300 秒 | 1,800 秒 |
| --- | ---: | ---: | ---: | ---: |
| /2 单次普通 | 0.08417 | 0.04462 | 无边 | 无边 |
| /3 单次普通 | 0.08534 | 0.05304 | 无边 | 无边 |
| /2 单次强度 4 | 0.17287 | 0.11420 | 无边 | 无边 |
| /3 单次强度 4 | 0.22050 | 0.15389 | 无边 | 无边 |
| /2 重复 | 1.00000 | 0.98477 | 0.21198 | 无边 |
| /3 重复 | 0.99993 | 0.99948 | 0.99533 | 0.97256 |

新版重复组结束时边 H 约 12.45 小时；30 秒后因末次输入余下活动继续强化至约 12.52 小时，之后回落。节点 H 约 6.09 天。旧版重复组 1,800 秒时边已消失但支持度仍为 1；新版将支持度保持改为有限衰减。单次强刺激产生增益和疲劳，却没有在本探针中直接达到长期保持，此结果原样保留。疲劳由 0.1 秒时 2.9406 降至 30 秒时 0.00744；独立测试验证开启能量账本时消耗也增加。

另用有明确人工初值的仪器夹具验证：H=3,600 秒、权重 0.5 时，无强化 300 秒约保留 94.4%；长期闲置 H 会回到 30 秒。这是公式和实现核对，不能当作自然教学成果。

## 背景、复活和适应边界

背景每两秒输入一对幅度 0.3 的通道，共 120 秒，再停止 300 秒。固定组 32 个通道；扩展组逐次用新通道，累计 120 个。限制 128 节点、512 条活跃加休眠连接。本批没有触及容量上限。

| 新版条件 | 固定背景结束：节点/活跃边/休眠 | 扩展背景结束：节点/活跃边/休眠 | 停输入 300 秒 |
| --- | --- | --- | --- |
| 自动，休眠关闭 | 32 / 36 / 0 | 96 / 70 / 0 | 均为 0 |
| 手动，休眠关闭 | 32 / 36 / 0 | 80 / 70 / 0 | 均为 0 |
| 自动，仅休眠 | 32 / 36 / 28 | 96 / 70 / 26 | 均为 0 |
| 自动，休眠与复活 | 32 / 36 / 28 | 96 / 70 / 26 | 均为 0 |

本背景未触发复活；人工历史接触夹具另证 0.04 弱边能实际向目标传导，且无历史接触不造边。同一旧接触重新学习不因自己的休眠记录占容量而受阻。固定背景不是无限时长噪声测试，扩展组也不代表无限通道；频繁重复的无用背景仍可能被保留，自动模式并不懂语义垃圾。

新配对探针先教 1+2 二十秒，再教 1+3 二十秒。结束时 /3 两对权重约 0.90319、0.97620；300 秒后 0.23625、0.25831。新关系可学，旧关系也仍存在。这不是相反答案的行为反转或无干扰保证。

本机单次执行中，固定背景 /2 用时约 0.044 秒，/3 自动约 0.395 秒；扩展背景约 0.090 对 0.622 秒。样本小、未隔离宿主负载，不能外推速度比，但新增保持状态与逐间隔计算确有成本；大图、持续背景和完整外设负载需后续测量。根须式几何生长未实现，已列后续方向。
