# Third batch preregistration: formation, retention and expression of order information

Four blocks, 100121–100124; ordinary parameters and anonymous mappings. Facilitation is 0 or 1 second from creation. Teach A→B or B→A, with either single-channel events or paired AX/BX frames containing a common reference. Each element has value 1 and each frame intensity 0.4. The reference is explicit experimental material, not evidence that the model invented a clock. Opposite orders have equal input dose and duration. Reference-present and reference-absent conditions have different total dose, so their difference identifies the material as a whole, not an isolated dose-independent reference effect.

AB/BA therefore share their final input but may retain different prior internal states. Maintenance K=0.2 every 0.5 seconds is unchanged. X is new in reference-absent training; this tests the expression boundary without prior reference connections, not an equal-dose reference control.

Require corresponding opposite signs in both orders for bidirectional expression; one responsive direction is insufficient. Report every block, interval and delay at thresholds 1e-9 and 1e-6. This tests input-history dependence, not automatically semantic time, causal reasoning or language understanding.
