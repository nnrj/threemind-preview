# E63：把纠错对准实际作答活动（条件性补充）

2026-10-08，北京时间；原定纠错复习正在执行，尚未看到其正式测试结果，也未执行本补充。

首轮32题仅对3题。代码核查发现一个教学/测试差别：原课程先让意识听到“这是红色”等正确陈述，再提问并监督表达器；独立测试先前没有正确陈述。因此已教表达器可能更擅长翻译刚听过答案后的活动，而没有学好独立看物、听问时的活动。本条是假说，不是由3/32单独证明的根因。

先完成既定纠错和实际测试。若仍未可靠回答，且预算允许，再让纠错后的**同一个完整个体**继续以下课程，不更换/重置外设、不回滚权重、不改Core：

1. 每次放置一个基础物体，先正常提问2秒，保存它真实的回答与整个活动过程。
2. 教师使用这个**答案公布前**的原始活动窗口，给同一表达器8次现有训练更新；使用现有历史复习缓存，没有把正确标签附加到推理输入。
3. 然后教师正常说出正确陈述1.5秒，经原文字感官进入Core。
4. 八个基础知识交错5轮，分别在第2、3、5轮前等待2、6、18秒，背景始终持续。共40次练习，166模拟秒。不教新组合答案。
5. 仍用已登记的位移/新题序32题测试（与纠错后测试完全相同）。主结果仍为每题末时实际选词，所有错误保留；不改变标准、不挑中途对的瞬间。其后按效果和预算完成固定外设干预。

本补充只改变教师反馈对应哪段已经真实发生的活动，不改变个体、控制路径、外设结构或感官映射。若结果提高，首先说明这种反馈方法改善了整体回答；没有等时教学对照时，不能把增益全部归为反馈时刻而排除额外教学量。若仍失败，不无界加训，保留为后续线索。

English: This conditional supplement was registered before the original corrective course finished. The original supervision follows a spoken correct statement, unlike answer-free evaluation. If correction still fails and budgets permit, continue the same complete individual: ask first, retain the raw answering window, apply eight existing supervised updates to its own peripheral, then speak the correct statement. Five interleaved rounds of eight basics with2/6/18-second gaps total166 simulated seconds. No new-combination labels, changed scores, architecture, mappings or Core rules. Test the same32 changed-position/order questions. Any improvement is a whole-system result; without equal-duration teaching control it cannot be uniquely attributed to feedback timing rather than additional teaching.
