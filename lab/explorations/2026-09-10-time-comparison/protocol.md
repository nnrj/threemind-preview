# 第一阶段：时间与活动节律对照（不改内核）

状态：计算前固定，2026-09-10。边界：只使用当前公开接口与 Git `97d8592` 原样加载的统一旧 V3；不修改 Core、感官、读出器，不建立改变传播调度的候选内核。

## 待检问题

1. 相同模型输入／推进次数下，宿主执行快慢、调用批次、观察频度、暂停及保存恢复是否改变结果？这检验计算与墙钟的关系，不测量主观体验。
2. 同一环境周期收到多帧时，旧 V3 的 tick 与当前模拟时间分别如何变化？使用一个单通道脉冲，另加四个同通道零强度帧作调度诊断；不把零强度帧当作无操作的先验假设。
3. 重复短句后停止新输入，旧版与当前是否保留自持活动、周期变化、节点间差异？两者还有传播幅度、目标响应、巩固及生命周期差异，不能把整体差别单独归因于传播时钟。

## 固定输入与比较边界

- 两个编码种子：41701、41702；使用当前默认 `text-sensor/2`、匿名分布式、NFKC、192 通道。原文、全角标点、说话人不改。将同一既有感官输出的通道、幅度、强度直接交给两套内核公开输入接口；这是共同仪器下的内核比较，不是复现旧应用所有适配器。
- 配对组：`甲是松子。`、`乙是铃铛。`，每句连续20次，整组2轮，共80次。
- 对话组：前轮已固定的十句（包括完整说话人、自述、问答），每句连续20次，1轮，共200次；不将这个较短诊断解释为充分语言训练。
- 各句均经感官确认为一帧。首帧在第1环境周期；随后起点间隔8周期。横轴按旧默认每周期0.1秒换算，仅为比较坐标，不宣称旧内核拥有精确模拟秒。当前对应100,000微秒首帧、800,000微秒间隔。两侧默认参数不调优，外部背景、能量和空间实验均不接入。
- 每组教学结束留完整状态。由该状态分别继续12秒／120周期：①不再输入；②在下一周期输入`甲`。副本不写回来源。不清空激活、不冻结学习、不人为补连边。
- 全部节点在训练期间每100毫秒／每旧tick记一次，后续当前每10毫秒、旧版每完整tick记一次。旧tick内部没有现成独立时间坐标，不插值制造旧子周期证据。保存激活、抑制、身份／通道，末态完整结构及参数。
- 当前线索副本额外接现有默认时序读出器，保留完整窗口、分类、窗末强度排名（并列保留），作为观察补充。旧版不套用当前收敛分类；主问题是节律，不进行语言回答准确率推断。

## 实现验证

- 旧模块直接执行 `git show` 的原始字节；记录 SHA-256，不改旧公式或调度。当前记录 Python/Rust 源码和原生二进制哈希，前后核对。
- 宿主控制采用固定匿名输入：当前实时、加速、无界；旧版手动推进加不同宿主等待。比较各自模型状态，不跨版本要求字节相等。
- 当前比较大批次、小批次和细观察推进，旧版比较 `step(ticks=N)` 与逐次推进。暂停期间不给时间／步数，不关闭输入源。验证保存恢复的继续结果；不以变化的存档时间或信封UUID判动力学不同。
- 阈值、衰减时间、传播周期均用默认值。报告无输入尾段的全零时间、持续活动范围、节点间极差、同相位跨周期变化、终态排序。样本量只有两个编码，不做泛化显著性宣传。

## 资源与停止条件

- 单个子进程顺序运行，每个≤180秒；累计计算≤720秒；父进程超时终止自己的子进程，保留部分证据，不无限重试。
- 子进程RSS≤1GiB；主机可用内存≥3GiB；D/E盘各保留≥15GiB。最多256节点、50,000连接；达到边界停止实验，不把限制加入意识动力学。
- 新增数据库增长＋本目录及本轮`.work`证据预算512MiB；400MiB停止新增计算，留112MiB整理报告。完整证据压缩流写，不逐步重复保存整个模型。
- 账号额度基线已用73%；达到77%停止新增实验，最多到78%完成整理（本阶段最多5个百分点；账号读数共享且可能滞后）。每个批次检查，不承诺精确token计量。
- 新建独立研究项目，先写实验笔记，结束写记录／报告和原始附件；旧实验仅核对小型元数据摘要。不开全局worker、不清数据，不自动继续旧意识。
- 若原版无法不改动地运行，或下一结论必须依赖改变传播调度的实验版本，则停在该边界，说明最低限度的下一步。不能为了证明某个解释临时改公式。
