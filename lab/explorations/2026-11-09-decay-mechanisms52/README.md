## Initial preparation record

2026-11-09. The user has authorized a distinct /5.2 candidate with exponential,
inverse-logarithmic and power-law decay, crossed with relaxation on/off. R44 and
R45 remain unchanged and must finish first. No /5.2 kernel is installed or run yet.

`decay_reference.py` is a mathematical reference only. It tracks the age of each
accepted reinforcement contribution, preserves old ages, and integrates the
existing linear relaxation of the shared decay timescale. Its ten isolated
tests cover half-value normalization, batching invariance, cap behavior,
proportional damage, inverse time conversion, long-tail crossings, invalid
parameters, very short steps at long timescales, and recent learning after an
extremely long history. Elapsed ages are stored separately to avoid cancellation
between a large cumulative age and a recent birth age.

The equations, integration checks and still-unfrozen behavioral design are in
[design-notes.zh.md](design-notes.zh.md). The bilingual authorization and scope
are in [the project plan](../../../docs/en/plans/decay-mechanisms-v52.md).

These files contain no experimental outcome and do not establish a replacement
default. Completed /5.1 originals, installed implementation and frozen study
dependencies must remain intact.
