# E51：钟面和句式可读，刚刚发生的事仍未可靠说出

2026-10-05。[English](report.en.md) · [执行登记与工具纠错](design.zh.md) · [逐项数据](results.json) · [时间教学的讨论](../../../docs/zh/plans/clock-grounded-recollection.md)

**本轮成功接入了可感知的时钟，也能按问法输出“现在／刚刚”的句式；但还不能正确复述刚才看到的物体。与此同时，不同的前情确实留下了不同的当前活动，学习还放大了这种影响。**因此，“没有留下任何前情”和“已经能复述经历”都不符合本轮事实。

## 实際完成的教学

四物体 MuJoCo 场景保留；外部指针每四模拟秒旋转一圈，四个方向光感受器每250ms取样。Core 接收的是匿名光强测量，不是时间答案、物体身份或“过去／现在”标签。教师示范钟面格数，并分时说出“现在看见了红球。”“刚刚看见什么？”“刚刚看见了红球。”等句式。感官编码保持原版；本批语言帧相隔20ms，实际经历时间过程。

12种物体先后组合，每种完整示范初次连续10遍，随后两轮更稀疏复习，共144轮、652模拟秒。这里连续重复的是完整的先后及问答示范，不能将其描述为把其中一句脱离场景连续输入。学习来源与无学习副本都收到相同课程、正常抑制／遗忘／背景；后者只关闭plasticity。背景是同一物理遥测记录的重放。探针没有教师答案输入。

每次检验先后观察两个物体，然后问“现在看见什么？”或“刚刚看见什么？”。视觉是有限曝光：每个物体五帧、总量10、普通强度1，而不是持续观看物体到回答结束；当前物体仍在模拟世界中。这个条件测的是**短暂观察后的复述**，不代表完整生活环境中的持续视觉交流。钟表在提问及观察期间继续运行。

外设用32条经历问答和4条钟面观察监督，从头训练。四种有向物体组合不给外设校准；Core自身教学已见过所有12种组合。因此留出检验是新观察片段的复述，不是从未教过的逻辑规则推广。阅读的是局部活动六字段和17个实际时刻，未给全图静态历史，没有无提示相减或按题缩放。

## 结果

| 检验 | 正确／总数 | 判定 |
| --- | --- | --- |
| 改变格内指针角度的钟面命名 | 4/4 | 这个小范围的钟面词语可输出；不足以证明Core理解流逝时间 |
| 正常学习组“现在”句式前缀 | 12/12 | 能按问法选句式，可能利用问题本身；不单独算时间概念 |
| 正常学习组“刚刚”句式前缀 | 12/12 | 同上 |
| 正常学习组当前物体完整回答 | 3/12 | 内容不可靠 |
| 正常学习组刚刚物体完整回答 | 2/12 | 未达到复述目标 |
| 外设未校准的4种顺序：当前／刚刚 | 1/4、0/4 | 未表现出可靠推广 |
| 无学习组：当前完整回答 | 6/12 | 该对照不是“关闭学习一定更差”；不能只挑正面组解释 |
| 无学习组：刚刚完整回答／只算物体名 | 0/12、3/12 | 多数仍使用“现在”句式；物体与时间词必须分开计分 |

固定钟、改变钟起点、加倍钟速后，每种条件“现在”与“刚刚”各1/4正确；正常留出本来为1/4、0/4。小样本且主表达失败，不能把增加的一道题说成时间理解提升，也不能据此说时钟无用。

具体误答保留：先红球、后蓝盒，问“现在”，回答“现在看见了红球。”；问“刚刚”，回答“刚刚看见了绿柱。”。这不是只有措辞不够漂亮，而是所指的物体经常错。宽松到只检查物体名称，也不能解决正常组的失败。

## 前情没有全部消失，但没有被可靠译出

额外做了只读仪器分析：保持当前物体、问题、钟面和背景相同，只换此前物体，形成12组配对；无学习副本同样12组。**24/24组的实际17帧表达输入都不同。**这一步只计算分析指标，没有把差值送入表达器或用于改写输出。

学习组局部字段的最大绝对差为 **0.000496～0.005751**，无学习组为 **0.00000436～0.000345**。在这一个来源、这12组比较中，学习组的前情影响幅度均超过无学习组的范围。这是一个值得保留的积极现象：**可塑学习增强了先前经历对后续活动的影响，但增强并没有自动变成正确的语言。**幅度不是语义正确率，也不是新的意识判据。更广来源和长期保持尚未做。

密集轨迹的活动差异也存在；学习组中，局部选择没有丢掉任何有差异的字段条目。某一例存储136节点、参与133节点，说明“局部活动”在该条件下仍可能分布很广，不能强行只保留几个节点来获得想要的局部画面。无学习组有少数差异被局部规则排除，但剩余及实际采样输入仍有差异。完整分析在证据包的 `observation-audit.json` 与 `sampled-observation-audit.json`。

## 为什么停在这里

2500步结束，表达器对**自己的36条监督样本只答对12条**，低于执行前登记的33条通过线；因而停止第二来源和更长时间跨度。仅从它的错答，无法确定这些活动差异能否由更合适的工具译出，更不能据此断言Core没有时间相关记忆。这次没有无限增加教学、改Core公式或临时换分类器来宣称成功。

“一小时前／昨天”尚未教学或检验。下一步应先让外设可靠读出已教的短时经历：定位它是否偏向当前问题／钟表而忽略较弱的经历差异；分别检验持续视觉与短暂曝光的用途；再做不同时间尺度的参照和语句教学。内部数值处理可以研究，但原始响应必须保留，不能重新引入无提示相减来制造答案。若表达改善，再做选择性联想屏蔽／恢复来定位内容依据。本轮未以未过关工具继续发表小时、日尺度结论。

## 工程及资源

外部时钟工具提供 Python API；时间起点／速度、相位、增益均显式配置。单位测试验证周期、移位、速度对应；4个时钟通道与20个视觉、63个本轮文本通道不碰撞。首个单帧视觉总量10因通道上限被拒绝，未递送；按已登记纠错拆成五帧普通输入，来源教学及失败目录保留，没有偷偷钳制或改强刺激值。

完成 **114个来源／探针、1个研究表达器**，累计模拟与训练约 **697秒（11.6分钟）**；归档前约 **90MiB**。另有不推进Core的字段分析。账户读数51%→52%，共享账户变化保守计入。最终归档与数据库占用见 `delivery.json`。中英文报告、原话、输入、状态、模型和失败记录保存到独立项目；Core、默认值及旧实验未改。
