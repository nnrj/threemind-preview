Capture, shell delay/work, shape, environmental measurements and body energy are exterior apparatus parameters.

The E30 scripts use a dedicated registered database project and fixed `.work/ocean-causality-20261003` paths. Do not rerun them over existing evidence. Create a new study registration for a new batch. `probe.py` uses saved states and actual input replay, `birth_probe.py` provides equal finite starting energy to structural-history comparisons, `closed_loop.py` retains the awake physical world for intervention forks. `ocean_causality.py` contains the reusable copy-only operations. These are explicit research interventions, not normal runtime restrictions.

Recorded input includes raw physical values, anonymous encoded channels, delivery time, actual actions and energy provision. The browser replay uses measured per-second body/food states; it neither simulates nor changes consciousness. Select a body to inspect shell, shape, feeding, captured prey, ancestry and reserves.
