# R51o: which internal states carry event order?

14 November 2026. Preregistered replication of the E21 state-exchange component under comprehensive revalidation plan v2. R51n established that kernel 6.1 can recall order after task activation subsides. This batch directly changes learned internal states to test whether connection weights carry the response direction. Production Core and defaults remain unchanged.

## Targets, expectations and decisions

The primary target is that exchanging only base connection weights between opposite teaching histories transfers the recipient's order-dependent response to the donor direction while other states are retained. All 16 references across four anonymous material blocks, two facilitation settings and two teaching orders must pass. Under the same X cue, the absolute net A/B activation-integral advantage must exceed 1e−6 activation·seconds, oppose the recipient's original advantage and match the donor direction. Passing all 16 confirms the primary target.

The second target tests the historical factorial pattern: all 128 cued conditions that include weight exchange follow the donor, while all 128 conditions without weight exchange retain the recipient direction. Each has a matched no-cue control. If rapid states or other history variables alter the effect, their contributions will be reported across the full factorial design. A zero-change exchange cannot establish that a mechanism is irrelevant.

A failed primary target is an adverse difference from the historical order-carrier result and pauses the campaign after evidence delivery. Invalid source states, time alignment or sham equivalence constitute apparatus failure, requiring apparatus correction. Changes in the secondary factorial pattern are judged separately and do not revoke a passed primary target. Connection selection, cue dose, observation window and default thresholds will not be adjusted from outcomes.

## References, continuity and exchange scope

The design retains E21's four material blocks, 100121–100124, facilitation time constants of 0/1 second and AX-before-BX versus BX-before-AX teaching with a 50-ms event interval. Sixteen complete teaching endpoints come from delivered R51n. Registered research copies retain observer and input-bus state, wait 30 internal seconds under the original schedule and save complete boundaries. Each Core hash must match its R51n pre-cue reference. Ordinary teaching references remain intact. Each waiting reference provides 16 exchange combinations by two cue conditions, giving 512 single-test diagnostic copies. The independent material count remains four.

Donor and recipient share the same configuration, simulated time, anonymous channels and directed topology but opposite teaching histories. On research copies, the existing same-time configuration API first settles lazily updated quantities to the current clock without changing configuration, advancing time or clearing events. All changes from this explicit operation are recorded. Calibration and formal sham conditions must match the original process readout to within 1e−12.

Changed weights or decay ages require recalculating the affected local deletion deadlines using existing 6.1 equations. Rapid-state exchange also maintains corresponding emission schedules and the active-node index. These derived changes are recorded separately. Source snapshots must have empty in-flight queues and no pending novelty, and source files remain read-only. Any legacy field serialized but inactive under this configuration is reported by its actual values and changes rather than treated as an effective intervention because of its name.

## Inputs and measurement

The 5,376 cue and maintenance frames in the 512 historical conditions have been matched for codes, dose, enqueue order and timing. The cue is X=0.5, with a no-cue comparison; independent K=0.2 inputs every 0.5 second maintain activity. Each copy receives one five-second probe, recording activation, inhibition, direct and associative activity every 20 ms. The primary measure is the difference between A and B activation integrals after subtracting each corresponding no-cue integral. The passive readout is fixed and does not learn.

Calibration seed 100198 is separate from the formal materials. Four taught references first test trajectory equivalence before and after same-time settlement. All 64 exchange states then undergo native save/restore checks, together with 64 exact self-exchanges. Evidence retains original references, settled and exchanged states, input receipts, observer state and trajectories. The formal read-only audit covers 1,856 states, 6,336 inputs, 528 stages and 256 exchanges. The additional 960 inputs belong to the 16 registered waiting copies. Integrals are independently checked with high-precision arithmetic.

## Budget, stopping and delivery

Scientific hosts run serially. One-second checks retain 5/4/5/25 GiB of commit headroom, physical RAM, C and E space; private memory is capped at 1 GiB, total runtime at two hours and each material-by-facilitation unit at ten minutes. A complete unit includes both histories, waiting references and 64 probes. Resource pauses occur only at these boundaries. A newly dead host with an in-flight marker is preserved and reported.

The 512 historical conditions occupy 48,329,185 logical bytes. Each new unit is estimated at 1.5 times its corresponding historical storage measurement. Reaching twice the historical value or exceeding the estimate by 50% stops execution for cost review. Originals, archive and API readback are each capped at 512 MiB, with 128 MiB for analysis and 25 GiB additionally reserved. The lossless file compression validated in R51n preserves all state contents. Actual space and running processes are checked before launch.

The bilingual report will separately answer the weight-only and factorial questions. Originals must be read back through the research API with pending=0 before closure. Coverage and bilingual histories will be updated, with Classical Chinese adaptations at meaningful phases and a local Git commit without pushing. E21 timing, repetition and sensory-formation conditions, and E22 dose-matched and additional exchange studies, remain separate parts of the original plan.
