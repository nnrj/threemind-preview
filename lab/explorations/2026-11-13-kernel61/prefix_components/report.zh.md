# 前缀区分的作用链：传导强化、稳定度与学习后的权重

2026-11-14 · R51t6 · 两个交换教材区组，70个科学阶段。

**本批定位出两个关键作用：实际联想传导对基础权重的强化，以及稳定度对权重遗忘的减缓。分别去掉任一作用，系统就失去按前缀区分结尾的能力。教学后单独交换权重，还能让成功和失败双向转换。**

另一个结果修正了我们对新颖性的解释：**即时新颖性的额外加成不是本批成功的必要条件。关闭加成后，完整状态和活动过程都与即时参照一致；到达窗口方式反而改变了权重，使系统偏向同一个结尾。** 因此，本题中即时方式的优势体现为避免窗口方式造成的不利改变，不能解释成“即时增强更强，所以记得更好”。

## 目的、预期和实验安排

R51t5已经在真实3.1和5.1中找到成功组合：旧式连接保持加即时新颖性。本批进一步拆分组合中的具体作用，预先要求区分三件事：新颖性增加的是什么，旧保持如何保护所学关系，以及学后的权重是否承担成功与失败的差别。预期至少一个分量的去除会破坏恢复，权重交换能够传递相应表现。本批实现了这两个预定目标。

本批是基于冻结5.1规则的隔离研究实现，身份为 `threemind.research-prefix-components/1`，不是生产5.1、6.1或6.2。九个出生配置各接受两个教材，每个教材包括一次教学及AB、DB两次研究副本诊断，共54阶段；随后增加16个预先登记的教学后干预阶段。研究实现只复制并拆分了建边、发送和连接更新三个局部方法。源码核验确认只有已声明的分量发生变化；参照与真实5.1原生实现通过完整状态校准。

一套教材教授A-B-C与D-B-E，另一套交换C和E。教学212.2内部秒；测试副本从完整教学末态继续，等待1秒后输入A或D，再隔1秒输入共同的B，观察15秒。两种前缀都应唤起各自所教的结尾。固定的过程记录包括激活、抑制、直接与联想活动，没有可训练读出器。

沿用旧主指标：正确结尾的激活峰值减去另一结尾的峰值须大于1×10⁻⁶；同一教材的两个方向均通过，才算一个区组通过。两个区组是交换教材的重复，不是70个独立个体。所有阶段、干预和判据均在运行前登记，没有按中途成绩添加条件。

## 哪些作用重要

| 条件 | 正确区分的教材区组 | 实验回答 |
| --- | ---: | --- |
| 旧保持＋即时新颖性参照 | 2/2 | 重现R51t5的恢复 |
| 改用到达窗口新颖性 | 0/2 | 恢复再次丢失 |
| 即时新颖性加成全部关闭 | 2/2 | 此额外加成不是成功所必需 |
| 即时新颖性只增加权重 | 2/2 | 与参照相同 |
| 即时新颖性只增加稳定度 | 2/2 | 与参照相同 |
| 去掉使用当期免于衰减 | 2/2 | 这项保护不是本题成功所必需 |
| 去掉稳定度减慢权重遗忘 | **0/2** | **稳定度对遗忘的作用是本组合的必要因素** |
| 去掉近期传导记录减慢稳定度回落 | 2/2 | 这项保护不是本题成功所必需 |
| 去掉实际传导对基础权重的强化 | **0/2** | **实际传导的权重强化是必要因素** |

这里的“稳定度”是旧保持规则中一个0至1的连接状态。共同刺激和实际传导能够增加它；长期不使用时它会下降。稳定度越高，权重遗忘越慢。“近期传导记录”是旧字段 `eligibility`，它还能暂时减缓稳定度下降。这两个量有不同作用。

默认旧规则每100毫秒检查连接。对于该周期没有实际传导的连接，权重乘以 `1−0.0023×(1−稳定度)`；使用当期则免于这次权重衰减。去掉稳定度保护的条件保留其他过程，只让这项倍率不再随稳定度改变。其AB、DB正确方向差值分别变为−0.008243803和+0.008242222：系统有响应，但偏向同一个结尾。去掉实际传导的权重强化时，差值分别为+0.000005919和−0.000005919，也不能同时区分两个方向。

参照的两个正确方向差值为0.000978373和0.002735434。去掉使用当期豁免后，仍为0.000793306和0.002890887；去掉近期记录的保护后，仍为0.000970360和0.002742758。这些是各自去掉一项的结果，不能据此声称同时去掉两项也已经验证。

## 学后的权重承担了什么

接下来的研究副本只替换全部连接的基础权重。节点活动、抑制、短时资源、稳定度、近期记录、队列和观察历史保留受体原值；拓扑、编码和权重时刻逐项核对一致。

| 教学后干预 | 正确区分的区组 | AB / DB正确方向差值 |
| --- | ---: | --- |
| 成功父体换入窗口失败组的权重 | **0/2** | +0.000996508 / −0.000996605 |
| 窗口失败父体换入成功组的权重 | **2/2** | +0.000978396 / +0.002735439 |
| 成功父体在诊断期关闭既有连接强化 | 2/2 | +0.000978193 / +0.002734240 |
| 成功父体在诊断期关闭权重遗忘 | 2/2 | +0.000993013 / +0.002721190 |

**权重交换让成功与失败双向转换，确认教学形成的权重差异足以改变本批前缀表现。** 正确关系能在测试期不再强化既有连接时表达；它不是必须在回答过程中重新学出来的。前缀仍通过当前活动进入网络，保存下来的权重决定这些活动怎样影响共同刺激B之后的结尾响应。

窗口组的差别不是简单的连接整体更弱。例如，第一个教材中B→C权重由参照的0.594162变成0.603411，B→E由0.576705变成0.585630。增加某些权重并没有提高关系区分。双向交换给出的因果证据比单独比较这些数值更直接。

## 新颖性结论的进一步明确

关闭即时加成、只保留它对权重的加成、只保留它对稳定度的加成，三组分别与参照比较两个教材的教学和两种测试：18/18份科学终态完全一致，18/18段节点过程记录完全一致。这里排除了身份、配置及执行计数等非科学字段，其他状态保持逐项比较。

**这项教材上的成功不依赖即时加成；窗口方式引入的学习后权重差异则破坏了成功。** 本批因此否定“必须依靠即时额外增强才能恢复”的解释。该结论与当年的窗口校准可以同时成立：窗口机制曾增强另一教材的短暂响应，但它没有因此成为所有任务的最佳机制。[原始授权与当时证据核查](novelty-authorization.zh.md)记录了这次变化的提出者、事前授权和验证范围。

本批没有分别拆开窗口方式自身的权重加成和稳定度加成，因此不把窗口的直接加权、后续保持和学习反馈分别声称为已单独证实的破坏来源。它已完成的定位是：窗口规则造成的权重结果能转移失败；旧保持的稳定度作用和实际传导强化分别是当前成功组合的必要因素。这一新问题如继续研究，须另定比较，不改本批目标或评分。

## 对ThreeMind及6.2的意义

本批给出了可操作的机制解释：经历通过实际传导强化连接，稳定度让连接具有不同的遗忘速度，从而保留能供前缀选择的权重关系。额外增强若改变了这些关系，也会损害已有能力。恢复方向应围绕这些已定位的作用，而不是只追求更长保持或更大激活。

建议保留即时与窗口两种既有新颖性选项，把即时方式作为6.2优先评估的默认候选。旧式连接保持值得作为可选参照，尤其应保留“经历影响遗忘速度”的候选作用。现有6.1的固定寻址、信号传递和单年龄衰减并未因本批而修改，6.2默认选择需在其实际组合中检验这项前缀恢复以及受影响的既有能力。

旧稳定度的增长、回落与现有时间尺度H的增长、回落是不同实现。旧式保持不用H计算权重衰减，直接开启H选项不会自动得到一套有明确定义的旧规则。建议旧规则按自己的增长和回落运行，并保留其独立控制；不要未经定义就再叠加H规则。[6.2评估](evaluation.zh.md)另列具体取舍及惯性感官预设。
