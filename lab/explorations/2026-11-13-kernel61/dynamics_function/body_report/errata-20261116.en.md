# Correction, 16 November 2026: online dose matching retains inertial sensation

While preparing the 6.3 replication, we checked R51t3's frozen executor and delivered inputs and found an incorrect description of the online dose-matched condition in the revised report.

The implemented method retains the full sensory input and multiplies every component in a frame by the joint-only total divided by the full-sensory total. It therefore reduces total stimulus quantity to the joint-only level while **retaining inertial information**. A zero total leaves the original empty input unchanged. The frozen protocol and the `sensory` function in `body.py` both specify this method.

The description that remaining channels were increased to the full-sensory total is incorrect. The table row described as removal of inertial sensation with dose matching should read “full sensation scaled to the joint-only total.” This is distinct from the condition that actually removes inertial channels.

This correction changes the method description and table label. The 296 stages, delivered inputs, complete states, body trajectories, numerical results, same-teaching-state response reversal, and failure to meet the registered posture-control benefit remain unchanged. Interpretation of sensory content and total stimulus quantity must use the actual control described above. Historical reports and the original package are preserved; this correction is appended as a separate document in the existing research record.

Evidence: the executor hash matches `closed-body61-v1/frozen.json`; all 400 closed-loop sensory frames in `cases/0031-body/inputs.json.xz` contain inertial channels. The new replication follows the original protocol and execution, rather than turning the mistaken prose into a different control condition.
