# 即时新颖性与旧式连接保持共同恢复前缀区分

2026-11-14 · R51t5 · 两个交换教材区组；42个新阶段，30个已完成阶段只读复用。

## 科学结论

**前缀区分在真实3.1和5.1内核中得到恢复：即时新颖性增强与旧式连接保持必须在本次配置比较中共同启用。** 单独改变任一项，两个教材区组都失败；两项合用，两个版本均在2/2区组同时正确区分A-B和D-B。再把节点保持改为手动方式，成绩和响应差值不变。

这项结果找到了此前单项比较遗漏的规则组合。新颖性增强时机和连接保持方式共同影响了前缀如何改变后续响应。恢复持续活动与恢复前缀区分也有不同条件：旧式连接保持此前已能恢复持续活动，但本批还需要即时新颖性，才能恢复两个前缀各自的结尾优势。

## 问题、预期和方法

旧R51t1发现，把第二版内核的新颖性增强改回即时方式，可以恢复第一版的前缀区分；3.1和5.1采用旧式连接保持后，可以恢复持续活动，却仍不能区分前缀。R51t2又发现，6.1中前缀A和D造成的活动差异尚存，后续结尾却保持同一偏好。因此，本批检验两次历史规则变化是否需要一起比较。

实验使用真实的3.1和5.1实现，各比较两种新颖性时机和三种保持配置。即时方式在该版本规定的直接输入处理过程中计算增强；到达时间窗方式等待规定的后续到达窗口再计算。旧式连接保持采用历史版本已有的`legacy-stability`选项，以稳定度调节权重衰减，并保留实际传导当期免于衰减的规则；第三种配置还把节点保持设为该版本已有的手动方式。所有配置从出生起实施，教学材料、剂量和时序相同。

一套教材教授A-B-C与D-B-E，另一套交换C和E。每次教学持续212.2内部秒，保留原固定背景输入。教学后的完整父体分别建立AB和DB诊断副本；等待1秒后输入首刺激，隔1秒输入共同刺激B，再观察15秒。内核、输入总线、随机状态和观察历史全部保留。过程记录包括激活、抑制、直接与联想活动。

沿用原判据：所教结尾的激活峰值减去另一结尾的峰值，必须大于1×10⁻⁶；同一区组的AB、DB都通过才算恢复。全部矩阵为12种配置、72个阶段。其中5种配置的30个阶段已有完整证据，本批只读取；另7种配置新增42阶段。统计材料为两个交换教材区组，阶段和副本不另算独立样本。

## 结果

| 保持方式 | 新颖性时机 | 3.1恢复区组 | 5.1恢复区组 |
| --- | --- | ---: | ---: |
| 该版本原默认 | 到达时间窗 | 0/2 | 0/2 |
| 该版本原默认 | 即时 | 0/2 | 0/2 |
| 旧式连接保持 | 到达时间窗 | 0/2 | 0/2 |
| 旧式连接保持 | 即时 | **2/2** | **2/2** |
| 旧式连接保持＋手动节点保持 | 到达时间窗 | 0/2 | 0/2 |
| 旧式连接保持＋手动节点保持 | 即时 | **2/2** | **2/2** |

成功组合中，3.1的AB、DB正确方向差值分别为0.000977870和0.002735633；5.1分别为0.000978373和0.002735434。交换教材后，两种条件仍各自偏向所教结尾。手动节点保持没有改变这些数值。

相反，单独使用即时新颖性时，3.1的AB、DB差值约为−0.007445、+0.007444；单独使用旧式连接保持时，约为+0.000994、−0.000994。两种单项改动各有一个错误方向，说明改变固定偏好与恢复按前缀选择是不同结果。5.1出现同样的比较关系。

## 解释与对ThreeMind的意义

**本批支持两项规则共同恢复前缀能力的假设，否定仅改其中一项就能恢复的预期。** 节点手动保持不是本矩阵恢复所必需的附加条件。结果把后续改进的重点放在新颖性增强与连接强化、遗忘的共同作用上，而不是把问题归结为输入寻址或节点数量。

旧式连接保持同时改变不止一个局部过程，因而下一步应从其实际公式中区分有用的强化和遗忘作用。这是已经定位的后续问题。本批没有给6.1重新加入旧机制，6.1的前缀恢复仍按R51t2和R51t4自己的结果报告。若建立6.2，应据此提出具体、简洁的规则改动，再讨论受影响机制的复验范围。

## 2026-11-14机制表述修订2

本修订更正“旧式连接保持同时改变强化与遗忘”的笼统表述。5.1两种保持配置共享基础权重强化公式；legacy-stability改变权重遗忘以及稳定度、近期传导记录的相关作用。旧模式不用H计算权重衰减，不能把旧稳定度增长回落与现有H增长回落开关等同。正文后续所说的强化作用，属于在共同强化规则下检验它与遗忘的相互作用，不是已经证明两组用了不同的强化公式。本批数值、双因素比较判定不变，原报告及原件包保留。
