# Functional tests of three dynamical differences

Authorized by the author on 14 November 2026. The comprehensive replication campaign remains paused. This work does not change production kernels, defaults, or the manuscript.

We ask three questions. Does inertial response reversal improve actual closed-loop body control? Does longer persistent activity preserve useful distinctions and improve delayed choices, or merely prolong saturated competition? At which step is prefix information lost, and can existing configurations restore it?

R51t2 first performs a bounded mechanistic comparison using the two historical, exchanged-curriculum blocks. Completed R51t1 references are read, not rerun. This is exploration, not independent confirmation. It compares existing inhibition gains and decay times, synaptic-resource settings, novelty timing, transmitted-signal thresholds, input competition and inhibitory reinforcement. No new rule is introduced.

A second batch uses four coding blocks in a closed-loop simulated body. It first tests thresholds changed only after the same teaching state; R51m's thresholds differed from birth, so that stronger same-state claim needs this direct comparison. Fixed process-based output rules then produce real actions. Stabilization and damping are scored separately, with crossed actuator polarities, error, effort and success. Directed target movement would require additional target teaching and is deferred until this basic role is understood. The two thresholds are compared with joint-only, dose-matched, shuffled-inertia and untrained controls. The previous static reversal is not an action score. Body, Core, sensors, current actions and recent readout are saved together. Apparatus calibration uses separate material before scientific runs.

A third batch tests delayed choices and prefixes in four new coding sources, each with exchanged teaching relations. At most four configurations are admitted: the default, the most promising inhibition-preserving configuration, one explanatory alternative, and the disinhibition saturation control. Selection uses only R51t2. Immediate, short-delay, long-delay and distractor conditions are reported separately. If no candidate restores prefixes, test the two most diagnostic candidates and report failure rather than search indefinitely.

Each batch receives an exact, separately registered protocol before scientific execution. Passive mechanism measurements retain the historical course and do not acquire an unnecessary trained reader. Any learned peripheral must follow the training protocol, including temporal observations, spaced review, correction and held-out materials. A single brightest-node sample is not a substitute for a time course.

An inversion that helps stabilization but harms directed movement establishes a task-dependent tradeoff. Longer activity with worse choices or saturation is not functional improvement. Shorter activity with preserved or better delayed choices establishes that shortening is not a loss on that task. Prefix recovery requires both taught alternatives in both exchanged blocks, followed by independent-material testing. Merely reversing a fixed preference does not qualify. Outcomes are closed separately; no post-result criterion is added.

Runs are serial. Each batch is limited to 2 GiB of originals plus 4 GiB for archival and full API readback; total additional peak space is at most 18 GiB. Each host is limited to two hours and each stage to five minutes. A one-second guard reserves 5/4/5/25 GiB for commit/RAM/C/E. Resource stops occur at complete boundaries. Dead in-flight states, damaged evidence or observer interference are preserved and reported. Registered causal copies retain full parents and explicit identities; ordinary tests never restore per question.

## 14 November follow-up hypothesis: crossing historical rules

R51t2 localized retained prefix activity with a shared ending preference. Together with the two historical changes identified in R51t1, this motivates separately registered R51t5: two novelty timings crossed with three existing retention settings in genuine /3.1 and /5.1. Of 72 stages, 30 are reused read-only and 42 are new. It runs serially after R51t4 computation, without using R51t4 scores for selection or changing the first three batches' criteria. Its 1.5GiB delivery budget uses confirmed spare capacity within the existing 18GiB total. See [protocol](prefix_cross_protocol.en.md).
