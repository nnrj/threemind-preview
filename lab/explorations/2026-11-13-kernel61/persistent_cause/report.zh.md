# 持续活动为何消失：旧内核与6.1的原因定位

2026-11-14 · R51t1 · 已完成476个科学阶段；两个交换教材的区组。

## 科学结论

**旧实验中的持续活动能够重现，其维持和终止也能够通过内部机制干预控制。6.1中活动停止时，相关连接仍然存在；在教学结束、活动尚未停止时关闭抑制，两个教材区组都能持续活动到300秒，并通过随后15秒的完整观察。** 这说明，连接留下来与活动持续下去是两个不同的结果；抑制参与了6.1在本条件下的活动终止。

本轮还定位了两个历史变化。持续活动在/2到/3.1之间消失，/3.1和/5.1改用其已有的旧式连接保持方式后均恢复。共享中间刺激的序列区分则在/1到/2之间改变：/2改回旧的新颖性增强时机，就精确恢复了/1的响应差异。这个改动在6.1中没有恢复序列区分。

**惯性反向与这里的持续活动并非同一个已测门槛造成的变化。** R51m中能恢复惯性反向的传递信号门槛0.004，在本轮不能恢复持续活动，也不能恢复序列区分。两类现象都受到内部传递和抑制的影响，但变化发生的版本阶段及有效干预不同。

## 目的、预期与实验组织

R51t发现6.1没有复现旧E12的两项表现：一是停止新任务提示后持续活动300秒；二是学习A—B—C和D—B—E后，能根据A或D的不同前缀区分结尾。作者据此要求比较新旧内核，并检验这是否与惯性反向的消失有关。

我们使用各版本的真实原生实现，重放相同刺激、强度、时序和顺序。先比较/2、/3.1、/5.1、/5.3、/6.1及公开配置下的对照，共384阶段；发现历史版本标注问题和版本变化阶段后，登记并追加真实/1与旧式保持方式的80阶段；最后根据新颖性配置差异，登记12阶段的时机对照。后两项是本轮观察之后提出的探索，分别保留协议和登记时间。

本装置使用被动时序读出，没有可训练适配器。教学连续进行，诊断干预使用另行登记的完整副本，保存内核、输入总线、随机状态和读出历史。两个教材区组交换C/E，所有条件使用这些材料；476是执行阶段数，**统计材料规模仍为两个区组**。这些是旧材料上的机制定位，不计作476个独立个体。

持续活动采用旧011条件：关闭突触资源耗竭，开启短时易化和既有连接强化。教学持续81.2内部秒，随后等待300秒，保留原背景刺激，不再输入任务提示。之后每10毫秒记录一次活动，观察15秒；五个任务节点中的最大激活在每个采样点都超过1×10⁻⁶，才通过该区组。两区组均通过才称恢复。记录保留激活、抑制、直接和联想活动的全过程，存在性判断沿用上述预设指标。

序列教学持续212.2秒；等待1秒后，在分别登记的副本中给予AB或DB。我们从第二个刺激开始观察15秒，比较所教结尾与另一个结尾的激活峰值。AB、DB两项差值都大于1×10⁻⁶，才通过该区组。这是需要区分共同中间刺激B的任务，与已经通过的两事件顺序实验分别计分。

## 一、历史持续活动重现，变化首先出现在连接保持方式上

| 真实版本或对照 | 持续活动通过区组 | 前缀区分通过区组 |
| --- | ---: | ---: |
| /1 | 2/2 | 2/2 |
| /2 | 2/2 | 0/2 |
| /3.1 | 0/2 | 0/2 |
| /5.1 | 0/2 | 0/2 |
| /5.3 | 0/2 | 0/2 |
| /6.1 | 0/2 | 0/2 |
| /3.1，旧式连接保持 | 2/2 | 0/2 |
| /3.1，旧式连接保持＋手动节点保持 | 2/2 | 0/2 |
| /5.1，旧式连接保持 | 2/2 | 0/2 |

/1和/2在300秒后保持小幅持续活动，随后15秒内最大任务节点激活在0.017154—0.023055之间变化。/3.1和/5.1的最后一次正激活采样出现在等待3.6秒，300秒时任务连接已经消失。两版本改用已有的`consolidation_mode=legacy-stability`后，持续活动恢复，幅度与旧版一致。

因此，**旧式连接保持与后来自适应保持之间的改变，是这段历史持续活动差异的一个可恢复原因**。这里的配置同时涉及连接权重的强化与遗忘，应作为保持方式的组合对照解释。我们没有把结果单独归因于一条衰减公式，也没有以300秒的结构终态推断3.6秒时连接已经删除。

## 二、6.1的连接仍在，抑制干预能够维持活动

默认6.1在等待28.2秒时仍采到正激活，30、60、300秒均为零。300秒的完整图仍保存四条任务连接，权重为0.632698—0.654313。故本轮6.1的活动停止，不能用“任务连接已经删除”解释。

在两个区组中，从出生起关闭抑制，或者只在原样教学结束时关闭抑制，都使活动延续到300秒。随后15秒的最大任务节点激活最低为0.744045、最高为1，全部采样点通过判据。教学后干预使用相同完整教学末态，因此这一恢复不需要改变此前的教学。

干预时活动仍然存在。这里观察到的是**维持尚存活动**，不是把已经停止的网络重新启动。公开关闭抑制操作也会清除已有抑制和待处理的抑制事件，并在同一内部时刻结算状态；全部实际改动保存在各阶段`intervention.json`，没有将它描述成只改一个数值而其他字段不动。

我们又从300秒的完整状态建立诊断副本，改变突触资源耗竭、短时易化和既有连接强化，检验活动靠什么继续。

| 300秒时实施的干预 | /1首次采到零激活 | 6.1教学后关闭抑制组首次采到零激活 |
| --- | ---: | ---: |
| 不干预 | 15秒内持续 | 15秒内持续 |
| 开启突触资源耗竭 | 0.65秒 | 2.06秒 |
| 关闭短时易化 | 0.55秒 | 4.09秒 |
| 同时实施上述两项 | 0.55秒 | 2.01秒 |
| 关闭既有连接强化 | 15秒内持续 | 15秒内持续 |

两区组结果相同。这里的时间分辨率为10毫秒，表中是首个零值采样时刻。短时易化指近期发送提高突触资源释放比例的机制；它与增加有效权重的短时增强分别设置。

**这些干预说明：已经形成的局部连接与反复传播能够维持活动，短时易化参与维持，耗竭能够终止活动；在所测15秒内，继续增强连接不是维持活动的必要条件。** 6.1关闭抑制后的活动比旧版强得多，最高达到激活上限。它给出了明确的因果证据，却不是本报告建议采用的生产默认配置。

## 三、与惯性反向的关系

R51m的惯性反向改变发生在5.1到5.3之间；本轮持续活动在/2到/3.1之间已经改变。R51m把6.1传递信号门槛从0.0004提高到0.004后，四个教材区组都恢复惯性反向。本轮在出生时或教学后采用同一0.004门槛，两项目标均为0/2。

这一比较否定了“将惯性反向恢复所用的门槛搬过来，就能同时恢复持续活动”的预期。抑制仍是两项研究共有的重要因素：R51m的旧版关闭抑制对照改变过反向响应，本轮关闭抑制则维持了活动。后续若调整抑制，应同时检查方向选择与持续活动，不能用其中一项代替另一项。

## 四、前缀区分的早期变化来自新颖性增强时机

/1在两个教材区组中都能区分AB、DB。两项峰值差分别为0.0009778696465850764和0.00273563307296195，本轮四项结果与旧原件逐项完全相同。/2默认改为按到达时间窗口计算新颖性后，两个前缀倾向同一结尾，区组通过数为0/2。

我们只将/2的`novelty_mode`改回`immediate`，即原先立即计算新颖性增强的方式，两个区组都恢复，四项数值再次与/1精确相同。**这项规则变化足以解释本材料中/1到/2的前缀区分差异。**

6.1采用同一改动后仍为0/2，AB、DB的峰值差分别为+0.0000361310和−0.0000361394。它改变了偏向，但没有恢复两条序列各自正确的结尾。**本轮完成了早期版本原因定位；6.1这项共同中间刺激任务的恢复目标未达到。** 旧式保持、关闭抑制和本轮其余候选也均未恢复该目标。后续需要另行提出具体假设，不追加无边界参数搜索。

## 核验、成本与版本更正

完整核验通过：476阶段、2248份完整状态、44652条输入；48个等待阶段均无任务提示输入；20份默认6.1终态与前批R51t完整状态摘要精确一致。原始轨迹的独立算术复算最大差为3.47×10⁻¹⁸。这里的独立复算由同一研究流程中的另一路算术完成，不称外部研究者复现。

三个科学宿主合计58.57分钟，不含装置检验、审计和后处理；峰值私有内存747.67MiB。最低空闲提交内存、物理内存、C盘、E盘分别为13.73、12.09、7.34、67.92GiB，均高于保留量。相同20阶段记录的6.1与5.1耗时比为1.31；该值包含观察与保存，不作为纯内核性能基准。归档前目录逻辑大小约1.095GiB，真实分配约1.108GiB，6778个文件无重复硬链接；该口径包含逐字段干预审计资料，不含随后生成的归档及读回副本。

本轮核对旧E12的592份结果，全部版本字段为`threemind.continuous-memory/1`。R51t曾把历史参照写成/2，现以[独立勘误](../memory_timescales/errata-20261114.zh.md)及原科研记录中的追加说明更正；旧报告、数值、原件和已运行的真实/2均保留。还修正了登记事件类别及审计器对回执字段的错误假定，过程见[审计说明](audit-correction.zh.md)与数据中的`registration-corrections/`。这些修正未改变科学输入、评分或重跑任何已完成个体。

最终审计入口为`analyze_v3.py`和`analyze_novelty_v2.py`；较早审计文件保留为过程记录。原件、配置、源码冻结记录、两次追加协议、状态、投递、图表和本报告通过同一科研API交付；完整包下载校验与待同步为零是结项条件，回执保存于`publication/completion.json`。

## 对ThreeMind的意义与后续决定

这次对照把“过去出现过持续活动”推进为更具体的机制认识：**连接保存了传播路径；传播能否持续，还取决于短时易化、资源耗竭和抑制。** 历史现象可以重现，也能被干预维持或终止，因此它是值得保留和继续解释的实验证据。另一个重要发现是，新颖性增强的时机足以改变两个相似序列能否被区分。

本批诊断结束，生产Core、默认值及论文均未修改。全面复验继续按R51t的不利机制差异规则暂停。建议下一步围绕保留抑制的传播平衡开展有界比较，同时检验持续活动、惯性方向和共同中间刺激的序列区分；具体改动和新实验由作者决定。当前不将关闭抑制设为默认，也不以持续活动恢复替代尚未恢复的前缀区分。
