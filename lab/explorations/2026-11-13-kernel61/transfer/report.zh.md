# R51j：局部连接移植转移了特定门选择，并保留无关响应

2026-11-13。**8个独立来源全部达到预定转移目标：目标连接移植使48/48次目标选择转为供体所学方向，同时保留48/48次无关选择。移回原连接后，完整状态和逐题响应恢复。**本批确认了6.1中局部经历结构对实际选择的选择性因果作用。

## 目的与预期

本批沿用旧X1的8来源规模，检验移植经历形成的局部连接，能否使受体采用供体的特定响应，并产生实际行为后果。预期目标移植有效，匹配连接移植不改变目标题，假操作不改变响应，恢复原连接恢复原响应。持久连接状态与快速状态另行交换，分别判断其作用。[执行前协议](protocol.zh.md)固定了全部条件、标准和停止规则。

## 实验方法

每来源建立两个连续教学父体，分别接受相反对应关系。通道含义和跨副本对应在教学前确定；内核使用6.1，16轮教学后在18内部秒保存完整父体。目标连接为X/Y到回答通道A/B的两条边，匹配连接为Z/W到A/B的两条边。两组数量、度数相同，权重和教学活动残差须在0.02以内。连接选择未使用终试答案。

两种教学历史分别建立完整参照、假操作、目标完整包、匹配完整包、目标持久包、目标快速包及恢复七种研究副本。完整包交换所选边及相关定时器；持久包保留受体的快速字段；快速包保留受体的连接指向和持久权重。节点、固定读出、身体、随机状态及其余连接保持。

固定读出使用A−B响应差，在提示后110毫秒按±1e−4门槛选择两扇门之一。选择在250毫秒决定后续感觉输入，360毫秒记录第二次动作。因此移植的响应实际进入了行动—感知循环。主成绩只计首次选择。每条件包含X、Y、XY三个目标题及Z、W、ZW三个无关题，总计672次探测；独立来源数为8。

主要通过标准为至少6/8来源同时达到：目标题与供体一致至少75%，较假操作提高至少50个百分点，无关题损失不超过10个百分点，匹配移植的目标题收益不超过10个百分点。持久包和快速包另按至少6/8来源的目标题成功率达到75%判定。

## 结果

下表的目标题按供体新方向评分，无关题按受体原方向评分。完整参照的目标题0/48表示它保持自己的原教学方向。

| 条件 | 目标题与供体一致 | 无关题保留受体原响应 |
|---|---:|---:|
| 完整参照 | 0/48 | 48/48 |
| 假操作 | 0/48 | 48/48 |
| **目标完整包移植** | **48/48** | **48/48** |
| 匹配完整包移植 | 0/48 | 0/48 |
| **目标持久包移植** | **48/48** | **48/48** |
| 目标快速包交换 | 0/48 | 48/48 |
| 移回原连接 | 0/48 | 48/48 |

主要转移目标8/8来源通过，平均收益100个百分点，无关损失0；持久包目标8/8通过。匹配连接承载另一组对应关系，移植它改变了无关题，而没有造成目标题收益，进一步显示改变发生在被替换的对应关系上。

16次目标完整包交换中，成对连接的数值状态原本相同，实际改变的是目的节点及相应定时器的端点。仅交换持久包产生相同效果。16次快速包交换的字段两方完全相同，实际为零改动，转移目标0/8；它提供了零改动参照，未检验不同快速状态之间的作用差异。

假操作和恢复条件的全部完整状态、逐毫秒响应与各自参照相同。目标与匹配组的最大权重残差0.000591、教学活动残差0.000640，均在预设限值内。

## 科学结论及对ThreeMind的意义

**本批学到的选择对应由局部连接的指向承担：把相应连接转移给受体，就能选择性地转移响应和门选择；换回原连接就恢复原选择。**固定读出器全程没有重新学习，无关关系由未改动的连接继续表达。实验完成了“局部经历结构能否选择性转移并影响实际选择”的预定目标。

这是6.1的有利复验结果。它将此前的连接阻断证据推进到可逆、选择性的行为转移，并明确了本批发挥作用的具体字段。主要目标和持久包目标通过，快速包转移目标未通过且属于零改动条件。没有触发全轮停止规则，后续继续固定个人读出器和独立48来源移植确认。
