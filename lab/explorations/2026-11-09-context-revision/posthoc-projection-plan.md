# Exploratory output-port diagnosis / 输出端口的事后诊断

2026-11-09, after inspecting the first four completed scientific sources, before reading projection results. The original eight-source experiment continues unchanged. This is a read-only explanation of the recorded results, not a new confirmatory goal or a replacement score.

The interim records show successful responses after discriminating evidence but poor first-window joint judgments. A useful next distinction is whether the intended category is already visible in the declared output ports while the fixed personal Transformer fails to express it, or whether this simple port measure also lacks the category.

For each existing one-second window, average raw `activation` over all 20 frames separately for each already-declared output port. Choose the largest mean within the sound, vision, or action interface. Equal maxima within 1e-12, or a maximum at most 1e-12, count as unresolved and incorrect. The port-to-category map is the one explicitly used by the original teacher: S0/S1, V0/V1, A0/A1/AO. Do not fit any parameter, change the time window, normalize per question, or choose a rule using an answer. Include every final trial from every source and history. Report intact-condition counts as the main descriptive table and each control separately.

Compare this fixed projection with the actual personal adapter's recorded answers. An advantage for the projection would motivate a future, separately registered test of output-adapter mismatch. Poor projection results would show that this particular simple measure does not recover the answer; they do not establish the absence of all internal information. No existing scientific verdict changes. No subject is loaded, stimulated, trained, or advanced.
