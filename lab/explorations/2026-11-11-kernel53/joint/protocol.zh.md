# R47c：四种衰减曲线下的完整个体共同培养、纠错与重学

2026-11-11，运行前协议。[English](protocol.en.md) · [5.3计划](../../../../docs/zh/plans/kernel53.md)

## 目标及科学判断

R47a/b用固定仪器比较连接和整段响应。R47c回答实际学习问题：内核与自己的时序Transformer、执行器连续发展后，能否学会选择、保留旧能力、适应反转规则，并重新学会原规则；四条曲线在这些任务上的差别是什么。本批为八个来源探索，局部实验的成功不替本批计分。

独立来源八个，种子261111700—261111707；每来源在指数、幂律、逆对数及先幂律后指数下各培养一个完整个体，共32个。来源内配对，独立N仍为8。四组均采用H=30、A=10、强化继续计龄、保持增长及回落关闭；其余5.3初始参数相同。新生个体，不载入旧实验对象。

每阶段的主要测验为无答案的即时题和其后300秒的延迟题。以下目标都要求相关子组在两次测验中各至少75%正确；每曲线至少6/8来源满足才达标。

| 目标 | 课程与预期 | 明确结论 |
| --- | --- | --- |
| J1 初学与保持 | P0→0、P1→1、A0→0、A1→1；四题型均衡计分 | 是否学会并在该连续流程中保持最初对应 |
| J2 新学与旧能力 | 加教B0→0、B1→1；分别计新B组及原P/A组 | 能否在学新对应时保留旧选择能力 |
| J3 规则反转 | 改教A0→1、A1→0，P/B不变；分开计反转A组和保护P/B组 | 能否改学相反规则并保留无关能力 |
| J4 返回原规则 | 再教A0→0、A1→1，P/B不变；分开计A与P/B | 能否重新学会原规则，同时保留其他能力 |

达标就明确支持该项学习能力；未达标按实际失败阶段和类别解释。开发集纠错前后另报，不以教师示范或训练损失代替正式成绩。重学的教学次数和优化更新按实际记录；本批没有设置等价的初学与重学成本对照，因此只作连续流程的成本描述，不把较少纠错自动归因于某一记忆机制。

若某曲线全部J目标达标，可称该完整任务中的能力候选。各目标单列，不以累计通过数造通用冠军。默认选择还要结合R47a/b的保持、弱经历遗忘和成本；若没有曲线满足完整目标，明确结论为暂无综合默认候选，并保留已证实的分项收益。

## 实验对象与参照差别

完整对象包含真实Rust 5.3内核、匿名映射、一个属于自己的Transformer输出读出器、Adam及学习随机状态、全部既有校准材料、近期20帧活动、内部时钟及输入队列、身体位置、执行器上次命令、世界阶段和课程游标。每次教学、采样、校准、开发问答、纠错及正式测验都承接同一对象的完整状态。

| 内容 | 本次做法与参照 |
| --- | --- |
| 时间读取 | 沿用E56/R43的1秒20帧，均匀选8帧；激活、抑制、直接/联想四字段，原始值不按题重标或扣基线 |
| 个人读出器 | 沿用ActivityController：48维、4头、单层Transformer、前馈96、dropout0；读取两个已声明输出端口，共8个原始特征，输出两个选择词 |
| 连续学习 | 沿用CalibratedActivity.continue_calibration；AdamW 0.002、weight decay0.0001、batch≤32、梯度裁剪1，每次1200更新，提交最后状态；不回退到最小损失点 |
| 任务 | 将R43的声、视、动作三头情境任务收为一个匿名二选一任务，以隔离衰减影响；新建自己的读出器，不更换任何旧个体的外设 |
| 执行器 | 固定执行所选位置0或1，再把实际位置作为本体感觉刺激送回；没有物理手臂、伺服或视觉识别，本批评价选择与记忆 |
| 校准 | 收集同一个体在无答案提示下的实际作答窗口；教师标签仅监督外部读出器；Core不接任务标签，推理不接题号、标签、当前规则或正确位置 |
| 读出后续 | 与R43“随后冻结外设只教Core”的主问题不同，本批每个新阶段继续共同培养；所有正式题期间外设固定，Core及身体继续运行 |

观察API读取声明端口的完整过程，属于已登记测量；它不推进内部时间。学习更新期间Core和身体保持在当前时刻，更新后的外设接着参与同一对象的后续经历。优化器更新不是模拟秒。

## 教学、复习、纠错与题表

初始P/A四对应，后续为P/A/B六对应。每阶段先教每个当前对应八课，课序用个人随机状态打乱、相互交错；每课1.5内部秒，在0、0.25、0.5、0.75、1秒给提示和目标输出端口各0.4的共同刺激。之后间隔2、6、18秒，各复习全部当前对应一课。背景通道每0.5秒输入0.2；实际时间和所有输入均保存。

完成本轮教学及三次复习后，每对应以0.76、0.8、0.84、0.8四个无答案提示采样，保存其全段活动，以当前教师对应监督个人读出器1200更新。原校准材料全部保留并参加后续更新，最大样本量低于1024。随后每对应以0.76、0.84做开发题。新学、反转、返回阶段在教学前也做一次开发题，记录已有能力和旧规则响应。

只要开发题仍有错误，就对出错对应各补五课，再按2、6、18秒复习所有当前对应，重新采样并用新旧材料连续更新1200次，再做开发题。最多两轮纠错。若提前全对，停止额外纠错；各曲线获得同一纠错机会与上限。初次、每轮纠错和开发成绩分别保存，不能将示范回答算作自主回答。

完成本阶段教学后，使用未用于校准或开发的0.72、0.78、0.86、0.9四个提示幅值逐一测验，题序由个人随机状态打乱。初始16题，后三阶段各24题。即时测验后继续背景输入300秒，再做同幅值范围的新顺序延迟题。迟测包含该个体此前即时测验的经历，不当作“从未测试过的纯保持队列”；纯保持由R47a/b的独立时点队列回答。所有正式题只计分、不反馈正确答案、不用于外设更新或选模。

每次作答由读出器原始logits的最大项确定，执行器按这个结果更新位置。评分器事后比较目标；本体反馈只报告实际选择的位置，不报告正确性。保留起点与保持/改变位置的记录；成绩称“正确选择”，不改称物理运动学习或眼手协调。

## 冻结、验收、资源及交付

正式来源、规则、课程上限和分析先冻结。工程种子98765063的一次校准已在6.80墙秒内完成首轮1200更新，开发8/8；它不进入科学N。正式前还核验全态保存恢复后下一次作答及下一次优化更新一致、只读不扰动、完整四字段与真实执行反馈、既有版本见证。

每个声明操作为完整保存边界，保存前后状态哈希、结果、个人模型/Adam/RNG依赖及时间。任何新死亡、孤立in-flight、原件不一致或真值泄漏先保全并停止。普通未达标正常完成并报告。

原件上限4GiB、私有内存上限3GiB、宿主4小时，提交/RAM/C/E余量5/4/5/25GiB，每秒守卫。启动提交余量至少8GiB，磁盘至少37GiB以覆盖原件、归档、读回和保留量。守卫只请求完整操作边界暂停，不半途丢弃优化器更新。根据校准估计约15—40分钟，实际耗时及峰值另报。只在R47b交付后启动一个科学宿主，旧批和用户服务保持原状。
