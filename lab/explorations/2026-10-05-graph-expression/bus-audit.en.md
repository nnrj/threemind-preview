The user recalls a bus carrying actual signals strong enough to propagate, with adapters selecting channels, and requests a later audit/comparison without interrupting this experiment.

Current code: [OutputBus](../../../src/threemind_runtime/bus.py) copies/distributes subscriptions but applies no universal propagation threshold. [ReadoutHost](../../../src/threemind_runtime/readout_host.py) samples nodes and optionally induced edges. [RawActivityStream](../../../src/threemind_runtime/activity_stream.py) is explicitly a research measurement feed. E50 selects local activity downstream: using the bus does not turn sampled state into an emitted signal. [Output organs](../../../src/threemind_runtime/output_organs.py) consume activations at organ cadences rather than the complete stored graph. [Continuous propagation](../../../src/threemind_kernels/continuous.py) applies connection thresholds and schedules signal/inhibition events; [ordinary observation](../../../src/threemind_runtime/event_observation.py) uses input-only event capture to avoid copying every internal arrival. The main expression path does not currently consume that actual transmission stream.

The recalled design and the research sampling path therefore differ. A common bus can unify protocol, identity, time and subscriptions while carrying multiple channels; it need not claim to reproduce a single anatomical wire. Distinguish actuator signals, research-state observation and linguistic interpretation. E50 does not replace production output protocols or introduce a propagation threshold.

Recommended, not executed here: matched frozen sources and inputs comparing actual transmission events, local activity/inhibition and both. Declare emission versus arrival, amount, timing and direction. A state crossing an observer threshold is not automatically an actual transmission. Add missing read-only event evidence if necessary and check observer neutrality without re-simulating propagation inside the observer. Validate taught referents before testing new history/relations.
