## 先说清楚本轮发现

**当前形色指认装置，不能按“意识完成识别，运动中枢只把意图翻译成动作”来解释。** 它实际训练了一个有监督物体选择器，再让伺服把指针移向它选的位置。外部选择器确实能自己完成这套有限任务：绕过Core，仅给相同的匿名感官输入，三个训练种子均为24/24。

**Core也不是完全不起作用。** 同样的眼前场景和问题，不同过去经历留下的内部状态会改变答案。但本轮进一步定位发现，第一来源主要利用了教师指向感官中残留的激活来区分两段历史。只交换五个这样的节点的激活，固定读取器的32个选择全部变成供体历史的选择；交换视觉—文字连接却没有改变选择。它证明了真实内部状态的因果作用，尚不能证明这些连接已学会物体概念或自主形成了指向意图。

这是对本套装置分工的实质纠正，不能包装成语言理解的新突破；也不推翻其他实验中已经定位的经历与联想作用。旧报告不覆盖，E56的24/24仍是系统能力成绩，而不是Core独立识别成绩。

## 1. 正常路线没有偷传测试答案，但训练目标改变了分工

正常E56路线是：物理世界和问句 → 原感官编码与输入总线 → Core → 输出总线中的激活、抑制、直接触达、联想触达 → Transformer选择器 → 四个位置之一 → 伺服执行。

推理接口没有另传原始问句、正确物体身份或评分答案。问题不在这里，而在于**选择器接受了“正确物体在哪个位置”的监督**。它可以从Core的直接感官响应中自行学会颜色、形状、问句与位置的关系。输入经过Core，不等于识别由Core学成。已知的四个物理视场共享读取规则，也是外设提供的结构，不是内核涌现的脑区。

本轮绕过Core的路线是明确标出的排除对照，未接入正常产品。入射量保持原通道、原幅度和实际递送顺序；其余未定义的活动字段填零以匹配模型容量，不把这组数据冒充内核响应。没有无提示相减、按试次归一化或替换感官映射。

## 2. 外部选择器单独能做多少

复用E56的48条校准＋12条练习监督；确认题固定为原24题。每种条件使用相同的76,657个参数、1200步优化和三个预定种子。种子改变外设训练，不是三个独立世界。

| 读取的信息 | 种子223 | 种子279 | 种子337 |
| --- | ---: | ---: | ---: |
| 有学习Core的8时刻原始活动 | 24/24 | 23/24 | 23/24 |
| 从出生关闭结构学习的Core活动，另训同等选择器 | 24/24 | 24/24 | 22/24 |
| 绕过Core，8时刻的真实入射量 | **24/24** | **24/24** | **24/24** |
| 绕过Core，完整20时刻入射量 | **24/24** | **24/24** | **24/24** |

因此这套有限颜色、形状和组合题，并不要求Core先学成概念。绕过成功不等于原读取器在每道题都忽略Core；E56固定读取器下已有连接使5道题由对变错、恢复后回来的事实仍成立。但不能仅用这种扰动敏感性证明那5道题的概念判断发生在Core里。

## 3. 换过去经历，保持眼前完全相同

新建两种命名历史：甲乙丁戊分别对应四种灰色形状，另一历史循环换一个对应。每名先连续教10次，再三轮交错复习；各复习轮开始前另停留0、6、18模拟秒，共52课、102模拟秒。每课1.5秒，所以同一项目后三轮的起始间隔实际为12和24秒；0/6/18并非每个名字的完整重访间隔。原始记录保留每次递送时刻。保留完整身体和天气背景、正常强度、遗忘和抑制。

同一读取器同时学过两段历史的32条监督，之后冻结。测试用新的布局/角度：同一场景、同一问句、同样当前身体和环境，因过去不同而应选择不同形状。测试已撤教师标记，历史编号不进入推理。每个试次从快照独立恢复，不能把32题当32个独立意识。

这套题中，不知道历史的确定性读取器最多16/32；这不是四选一随机机会水平，而是两份完全相同眼前输入对应相反答案的上限。

| 固定当前输入的条件 | 环境来源223（天气47） | 环境来源279（天气103） |
| --- | ---: | ---: |
| 正常学习Core＋同一读取器读两历史 | **25/32** | **23/32** |
| 关闭结构学习、另训同量共同读取器 | 21/32 | 31/32 |
| 只读当前感官，另训同量读取器 | 16/32 | 16/32 |
| 读取器冻结，只给Core继续/反向教学 | 22/32 | 22/32 |

正常组各有9/16对题在两历史中都答对；只教Core之后为6/16与8/16。第二来源正常组没有达到24/32的定位门槛，不把23写成达标。两来源无学习状态均无连接，历史差别保留在激活/抑制中。学习组未表现出跨来源一致优势：第一来源比无学习高4题，第二来源低8题。

只教Core确实能带动部分改答，但两来源均22/32，且本流程末次教师示范的指向也随历史变化；这项结果未排除同样的近期感官残留途径，不能直接称为读出了新学成的概念。

上述对照能证明读取器是否用到历史信息，却还不能证明它发现了新的概念映射：读取器训练时见过两套对应，可能只需从内核状态辨认“是哪段过去”，再使用外设自己学会的对应。因此还必须定位历史信号。

## 4. 关键定位：是过去示范的感官残留，还是已学成的连接

第一来源达到事前24/32定位门槛。在其两种历史中，屏蔽视觉—文字既有连接、等数量其他连接、解除屏蔽，并交换相反历史相应连接及短时连接状态。掩码按物理通道来源选，不看测试答案。

| 第一来源，冻结同一读取器 | 按原历史答对 | 相比正常改变了几个选择 |
| --- | ---: | ---: |
| 正常 | 25/32 | 0 |
| 静默视觉—文字既有连接 | 25/32 | 0 |
| 静默等数量其他连接 | 24/32 | 1 |
| 解除目标连接静默 | 25/32 | 0 |
| 换入相反历史的目标连接及对应短时连接状态 | 25/32 | 0 |
| 换入相反历史的其他连接 | 25/32 | 0 |

这不证明所有连接都无用：只处理所选既有连接，没有消除新生边或撤回已发出的信号。其他边仅数量相同，平均权重差约0.275，拓扑也不匹配，不能称严格等价损伤。不过目标边的静默与交换均未改变选择，已足以反对“这一组成绩就是这些视觉—文字连接的作用”的说法。

随后先做离线字段诊断，再在**真实Core快照副本**中验证，不把人造读取数组冒充真实活动。只改指定受体节点的激活，其余抑制、历史、全部连接、短时连接状态、能量、时钟和在途信号原样保留。之后照常送入完整环境和问句，运行Core，读取真实输出。原件不动。

| 真正修改Core副本的状态 | 原历史答对 | 相反历史答对 | 对应解释 |
| --- | ---: | ---: | --- |
| 正常 | 25/32 | 3/32 | 基线 |
| 只清零5个教师指向受体的激活 | **16/32** | 16/32 | 两历史选择完全相同，失去历史区分 |
| 只换入另一历史这5个节点的激活 | **3/32** | **25/32** | 32个选择全部等于另一历史的正常选择 |
| 交换5个自身指针受体的激活 | **25/32** | 3/32 | 选择不变 |

教师指向是过去真实示范的感官输入，不是额外偷塞的历史标签。它的残留**属于Core真实的短时状态**，因果作用明确。但外设利用这少量残留，就能选择自己已经学过的一套回答规则；这比“已在内核形成可迁移物体概念”的解释更直接。这里没有排除其他未读出的记忆，只是定位了本轮读取器实际依赖的信息。

干预强度的限制必须同时保留：两种交换都选取5个节点，其中实际有3个激活值改变。教师节点变化绝对量之和约1.668，自身指针节点仅0.000426；后者**只有数量匹配，没有幅度匹配**。不能把其“选择不变”用来证明任意其他部位的同等扰动都无效。核心证据是限定的教师感官状态交换足以把全部选择转为供体结果，而不是已经穷尽了所有其他原因。

离线诊断遍历视觉、文字、教师指向、本体/环境以及四种活动字段，全部结果保留；不能只挑对解释有利的字段。第二来源正常23/32，离线清零教师字段后15/32；交换教师字段后按原历史5/32、按供体历史23/32，也提示这一路信息的重要性。离线改数组会产生不自然组合，不能与真实Core状态干预混称。真实激活交换仅做第一来源，未伪称两来源均完成全部因果干预。

## 5. 没有意识活动，为什么仍然运动

冻结原E56读取器，不创建Core，保留24个物理场景、风和身体。给它全零的8帧，四个共享视场面对相同输入，选择逻辑仍强制取最大值（平分时取首项）；实测24次全选位置0，其中6次碰巧正确。后面的伺服照样发出960条非零动作命令，最大位移1.443米。

另一对照不递送帧、不调用读取器，也不发动作命令。结果是零条命令，身体受风的最大漂移约0.070米。因此必须区分：**“一组值为零的输入”与“没有输入、不执行选择”**，也要区分主动命令与被动漂移。

当前选择器缺少“没有可表达意图/暂不动作”的结果；不能把这种机械选择解释为意识自己想动，也不能据此证明学成了条件反射。这是实验控制器的定义问题，不是Core无输入仍产生指向意图的证据。本批只验证，没有暗中给正常运行加门控或更改动力学。此前两段课间画圈的停核物理对照仍见[E56追加报告](../2026-10-06-vision-correction/report.zh.md)。

## 6. 少训外设，是否让意识更重要

用户提出“中枢学成快速反应”的积极解释，并允许共同决定，但保留排除要求。这里固定60条监督材料与Core全部经历，仅比较外设100、300、1200步优化；不是减少Core教学次数，也没有证明生物学意义的条件反射。

| 外设优化步数 | 正常Core：三种子各自成绩 | 固定这些头读旧边静默活动 | 直接感官绕过Core |
| --- | --- | --- | --- |
| 100 | 16、16、22 /24 | 12、11、21 /24 | 23、24、23 /24 |
| 300 | 24、22、23 /24 | 19、18、20 /24 | 24、24、24 /24 |
| 1200 | 24、23、23 /24 | 19、18、20 /24 | 24、24、24 /24 |

静默导致失去的原正确题，三种子合计分别14、12、13；100步还新增4个正确答案。解除静默全部恢复原选择。没有“越少训练，Core决定作用越强”的稳定趋势，主要变化是正常拟合不足。各行重复使用相同24题，不把合计72次当72道独立题。优化步数不改变推理网络规模，本批不宣称训练更多就执行更快。

## 7. 对当前成果的明确判定与下一步

1. **形色指认的系统能力成立，Core独立学会并决定形色指认尚未成立。** 当前装置确有外设完成识别的充分途径，不符合“运动中枢只翻译内核意图”的强表述。
2. **Core短时历史能影响答案，而且已定位一处原因。** 第一来源中5个教师指向受体的激活可控制历史选择；这是具体成果，但不能升级成概念、逻辑或自主运动意图的证据。
3. **减少外设优化不是现成解法。** 外设学成的响应可以有工程价值，也允许与Core合作；只是本任务不应再用总正确率衡量Core的新能力。
4. **本轮不能判ThreeMind整个项目无用。** 这套题有绕过Core的解法，说明任务和分工不足以证明需要Core；E50、海洋等在不同条件下的经历/联想干预应按各自证据评价，不能因本轮结果一并撤销，也不能拿它们替本题补证明。

建议下一步保留当前选择器作为明确命名的外部识别基线，另外建立真正要求经历的任务：相同眼前输入、读头冻结、只教Core新对应；平衡最终教师示范及其残留，不能让读取器预先记住两张答案表再靠残留选择。再查保持、纠错、相关通路的屏蔽/恢复和移植。若仍不能超过直接输入与简单短时记忆基线，再定位内核学习或外设读取的缺口。

动作方面，应把“选择对象”和“执行动作”分别命名，单独验证无意图时的处理以及真实闭环控制。**本批没有擅自修成所谓意图门控，也没有改Core来制造好结果。** 可见自身肢体、真正自主画圈回应、能量形成动机、长期保持与未见关系迁移仍是后续事项，不因本次诊断被遗忘或冒称完成。

## 8. 复现、资源与交付

2026-10-07结项。完成113个阶段、588次新来源/副本创建，累计登记计算**71.69分钟**，未完成阶段为0；低于600次/90分钟上限。归档前工作目录约**0.755 GiB**。报告、证据ZIP和数据库合计以交付记录实测为准，保持4 GiB硬上限。共享账户用量从74%到76%，增加2个百分点，包含其他并行任务消耗。

通过6项定向测试：感官对照不读取答案元数据、冲突历史评分、移植的通道对齐及原件不变、共享视场置换、读取器验证集边界；新增脚本语法检查通过。一次完整核查确认26组配对、8320对实际刺激帧相同；6个状态干预快照除登记的激活项外其余保存字段完全相同。没有用反复全量哈希代替研究。

新研究项目为 **E57 指认答案的内核与外设归属**（`e7606f95-62ea-4645-badd-46bdcf54ec47`）。中英设计、执行笔记、中英报告和完整证据分别保存；归档带有本轮实际用到的旧E56读取器、状态与特征，旧原件保留原处。研究总表、现代中英文史书和两部文言改写同步续记。本批没有增加新录像或改UI，不把研究脚本验证冒充新UI验收。

原始登记保留，追加C/D/E/F与第二环境修正均写在执行前记录。第二来源原拟只改Core种子，核查发现普通配置下该种子只用于未启用的空间坐标，故在执行279之前改为不同天气种子47→103；通道映射、课程、两历史内部的配平保持。没有事后挑好天气，也不把两个来源称为独立总体。

代码仅在实验和通用研究工具层新增；没有改内核动力学、默认值、旧意识或旧实验。所有教学、真实输入、活动、快照、干预收据、读头权重和逐题结果保留。输入一致性的核查只对归因必要的数据做一次完整比较，不重复遍历旧库或反复哈希。
