# E58 preregistration

2026-10-07. [中文](design.zh.md) · [Decision](../../../docs/en/plans/embodied-memory-content.md)

Short sensory traces qualify as memory. Determine their content and causal role without changing that definition. Preserve continuous-memory/2 defaults, text normalization, timing, forgetting and inhibition, all historical instances and protocols. Intervene only on new copies; no baseline subtraction, per-example normalization or answers at inference.

## A: whole-scene vision

Add grounded-classroom/3: one fixed camera observes the entire tabletop, objects, teacher marker and visible self-pointer. Support continuous jittered positions and variable object count. Measure RGB and distance without object IDs, boxes or correct coordinates. Start with16×16 rays; check optical distinguishability and real self-visibility before expensive learning. Retain proprioception/weather and add measured boundary contact forces; this is still a2D pointer, not an articulated arm or complete skin. Use fixed held-out layouts and ordinary, expanding reviews. Shared weights on regular retinal pixels are allowed; target-based cropping is not. A same-reader direct-sensory baseline receives equal supervision.

## B: feedback versus command

Record actual commanded and uncommanded motion with replayable physical weather. Compare complete, vision-masked, proprioception-masked and both-masked input on the same starting Core. Removing bodily feedback includes acceleration, power and temperature effects, not just position. Replace masked channels with the corresponding prerecorded stationary physical observation; keep weather identical. Record actual activity, association and command. Compare a Core intervention's first command before new motion feedback returns. No activity/remaining activity does not establish subjective agency; no learned reader means no claim of autonomous pointing.

## C: memory after identical terminal experience

Reuse E57's two histories, two sources and learning/no-structural-learning snapshots with the OLD four-field protocol to isolate this explanation from an eye change. Give both histories the same unnamed teacher-pointing/body/scene sequence, followed by0/6/30s waiting with continuous physical background. Measure teacher, visual and text state differences. Test frozen old readers and equally recalibrated readers on new layouts. Current-input-only ceiling remains16/32. If history remains useful, use copied-state activation/edge interventions, rescue and transfer. Otherwise report unavailable information under that reader, not absence of all memory. Source223 first; source279 is targeted replication, not exhaustive search.

## D: fixed versus adaptable external reader

Teach a genuinely new name–object permutation absent from both old maps. Evaluate a frozen reader, then allow a small, recorded amount of new teacher feedback plus old-example rehearsal. Evaluate unseen layouts and old-map retention. Give a parameter-matched direct-input reader the same feedback. Continual Transformer training belongs to the external adapter and must not be credited to Core alone. Keep original models and register concrete material before running.
