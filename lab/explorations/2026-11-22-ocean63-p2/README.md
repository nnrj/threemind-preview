# OCEAN63-P2　小体型幼体、三胎和亲代哺育

P1 的第一座常规供给水域已封存恰好 1500 内部秒的完整状态。执行切换时，世界已越过该时点，记录器在 1520.70 秒保存了后续经历并退出。前一快照的全部 85 个内核和后一快照的全部 91 个内核都已逐一读回。P2 在两个独立水域初态下分别比较两种颗粒供给，每个世界从 53 个空白创始个体开始。

[中文实验方案](protocol.zh.md) · [English protocol](protocol.en.md) · [启动核查和完整快照校验值](launch.json)

在实验环境中运行 `p2_launch.py run` 可接续 P2 的完整快照。工作目录使用本批独立的 `.work/ocean63-p2-20261122`，运行原件位于 I 盘的 `ThreeMindData/experiments/ocean63-p2-20261122/evidence`。其中 `progress.json` 给出当前水域及最近进度，各水域的初始状态和封存分段在 `cases` 中。常驻进程依次运行四个世界并重算双语报告。设定本批 STOP 文件可请求完整状态暂停。科研页面的原件读回权限单独登记。
