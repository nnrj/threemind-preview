# R42: SAT Core necessity exclusion v3

1 November 2026. Prospective protocol. The author authorized clearer exclusion experiments to determine whether Core contributes. Outcomes may support or reject that expectation. Scope is this declared hybrid SAT apparatus. Preserve v1/v2, production Core, half-life, old studies and manuscripts.

## Questions and closed decision rules

Separate necessity of trained Core state, necessity of online Core processing for the fixed reader, sufficiency of independently trained peripherals, and the value of current input information. A shuffled-teaching comparison alone cannot establish these claims.

A read-only preflight found zero edges at all eight normal v2 final-training and final-test boundaries. This does not imply zero edges throughout questions. Silencing existing edges there would be a no-op; node states still exist. Replace full Core state or bypass it instead.

Q1: blank-core versus intact supports non-necessity of prior Core state in this task if the 90% paired-origin bootstrap interval for SAT solve-rate difference lies entirely inside ±5 percentage points and balanced local accuracy drops by at most 1 point. Otherwise report contribution or insufficient precision. Exact stepwise equality is an additional stronger claim for the finite test set.
Q2a and Q2b: apply Q1 separately to relay-fixed and template-fixed. Never choose the successful replacement after observing outcomes and call both successful. Compare every choice and assignment, not only total scores.
Q3: relay-trained applies Q1 and must correctly classify all four allowed input categories; it establishes sufficiency of the same peripheral supervision without Core, not fixed-subject ablation.
Q4: constant-fixed and constant-trained test removal of input information. A balanced local accuracy loss of at least 25 points plus a positive lower 95% paired-origin interval for SAT loss supports behavioral value of category information. Report local and solving effects separately if only one is present.
Validity: restored must exactly reproduce intact activity, predictions and actions; verify every SAT witness independently; sentinels may only return UNKNOWN; parent hashes and fixed reader weights/Adam/RNG must remain unchanged; no-Core inference must never construct or invoke Core. Invalid measurement stops interpretation and preserves originals. Preregistered precision failures are not evidence of no effect. Eight existing independent origins are the statistical units; branches/questions are nested, not a fresh 48-origin confirmation.
