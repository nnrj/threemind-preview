# 预先方案：默认映射复验，逐句重复与完整标点

2026-09-09。独立创建实验项目，不覆盖此前任何实验。上次将“发送原句标点不变”解释为关闭NFKC，是执行条件错误。本次恢复使用产品现有的完整默认感官配置，不修改映射器源码或内核。旧实验保留为不同感官条件的记录，不拿来替代本次复验。

## 原句与教学

下面每一行是一个完整发送载体。发送不带方括号，不删除说话人，不改变句子成分，不在逗号、冒号或问号处分开。原文保存在输入信封中；之后的规范化与编码由现有感官自己处理。

```text
甲是松子。
乙是铃铛。
丙问甲，谁是铃铛？甲说：乙是铃铛。
丙问乙，谁是松子？乙说：甲是松子。
甲对乙说：我是松子，你是铃铛。
乙对甲说：我是铃铛，你是松子。
谁是松子？甲是松子。
谁是铃铛？乙是铃铛。
松子是谁？松子是甲。
铃铛是谁？铃铛是乙。
```

1. 按以上顺序，第一句连续20次，再第二句连续20次，直至第十句。完整练习3轮，每轮每句仍连续20次，共600次输入。每句已经累计60次后才进入后续阶段。
2. 以下7句同样逐句20次、完整3轮，共420次。前4句是用户最新补全标点的原句，后3句仅替换名字。

```text
C的父亲是B。
B的父亲是A。
C的爷爷是A。
父亲的父亲是爷爷。
F的父亲是E。
E的父亲是D。
F的爷爷是D。
```

3. 回顾最初10句，每句连续5次，共50次；这是每句先获得60次教学后的回顾，最终每条对话累计65次。
4. 用以下未见家系训练，每句连续20次，完整3轮，共240次。不输入Z或W的爷爷答案。

```text
Z的父亲是Y。
Y的父亲是X。
W的父亲是V。
V的父亲是U。
```

每条完整课程1,310次输入。每句起始时间相隔0.8模拟秒，共1,048模拟秒（17分28秒）。重复块中不插入其他训练句，不加入人工噪声；测试只在独立副本中进行，不写回原教学意识。

## 内核和感官边界

直接使用`Config()`和`TextSensorConfig()`。当前内核causal/9；匿名分布式文本感官text-sensor/2，默认192通道、默认NFKC规范化、默认24字符分帧、默认帧间隔20,000微秒、默认增益1，输入强度1。逐字保留发送载体不等于禁止感官规范化。不会手动把全角标点换成半角，也不会为了保留全角而关闭感官规范化。

冻结感官、受体、内核和其他产品源码摘要及原生二进制摘要；每个阶段开始和最终验证时检查。每条实际落库帧必须等于同一默认感官对原句产生的结果。预检所有训练句都可由现有感官形成单帧；不修改帧宽来通过预检。

本次相较最近一轮同时纠正NFKC设置、补上家系句末句号。因此跨轮结果差异不能单独归因于其中一项。此次10条对话及其重复顺序保持不变。无论结果方向如何，都执行和报告同样的计划。

## 观察方法

恢复点设在第20、40、200、600、1,020、1,070、1,310次输入，家系互换保留最终恢复点；名词互换保留其中除1,020次外的6个点。每个重复块末记录实际教学计数和网络统计，最初第1、5、10次也记录。

主观察是连续状态副本：保留当前活动、时钟、在途信号，等待0模拟秒，测试期间学习仍开启。每个提示与无提示对照各用独立副本，从同一恢复点开始。辅助观察是结构出生副本：依据现有出生规则清空活动等运行状态；必须单列，不能作为同一持续意识的即时回答。

测量沿用既有工具和默认感官。强度1，观察0至1模拟秒，每20毫秒记录全部节点的零/非零激活。固定主要摘要为0.2至1秒的积分平均减同源无提示对照，同时报告0至0.2秒和完整曲线。饱和仅记录，不能用来取消教学或删掉结果。

- 配对提示`甲`、`乙`，比较松子/铃铛；在40、200、600、1,070、1,310次输入后测量。
- 问答提示`谁是松子？`、`谁是铃铛？`、`松子是谁？`、`铃铛是谁？`，比较甲/乙；从200次起在上述后4个点测量。独立测试提示不等于把训练原句拆开。
- 已教家系：1,020次后用C/F的爷爷、父亲问题及裸名字，比较A/B/D/E。
- 未见家系：最终用Z/W的爷爷、父亲问题及裸名字，比较X/Y/U/V；正常与家系互换对照分别按各自真实教学事实评分。

词投影只是一种外部测量：依既有工具排除模板重叠及提示直接触达的通道，仅影响评分，不裁剪原始活动。模板没有剩余通道时记为无法评分，不填零。所有候选、正负差值、并列和无法评分项都保留。不根据结果选择观察窗或模板，不让AI编造文字回复。

同时用现有只读诊断区分原出生连接的延续与同端点重新生边，并比较完整问题提示与无提示对照的全部匿名节点激活。这些诊断本次预先列入；不额外运行模拟、不据此修改内核。检查局部状态不等于给模型施加“保护”或语义指导。

主要报告每个种子、每条提示的数值和对照方向。关系组合除了孤立的祖父候选领先，还须检查是否随互换事实改变，是否区分父亲/爷爷问题。小样本不做确认性显著结论，也不将读出失败等同于证明不存在任何内部表征。
