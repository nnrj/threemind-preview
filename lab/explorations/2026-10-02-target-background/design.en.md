# E24: target response, local convergence and matched physical backgrounds

Preregistered 2026-10-02 before new simulations. Preserve E23 evidence, global criteria, Core and production mappings. The user authorizes both improvements and accepts small telemetry-driven dynamical changes that leave the target result intact as ordinary environmental feedback.

## Tools and historical calibration

A read-only tool accepts complete saved samples and explicit target node IDs. It measures peaks, integrals, duration, recurrence and endpoints, separately from local pattern convergence and local steady activity. Stable proportions are not stable amplitude. Defaults: uninterrupted 800 ms, total-variation drift <=0.08, relative amplitude span <=0.12, normalization floor 1e-8. Reporting tolerance 1e-12 never trims raw values. Gaps cannot establish sustained stability. Preserve global classification, censoring and baseline provenance under a separate tool version. Targets are nodes for registered A/B channels, never selected from winners. Reanalyze the 96 E23 dense probe conditions without retraining; unavailable windows remain unavailable rather than zero.

## Matched backgrounds

Retain the full E23 continuous-memory/2 configuration, including forgetting, inhibition, depletion, fast connections and input competition. Four identity blocks: 100121–100124. Record one new 44-second physical tape per block with host/process/runtime telemetry, each sampled at 500 ms and intensity 0.2, with current smoothing, mapping and causal delay. Acquisition copies receive K=0.2 every 500 ms; K is excluded from the physical tape and subsequent three-background courses. Preserve raw values, mapping, timestamps and scope.

Conditions: real tape replay; matched random assignment; no background. For each random frame preserve delivery time, scope, number of channels, amplitude multiset, intensity and grouping, but randomly assign amplitudes without replacement to that scope's observed channel pool using a fixed independent seed. This breaks stable physical-metric/channel correspondence, not the common total-dose profile; it is not independent white noise. Never inspect the network to choose channels. This is an explicit research intervention, not a production mapping change. The intentionally absent background cannot be dose-matched to the other arms.

Repeat the established 12 AX/BX pairs, both AB and BA order, 550 ms pair spacing, 50 ms within-pair spacing, 40 ms initial offset, intensity 0.4. Supply common Y=0.2 at 7 s. Clone trained states; wait 1 or 30 s, cue X=0.5 or no cue, observe 5 s. Background spans training, waiting and testing. This gives 24 training and 96 probe cases. Primary task metric is cued-minus-uncued A/B process integral, then later-taught minus earlier-taught, threshold 1e-6. Report both directions. Use the reusable tool's left-hold integration, with E23 trapezoidal integration separately for continuity. Retain convergence-time and endpoint rankings; unavailable is not zero. Analyze truncated pairs over their shared early interval separately, without calling it a complete five-second outcome. Death is a background effect, not zero memory.

Additional 12 cases: one historical E23 block, both trained orders, three testing backgrounds and cued/uncued copies, 1-second wait. This isolates expression-stage background from the full-course comparison.

## Live observation load

Four blocks, balanced AB/BA parent order. Randomize minimal/dense observation order in advance. Each copy runs 6 physical seconds, fixed K maintenance and X=0.5 at +1 second; all three telemetry scopes as above. Dense observation serializes full state every 20 ms, minimal uses common basic observation; identical advancement boundaries. Measure total process CPU separately from advancement-thread CPU and advancement wall time; do not bill readout as Core time.

Replay each of 8 actual tapes twice: exact input replay with common V2 observation and matching complete final Core hash; then the same physical tape with only X removed for a matched offline cue contrast. The latter is an intervention, not a claim that the uncued physical closed loop would generate the same tape. Total 8 live plus 16 replay copies. Compare input variation, replay sufficiency and target effects. Different states with the same target direction are acceptable. A changed direction prompts input/dose analysis, not automatic bug or quantum attribution. No repeated delayed-choice or physical quantum test.
