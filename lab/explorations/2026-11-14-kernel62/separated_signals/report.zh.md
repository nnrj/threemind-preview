# R51t12：分离激活与抑制状态，未恢复前缀区分

2026-11-15。内核：ThreeMind6.2。科研记录：`b6725bdc-406d-5ae8-9981-67e071bc7424`。

**结论：保留抑制学习时，单独或组合分开基础权重、突触资源和学习记录，均未恢复本批前缀区分。** 两套配置、每套六组，各为0/2教材通过。分离功能已实现并通过工程核验，但本次实验没有为开启它们提供能力收益依据；默认仍全部共用。

## 目的与预期

此前R51t11发现，即使关闭显式抑制学习，抑制传导仍会刷新连接使用时间，进而影响保持与后续共同刺激强化。在特定抑制传播配置下，取消这项记录可以恢复前缀区分。作者据此提出另一条路线：保留抑制学习，让激活和抑制分别使用自己的权重和资源。随后又批准分开学习记录，并要求同时衡量性能代价。

本批预期是：如果两类信号共用状态是本装置丢失前缀差异的充分原因，分离相应状态应使两个前缀各自唤起正确结尾。结果未达到该预期，所测分离方案不是本装置的恢复办法。

## 实验方法

我们在两套固定配置中分别比较六组。P沿用6.2默认的单年龄逆对数衰减、到达窗口新颖性和0.0004连接门槛；S采用此前定位时使用的稳定度保持、即时新颖性及0.004激活连接门槛。S的抑制连接门槛仍为0.0004。两套配置的节点发送门槛、抑制学习、两类权重强化、资源释放前检查和活动到期维护均保持原规定。

每组使用两套交换结尾对应关系的教材。每个新个体连续教学212.2内部秒，保存完整父体，再建立AB、DB两个诊断副本。测试用相同B提示衔接不同前缀，连续记录15秒过程，每10毫秒记录激活、抑制、直接激活和联想激活，共1502点。教学不逐题恢复。统计单位为两个教材区组，72阶段和48段过程不是72或48个独立重复。

预设标准为：共同B之后，正确结尾的激活峰值减另一结尾峰值须大于1e-6；AB和DB均满足，教材才通过。两教材全过才称恢复。只有通过者才进入新编码检验。全部组均未通过，因此按事前规则结束，没有追加新编码批次或扩大参数搜索。

仅分开权重时，保持和使用记录仍共享；分开学习记录时，两类信号分别更新短时增强、资格迹、稳定度、保持时间尺度、衰减年龄和使用记录。分开资源时，每一池保留原容量，因此同时改变了消耗隔离与总容量。完整定义及总、子开关优先级见[实现说明](implementation.zh.md)，运行前方案见[协议](protocol.zh.md)。

## 结果与解释

| 条件 | P：默认保持配置 | S：稳定度保持配置 |
| --- | ---: | ---: |
| 全部共用 | 0/2 | 0/2 |
| 仅分开资源 | 0/2 | 0/2 |
| 仅分开权重 | 0/2 | 0/2 |
| 分开权重和资源 | 0/2 | 0/2 |
| 分开权重和学习记录 | 0/2 | 0/2 |
| 全部分开 | 0/2 | 0/2 |

所有48段诊断记录完整，评分中不存在因缺样而判失败的情况。P中各组均有一条提示的正确结尾分差为负，另一条为正；S也如此，只是偏向反转。以教材0为例，共用组P的AB/DB分差分别为−0.000133286和0.000133321；全部分开后为−0.000191893和0.000189921。S共用组分别为0.001558728和−0.001558713；全部分开后为0.001272596和−0.001272573。教材1的对应评分相同。

这意味着系统仍偏向同一结尾，没有根据不同前缀正确改变结尾响应。分离确实改变了传输和连接状态。例如P配置下，资源单独分离使本组六阶段的抑制传输量合计从7.076增加到18.798，但前缀判据仍未通过。增加传导或独立保存记录，没有自动保留所需的关系差异。

**科学判断：本批否定了在这两套配置下，仅靠所测状态分离就能恢复前缀区分的假设。** R51t11已经成功的研究配置使用了不同的抑制传播与使用记录处理，其结果保持有效。本批将“分开存储和更新”与该成功组合区分开，缩小了后续机制定位的范围。

正式实验72阶段的推进与记录耗时合计163.51秒；宿主总历时215.89秒，私有提交内存峰值99.69MiB。两套配置中全部分离的最大完整状态分别为约1.16MiB和0.91MiB，共用组约0.79MiB和0.62MiB。运行没有触发资源停止。性能结论适用于这批材料及32节点基准；大型具身网络的成本需按其实际活动量测量。

**对6.3的建议：当前不宜以恢复前缀为理由默认开启这些分离项。** 保留本次实现用于明确的后续对照；若后续证实某一分离确有收益，可优先减少重复状态投影、改善分离状态的存储，并简化最终不需要的配置组合。本批没有修改默认，也没有开始6.3优化。
