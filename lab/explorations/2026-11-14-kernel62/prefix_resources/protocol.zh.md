# R51t9：突触资源、发送门槛与前缀区分

2026-11-15，运行前协议。本批由作者提出：保留先释放突触资源、再检查信号量的顺序，检验降低门槛或增加可用资源能否恢复前缀区分。作者随后要求同时考虑节点发送门槛及弱活动长尾。本批只运行研究个体；正式6.2、默认值、旧原件、论文和已暂停的全面复验均不改。

## 问题和明确的完成目标

前缀区分指同样接收B时，先前的A或D使系统分别偏向教学指定的不同结尾。区组0教授A→B→C与D→B→E；区组1交换C/E。每个区组的AB和DB两项提示都须正确。只把某个结尾普遍放大，不能完成此目标。

1. **检验作者的解释。** 保留资源释放在前，降低连接信号量门槛、加快资源恢复，或二者结合，能否恢复前缀区分？若至少一个配置在两个区组的两项提示中均通过，明确结论为该方案可以在不恢复释放前筛选的条件下恢复前缀区分。若全未通过，明确否定本批所测范围内“这些调整足以恢复”的预期。
2. **分清两种门槛。** 单独改变节点激活/抑制发送门槛，比较它们是否改变上述结论及成本。连接门槛作用于资源释放后的信号量；节点门槛决定是否继续安排发送。两者不能合称同一个参数。
3. **检验适用配置。** 稳定度保持＋即时新颖性用于衔接R51t7/R51t8；另在6.2当前默认的逆对数衰减＋到达窗口新颖性下进行对应比较。两类结果分别报告。
4. **检查弱活动长尾。** 从完整教学父体建立无后续刺激的诊断副本，比较默认条件与门槛关闭、恢复加快条件的300秒活动及计算成本。此项测有限窗口内的活动，不把300秒末仍有活动说成永久活动。

另一种竞争解释是：问题还涉及抑制传播对各条连接的作用方式。若全部当前传播配置均失败，再运行事先列出的三个旧抑制研究对照。这个条件分支用于判断“只调门槛和资源”是否还缺少传播条件，最多三配置，不无限追加参数。

## 完整个体、教材和分支

沿用已核验R51t7的两个交换教材区组、匿名编码、刺激强度、时序、背景和212.2内部秒连续教学。每个配置从新建完整个体开始，保存初末完整状态、输入记录、时钟、队列、随机状态、节点和全部连接状态。这里没有可训练的读出器、身体或执行器；完整系统为内核、声明的输入重放及被动过程测量器。它是机制定位装置，不能把它说成共同培养形色个体；也不额外加入改变原问题的适配器拟合或纠错课程。

为比较同一学习结果对两种前缀的反应，从212.2秒的完整教学父体分别建立AB、DB研究副本；正常父体保留。每份副本等1秒，给予第一个提示，再隔1秒给予B，观察15秒。测试仍按原方案允许局部学习，单个副本内部时间连续。尾部观察另建研究副本，停止外部刺激且不重置内部状态。这些是事前声明的因果诊断分支，不是普通考试逐题恢复，也不是新增独立样本。

两个区组是开发定位材料，配置、提示、快照数量均不充当独立N。本批不冒称新材料确认，不重跑已结项的旧对照。已有四份完整配置参照复制后逐文件哈希核验；原件不改。

## 冻结配置

`study_resources.py`中的完整配置表与源码一起冻结。所有新配置都关闭资源释放前筛选，保留固定函数寻址、抑制以及两类成功信号的权重强化。

| 因素 | 条件与含义 |
| --- | --- |
| 保持与新颖性 | 稳定度保持＋即时新颖性；6.2默认逆对数＋到达窗口 |
| 连接信号量门槛 | 0.0004、0.00004、0；同时用于激活和抑制，独立覆盖值维持未设置 |
| 资源恢复 | 原恢复时间常数0.8秒；加快为0.08秒；关闭耗竭作为资源始终充足的上限对照 |
| 节点发送门槛 | 默认激活0.004、抑制0.002；分别关闭或同时关闭的指定对照 |

两种保持配置分别完成3×3连接门槛与资源条件，共18配置。其中2份默认参照复用，新增16配置。稳定度组在连接门槛0.0004/0、恢复时间0.8/0.08秒的四条件下同时关闭两种节点门槛；默认保持组在连接门槛0、恢复时间0.8/0.08秒下做两条件。稳定度组另在连接门槛0、恢复0.8秒时分别只关闭激活或抑制节点门槛。合计24新配置、144阶段。

资源总量在现实现中被归一化为1。“增加可用资源”在此具体落实为加快恢复；不把数值总量另增到1以上。关闭耗竭仍按0.5的利用率释放，传导比例为0.5，不等于关闭整个突触资源算子。此对照提供上限，不能把它当作保留了正常资源耗竭。0.08秒为有界、十倍变化的探索条件，不声称是生理最佳值。

节点激活归零下限`activation_floor=0.004`不变，`propagation_activation_min=0`不变，旧的抑制发送量门控仍关闭。因此把节点发送门槛设0并不代表取消所有微弱活动处理。连接权重门控仍关闭。完整配置随每个状态保存。

若24新配置均未恢复，追加旧抑制传播的三个隔离研究配置：连接门槛0＋恢复0.8秒、连接门槛0.0004＋恢复0.08秒、连接门槛0＋恢复0.08秒。保留先释放后检查的激活路径。旧抑制本身使用邻接权重分配，不消耗这份连接资源，其既有抑制门槛不跟随通用连接门槛；报告须说明这一差别。原旧抑制低门槛参照复用。最多18阶段。

尾部观察固定选择稳定度组、默认保持组的原参照及“连接门槛0＋节点门槛均0＋恢复0.08秒”，每种两个区组，共8副本。观察0、1、5、10、30、60、120、300秒；网络按自身死亡规则死亡则记录正常终止。此项不根据前缀成绩挑个体。

## 测量、判定与解释

主指标沿用原门槛：B到达后的过程里，正确结尾的激活峰值减错误结尾的峰值须大于10⁻⁶；AB、DB均通过才算区组通过，两区组均通过才称恢复。峰值窗口、教材和分母不随结果改变。

保留每10毫秒的激活、抑制、直接及联想活动，分别计算峰值、积分和末值；教学每100毫秒记录任务节点、连接权重、资源、快速状态和传输累计量。另列最大激活、结尾选择差异、被门槛截去的信号量、已传输量、运行时间、峰值内存与证据体积。通过率与激活总量分开，增强全部结尾不算区分成功。

对突触资源作同一内部时刻的被动恢复换算后再比较；禁止把不同更新时间的缓存值当作同时刻可用资源。两因素交互同时报告每个区组的差分，不以两个教材区组做群体显著性推断。资源变更会影响实际传播、抑制及后续学习；因果结论对应整项声明干预，不预先把结果归因于“权重增益被抵消”这一尚待检验的细节。

Python与Rust在独立编码的5秒装置材料上核对；观察、保存恢复、暂停和不同推进分段应给出相同完整状态。正式阶段使用已安装原生6.2；仅条件性旧抑制使用现有隔离研究实现。独立只读复算检查完整状态、分支谱系、过程和判定。

## 生物学启发的定位

Tsodyks与Markram的原始研究把资源释放比例和恢复速度作为短时压抑的决定因素，支持把它们分别作为本批实验因素。[PNAS 1997](https://pmc.ncbi.nlm.nih.gov/articles/PMC19580/)。该工作不证明ThreeMind当前的节点发送门槛、连接硬门槛或预检查顺序具有相同的生物实现。本批首先检验计算模型内可观测的作用；关于“自然”的评价另与实际效果区分。
