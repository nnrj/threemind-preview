# 冻结校准决策与执行说明

实验方案先保存到新项目的实验笔记，再执行校准；校准材料与正式验证材料分离。

| 探针强度 | 符合事先规定物理可观测性条件的提示案例 |
|---|---:|
| 1 | 3 / 16 |
| 2 | 16 / 16 |
| 4 | 16 / 16 |

因此固定强度2；没有根据目标词评分选择强度，没有更换内核门槛、编码映射或192通道默认值。校准和验证均使用完整匿名活动原始证据，文本只是外部观察标签。

首次校准尝试中，第一个父本和7个探针副本已成功计算并保存。脚本随后在累加 PostgreSQL 返回的数值字符串时发生类型错误（`int += str`），尚未写入用于分析的案例列表。这是新研究脚本的预算记账问题。修复为显式整数转换，保留首次结果文件、父本、检查点、校准记录和所有证据。完整校准在新尝试文件重跑全部8个父本；正式分析只用预先指定的完整尝试，未挑选其中更好的结果。该修复不触及 Core、刺激或评分。

`calibration-decision.json` 固定剂量与完整校准结果哈希。平台中的每次校准都绑定明确检查点、原状态哈希、感官配置、编码种子和协议；完整证据包包含初态、终态、原始节点轨迹、真实输入和到达事件。复制模型上的观察与无观察执行已分别在 Python 和 Rust 路径验证最终哈希一致。

配对阶段完成后才启动关系阶段，后者使用另一组编码种子和未见名字家系。统计时把种子作为块，完整平均块内指定条件；不把数千个副本或大量采样点当成独立被试。

本轮没有修改内核动力学，没有自动清理任何数据库实验数据。旧项目900个模型的编号、修订号、状态哈希及状态有整体摘要核对。预算以实际数据库增长和载荷加查询投影估计的较大值计，另计本地证据文件；4 GiB 是上限，不是目标用量。负结果、零结果和程序性失败同样保留。
