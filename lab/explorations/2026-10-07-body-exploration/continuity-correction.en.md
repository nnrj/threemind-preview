# E61 correction: the tested system changed between stages

2026-10-07, corrected after the user's objection. All original simulations, measurements and failed attempts are retained.

**Withdraw the interpretation that E61 found no consistent preschool benefit in a continuously developing Core plus Transformer. This experiment did not validly test that question.**

Preschool used fixed anonymous motor wiring and separately recorded motor variation; teaching used teacher-applied body forces; a newly initialized Transformer was then fitted to teaching records and connected for testing. Core continuity is not whole-system continuity. The caregiver W2 correction repaired a separate wiring reset, not this main pipeline error.

This is a design error relative to the requested experimental subject, not a minor limitation to disclose at closeout. Applying the same segmented pipeline to every group does not make it a test of continuous joint development. This correction governs conflicting interpretations in the earlier report/stage notes.

## Retained observations and required reruns

- Toy contacts, sensory feedback, pointing scores, commands and trajectories remain measurements of the actual segmented pipeline.
- Interventions retaining the same saved adapter while changing Core connections/output can test Core's behavioral contribution to that fixed combination. They do not establish continuous joint-development effects.
- Whether preschool improves subsequent learning, fixation and pointing in the same Core and Transformer requires a rerun.
- These low scores do not justify abandoning preschool, declaring the Core incapable, or concluding that separate adapter fitting is sufficient.

## Execution requirements

Preserve Core, Transformer weights and optimizer, random state, recent readout history, body state and sensory/motor mappings together. Replacement, reset, freezing or bypass must be disclosed before execution as a separately approved intervention, never folded into ordinary development. Assessment may clone the complete system; it must not clone only Core and attach a newly fitted adapter.

The user subsequently allowed closeout now and reruns in the next phase. No rushed long simulation is added to this study. First audit history, preserve evidence and register the integrated rerun. Physical background, teaching, dense-to-spaced review and hand mass/wind calibration remain required.
