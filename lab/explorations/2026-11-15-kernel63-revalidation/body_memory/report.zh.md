# R63c：6.3保留身体经历，并通过相关连接唤起对应响应

2026-11-15。按全面复验计划v2，以6.3重新进行E18身体经历及过程读出实验。正式材料有4个独立编码区组；区组内的配置、等待时点和干预副本均为配对比较，不计为新的独立样本。16个装置校准条件与正式材料分开，正式计算共616个阶段。

## 目的与预期

本批检验：感官与身体的共同经历能否被保留，在等待1、60或300内部秒后由提示重新唤起；唤起的响应是否依赖经历形成的相关连接。预期受训条件保留教学方向，未训练条件无相应响应；阻断目标连接应破坏表达，阻断匹配连接影响较小，立即解除阻断后恢复。

每区组保留普通与易化两种配置，以及完整感官、去除惯性感官、剂量匹配、打乱惯性感官和未训练五种条件。使用冻结的身体运动及感官输入材料；教学后从完整状态建立登记的研究副本。等待期间保留每0.5秒一次的独立背景刺激K。读出器被动记录激活、抑制、直接激活和联想激活，不参与学习，也不改变内部时间。

原生分析器在收敛时点读取目标节点；过程指标则在完整5秒轨迹中，扣除对应无提示轨迹后，比较两个目标节点的激活积分。两种测量均在开始前规定，分别报告。

## 结果

| 比较 | 结果 | 回答的问题 |
|---|---|---|
| 受训个体的过程响应 | 192/192符合教学方向 | 经历在三个等待时点均可被提示唤起 |
| 未训练参照的过程响应 | 0/48 | 相应响应来自教学经历 |
| 300秒后的目标连接阻断 | 0/32保留对应响应 | 相关连接承担表达的因果作用 |
| 匹配连接阻断 | 32/32保留对应响应 | 作用具有连接选择性 |
| 立即解除目标阻断 | 32/32恢复，完整末态及过程与参照相同 | 解除阻断恢复表达 |
| 原生收敛时点读出 | 0/240；全部为收敛时目标未被唤起 | 该时点读出未捕捉到此前出现的目标响应 |

受训条件在普通、易化及四种感官教学方式下，每个等待时点均为8/8。300秒提示开始前，目标节点的当前激活、抑制及直接激活均为零；记录的联想活动量最大为0.00114034。提示后，完整过程再次出现教学对应的响应。因此，静息时没有目标激活与经历仍可被唤起可以同时成立。

四种受训感官方式的过程成绩均为满分，本批没有显示惯性感官在这一指标上的额外收益。身体感官输入本身触发的响应方向与迁移能力，将由后续身体迁移和惯性反向实验另行检验。

## 科学结论与意义

本批在6.3复现了身体经历的保持、提示唤起和连接选择性的因果作用。只看收敛时点会漏掉已在响应过程中出现的信息；保存完整时间过程能明确识别这些信息。本批测量的是有背景输入条件下的经历保持，300秒等待后的可唤起性与无外部输入的持续活动分别研究。

这些结果说明，微弱激活及时结算修复后，ThreeMind仍能保留经历，并通过相关连接将其重新表达出来。原生收敛读出未达成目标的结果继续保留，不用过程读出的阳性改写它。没有触发新不利矛盾或资源停止条件。

## 核验与成本

1264份完整初末状态、632段轨迹和父子承接核验通过。336次有提示探测的四类活动由45位精度的独立算术复算，最大绝对误差为1.74×10⁻¹⁸，全部判定一致。冻结源码、实际原生模块及输入材料的散列均通过复核。

正式宿主耗时2089.31秒，约34.82分钟；含校准的逐条件计算合计1315.24秒。私有内存峰值947.29 MiB，分析前原件实际分配258.91 MiB，均在冻结预算内。逐条件耗时为6.1历史记录的93.33%；该比较没有控制两次运行的宿主负载，不能据此认定同幅度的性能提升。

事后只读比较覆盖632个条件：采样时点、生命周期分类、过程判定和原生判定均与6.1相同；激活积分及峰值完全相同，四类活动完整轨迹的最大差异为2.78×10⁻¹⁷。比较结果另存于historical-comparison.json，不参与本批判定。

证据位于body-memory-63-rerun-v1：frozen.json、cases/、analysis.json、arithmetic-verification.json、historical-comparison.json、audit.json及publication/completion.json。原包与报告经科研API完整读回且pending=0后结项，再进入五系统比较。历史实验及其原件保持原样。
