# R63d: eight-group replication of the four autonomous-activity criteria on 6.3

Verification completed on 16 November 2026. This batch repeats the eight-group X3 comparison under comprehensive revalidation plan v2, using the current 6.3 defaults and the frozen implementations and learning procedures of four controls. Registration and computation took place on 15 November. Eight independent origins provide five systems each, for 40 system units. The subsequent 64-origin confirmation will be registered separately and will exclude these pilot origins.

## Purpose and methods

The experiment asks whether the same anonymous teaching materials and circular bodily environment support experience dependence, selective internal causality, temporal interaction and feedback adaptation in ThreeMind. Each system completes two continuous teaching histories with opposite pairings. Registered research copies undergo target blockade, matched blockade, sham intervention, restoration or interruption of internal communication. Complete response processes are compared under identical cues.

Closed-loop courses preserve each system's model, personal readout and learning state, random state, body, input and recent activity. Output changes position, which determines the next sensory input. Matched input replays and reversed action directions distinguish input effects from closed-loop feedback. Apparatus checks passed for observation, host pauses and complete save/restore in all five systems.

The original X3 measures, windows and thresholds are retained. Each criterion requires at least six of eight origins to pass. The number of origins satisfying all four criteria simultaneously is reported separately. Connections and readouts were not selected or adjusted from test outcomes.

All eight ThreeMind origins jointly pass, whereas no control origin does. The recurrent network passes temporal interaction in five of eight origins, below the preregistered six-of-eight threshold; it passes experience dependence and feedback adaptation. Every system's criterion counts match the historical eight-group 6.1 replication.

Target intervention changes ThreeMind's corresponding responses under both teaching histories. Matched and sham interventions leave the relevant difference unchanged, and restoration error is zero. All Core matching checks pass. Independent numerical replay verifies all 16 recurrent-network teaching histories and matching selections. Their largest standardized matching residual is 0.36473, below the 0.5 limit.

## Scientific conclusion and significance

Across all origins in this batch, 6.3 forms autonomous activity that depends on experience, has internal causal support, allows successive inputs to interact and is reshaped by environmental feedback. The controls exhibit subsets of these properties; only ThreeMind exhibits all four jointly. This reproduces the functional distinction tested by the original eight-group apparatus and shows that timely weak-activation settlement preserves joint performance in these courses.

The registered objectives are met, with no new adverse contradiction. The next batch uses 64 new origins for independent confirmation with the same measurements. Its thresholds will not be changed in response to these pilot scores.
