# E49：意识的变化能读出来，但表达器必须学会跟上

2026-10-05。已完成。[English](report.en.md) · [登记](design.zh.md) · [逐项结果](results.json) · [工具](../../../docs/zh/reference/bus-expression.md)

**这轮找到了一个可以修好的实际障碍：小 Transformer 连已经给过它的表达样例都没有充分学好。调整外设训练方式后，三个意识来源的已教对应、新视角命名达到24/24；追加教学后跟随校准，两个来源在新视角及再过60模拟秒的测试都达到4/4。Core公式、默认值和感官映射没有修改。**

**但冻结表达器直接读出没教过的新对应，仍然不可靠。** 本轮证明了有限词语表达可以变得可靠、表达器可以跟随意识变化；没有完成新关系的自主迁移、组合推理或自然对话。它不是对ThreeMind能力上限的判定，也没有撤回此前海洋中的机制干预证据。

## 1. 做了什么，什么没有变

重用E47/E48原始证据，来源223、251、279，四物体与四个名字。三个来源的Core种子、教学顺序不同，输入外设和匿名通道接线同为71；不能把它们当成任意异构意识的代表。主材料为每条2秒过程中的17个采样点、119匿名通道及存在标志、激活、抑制、痕迹、支持度、稳定度。原始量不减无提示副本、不逐样本归一化。

表达器是从零训练、195,264参数的小Transformer，输入为匿名状态，输出为文字字节。训练时允许给目标词；推理时没有题目、来源编号、对应答案、人工时序标签或对话缓存。没有读取数据库中的答案作回复。视觉同一物体的新视角和强度组合留出：校准视角8/10、强度0.4/0.6，检验视角9、强度0.5。

沿用`continuous-memory/2`、普通教学强度1、抑制、局部耗竭/恢复、遗忘、生命规则及已有强刺激额外项。背景重放先前采得的真实物理遥测，保留环境输入，又避免本轮读出负载反馈进刺激。无提示指没有当前物体提示，**不等于完全没有外部背景**。

后续分支均先追加登记：[跨状态与纠错](followup-registration.zh.md)、[重新教意识](reteaching-registration.zh.md)、[交替校准](joint-registration.zh.md)、[共享表达器](shared-registration.zh.md)。循环1被加入校准后明确改称“已教”，先前未教成绩原样保留；循环2仍留出。没有把改过课程的结果倒填成原先的盲测成功。

## 2. 总线不是这次失准的主因，旧观察压缩确实丢信息

| 核查 | 结果及范围 |
|---|---|
| 原输入直接递送与默认InputBus | 代表性样例的队列、最终状态、轨迹相同；观察标签不进Core。显式配置的输入策略仍可按协议调整准入，不声称所有策略都透明 |
| 八条真实探针直接读取与OutputBus | 每条101帧，节点数据及时间全部相同 |
| 原语言`ProcessFeatures` | 只提取正激活、哈希合并通道、按时间箱汇总。构造对照中，改变抑制或交换箱内先后，最终特征可以完全不变 |
| E48原始表达路径 | 已经直接保留这些原始节点量。因此旧压缩器的损失不能解释E48全部欠拟合 |

新增`RawActivityStream`把完整观测节点帧经OutputBus交给外设，不按激活排名裁切，不补语义。它不是全连接快照协议；表达投影仍显式选择字段和采样点，原始101帧另存，20ms以下的过程本轮未观测。接口只读，不推进内核。

因此，**正确修复位置包括观察和外设训练，不需要先改Core动力学**。[审计证据](audit.json)保留了有限实例验证和压缩反例。没有反复重扫旧大数据。

## 3. 一个明确增益：把小样本真正教给表达器

此前训练每步有放回随机取样；新工具的小样本默认每步使用全部教学样本，保证每一条都参与更新。输入、模型结构、学习率和损失定义保持，改变的是外设训练的批次组织；选模型只看训练准确率及训练损失。

| 来源/方法 | 训练拟合 | 已教原对应＋反对应，新视角 | 再过60秒，原对应＋反对应 |
|---|---:|---:|---:|
| 223，有放回取样，2500步 | 12/16 | 6/8 | 见完整记录 |
| 223，全批均衡，2500步 | 16/16 | 8/8 | 1/8 |
| 251，全批均衡，1500步 | 16/16 | 8/8 | 7/8 |
| 279，全批均衡，1500步 | 16/16 | 8/8 | 4/8 |

后两来源沿用首来源已选的方法确认，不按它们的测试答案继续调参。三个个人表达器当前时点合计24/24。一次小MLP诊断只拟合9/16，没有因此继续无边界搜索。学习率和初始化等原备选没有全部展开，因为均衡训练已解决标定障碍。

这不是“大模型猜出了答案”，也不是内核学会了整套自然语言。具体收益是：**同一物体在不同已教对应下，小表达器现在能依据内部状态输出相应名字；已教状态的新视角表达可用。** 此时还不能单独决定它读取的是哪一类记忆机制，需结合干预验证。

## 4. 晚一点读错，并不自动意味着记忆消失

223来源，532秒校准的表达器在592秒只有1/8。**不重教、不改动该意识或原始轨迹，只换外设校准材料为592秒的教学视角，留出视角恢复8/8。** 同时覆盖266/326秒正常、532/592秒继续和反转的48条校准材料，六组留出题24/24。

这里定位到了表达器覆盖不足：这些晚期状态仍有可用的区别。它不等于证明所有原记忆完整保留，也不能由分类成功单独证明某个长期连接承担了记忆；但足以排除“固定解码器读错，所以该意识已经全部忘掉”的推断。反向也有代价：只在592秒校准的表达器回读532秒仅2/8，状态覆盖不能靠只追逐最新样例解决。

因此，本轮**没有根据失准现象直接调小遗忘率**。遗忘仍是所需机制。后续若在可靠读出和完整状态指标上仍发现过快丢失，再做独立参数对照。

## 5. 允许纠错；分清纠正的是谁

先只教外设新对应：223来源在循环1未被表达器教过时，新视角1/4；把循环1教学视角纳入校准后，继续已有表达器和从零训练均达到4/4。279的同类继续校准达到3/4。未教循环2仍低，不能把外设收到目标词后学会的对应说成Core独立完成了关系迁移。

再**真正继续教意识**：从两个来源相同592秒父状态复制，分别仅背景等待、48次均衡复习、48次针对错项复习。先密后疏，普通强度1，使用原图像和原短句；不向Core输入“答错了”标志，不修改连接。此时表达器冻结。

| 来源/处理 | 650秒正确名字 | 710秒正确名字 |
|---|---:|---:|
| 223，只等待 | 1/4 | 1/4 |
| 223，均衡复习 | 3/4 | 3/4 |
| 223，针对错项复习 | 3/4 | 2/4 |
| 279，只等待 | 2/4 | 4/4 |
| 279，均衡复习 | 0/4 | 0/4 |
| 279，针对错项复习 | 0/4 | 0/4 |

**一个来源只通过重新教意识就改善了表达，另一个却无法用冻结读法看见改善。** 不能只报道前者，也不能把后者0/4称为新教学清空了记忆。[完整复习结果](reteaching-results.json)保留所有错词、无提示词和存活状态。此处不是两组群体统计。

最后让外设跟随新经历：固定选择两个均衡复习分支，710秒另取8条校准视角，与旧24条一起训练；既有710秒检验视角始终留出。再仅给相同背景走到770秒，不教这一时点。

| 来源 | 跟随校准前，710秒 | 外设继续校准后，710/770秒 | 外设同资料冷训练后，710/770秒 |
|---|---:|---:|---:|
| 223 | 3/4 | 4/4、4/4 | 4/4、4/4 |
| 279 | 0/4 | 4/4、4/4 | 4/4、4/4 |

四个表达器均拟合32/32，同时保住旧原/反对应532秒8/8及循环1新视角4/4；部分未纳入的旧时点仍会读错。继续校准在1000步停止、冷训练在1500步停止；继续者已经有前期训练，不能说总训练成本一定更低。

**这是“意识接受教学—语言外设跟随学习”路线的实际增益。** 它没有预设每次学习必须第一次答对，也没有要求百分百还原复杂思想。它仍是教师监督下的交替校准工具验证，尚非无人提供表达样例的共同演化。

## 6. 一个表达器能不能跨意识使用？这次可以一部分

只用223与251原/反对应共32条训练一个共享表达器，不给来源编号。已教两来源新视角合计16/16；**从未用于表达器训练的279来源也为8/8**。三个来源晚期各6/8，循环1分别1/4、2/4、2/4，循环2均0/4。

因此不应现在锁死“每个意识必须一个完全独立表达器”。**共享基础表达器，再按经历补充校准**值得继续；完全异构接线、更多个体和复杂句子还没有验证。输入接线相同是这一结果的重要适用条件。

## 7. 以前验证的好机制有没有被丢掉？

核对[实际生效配置与创建默认](effective-mechanisms.json)，通过配置类恢复序列化时省略的默认字段，避免把“文件里没写”误认成关闭。本次核查范围是本语言主线引用的机制和近期参数增益，不冒称穷尽所有历史假说。

| 机制或改进 | 当前及本实验状态 | 本轮决定 |
|---|---|---|
| 局部能量耗竭/恢复、连接巩固、可塑性 | 开启；恢复常数0.8秒 | 保留 |
| 连续版短时连接、局部竞争 | `fast_enabled`、`context_enabled`开启 | 保留；不与另一种输入帧竞争混淆 |
| 局部新颖性 | `arrival-window`，增益0.018、参考0.2 | 已是默认，未遗失 |
| 强刺激额外巩固 | 系数0.075保留；普通输入1，强刺激预设4 | 按此前决定保留；普通教学没有借用强刺激 |
| 抑制、遗忘、传播巩固 | 开启；学习率0.055、传播巩固0.01、遗忘0.025 | 保留 |
| 额外易化1秒 | 独立研究预设存在；普通默认0 | 不普遍打开。E45该任务6/32，原默认7/32，尚无可普遍提升语言的依据 |
| 输入帧竞争、全局钳制 | 默认关闭，与局部竞争不是同一机制 | 不因“有这个功能”就一律启用 |
| 原始激活＋抑制及过程信息 | 本轮确实送给表达器，保留实际值 | 通过新的原始输出口继续使用 |
| 均衡外设训练、跨状态覆盖 | 本轮有明确增益 | 均衡成为新增校准CLI的默认；覆盖/交替校准形成可复用方案 |

E45学习率加倍和加快恢复均5/32，增强抑制7/32且辅助指标更差；这些旧结果用的是当时的评分，不能直接与E49分数跨表相减。[原报告](../2026-10-05-language-calibration/report.zh.md)保留。它们说明当前没有充分理由把这些候选全部默认开启，不是认定其在所有环境无效。

**本轮没有发现需补回的已证实通用Core增益，也没有产生足以修改Core默认的新对照证据。** 已证实的本轮工具增益已经落实到可调用接口；没有为了满足“应用增益”把外设训练收益伪装成内核升级。旧意识身份、旧公式和既有证据均保留。

## 8. 对目标给明确判断

| 目标 | 本轮判断 |
|---|---|
| 可靠表达教过的少量名字—物体对应 | **在所测新视角与已覆盖状态中实现**；输出是真实字节文本 |
| 后续教学能纠错 | **条件性实现**：冻结外设的一来源改善；两来源跟随校准都改善 |
| 表达器一定要每意识独占 | **不成立为当前必要条件**：相同接线的未教来源8/8 |
| 冻结外设，读出没教过的新对应 | **尚未实现可靠迁移**；主模型和共享模型未过事先门槛 |
| 组合推理、自然句子交流 | **本轮没有建立证据，复杂课程未启动**；不是已经做过而失败 |
| 无提示词就是可信内心独白 | **尚不能这样解释**。全部原词保留，没有强制空白，但四词外设偏置也能产生词语 |

下一步建议依次为：把共享基础＋个体持续校准用于更小的在线教学闭环；冻结新对应测试保留，同时增加“教后可修正”的测试；成功后再开展句式/关系组合及匹配的通路干预。需要进一步定位的是**持续变化的内部状态如何稳定表达新对应**，目前没有定位到必须更换Core公式的单一缺口。

## 9. 工程、资源和证据

新增原始输出接口、均衡/继续训练API与CLI、CPU解码与GPU回退路径。推理CLI拒绝混入教学目标；带清单的新检查点校验通道及字段顺序。旧生产聊天的协议和模型不静默升级，本轮工具可通过Python/CLI调用，并通过已有报告与证据页面查看；没有把一次实验模型直接设为所有意识的嘴巴。

102项新来源/分支/探针，14个Transformer表达器及1个MLP诊断。记录的模拟与训练时间合计上界526秒（包含少量重叠的审计计时），新工作归档前约144MiB。未用满256项/24训练/3小时预算；共享账户从48%到49%时停止新模拟，后续交付用量和全部归档/数据库空间见`publication-resources.json`。没有清理旧数据或调用付费模型。

验收包括八条代表性总线轨迹、已有原始投影与新总线测试、真实保存模型的CPU CLI解码、推理标签拒绝及错误通道顺序拒绝。[CLI验收](verification.json)。不做无关全库哈希扫描。双语笔记、报告、逐题原词查看器及证据包写入独立项目 **E49 总线与表达器校准**（`2bbb612d-ed99-4021-8886-c250e33727f7`）；完整源状态、轨迹、教学、模型、错误输出和来源依赖可追溯，旧E47/E48资料只引用、不覆盖。
