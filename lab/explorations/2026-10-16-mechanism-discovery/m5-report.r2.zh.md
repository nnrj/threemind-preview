## 实验目的、预期与研究范围

本批要区分两个解释：**新对应是 Core 学到了，并由已经固定的个人外设表达；还是主要靠外设重新学会“提示—标签”关系，才表现为会答题。** 同时检验读取范围是否会让已经学到的对应无法表达。任务限定为原生 `/5.1`、默认 H、两个熟悉回答标签与新的匿名提示；8 个独立出生来源，每源有两种相反教学历史。

试前先用旧课校准全活动、输出端口两种个人读取器，再同时冻结其尺度与权重，只向 Core 教新对应。若 Core 承担新学习，预期固定读头在新题改善、旧题保持，目标连接静默选择性损伤新题，匹配干预不损伤新题，恢复后答案返回；若表达失败来自读头，预期读取范围改变或继续校准会改变成绩，早晚活动与早晚读头交叉能够定位改变来自哪里。两个读头各自计分，不在结果后挑赢家替代另一项。

## 总体结论：有利结果，同时定位了表达瓶颈

**M5 对 ThreeMind 核心研究路线是有利的：本任务的新对应确实能够在 Core 中学到，并通过不再训练的个人端口读取器正确表达。外设并非每遇到新对应都必须重新学习。与此同时，实验否定了“旧课校准成功的全活动读取器自然就能表达后续新经历”这一做法在本任务中的有效性，并定位出读取范围造成的表达瓶颈。**

这项结论来自同一 Core 轨迹上的反差及干预，不是把“4 项达标、3 项未达标”相加后的总分。输出端口读头回答新单路题 64/64，全活动读头却为 0/64、全部 WAIT；二者旧题同为 64/64。新学习已能通过一种预先声明并固定的接口表达，另一接口的失败便不能归结为这个 Core 没有形成可用的新对应。

## 为什么两个读头表现相反

全活动读头从 12 维活动学习旧标签，端口读头只读事先声明的 A/B 回答端口；端口的标签含义也来自旧课校准，并非试后按答案挑出。给读头更多活动维度，没有在本次产生更好的新经历表达，反而允许旧课的提示表征主导读出。只读算术显示旧提示贡献占全活动旧题绝对贡献的 87.77%—96.31%，新提示维度的旧权重全为零，新题分数落在 WAIT 区间。这是原件上的机制解释，身份为事后算术分析。

决定性的因果证据来自不同层面：同一轨迹的读取范围比较说明瓶颈在表达接口；目标／匹配静默及恢复说明端口成功依赖相应的 Core 连接；早晚交叉说明外设续校准也可独自增加提示—标签对应。三者合起来，明确区分了**Core 学习后经固定接口表达**与**外设学习后识别已有提示表征**两条途径。

全活动续校准在未用于拟合的剂量上由 0/128 变成 128/128，证明这种表达瓶颈可以由追加外设校准补救；但其学习前活动也可被新读头正确解码，说明这个补救成绩不能单独归给 Core 的新学习。端口固定表达已经满分，续校准增益为零是没有新增收益，不能算成对 Core 机制的反证。

## 对 ThreeMind 的具体研究意义

**有利之处是核心路线得到一次直接的选择性因果验证：先教会个人外设如何表达熟悉答案，后续的新对应可以通过 Core 的经历改变形成，不必为每个新对应重训外设。** 这回答了此前固定个人表达失败所留下的关键能力问题。

**不利之处是表达能力并不自动随 Core 学习而出现。** 本批全活动读头在旧课上完全合格，却不能表达新对应；这暴露了接口设计和校准材料的实质限制。未来实验应把读取范围作为明确变量，并同时检验 Core 新学习与外设捷径。这里提出的是由本批证据导出的研究选择，不更换旧个体的读头。

本批是被动回答终端，同一轨迹并列记录读头输出，端口成绩是保存下来的真实表达结果；`actuator` 字段记录全活动读头，输出不改变下一题。因此这次解决的就是新经历的表达归因。联合提示另为端口 16/32，没有合并到单路满分；E69 的历史 WAIT 因果也仍按其自身材料另行检验。

## 首版证据与方法（原文保留）

2026-10-16。范围为原生 `continuous-memory/5.1`、默认 H、两个熟悉回答标签与新匿名提示的配对任务。8 个独立出生来源，各有两种相反教学历史。协议与评分冻结于 `1cee65d`；全过程没有修改 Core、旧个体、E69 或作者论文。[试前协议](m5-protocol.zh.md) · [English](m5-report.en.md)

**本批确认：Core 新学的对应能够经已固定的个人输出端口读取器表达，而且依赖相应的局部连接。相同旧课校准的全活动读取器没有表达出这些新对应；读头的读取范围确实改变了新经历的表达结果。** 这是本批完整验证的结论，依据包括相反历史、旧能力保持、固定权重、感官直读、可塑性组合开关、目标与匹配静默、立即恢复和早晚交叉。各目标独立判定，不以一个通过掩盖另一个失败。

### 目标、冻结判据与判定

每个来源必须在两种相反历史中同时满足条件；至少 6/8 来源达标才通过。主测每历史新、旧单路提示各 4 题，等总剂量联合提示另各 2 题。110 ms 是唯一主回答端点，普通题间不恢复。

| 目标 | 事前判据概要 | 实际结果 | 判定 |
| --- | --- | --- | --- |
| 全活动读头：固定表达 | 新题≥75%，比基线提高≥50个百分点；旧题≥75%，下降≤10个百分点 | 0/8 来源满足；新题 0/64，旧题 64/64 | **未达标** |
| 输出端口读头：固定表达 | 同上，另要求基线旧题≥75% | 8/8；新题 64/64，旧题 64/64 | **达标** |
| 全活动读头：Core 因果归因 | 完整参照比关可塑性及目标静默各高≥50个百分点；匹配新题与目标旧题损伤≤10个百分点；恢复误差≤1e-9 | 0/8；完整参照和干预新题均 0/64 | **未达标** |
| 输出端口读头：Core 因果归因 | 同上 | 8/8；目标损伤100个百分点，匹配新题损伤0，目标旧题损伤0，恢复误差0 | **达标** |
| 读取范围贡献 | 端口新题比全活动高≥25个百分点，端口旧题≥75% | 8/8；优势100个百分点，旧题全对 | **达标** |
| 全活动读头：继续校准收益 | 留出剂量新题提升≥25个百分点，旧题下降≤10个百分点 | 8/8；新题 0/128→128/128，旧题 128/128 不变 | **达标** |
| 输出端口读头：继续校准收益 | 同上，不为原来满分更改门槛 | 0/8；新题 128/128→128/128，收益0 | **未达标** |

64 是 8 来源×2 历史×4 题的嵌套计数，128 另含两种留出剂量；独立 N 均为 8。教学前的同一份基线每来源只有 4 个独特新题和 4 个独特旧题，共各 32 题；按两种后续历史分别评分时显示 0/64、64/64，不能解释为又做了 64 个独立基线题。

所有来源的主差异相同，按来源重采样的描述性 95% 区间为：端口学习、目标损伤、可塑性组合效应及全活动续校准收益各 [100,100] 个百分点；预定无关损伤各 [0,0]。这种退化区间只反映本批观测值一致。来源通过率的 Wilson 95% 描述区间为 8/8 对应 [67.56%,100%]、0/8 对应 [0,32.44%]。本批是预登记的探索队列，不进行事后显著性筛选或把题目当独立重复；预定 6/8 门槛及本表判定不变。

### 固定外设下的选择性因果链

个人读头先用旧对应 U/V→正、Z/W→负的 12 次校准学习。全活动读头接收 12 维原始 activation；端口读头仅保留预先声明的 A/B 回答端口，其正负含义同样由旧课校准学习。两者都是无截距岭回归，归一尺度和所有权重在新教学前固定；不是事后挑出表现好的端口。外设不接收题号、阶段、历史编号、标签或评分答案。

随后 Core 接受 X/Y 与 C/D 的新教学，两种历史的配对方向相反，而测试时当前提示完全一样。每条普通生涯连续；干预研究副本保全完整父体、个人外设及正规方程、全部旧样本、映射、随机状态、身体、近期轨迹和执行器。

| 条件 | 端口读头：新单路 | 端口读头：旧单路 | 全活动读头：新单路 | 全活动读头：旧单路 |
| --- | ---: | ---: | ---: | ---: |
| 完整参照／假操作 | 64/64 | 64/64 | 0/64 | 64/64 |
| 新教学时关闭可塑性组合 | 0/64 | 64/64 | 0/64 | 64/64 |
| 静默新对应的目标连接 | 0/64 | 64/64 | 0/64 | 64/64 |
| 静默匹配的旧对应连接 | 64/64 | 0/64 | 0/64 | 64/64 |
| 目标静默后立即恢复 | 64/64 | 64/64 | 0/64 | 64/64 |

**新对应和旧对应出现选择性可分离的连接作用：目标静默只损伤新题，匹配静默只损伤旧题；恢复使原表现精确返回。** 感官直读对照在新题 0/64、旧题 64/64，新题全部 WAIT；相同当前输入不能替代相反的教学历史。全活动读头的新题也全部 WAIT。

目标边 XYCD→AB 与匹配边 UVZW→AB 各 4 条，只依据教学接口指定，不用正式答案选边。两组度数分布完全一致；同刻平均有效权重残差最大 0.00652154，教学平均活动残差最大 0.00020110，分别低于事前 0.05、0.02 上限。静默仅改变 `core.silenced_edges`，立即恢复全状态相同。原可塑性开关还涉及保持衰退和快速学习，报告按这个实际组合命名；开、关均在同刻执行现有 reconfigure，包含其结算边、节点及定时器的实际作用，不能单独归因为某一种学习字段。

### 交叉分析解释了两种表达路径

首次测验完成后，另从完整当前末态登记固定读头与续校准副本。续校准只追加 6 条新提示活动及标签，保留原 12 条校准、正规方程和原归一尺度。0.85、0.95 两种总剂量从未用于拟合，两份各连续完成 24 题，最终 Core 与输入轨迹精确相同。

| 离线组合：新单路对应 | 全活动读头 | 端口读头 |
| --- | ---: | ---: |
| 旧读头 × 新教学前活动 | 0/64 | 0/64 |
| 旧读头 × 新教学后活动 | 0/64 | 64/64 |
| 续校准读头 × 新教学前活动 | 64/64 | 0/64 |
| 续校准读头 × 新教学后活动 | 64/64 | 64/64 |

这是预定的离线归因四格，不回写个体。续校准读头使用过新教学后的答题资料，相关四格含拟合资料；上表与未见剂量的留出成绩分别报告。

**端口读头的成功来自 Core 新教学后的活动变化；全活动读头续校准则能把新标签加到学习前已有的提示表征上。** 两条学习路径在同一个实验中得到区分。全活动读头答旧题的能力，甚至在相关旧连接静默时仍保持，说明旧题高分不能替代固定外设对新经历的表达检验。

事后算术解释另标身份：旧提示通道贡献占全活动旧题分数的绝对贡献之和的 87.77%—96.31%；所有来源的新提示维度权重均为零，新题总分范围为 −0.21917 至 0.13220，全部处于 ±0.25 的 WAIT 区间。这解释了本批读头如何依赖旧提示活动，不更换冻结评分或冒作新增因果干预。

### 完整性、规模与复算

5 项隔离测试通过。正式装置来源 1056002 的普通、频繁观察、保存恢复、墙钟暂停四路径全状态哈希一致；正式来源为 1056100—1056107。设计预检来源及未保留完整体的临时调试明确排除在科学 N 外，详见协议。科学运行一次，8 个完整来源结束，无 STOP、in-flight 或运行错误；没有补跑失败题。

只读审计全部通过：逐题核对原快照哈希、前后状态、1 秒连续时间、110 ms 特征、三种读头的独立算术、输入无答案、读头不变、谱系、64 份干预回执的字段白名单与匹配边数/度数/投影有效权重，以及 32 组续校准读取器统计。科学测验共 1,824 题，其中 1,216 个单路题；另有 96 次旧课校准。科学完整快照 2,024 份，装置另 10 份。每来源新教学后的参照为 60 内部秒、11 节点/24 边；最长连续副本到 96 秒。分支时间不能拼成一个成长个体的总寿命。

### 研究位置与下一步

可塑网络承载新经历已有明确文献，包括以梯度优化连接及 Hebbian 可塑性的 [Miconi 等，2018](https://proceedings.mlr.press/v80/miconi18a.html)，以及以快速权重保存短期过去的 [Ba 等，2016](https://arxiv.org/abs/1610.06258)。本批没有与这些实现做性能对比。当前新增证据是 ThreeMind 内部学习与个人表达的分离：同一个新经历，固定端口读头可以表达，全活动读头可以失败；声明的局部干预与早晚交叉定位了二者作用。

E50、E52 的固定新对应失败及 E69 的手部 WAIT 原件保持原结论。本批是另行冻结的小型匿名任务，不能据其结果直接改写那些实验的原因。下一优先项是按总计划用新来源、新题材确认这个完整机制，并把“读取范围”列为新训练方案的显式变量；E69 及其有界改训仍独立暂停。M4 功能分工、生态推广和较长经历表达按各自预定问题推进，不是本表通过项的追加门槛。

## 本次修订的最终结论

M5 证实了“Core 新学习—固定个人外设表达”这条路线在本任务中成立，并通过选择性干预定位了相应局部连接。它同时揭示：全活动读头可以遮蔽已经形成的新对应，外设续校准又可以凭已有提示表征制造答题进步。总体判断是核心机制获得支持、表达接口暴露瓶颈；这是可用于决定后续实验方向的机制结论，而不只是通过与未通过的成绩清单。
