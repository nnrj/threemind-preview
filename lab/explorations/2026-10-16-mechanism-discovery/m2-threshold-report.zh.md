# M2 局部释放门限：短时资源控制表达，首版预测遗漏输入增益

实验于 2026-10-16 完成；分析与报告于 2026-10-17 完成。[English](m2-threshold-report.en.md) · [冻结协议](m2-threshold-protocol.zh.md)。源码及协议冻结 `85b6d7f`。这是 8 个新出生来源的探索批，两个教学历史、等待条件及研究副本均为来源内观察。

**科学结论：保持持久连接不变，仅改变目标通路的短时资源状态，就能使已学对应的响应出现或消失。该因果目标在 8/8 来源成立。事前预测公式则漏乘了既有输入增益，错误预测了接近门限的条件，没有通过预测目标。本批完整合取目标为 FAIL，两项目标分别结项。**

## 目的与预期

本批裁定两个具体问题：P1 能否只用提示前完整状态与提示剂量，预测 110 ms 时特定经历的首次表达；P2 目标通路的快速资源状态是否具有独立于持久连接权重的、可逆的表达控制作用。原预期是两项目标均至少 6/8 来源达标。

每个 `/5.1` 来源接受两种相反教学历史 XYA/XYB，固定 A−B 输出投影、不训练读取器。两个历史共享声明的出生来源，分别连续培养到 104.5 内部秒；随后在独立完整副本等待 0 或 2 秒。六臂为完整参照、目标耗空、目标充足、匹配耗空、匹配充足、恢复。干预只改变预登记的短时资源字段束，所有持久权重、Core 配置、身体与个人状态保留；这是因果研究副本，不是普通测验逐题回档。

目标取全部两条 X 出边，匹配取不接 X 的两条边，选择不使用测验成绩。64 个配对的最大权重残差 0.00200855645，小于冻结容差 0.01；四项节点度数及两端激活残差均为零。每臂测试空白、0.55、0.8，完整臂另测四个未见强度 0.47、0.57、0.63、0.73。每次预测先于输入写入原件。

## 分析及对 ThreeMind 的意义

**P2 支持“存下的对应关系与此刻能否表达由不同状态共同决定”。** 目标充足使同一中等提示表达原教学方向，目标耗空使强提示失去表达；相同规模和匹配特征的其他连接干预没有这些效果，完整恢复又精确恢复响应。由此排除了“所有差异只是持久权重改变”及“任意同量快速状态改动都一样”的充分解释。对 ThreeMind，这是有利的选择性因果证据：无响应可由暂时表达受限产生，不能把这类无响应直接记作经历痕迹消失。本结论针对所干预的资源字段束，不分拆成每个字段的独立贡献。

**P1 的失败来自预测工具遗漏已存在的输入增益。** 16 个未见条件错误均为 0 秒等待、0.57 提示被预测有响应但实际为零。全部 704 条预测另有 80 个同类错误，均在 2 秒等待、0.55 提示的五个非耗空目标臂；总准确数为 608/704。

以下为明确标记的**事后诊断**：真实 Core 在刺激接收处乘 `direct_gain=0.9`，首版 `m2_threshold_predictor.py` 没有乘此项。独立文件算式纳入该既有因子，并计算接收节点的抑制响应后，704/704 方向与原件一致，端点最大绝对误差 8.68×10⁻¹⁹。诊断只读取保存文件，没有载入或推进个体，没有修改 Core、冻结预测器或 P1 成绩。它把失败定位为预测实现遗漏，不能将这一事后复算改称已经通过了前瞻验证。

这次结果要求修正研究工具，并另用未见材料验证修正公式；不要求改变 Core 动力学。原 P1 失败是完整记录的一部分。它也不抵消独立干预得到的 P2 结论。
