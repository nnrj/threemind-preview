# 本批所区分的抑制学习作用

2026-11-15源码核查，先于本批逐项学习对照结果。来源为`src/threemind_kernels/local63.py`的`_emit`、共同刺激更新及局部到期处理。此表说明开关实际控制的字段，不把源码作用直接当成实验效果。

| 量或记录 | 抑制成功传导时可能发生的更新 | 后续用途 |
| --- | --- | --- |
| 最近传导时间 `last_pass_us` | `inhibition_updates_usage`决定是否更新；兴奋成功传导照常更新 | 稳定度保持的当轮权重衰减，以及共同刺激强化系数 |
| 基础权重 `weight` | 开启显式抑制学习及抑制权重强化时，按成功传导量增加，受上限限制 | 影响随后信号传导；也影响按权重分配时的份额 |
| 短时增强 `fast` | 按传导量增加，随后按原规则衰减 | 与基础权重共同决定有效传导权重 |
| 资格迹 `eligibility` | 按`min(1, 0.7 × 原值 + 学习信号量)`更新 | 参与稳定度的衰减计算；更新并不保证数值总是上升 |
| 稳定度 `stability` | 开启增长时，按学习信号量增加 | 改变稳定度保持中的权重衰减速度 |
| 保持尺度 `half_life` | 仅在保持尺度增长开启时更新 | 本批沿用的配置关闭这一增长，因此该单项是无实际改动的参照 |
| 触达次数及最近触达时间 `touches`、`last_touch_us` | 一次有学习贡献的发送增加次数并更新时间 | 触达次数还用于后续共同刺激引起的稳定度增长；这组记录与最近传导时间不同 |

显式抑制学习关闭时，上表除第一项外的抑制贡献关闭，兴奋贡献仍保留。抑制不更新最近传导时间只控制第一项。它们是两个实际不同的干预。本批用完整配置、资源处理、门槛及必要的逐项对照，检验这些区别是否决定前缀区分。
