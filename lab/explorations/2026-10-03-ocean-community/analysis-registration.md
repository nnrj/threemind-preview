# E32 analysis details — fixed before the first 120-second world completed

2026-10-03. This adds precise read-only summaries to the frozen design; it changes no world, input, stopping rule or primary comparison.

- Independent unit: one world seed; report each of the two pairs, never test frames/descendants as independent replicates.
- Whole-world outcomes: food intake, intake per living-body second, captures, births, surviving bodies, energy, action continuity. Their differences do not by themselves establish purposeful seeking.
- Actual input/action stream: mean action projected onto the observed local nutrient gradient `(raw[1]-raw[3], raw[2]-raw[4])`, divided only by gradient length; normalized angular alignment separately when action magnitude is nonzero. Compute all-sample descriptive means and paired differences. This uses measurements, not an answer injected into Core.
- Focal counterfactuals: compare the same 60–120 s world interval. Predeclare action comparisons over 0–2, 0–10, 0–60 s after intervention, and the first time actions differ. Include common-alive coverage; never compare a dead body's zero output with a live body and call it a transfer success.
- Local pathway mechanism: selected target activity in both arms during their common absence of direct input in the preceding 1 s. Drop the first second after a newly started observer. Report activity differences and subsequent action differences, distinct from food/capture/survival effects.
- Behavior processes: record nearest food/weaker/stronger neighbor, physical gap and approach relative to local water, and actual capture-start/release/ingestion events. Nearest-object annotations are not semantic senses. Neighbor/food fields superpose over a 3× sensor-range cutoff; use gap within one sensor range as a conservative local window. Weak/strong labels are observer body comparisons, not instructions.
- Transfer: target/matched graft into aligned blank state compared to the experienced structural birth and blank birth. Action proximity, intake, capture and survival are separate claims.
- Actual event excerpts may be selected for illustration only after results. They add no independent samples. Full-habitat viewport remains visible, with a supplemental focal inset if useful.
