# 003 — 独立对照组实验模块计划

[中文](003_对照组实验模块计划.md) | [English](../en/003_control-experiment-module-plan.md)

## 目标

在“实验与调试”中新增“对照实验”页面，用统一输入和统一指标比较 ThreeMind 与若干既有网络。对照网络必须作为独立包/子模块实现，不导入、不修改 ThreeMind Core；宿主编排层只负责生命周期、刺激广播、采样、显示和统计。

## 页面构想

- 中央区域按实验臂分屏：一侧 ThreeMind，可增加多个对照网络；每臂独立显示状态、拓扑/活动视图和资源指标。
- 右侧为统一刺激与协议面板：选择起始状态、刺激序列、分帧、强度、背景、seed、试次数和时间窗。
- 统一时间轴可同步运行、暂停、单 tick、打标和冻结证据。
- 下方或独立标签展示各臂曲线、差异图、响应簇、遗忘/干扰曲线和导出入口。
- 所有结果标明模型不支持的能力，不通过人为添加 ThreeMind 机制来制造“公平”。

## 最小协议边界

每个实验臂适配器实现自身命名空间下的接口：

1. `create/reset`：按显式配置和 seed 初始化；
2. `accept(frame)`：接收相同的无语义刺激帧或声明无法等价接收；
3. `tick(n)`：推进自身动力学；
4. `observe()`：输出通用的节点/单元、连接、活动和结构摘要；
5. `snapshot/restore`：在该算法允许时冻结和恢复；
6. `capabilities()`：声明可塑、遗忘、抑制、空间、克隆等支持情况。

该协议属于实验宿主，不成为 ThreeMind Core API 的反向依赖。

## 建议对照臂

1. 同规模随机循环图（无可塑或只有匹配衰减），用于检验结构本身的零模型。
2. 标准 Hebbian 循环网络，匹配节点数、刺激帧和衰减。
3. 经典 Hopfield 网络，检验预存模式的能量收敛和误差校正。
4. Echo State / reservoir 网络，检验固定循环动力学与训练读出的差异。
5. STDP 网络，检验精确前后时序塑性与 ThreeMind tick 窗口机制的差异。
6. Wilson–Cowan 或简化兴奋—抑制群体模型，比较振荡、稳定态和抑制动力学。
7. Transformer/现代 Hopfield 只用于回答不同问题：全局注意或模式检索能力；不可把参数规模和任务训练不匹配的结果当作意识优劣比较。

## 公平性与审计

- 在有意义处匹配节点/状态维数、输入带宽、总 tick、随机种子和计算预算；不可能匹配的项目明确报告。
- 同一刺激帧只由编排器复制，不允许某臂看到另一臂内部状态。
- 指标计算器只消费标准观察输出；原始臂数据同时保留，避免公共格式抹平关键差异。
- 默认从多份独立初始状态重复并报告置信区间，不用单张画布比较作结论。
- 对照实现、版本、参数和来源论文随实验包归档。

## 分期

第一期完成协议、双臂分屏、随机循环图和 Hebbian 基线；第二期加入 Hopfield、reservoir、STDP 与统一统计；第三期才考虑神经群体模型、Transformer 类对照和批量实验调度。
