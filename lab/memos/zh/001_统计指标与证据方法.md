# 001 — 统计指标与证据方法

[中文](001_统计指标与证据方法.md) | [English](../en/001_statistics-and-evidence-methods.md)

## 目的

为 ThreeMind 的逐 tick 动力学、重复结构、时间区间收敛、遗忘和干预建立统一且可导出的统计口径。统计模块位于 Core 外部，只读取输出总线、历史与冻结快照，不参与激活、传播、抑制、联想、可塑或遗忘。

## 节点与局部响应指标

每个观察窗至少保留：

- 首次激活、峰值、最后激活和退出 tick；
- 激活持续 tick、最长连续段、重新进入次数；
- 峰值、均值、激活积分及超出基线的积分；
- 抑制积分、直接触达次数、联想触达次数；
- 窗口尾部保持、支持度、稳定度及其变化；
- 若记录了传播路径，则保存实际先后和边；若没有，不得从终态反推因果路径。

## 重复结构与响应簇

- 匿名结构签名、节点集与边集；
- 出现次数、持续时间、间隔、来源分布；
- 同一探针重复响应的 Jaccard、余弦相似度和轨迹距离；
- 收敛延迟、稳定集合大小、尾部波动、簇内/簇间距离；
- 单纯残留衰减、周期振荡、稳定响应三类候选应分别判定；
- 显示标签只作离线注释，结构身份以匿名节点和边为准。

## 系统级指标

- 总激活、总抑制、活跃节点数；
- 激活分布熵、top-k 集中度或 Gini；
- 热点数量、寿命、迁移速度和重访率；
- 节点/边数、边权和稳定度变化率、度分布、聚类系数、连通分量；
- 有效传播范围、饱和比例、拓扑新生与遗忘速率；
- 激活—抑制时滞、互相关、积分比；
- 快活动与慢拓扑两个时间尺度的关系。

## 实验统计原则

1. 从冻结快照做配对试验；报告独立 seed、重复次数、效应量、置信区间和负结果。
2. 原始数据优先导出 CSV（表格指标）和 JSONL（逐 tick 事件/稀疏轨迹）；模型包、配置和校验和共同归档。
3. “没有详细轨迹”与“数值为零”必须区分；缺失数据不得用终态补造。
4. 原始观测、规则计算出的统计摘要、人工/AI 解释必须分层存储。
5. 可视化降采样不能改变原始数据；图表须标注窗口、基线、采样率和过滤条件。
6. 如需“激活预算/能量”指标，只能作为显式开启的消融变量；它不是默认 Core 动力学的解释前提。

## 论文证据最小集合

每项主要结论应能追溯到：实验协议版本、初始快照校验和、模型参数、适配器状态、seed、刺激帧、逐 tick 或明确采样的原始记录、统计脚本版本和最终图表。可读标签不能替代匿名原始数据。
