Use identical current cues after opposite histories, preventing current input alone from specifying the correct response. Compare intact, sham, targeted silence, matched silence, release, target graft and matched graft. Separate persistent and fast-state interventions; label combined manipulations.

Select targets using teaching/development only. Match count, effective weight at the same time, node degree and activity, reporting residuals. Failed matching cannot be fixed by choosing favorable final-test edges. Graft only across declared receptor/actuator correspondences, without answer-based alignment. Freeze personal readers; no post-graft refitting.

Primary outcomes are opposite-history response contrasts, donor-directed displacement and off-task damage. Closed-loop benefit has a separate confirmation phase. Questions, frames, descendants and sibling copies are nested. Independent delay cohorts and multiple groups add to total cultivation cost; 48 per cell is not 48 for the entire program.

Before execution, simulate power for a 10 percentage-point behavioral difference or paired standardized continuous effect of 0.5, targeting at least 80%. Freeze N before confirmation; never add subjects based on significance. Report effects, intervals and denominators; control multiplicity for primary comparisons. An interval that cannot exclude a meaningful effect is inconclusive. Independently replicate key positives with fresh origins/materials and deliver key negatives.
