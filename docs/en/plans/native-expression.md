# Individual activity patterns and language expression

[简体中文](../../zh/plans/native-expression.md) · [Research backlog](research-backlog.md) · [E46 registration](../../../lab/explorations/2026-10-05-native-language/design.en.md)

2026-10-05. The user authorized further tuning and experiments; E45 findings remain intact.

The user proposed that an expression adapter may need to learn each individual's internally formed patterns and develop alongside it, rather than expect a copy of direct sensory images. A general decoder inspired by Transformer principles is another candidate. These options can coexist: shared algorithms/language generation with individual alignment. Present evidence does not establish that every individual requires an entirely separate full Transformer.

## Order of work

Reassess all six E45 routes through native patterns. Train output adapters on actual post-teaching activity: shared, individual, developmental continuation and cold training on the same accumulated history. Compare the scratch Transformer and an explicit finite-phrase cosine-attention reader. Freeze them before Core continues/reverses teaching or receives background alone. Answers must follow Core's new experiences, not merely demonstrate memorization by the output model. Use targeted and matched edge silencing where effects are found. Expand unseen composition only after basic correspondence works.

Co-development here means alternating ordinary Core teaching and output-adapter calibration with fixed input encoding. It does not mean gradients/rewards added to Core or delegating its reasoning to the decoder. Shared performance with identical sensory wiring is distinct from arbitrary cross-wiring transfer.

E45's calibration-to-expression gap could reflect direct-sensation/recall distribution shift, experience, encoding or missing information. Transformer sequence mapping is a useful candidate, not a guarantee: [original paper](https://arxiv.org/abs/1706.03762). Individual calibration in neural semantic decoding offers a methodological analogy, not evidence of human-level language in ThreeMind: [Tang et al., 2023](https://www.nature.com/articles/s41593-023-01304-9).
