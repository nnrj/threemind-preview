Reading Core's actual trajectory is distinct from keeping a separate conversational memory; developmental weight training is also distinct from inference-time conversational caching.

Primary observation uses raw quantities without counterfactual subtraction, per-sample norm normalization, clipping, top-k or semantic inverse mapping. Compare full node fields, connections and short-term/fast states. Preserve full restoration snapshots separately: feeding dynamical state does not authorize feeding configurations, external queues or experiment IDs. Explicit direct-sensory exclusions remain attribution controls, never hidden filtering of the primary path.
