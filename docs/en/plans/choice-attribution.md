## Supplement during execution, 2026-10-06

The user proposed that repeated practice might produce a useful learned response
in the external motor centre, analogous in function to a conditioned response,
and asked whether less training makes Core more decisive. The user accepts joint
control but explicitly retains the exclusion tests: ThreeMind must not become
an unnecessary appendage. The verbatim Chinese statements are preserved in the
[Chinese counterpart](../../zh/plans/choice-attribution.md); this is a translation
and summary, not an additional measured result.

Compare 100/300/1200 external optimization steps with identical Core experience
and supervision. This tests external fitting practice, not fewer Core lessons;
the latter remains a separate variable. Distinguish direct sensory sufficiency,
the influence of transient Core state, the contribution of learned connections,
and recognition performed by the external selector. A residual teacher-marker
state may carry history without establishing learned object concepts. Keep all
interventions in copies and preserve old evidence. Detailed additions and the
pre-execution correction to the second environmental source are in the
[execution record](../../../lab/explorations/2026-10-06-choice-attribution/execution-notes.md).
