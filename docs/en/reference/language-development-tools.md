# Language development and continuous activity tools

[简体中文](../../zh/reference/language-development-tools.md) · [Research plan](../plans/language-development.md)

These tools operate in the peripheral and observation layers, without modifying Core. Agents and human researchers can use the same Python and CLI operations. E44 reports, records and a continuous-translation viewer are delivered in its research project. This is not yet a general-purpose conversational language centre.

## Compile text into ordinary stimuli

Python API: `threemind_transformer.development.compile_stream(text, model, StreamInput(...), intensity=1)`.

The new `threemind.language-character-stream/1` protocol emits causal Transformer features after each complete character, retaining NFKC normalization. Defaults:64 dimensions,4 largest absolute components, mapped amount1 per frame,20000 microseconds between characters. `top_k=0` selects the dense control. Positive/negative features use separate anonymous channels. Freeze protocol, wiring seed and input checkpoint together. Existing sentence-vector and text protocols retain their original meanings.

Returned ordinary `Stimulus` frames with empty labels can be delivered by `ReadoutSession.schedule` or the existing anonymous-input API. Core receives no word meanings, object names or answers. Merge sensory streams only for an explicitly declared joint acquisition, never merely because timestamps coincide.

## Record and translate an activity process

`TrajectoryBasis(channels, bins=16, residual_buckets=16)` explicitly registers channels. Each time bin retains activation peaks. Unregistered channels remain in separate residual buckets, with counts and identities reported. Preserve raw trajectories alongside projections. `activity_changes` counts rises, reentries and total activity changes; it does not establish their external or internal origin.

Each process JSONL row contains `start_us`, `planned_end_us`, and a `trajectory` of frames with `time_us` and `nodes`. Nodes carry `id`, `channel`, and `activation`.

```powershell
$py = '.work/kernel-venv/Scripts/python.exe'
& $py -m threemind_transformer.development_cli project --input process.jsonl --basis basis.json --output features.jsonl
& $py -m threemind_transformer.development_cli train --input calibration.jsonl --basis basis.json --output expression.safetensors --device auto --steps 1600
& $py -m threemind_transformer.development_cli decode --input features.jsonl --model expression.safetensors --output words.jsonl --device auto
```

Training rows provide `values` and external teacher `text`; an empty string explicitly teaches expression termination. Targets never enter Core. Randomly initialized models save architecture, bins, basis and training metadata in safetensors. `auto` uses available CUDA, otherwise CPU; `cpu` forces CPU. Preserve a GPU execution failure before retrying on CPU; execution errors are not silently hidden. Bit-identical cross-device results are not claimed.

Outputs retain decoded UTF-8, generated bytes and termination status, including malformed text and empty output. No text cache crosses windows, earlier text never prompts the next window, and generated text is not fed back to consciousness. A familiar word alone is not evidence of a specific thought.

CLI outputs are exclusive-create, with256MiB/16384 input-row limits. It is not a complete resource scheduler. Large studies use instance, time, memory, storage and account limits in `lab/tools/service_study.py`. The E44 driver in `lab/explorations/2026-10-04-language-development/` enforces a preregistered route/seed selection.

## Teaching apparatus and interpretation

`lab/tools/language_teaching_world.py` supplies a small MuJoCo apparatus with gravity, four rigid objects and five actual range/material-colour rays. An external teacher changes camera view; object names remain teacher metadata. It has no active body control and does not replace full ocean or robot behaviour experiments.

Retain raw activity, external input, actual transmission, text and no-cue/untaught/silencing controls together. Matched-background interventions locate internal contribution. New experiences absent from expression training test translation reliability. Describing sensory activity and recalling newly learned knowledge through language are separate capabilities.
