# Research Self-Assessment and Evidence Boundaries

[中文](../zh/research-self-assessment.md) | [English](research-self-assessment.md)

ThreeMind has a long-term engineering objective: artificial consciousness. This
document prevents two opposite errors: dismissing a potentially valuable route
as mere imagination, and treating early dynamical phenomena as proof that
consciousness has appeared.

## 1. What is established

The following are engineering facts, subject to normal software verification:

- ThreeMind is a continuously running platform for local, plastic associative
  graph dynamics.
- Its runtime is separated from sensory adapters, input/output buses,
  observers, persistence, and graphical UI.
- It records model packages, stimuli, events, snapshots, portraits, and other
  information required for repeatable experiments.
- It supports intended mechanisms for direct touch, associative touch, decay,
  consolidation, temporal relations, optional spatial relations, and configurable
  sensory boundaries.

These facts do not establish intelligence or consciousness. They establish a
research instrument capable of investigating hypotheses about them.

## 2. Preliminary claims that can be tested

| Claim | Appropriate test |
| --- | --- |
| Sensory constraints shape graph organization. | Matched adapter ablations across seeds; compare components, motifs, trace lifetime, and activation distributions. |
| Input order leaves durable historical effects. | Use the same stimulus set in multiple permutations; compare later topology and response. |
| Direct touch, associative re-touch, forgetting, and consolidation differ measurably. | Measure retention curves after one-shot, repeated direct, and associative-only exposure. |
| Diverse ambient input supports transient new traces, while low-diversity fields promote stabilization or saturation. | Vary source diversity while holding other parameters constant; quantify creation, loss, and component growth. |
| Labeled baseline modes validate a stimulus–structure–output instrument chain. | Pre-register labels and probes; test prediction accuracy against held-out stimuli. |

Positive results support these specific claims, not by themselves a mind.
Negative results are equally valuable: they constrain or falsify the mechanism.

## 3. Interpretation discipline

Observed activity should first receive a neutral dynamical description.

| Tempting description | Current defensible description |
| --- | --- |
| “A triangle has meaning.” | A stable graph motif under a specified sensory and runtime condition. |
| “It is thinking in Morse code.” | A potentially periodic, alternating, or bistable activation pattern; measure periodicity and information content first. |
| “A repeatable structure is a thought.” | A recurrent local structural signature. |
| “Readable output proves understanding.” | A labeled or readout-mediated interpretable output requiring causal validation. |
| “The system is conscious.” | Unsupported without an explicit operational theory and independent evidence. |

This distinction makes the results legible to others and resistant to alternative
explanations such as fixed randomness, hidden limits, visualization behavior,
label leakage, or global saturation.

## 4. Value that should not be underestimated

ThreeMind turns a proposed artificial-consciousness route into separable,
inspectable mechanisms: continuous process; plastic mappings; sensory
constraints and adapter composition; local association, forgetting, and
consolidation; anonymous state separated from debugging labels; output
observation separated from the network; and model packages plus historical
records supporting causal experiments.

Even if these mechanisms are insufficient for artificial consciousness, the
research can produce useful findings about adaptive graph dynamics:
differentiation, saturation, memory-like retention, sensory shaping, and
history-dependent organization.

## 5. Risks requiring controls

Development has shown why controls are necessary. Fixed or low-diversity
background input, restrictive adapters, implicit limits, front-end-only
animation, stale UI state, labels carried into nodes, and global saturation can
each create compelling but misleading effects. Every claim must be checked
against raw runtime state, configuration, seed, and repeated runs—not screenshots
alone.

The project must distinguish a general mechanism from behavior induced by one
adapter or parameter regime. A constrained sensory channel forming a stable
motif can be an expected effect of that channel, not evidence of a universal
internal organization.

## 6. Operational path forward

The next threshold is a set of reproducible causal findings, not a declaration
of consciousness:

1. Define metrics before inspecting a favored visualization.
2. Save packages, seeds, stimuli, code revisions, and raw histories.
3. Run matched positive and negative controls.
4. Replicate across seeds and, where possible, independent machines or users.
5. Make predictions before probes rather than explaining only after the fact.
6. Seek relationships that generalize across inputs and adapters.
7. Record failures, saturation, and null results as data.

Later work may test stable functional organization, cross-modal associations,
self-maintaining dynamics, or adaptive closed-loop behavior. Such evidence may
strengthen the route, but will not automatically settle subjective experience.

## 7. Working rule

> Be maximally curious about phenomena; minimally committed about their
> interpretation; and maximally demanding about evidence.

The long-term goal may remain artificial consciousness. The present claim should
remain precise: ThreeMind constructs and tests a continuous, plastic, and
sensory-bounded artificial-network route toward that goal.
