# 2026-10-04: multisensory correspondences and language

[Original Chinese dialogue](../../../zh/history/sources/2026-10-04-language-grounding.md) · [Plan](../../plans/language-development.md#2026-10-04-continuation-multisensory-experience-and-early-language)

Source: two user additions in the current project conversation while E44 was running. The Chinese source preserves the exact original. This is a translated account of a hypothesis and later direction, not an experimental finding. The user explicitly authorized the ongoing experiment to continue unchanged.

First addition: language should connect to an experienced world. Whether text-only training succeeds or fails should not restrict later work. Simulated teaching can resemble early childhood learning about apples, parents, colours and numbers, associating language with objects and food. Vision, hearing, touch and potentially smell should cooperate. Textual expression through a Transformer can temporarily stand in for speech. Reuse existing generic sensory adapters where possible, provide simulated acquisition sources, and reduce resolution/rate within an appropriate resource budget. Record the idea and assessment for later phases.

Second clarification: concepts and logic may arise from correspondences among multiple information dimensions and experiences. These correspondences are implicit in connections, not semantic annotations. Language can activate connections associated with visual or auditory experience; similar visual, auditory or linguistic input can evoke related activity. The user supports embodied environments containing other individuals and teachers.

Assistant interpretation: test both language-evoked sensory responses and sensory-experience-dependent language, with local interventions identifying learned connections. Existing adapters and environments are reusable foundations. Distinguishable input, successful external expression and transferable relationships learned inside Core are separate outcomes to measure.
