The original file/line links and statements about its planning stage are not revised to describe later work.

The original plan covers the audited project-context problem, the five configuration layers, the five navigation entrances and player-like workbench, sensory and viewing safeguards, defaults/templates, service/material separation, prepared-state APIs, the original five implementation stages, ten acceptance requirements and six next-day product choices. This is source preservation and plan revision, not measured implementation. Partial uncommitted code is paused; no real migration for this task or scientific-state change is authorized by maintaining history.
