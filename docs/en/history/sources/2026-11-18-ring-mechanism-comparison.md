# 18 November 2026: Authorization and sources for the ring mechanism comparison

## Author request

After AS63-01/02, the author asked whether the difference between 6.3 and historical threemind.continuous-memory/1 ring behavior might be related to configurations previously explored to recover prefix discrimination. The author authorized a small matched study using the two old peripheral sets and the same experience and evaluation procedures, comparing /1, current 6.3 defaults and the successful 6.3 prefix configuration, to locate differences in experience formation, birth inheritance or behavioral expression. The author explicitly excluded kernel and default changes. The verbatim Chinese request is preserved in the [Chinese source page](../../../zh/history/sources/2026-11-18-ring-mechanism-comparison.md).

This authorization covers the isolated comparison. It does not authorize changes to production kernels, defaults, historical individuals, existing reports or the manuscript, or resumption of other paused revalidations.

## Facts established before formal runs

The old E13 motor adapter hashes node IDs into signed coefficients. The old Core allocates IDs in formation order, whereas 6.3 addresses nodes by anonymous channel code. Saved traces show that the same channel acquired different IDs under different initial histories. Therefore identical peripheral code and seed do not imply identical actual sensory-to-motor bindings. This was established from implementation and archived records before new outcomes were inspected.

AS63-03 retains the original ID rule and adds a research-copy control that aligns motor coefficients to archived channel bindings. Teaching replays recorded inputs and recorded actions; subsequent behavioral assessment is controlled by the current Core. The two old peripheral sets each contribute c0 and c2 histories from predetermined starts in opposite regions. Blank controls, newborn offspring and offspring redevelopment distinguish a tendency absent before birth from one lost during birth.

The first apparatus check found unmet demand under the same nominal supply in the 6.3 local energy model. Before formal runs, revision 2 disabled energy simulation in all research subjects, while still requiring time-resolved reproduction of the old activity and motor record. Another complete-restore check found that construction rebased an inactive external supplier timer; the experimental wrapper now preserves that timer while energy is disabled, without altering production Core or supplier code. Both interrupted checks remain archived. Short native/reference, observation, pause and complete-restoration checks subsequently passed in all configurations.

## Additional author comments during execution

The author criticized ID dependence as a possible fixed stimulus-to-action route that could undermine learning and inheritance attribution. The author proposed mapping stimulus parameters to node addresses through an explicit function that is not the identity of a single parameter, requested recommendations after completion, and authorized the current experiment to continue. These are the author's assessment and design intention, not implemented kernel rules.

The executor clarified that the old adapter still multiplies ID-derived coefficients by node activation; it does not bypass all Core activity. Blank controls and aligned bindings test whether previously formed plastic connections are required. Address generation and address dependence in the output adapter are related but distinct issues. No addressing change was implemented.
