# 统计、证据与研究数据导出

[中文](statistics-and-evidence.md) | [English](../en/statistics-and-evidence.md)

ThreeMind 的“统计与证据”模块是 Core 之外的只读测量层。它可以读取持久化历史和 OutputBus 已输出的匿名观测，但不得向网络写入刺激、标签、边或解释。统计结论和画布动画都不能反向参与动力学。

## 测量对象

重复结构必须区分四种身份：

- `state_signature`：量化后的瞬时激活、稳定度和触达状态。它描述一次截面，不等于图结构。
- `structure_id`：节点 ID 集合与内部有向边集合的精确身份。同一结构在不同激活状态下仍可保持同一 ID。
- `topology_class_id`：忽略节点 ID 后得到的拓扑候选类，可用于分组相似结构，但不是严格图同构证明。
- `occurrence_id`：某结构在某 tick 的一次出现。结构观测和随后产生的告警若共享此 ID，只计一次出现。

检测时冻结一份匿名子图，其中包含当时的节点状态、内部有向边、权重和稳定度。可读标签只作为外部注释与冻结子图并列保存；它不是 Core 节点的语义属性，也不参与结构身份计算。

## 统计页面

标题栏的 **统计与证据** 页面提供：

1. 运行概览：刺激、事件、读出、时间区间收敛和动力学记录数量，以及刺激来源分布。
2. 动力学曲线：节点数、边数、总激活、总抑制、创建、移除、直接触达和联想触达。
3. 重复结构目录：精确结构的出现次数、首次／最近 tick、来源占比、状态指纹和冻结子图。
4. 时间区间读出：收敛、振荡、衰减、瞬态等分类及节点排名；可按需查看排名节点在该窗口内的逐 tick 激活曲线。
5. 配对消融：从同一源状态产生对照与干预隔离克隆，并对二者发送匹配刺激。

逐 tick 曲线只有在实验前开启详细动力学记录时才存在。没有记录表示“缺失”，不能补零、插值后冒充原始观测，也不能依据当前快照倒推出过去。

## 研究数据包

“导出证据数据”生成带 SHA-256 校验和的 ZIP。其主要内容为：

- `manifest.json`：数据集版本、意识 ID、生成时间和数据来源；
- `records/*.jsonl`：刺激、事件、观察、AI 解读和动力学原始记录；
- `tables/*.csv`：重复结构、时间区间读出和动力学分析表；
- `subgraphs/*.json`：检测时冻结的匿名子图及外部标签注释；
- `data_dictionary.csv`：字段含义；
- `checksums.sha256`：包内各文件的完整性摘要。

JSON Lines 是保真的主记录，CSV 用于统计软件和人工检查；CSV 使用带 BOM 的 UTF-8，JSON 使用 UTF-8。电子表格可以作为查看工具，但不应成为唯一原始数据格式。

## 解释纪律

- 结构重复不等于语义重复；拓扑候选类不等于严格同构。
- 明文标签是仪器化观察口，匿名节点仍是主要证据。
- AI 可以总结导出的记录，但不得替代结构检测、收敛判定或统计检验。
- 探索性阈值调整必须与确认性实验分开；确认性实验应预先锁定版本、参数、seed、刺激序列、主要指标和排除规则。
- 任何论文图表都应能追溯到证据 ZIP、模型包哈希和代码版本。
