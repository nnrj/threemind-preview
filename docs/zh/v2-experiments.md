# 第二代实验、比较与证据

本工作台用于检验可塑动力学，而不是用一个漂亮网络图代替研究证据。首先区分核心效应、感官编码效应、身体闭环效应和统计读出效应；研究结论需要明确实验单位与可反驳的假设。

## 配对实验流程

在“实验与训练”中设置共同培养时长、条件运行时长、独立环境种子及条件组。创建后协议被冻结并计算哈希。训练器为每个环境种子运行一次共同培养，将完整状态、实际输入和环境恢复点写入数据库，再从该起点创建各条件分支。

默认提供完整可塑性、关闭可塑性、关闭局部抑制三个条件。高级参数 `config_patch` 可以修改明确的机制参数；`intervention` 可以静默节点/边或损毁连接。干预不会凭空添加语义连接。积分步长改变应另做数值收敛实验，不能在一个已有时间相位的配对继续运行中随意换网格。

同一个区组中的分支共享初态哈希与外生力条件，但闭环动作不同后，身体轨迹和实际感官输入可以不同。这是闭环机制效应的一部分，不等于随机性失控。MuJoCo 版本与 XML 哈希进入环境恢复记录，版本不匹配时不能声称精确续跑。

从记录输入进行配对研究时，API 要求 `replay_blocks` 为每个区组提供独立采集的输入记录。仅修改一个未使用的 seed，反复播放同一确定性记录，不会产生独立样本。当前页面的默认协议使用模拟物理环境。

## 比较与统计

“比较与消融”选择对照与干预条件。只有研究中的条件运行完成后才执行分析；共同培养运行不混入条件样本。每个种子对应一对独立运行，时间序列中的每个采样点不被当作独立重复。

报告包含配对差值、Bootstrap 95% 区间、配对标准化效应、符号翻转检验和 Holm 多指标校正。小样本的检验分辨率有限；两对运行主要适合验证流程。缺失指标按指标报告并排除，不用零填补。差值方差为零时不输出虚假的无限标准化效应。

当前统计结果汇总最终节点数、边数、激活、抑制、平均权重和激活时间积分；这些是动力学描述量。更高的激活或更密集的连接不能直接解释为更高的意识或智能。时长相同、采样覆盖相同也是比较的前提。

确认性实验应预先说明主要指标、条件、独立样本数、排除标准和检验方法；研究者不能在结果出来后挑选最显著的一项，同时仍称其为预先指定结论。完整协议与结果文件均可留作研究记录。

## 数据查询与导出

“数据查询”可选择运行、历史恢复点、节点/边或连接变化，按激活、权重、变化幅度和源节点筛选。分页固定版本；当前模型继续演化后，如果分页版本发生变化，页面要求刷新，不把不同版本拼成一张伪一致表。

筛选导出包含全部匹配记录，而不只是当前一页。CSV 方便常用工具，JSONL 方便逐行处理，Parquet 保留类型并适合较大表的列式分析；ZIP 内的 `selection.json` 同时保存筛选条件、来源时间、版本、状态哈希和行数。

运行页面可请求标准模型、JSON 模型或证据包。证据包包含：

- 冻结运行协议和模拟环境恢复上下文；
- worker 启动时的源码清单/总哈希、原生内核二进制哈希、Python/平台及关键依赖版本，随恢复上下文保存；
- 请求版本之前的输入/干预事件与全部已采集观察，而非图表当前显示窗口；
- 完整核心模型 `.tmind`；
- CSV 数值表，SVG、PNG、PDF 动力学图；
- 范围、方法、模型状态和各文件的哈希清单。

配对统计另生成完整分析 JSON，含区组数据、来源运行和可复核的算法 seed。页面切换条件后不会继续显示另一组条件的旧统计结果。

实现信息用于识别运行实际使用的版本，不是跨平台逐位确定性的保证。归档研究应同时保存对应源码或发行包；仅有哈希无法重建代码。修改实现后不要将续跑的结果冒充原版本的无变化延续，应检查恢复上下文并建立明确的新条件。

## 记录精度与资源

默认保留外部输入、命令、定期完整恢复点和采样观察。连接变化表示相邻恢复点之间的差异，未声称捕获期间每一次权重更新。`trace=true` 可在每个数值边界提交状态，其数据库成本明显更大；采样周期、检查点周期、时间步和显示档位不是同一个参数。

暂停与故障不会补成“意识死亡”。失败运行保留错误与已提交状态，未完成的配对研究不产生伪完整统计。真实物理遥测不因为 seed 相同就可重放，必须以记录的输入为证据。

下一阶段的研究重点是：跨环境保持/遗忘曲线、扰动后的恢复、组合泛化、明确匹配的简单基线及闭环行为指标。它们需要相应任务和评估设计；本版提供可执行的配对实验底座，不将尚未实施的科研协议列为已经通过的能力。
