# 多代定向训练与固定证据

「实验与训练 → 多代定向训练」协调多个独立个体的发育、评估、选择和继承。它使用现有 Core、Runtime、总线和适配器，没有在内核中加入适应度、奖励路径、基因层或随机重连。这里先实现**定向选择**；资源、伤害、生态存活和繁殖形成的生态选择按[世界与演化方案](v2-evolution-and-world-plan.md)继续接入。

## 图形配置和参数

新建页面默认使用图形配置，种子高级设置折叠。右上方链接按钮切换带行号、高亮、格式化与校验的 JSON 编辑。切回图形和提交创建均校验，重复 JSON 键被拒绝。默认没有筛选指标，必须明确研究目标、指标和方向，不能用默认分数代替科学假设。

可从空白结构开始，也可选择先天版本。继承已有版本时，Core 参数和感官身份只读。发育与评估使用统一的完整参数编辑器，共享 Core 参数、感官通道和执行器身份；环境与记录设置分别调整。基础 `environment_seed` 留空，实际环境种子来自冻结计划。当前支持 MuJoCo 模拟身体和合成环境，拒绝会随宿主变化的遥测刺激，使用尽速或指定倍率时钟。

设置代数、每代个体数、父本数和一至八个不重复指标。列表从上到下依次比较，箭头调整优先级。每个指标分别设置较高／较低优先，以及跨筛选环境的均值、中位数或最差值。希望较高时，最差值是最小值；希望较低时则是最大值。

默认两代、每代四个体、两个父本、三个筛选环境和三个最终验证环境，发育与评估各 30 模拟秒。页面显示最大个体总数。协议上限为 1000 代、每代 64 个体、每组 32 个环境；这是校验上限，不是当前机器的实时能力承诺。显示档位不改变科学参数。

## 三组环境与评估隔离

| 种子组 | 使用方式 | 与选择的关系 |
| --- | --- | --- |
| 发育 | 每代、每个体分别配置 | 发育得到的网络成为候选 |
| 筛选评估 | 同一环境组在全部候选和各代间复用 | 参与选择，可能逐渐适应该组环境 |
| 最终验证 | 最终父本名单固定后，验证最终一代全部候选的独立副本 | 不重新排序，不改变继承源 |

三组种子不得重叠，各组内不重复。修改代数、个体数或环境数量后，显式重新生成或编辑实际种子表。生成器初值只帮助产生表格，不是 Core 参数。**不同种子不是样本统计独立的充分证明**；环境来源、任务族和物理过程的相关性仍需研究设计说明。工具隔离也不能防止研究者跨实验查看最终验证组并据此调参，应如实报告这种使用方式。

出生沿用 `threemind.birth/1`：继承父本全部持久网络及固定参数，清空活动、短期痕迹、队列和旧环境状态，初始化新个体。不因研究者认为某些连接无用、不相关或偶然而删去它们。出生不是让原个体复活，也不把零活动的新个体称为已有意识。字段边界见[发育与先天版本](v2-development.md)。

设继承结构为 $H_{g,i}$，出生转换为 $B$，可塑发育为 $D$，观测为 $Q$：

$$C_{g,i}=D(B(H_{g,i}),E^{dev}_{g,i}),\qquad Y_{g,i,b}=Q(D(B(C_{g,i}),E^{sel}_{b})).$$

选择器只读取冻结的 $Y$，决定哪些 **$C_{g,i}$** 繁殖。评估副本继续学习形成的网络留在该副本，永不替换候选。最终验证另行出生，使用 $E^{verify}$，结果不反馈到选择。

同分按冻结的个体序号升序选择。选中父本按排名循环分配后代，数量相差不超过一个，不再按分数隐含追加繁殖权重。例如五个后代、两个父本分配为三与二。直接遗传获得性结构是工程假设，不等同于生物基因遗传；差异来自声明的环境经历和可塑性，不隐含参数变异、结构拼接或突变。持续同分、缺少差异和种群趋同均应如实展示。

## 结果、失败和恢复

指标包括终点网络规模、活动、连接统计、能量账本、已观测存续时长和终点 Core 生命状态。能量指标需开启 Core 能量模拟，单位未经物理标定；声明的定时供给不等同于环境觅食。终点未死亡个体的已观测时长是**右删失值**，不是完整寿命，更不是意识质量。

一波子任务全部完成后，协调器一次固定结果。缺失、非有限指标或后台失败使实验阻塞，不补零、不只选择成功者、不把进程崩溃称为 Core 死亡。无节点／连接时某些指标可能缺失，应在研究设计中处理。

暂停通过普通停止命令等待个体提交恢复点；恢复继续原个体。失败重试创建新任务尝试，保留原个体身份；有恢复点就继续，没有恢复点则从同一冻结来源重复出生。终止后的实验不能原地重启。普通意识页面可观察及停止，但不能绕过协调器修改冻结实验的科学参数或重启个体；独立研究可从恢复点分叉。

协调器用短事务推进，等待子任务时释放 worker 和租约，单 worker 也能完成多代流程。操作编号防止重复提交，个体编号确定，并发完成、租约耗尽、暂停和取消都有日志。沿用 PostgreSQL 作业与项目额度，不新增 MQ。参与 worker 必须声明 `worker.evolution_v1`。

## 图形观察、记录和报告

详情可按代次和阶段查看全部排名、入选父本、逐环境个体、来源版本、固定恢复点、哈希和指标，个体链接进入普通意识工具。结构与读出沿用被动观察边界，排名不修改原始活动。

跨代图显示全部候选均值、已选父本均值、最小／最大值。这些是**描述统计**，范围不是置信区间。页面显示所选代及此前最多 99 代，导出包含该快照全部已完成代次。共用祖先、重复环境和网络副本不自动构成独立的演化实验重复；图形本身不能证明遗传或选择有效。

「记录与报告 → 添加数据来源」可以选择多代实验、代次及阶段，固定全部候选的筛选汇总、逐候选逐筛选环境结果或最终验证结果。必须阶段完整固定，包含未入选者；可选指标来自该协议实际评估的目录。其他原始观测可从对应个体采集。来源生成默认分布图和表格，接入既有 Markdown、HTML、Word、PDF 导出。

作者或 AI 提议的文档 JSON 只能引用固定测量，不能提交替代测量值。AI 收到选定来源的汇总、范围和推断限制，不自动获得原始模型、完整刺激或研究执行权。解释文字需研究者复核。同一来源可生成多份记录与报告。

## 多代证据 ZIP

「生成证据 ZIP」后台任务按**执行时**的一次数据库一致快照捕获状态。训练继续不改变这份快照；导出成功后存入同库不可变附件。丢失完成回执后的重试复用同一成功文件，不换成更晚快照。

包内含冻结协议与哈希、全部个体及固定指标、逐环境评估、全部选择、完整协调日志、恢复点来源、执行软件版本和 worker 分配回执。`scores.csv` 保存逐候选结果；`descriptive-series.json` 保存图表聚合；`figures/` 提供各指标 SVG 与 PNG。清单记录逐文件哈希、字节数和范围。数据代次、个体和环境序号从零开始，排名及图上代次从一开始。

未完成个体保留未完成状态。此包不含每个个体的完整模型、原始输入和连续轨迹，仍可从引用的个体及恢复点单独导出；图表也不等于完整原始活动。导出使用有界流，超过 8 MiB 才暂存临时文件，未压缩总量超过 2 GiB 时明确失败，不保存截断成功文件。平时不自动改写模型 JSON。

schema 34 保存多代协议、个体、选择和日志；schema 35 加入导出能力及记录来源引用；schema 36 为引用演化证据的报告导出和 AI 草案匹配相应 worker，避免旧 worker 接到无法处理的来源。全部位于现有 PostgreSQL 和项目权限内，Core `causal/7`、状态 `state/5`、感官 `profile/5`、出生 `birth/1` 均不变。

## 验收和后续边界

工程验收覆盖单 worker 多代执行、父本与评估隔离、全部候选证据、确定性重放、失败不补零、暂停／继续／取消、并发完成、租约耗尽、项目隔离、旧 worker 拒绝、图形／JSON 编辑、报告及导出。这些验证实现正确性，不是意识或演化成功的研究结论。

生态选择、可编辑世界和虚拟躯体、AI 世界草案及不同遗传／选择规则的预算配对对照，继续按 F3 和演化方案实施。不会自动把工程样例作为研究结果，也不自动替研究者启动比较实验。
