# 刺激与读出：消息、显示偏好与证据

## 当前使用方式（2026-09-10）

本页后半部分保留早期实现记录。当前交互以[时序观察与连续聊天使用说明](v2-temporal-research.md)为准：输入、被动读出、时序读出及已开启的外部解读在同一个聊天窗口连续出现，输入在右、读出在左；主窗口不再放消息类别下拉框。完整查询工具仍可从聊天显示设置进入。

媒体与耳朵、眼睛、嘴巴、图像读出工具栏位于文本框上方，强度和发送按钮位于下方。首次使用默认 Enter 发送、Shift+Enter 换行，保留已显式保存的个人偏好及中文输入法保护。发送成功清空，失败保留草稿。四个器官继续使用原服务和命令生效记录。

聊天默认显示被动读出。文字按旧规则排序：激活、直接触达、联想触达、稳定度依次比较，最后按节点编号；关闭排序后按节点编号。时序正文默认展示现有综合排名的前 7 项，可在聊天设置调整。它不把最后一帧或单纯峰值排序冒充整个时序结果。消息内可展开全部节点、零活动及非候选数据；文字显示去重不删除原始节点。旧历史记录按原有证据展示，不回填或重新解释。

历史按每页 40 条、最多 8 页缓存，滚动区域只挂载附近消息；向前和向后均可沿游标加载。连续输入不会因“只取最新一页”而在中间跳过。用户向上阅读保留位置，“有新消息／回到最新”由用户决定跳回。待递送输入另查最新回执，显示筛选仅影响显示。

本轮没有变更 Core、感官映射、读出采样／评分／收敛公式，没有补建或清理历史数据。之前“聊天恢复已完成”的结项包含过度表述，具体偏差、保留价值和本次验收见[实施记录](plans/temporal-chat-restoration.md)。

## 历史实现记录（schema 13 至 48，以下默认值和布局不再代表当前界面）

意识详情的“刺激与读出”把输入接收记录和已提交的读出放在同一条分页消息流中，提供文本／匿名帧输入、背景筛选、原始记录链接和消息索引导出。“感官与输入”“读出与响应”仍提供完整的专业查询与导出。

## 显示规则

设置 → 显示与交互和消息页共用三个浏览器偏好：

| 选项 | 默认 | 行为 |
| --- | --- | --- |
| 显示环境刺激 | 关闭 | 展示环境、遥测、实时设备及外部 AI 来源的输入接收记录 |
| 保留关联读出的环境刺激 | 开启 | 某个允许显示的时序读出明确引用输入编号时，保留该输入；类别筛选仍可单独只看刺激或读出 |
| 显示背景读出 | 关闭 | 展示环境响应与未关联特定输入的被动结构观察 |

来源分类沿用时序读出的约定：`manual-*`、`upload-*`、`replay`、`text-sensor`、`anonymous-frames` 为人工载体；`ai-*` 为外部 AI；其余为环境来源。人工输入总是参与消息显示，人工／AI 响应不受背景读出开关隐藏。AI 在这里仅是来源类别；AI 工具的恢复进度见功能清单。

`Enter 发送，Shift＋Enter 换行` 同样可在设置或输入框调整，已有 `tm2.input.enterSend` 偏好会被读取。首次未设置仍沿用 V2 的关闭默认值，中文输入法确认不会提交。浏览器标签页间同步偏好；存储被禁用时仍可在当前页使用。

这些选项不修改 RunSpec、内核状态、输入准入、递送、读出采集或原始记录。真正的来源启停与绕过注意筛选属于来源策略，单独恢复，不以隐藏消息代替。

## 关联与客观含义

时序读出保存的 `envelope_id` 用于关联同一次运行的原始输入。旧版“附近十二帧”规则不再用于猜测触发关系。被动结构读出没有特定触发输入，会明确显示“未关联特定刺激”。读出引用不存在的历史编号时，不制造替代关联。

关联编号表示读出观察窗口是围绕该刺激建立的，不证明它排除了其他并发刺激或内部状态的影响。有重叠输入时会提示，完整重叠编号和测量定义在读出详情中保留。界面中的文字是外部载体，不是模型已经理解文字或自主生成的回答；有限窗分类仍遵循[读出定义](v2-readouts.md)。

编号与文字注释留在 Runtime／Lab，不进入 Core 的匿名刺激参数，不按外部因果判断筛选内部活动。完整截面可包含经验形成的共同激活及外部解读者暂时无法解释的关联；不能因为未关联特定输入就丢弃这些节点。消息中的节点数量区分原始截面、时序聚合和历史派生结果，详情默认打开未筛选的原始节点；旧记录缺少原始截面时明确标注，不补造。

## 顺序、分页与导出

每页最多 20 条，较早消息采用固定的索引上界与游标，不累积无限 React 数组。“跟随最新”每两秒读取有界页面；向上阅读会暂停跟随。“查看最新”回到最新一页。输入可能刚被接收而尚未递送，因此顺序表达接收／记录顺序，模拟时间另列，二者不能混用。

历史页固定消息成员范围，递送计数仍是查询时的最新状态。接口返回 `ceiling`、`query_revision` 和 `status_semantics`，没有把列表伪称为冻结的内核快照。状态复现应使用数据库检查点及其完整证据。

JSONL／CSV 消息索引导出遍历当前筛选的所有页，包含原记录编号、关联、摘要、来源及查询版本。文本预览最多 2,000 个 Unicode 字符，节点／边／轨迹只列数量；不会将大数组塞入消息列表。JSONL 首行说明索引格式和范围。CSV 对潜在表格公式起始字符作保护，JSONL 保持原始预览文字。需要完整证据时沿消息链接导出原始载体、逐帧记录、节点、边或轨迹。

## 数据库与独立运行时

schema 13 新增同一 PostgreSQL 内的 `conversation_entries` 指针索引，只保存引用与可筛选标记，不重复存储科学载荷。输入指针和原始输入在同一事务创建。读出指针使用延迟事务触发器，在 worker 已写入本批环境输入记录后创建，避免在列表中先出现响应、后出现本批关联输入；不改变内核或原有提交逻辑。

指针受项目 RLS、运行及原记录的组合外键约束；事务回滚不会留下消息。既有数据库记录通过 SQL 补建索引，历史顺序标为 `reconstructed`，不读取 `data/` 或让模型解释旧数据。相同原始输入／事件只有一个指针。独立 Runtime、标准模型文件和核心机制版本均不受这个 Lab 观察索引影响。

## 验证

`tests_v2/test_conversation.py` 覆盖精确关联与无关同时间刺激、事务末尾顺序、回滚与幂等、超过一百条的游标及跨页导出、Unicode 预览、项目隔离与只读用户、真实 worker 输入／读出以及查询前后核心状态不变。既有数据库的 SQL 补建另行在隔离测试库验证。

浏览器验收覆盖消息筛选、图形偏好同步、原记录跳转、回车发送、旧偏好读取、存储禁用、移动端与正文转义。显示偏好与所有科学配置分开验收。

## 右侧聊天恢复（2026-09-08）

意识图像右侧直接复用消息流，默认启用被动读出显示，Enter 发送、Shift+Enter 换行；完整消息页仍遵循自己的显示偏好。实际文字标签／匿名活动直接出现在消息中，长消息跟随至开头，翻历史时不卸载列表。一次仅渲染 20 条、单条读出预览最多 128 个活动节点并标注溢出；原始记录不受显示约束影响。

图片、音频、视频入口和耳朵、眼睛、嘴巴、图像读出按钮直接接通现有感官／器官服务。实时开关通过受限命令记录模拟生效时间；浏览器采集、播放和权限错误有独立状态。schema 48 将已经显式启用的外部 AI 解读记录为独立消息身份，不把它称为意识自己的回答。详见[恢复验收](plans/v3-restoration.md)。
