# AI 世界与虚拟躯体草案

世界库右上方「AI 生成世界草案」以当前选中的世界为基准；未选择时使用默认世界。填写目的、选择已启用的供应商，先预览完整发送内容，再明确发送。请求只包含设计目的、基准世界协议和协议约束，不读取脑模型或实验测量。接口复用现有供应商、授权、预算、独立 AI 队列、取消和调用审计；未配置供应商时不会自行寻找或调用其他服务。

提示模板 `threemind.world-authoring/1` 要求返回设计说明、局限和完整 `threemind.world/1` 协议。服务器拒绝重复 JSON 字段、未知参数、脚本、非法部件引用、无效数值以及无法由物理引擎编译的模型。响应截断或请求取消不会生成可采用的结果。校验成功仍只是一份「未审阅提案」；不会创建世界库条目、实例、实验、连接或刺激。

配置校验不是试运行，也不能证明数值长期稳定或设计达成了训练目的。AI 关于行为、合作或意识的解释仍是设计建议，不是研究结论。当前世界 schema 描述物理、躯体和感官，不通过给物体取名字实现资源、繁殖或生态规则。

结果页按部件编号逐项比较修改前后的属性。单纯调整 JSON 数组顺序不算接线变化；增删部件、感官端口和命名空间变更会出现在差异中。全部差异可分页查看，提供图形参数和三维预览；手机上按修改项显示前后值。预览不启动意识或生成像素刺激。

点击「载入草案并继续编辑」进入普通世界编辑器。用户可以继续用图形或 JSON 调整；保存时再次校验，并创建新的世界及不可变修订。保存项保留 AI 调用编号、原提案哈希、最终协议哈希和保存者。最终内容与提案不一致时显示人工调整标记。这个标记说明内容经过调整，不保证研究者已经检验 AI 文字中的每个论断。

「世界 AI 请求记录」可查看状态、供应商版本、用量、原始提示、响应和导出调用记录，也可以重新打开已有提案。关闭页面不取消已接收的请求；可在调用详情明确取消。响应确认丢失时，在原面板按原编号重试不会重复发起付费请求。重新刷新或关闭面板后，应先检查调用记录，再决定是否发送新请求。

schema 38 将 AI 来源引用保存在同一个 PostgreSQL 中，并增加世界提案的 worker 能力条件。生成 worker 会检查本机能否编译物理世界；仅做协议与静态编译，不需要 RGB 离屏上下文。真正运行 RGB 世界仍需要相应感官能力，不会因为草案通过编译就允许不具备离屏支持的 worker 领取训练任务。

模板、提示和协议合计最多 200 KB；超过范围需减少世界部件或说明。供应商可配置输出 token 上限；大型世界可能超出它，应调整明确的调用预算或拆分设计，不能将不完整 JSON 当作成功结果。实际输入及输出用量以供应商回执为准，未返回时保持未知。
