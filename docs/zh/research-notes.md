# 研究笔记与工作共识

[中文](research-notes.md) | [English](../en/research-notes.md)

## 正在实验的假说

本项目探索：一个持续运行、可塑的联想系统，能否在不断到来的外界刺激中形成持续的内部映射。最终目标是实现人工意识，但当前实现不宣称已经达成；画面活动、被动读出或类似语言的片段，都不能单独作为意识存在的证据。

当前工作假设：

- 连续的体验过程比静态训练完成的模型更重要；
- 不同个体可以形成不同内部映射，同时仍能对同一外部情形产生部分共同指代；
- 联想起初可以错误、间接或跨模态；只要通路有用并被反复触达，它就可能稳定，而不需要预设符号规则；
- 遗忘应是缺乏支持的连接状态自然衰减，不是独立的数据库清理策略。强烈或反复经过的通路依靠自身权重、资格痕迹、稳定度和支持度抵抗衰减；
- 被回忆或被联想触达的通路也是一种刺激，并应按程度得到巩固；巩固不只来自完全相同输入的机械重复。

## 不可妥协的实现约束

- 匿名 Core 的节点和连接不得将输入文字作为标签或值保存；
- 文字只是方便实验的载体，应和图像、音频、工具反馈或其他感官一样，由外部适配器编码；
- 可读标签、被动读出和 AI 解读日志都属于外部观察，不能暗中成为内部意义或刺激；
- 意识运行期间背景刺激应持续存在，但躯体与注意门可以令其实际送达形式变得微弱、间歇、过滤或带噪声；
- 视觉动画不等于拓扑变化。纯展示性的运动必须明确可选且默认关闭。

## 对实验现象的解释

重复结构特征、输入后延迟活动、聚类、或类似字符的读出，都值得记录与比较；它们本身不能证明意图、理解、自我或意识涌现。有效实验需要对照：改变刺激顺序、加入无关刺激、关闭躯体/注意插件、比较克隆包，以及重复运行。

## 实验纪律

以下做法从旧版 ThreeMind 的实验基线中保留。它们不依赖旧版 UI 或旧内核，仍是可复现实验的必要约束：

1. **保护因果边界。** 只有被接纳的 `SensoryFrame` 与运行时自身更新规则可以改变联想状态。渲染器、通知、被动读出、AI 摘要、日志和导出工具都是观察者，均不得把激活、节点或连接状态写回 Core。
2. **保持真正连续的过程。** 运行中的实例应持续耦合于外界环境信号；即使躯体适配器或注意门让实际送达帧变得稀疏，也不能把 Core 内部预写的“梦境”序列伪装成自发活动。
3. **优先采用局部原因。** 传播、联想、巩固与遗忘应可由局部状态、输入帧和有界邻域动力学解释。不得用全局图搜索暗中提供一个语义答案。
4. **让干预可恢复。** 记录模型包版本、随机种子、参数、适配器配置、刺激方案和观察窗口；对重要参数修改前创建具名快照；详细追踪必须是可选且有时间边界的。
5. **显式记录生命周期。** 创建、暂停、恢复、无响应、死亡、快照、遗照、克隆、恢复和删除都是事件，不能作为不可见重置处理。遗照保存终止状态，不能被表示为仍在运行的实例。
6. **将负结果也视作数据。** 崩溃、未复现和无法区分的反应都具有价值。单个视觉重复图样不足以说明问题；应同时报告可能的替代解释，例如参数诱导的吸引子、显示选择或观察器阈值。

## 空间基线与比较

最初的基线刻意将联想动力学与几何空间分开：2D/3D 布局只是显示投影。现在 ThreeMind 允许 V3 实验可选启用空间嵌入；这不是用空间取代“拓扑优先”基线，而是增加一个可控对照条件。仅当模型包显式启用时，坐标、邻域半径、传播衰减和局部簇统计才属于模型属性。

比较非空间与空间模型包时，应尽量保持刺激方案、注意/躯体配置、随机种子策略和观察器阈值一致。无论哪种模式，屏幕上的距离、相机运动和纯美术布局都仍只是展示数据，除非它们确实由模型包中的空间状态推导而来。

## 延后方向

- 未来的解码器可通过相关与无关探针检验稳定的刺激—反应映射，而不是直接假定某个结构等于某个文字；
- 功能区应由感官活动和连接自然形成，而不是人工预先命名；
- 自反馈、输出器官和远端生理信号都应保持为可选实验边界，并具备可观察的延迟与变换。
- 未来可构造关联验证解码器：提供相关与无关探针，比较匿名反应指纹和延迟，只保留可复现的刺激—反应关系。大模型可以在定量比较之后辅助撰写自然语言假说，但不得选择结果、向 Core 回灌，或被当作内部意义的证据。
