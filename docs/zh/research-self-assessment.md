# 研究自省与证据边界

[中文](research-self-assessment.md) | [English](../en/research-self-assessment.md)

ThreeMind 的长期工程目标是实现人工意识。本文防止两个相反的错误：把可能有价值的研究路线一概视为臆想，或把早期动力学现象当作意识已经出现的证明。

## 1. 已经成立的部分

以下是可通过普通软件验证确认的工程事实：

- ThreeMind 是一个持续运行的、用于局部可塑联想图动力学的实验平台；
- 运行时与感官适配器、输入输出总线、观察器、持久化和图形界面在因果上分离；
- 系统记录模型包、刺激、事件、快照、遗照等可重复实验所需信息；
- 系统支持外界直接触达、联想触达、衰减、巩固、时间关联、可选空间关系及可配置感官边界等机制。

这些事实不证明智能或意识；它们证明的是：已经建立了一台可用于研究相关假设的仪器。

## 2. 可检验的初步主张

| 主张 | 合适的检验方式 |
| --- | --- |
| 感官约束会塑造内部图组织。 | 多种子下做匹配的适配器消融，比较连通分量、图基元、痕迹寿命与激活分布。 |
| 输入顺序会留下持久历史影响。 | 对同一刺激集合采用不同排列，比较之后的拓扑和响应。 |
| 直接触达、联想再触达、遗忘与巩固具有可测差异。 | 测量一次暴露、重复直接暴露、仅联想再触达后的保留曲线。 |
| 多样环境输入支持短暂新痕迹；低多样性输入场促进稳定或饱和。 | 固定其他参数，仅改变来源多样性，量化新增、消失与连通分量增长。 |
| 带标签基线可验证“刺激—结构—输出”仪器链路。 | 预先登记标签与探测，利用留出刺激检验预测准确率。 |

正结果支持的是这些具体主张，而不是直接证明一个心灵；负结果同样有价值，因为它能限制或证伪机制。

## 3. 解释纪律

观测到的活动首先应获得中性的动力学描述。

| 容易出现的描述 | 当前可辩护的描述 |
| --- | --- |
| “这个三角形有意义。” | 在某个感官与运行时条件下形成的稳定图基元。 |
| “它在用摩斯电码思考。” | 可能的周期、交替或双稳态激活模式；应先测量周期性和信息量。 |
| “重复结构就是一个念头。” | 重复出现的局部结构指纹。 |
| “可读输出证明它理解了。” | 经标签或读出器介导的可解释输出，仍需要因果验证。 |
| “系统已经有意识。” | 除非有明确操作性理论与独立证据，否则仍是不被支持的结论。 |

这种区分使结果能够被他人理解，也能抵御固定随机源、隐藏上限、可视化行为、标签泄漏或全局饱和等替代解释。

## 4. 不应低估的价值

ThreeMind 不只是哲学断言，因为它将一条可能通往人工意识的路线拆成了可分离、可检查的机制：连续过程；可塑映射；感官约束与适配器编排；局部联想、遗忘和巩固；匿名状态与调试标签分离；输出观察与网络本体分离；以及支持因果实验的模型包和历史记录。

即使现有机制最终不足以形成人工意识，研究也可能产出关于自适应图动力学的有价值发现：分化、饱和、类似记忆的保留、感官塑形与历史依赖组织。

## 5. 需要控制的风险

ThreeMind 的开发已经表明，严格对照不可缺少。固定或低多样性的背景刺激、限制性适配器、隐式限制、仅前端动画、过期 UI 状态、进入节点的标签，以及全局饱和，都可能制造视觉上引人注目却会误导的效果。任何被主张的现象都应依靠原始运行时状态、配置、种子与重复运行核查，而不能只靠截图。

项目还必须区分一般机制和特定适配器／参数区间诱发的行为。受限感官通道形成稳定图案，可能正是该通道的预期结果，而不是某种普遍内在组织的证据。

## 6. 接下来的操作性路径

下一个证据门槛不是宣布意识，而是一组可复现的因果发现：

1. 在查看偏好的可视化之前先定义指标；
2. 保存模型包、种子、刺激、代码版本与原始历史；
3. 运行匹配的正反对照；
4. 跨种子、并尽可能跨机器或用户复现；
5. 在探测之前作出预测，而不是只在事后解释；
6. 寻找可跨输入和适配器泛化的关系；
7. 将失败、饱和和零结果也记录为数据。

后续可进一步检验稳定功能组织、跨感官关联、自维持内部动力学或适应性闭环行为。这些证据可以加强路线值得继续的理由，但仍不会自动解决主观体验问题。

## 7. 工作准则

> 对现象保持最大好奇；对解释保持最小承诺；对证据保持最高要求。

长期目标仍可以是人工意识；当前主张必须准确：ThreeMind 正在构建并检验一条持续、可塑、受感官边界塑形的人工网络路线。
