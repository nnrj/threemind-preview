# 6.1：局部删除与独立发送门槛

2026-11-13。作者明确批准在新版本中采用局部删除、保留全图扫描选项、分别设置激活与抑制的发送门槛，并优化发送实现。版本身份为 `threemind.continuous-memory/6.1`。新建默认选为6.1；保存过的个体按自身版本恢复，6.0及更早版本的实现不变。

## 删除发生在对象局部

每条连接使用当前权重、衰减年龄、保持尺度和删除阈值，直接计算下一次需要检查的时间。创建、强化或明确的参数干预会替换该连接的到期记录。队列中每条连接最多保留一个删除记录，不保留失效记录。

到期时只结算这条连接，并再次比较权重与删除阈值。低于阈值才删除；若已被强化，则重新安排到期时间。连接删除后，只检查它的两个端点。节点没有有效连接、激活已归零且支持度低于既有门槛时删除；尚未满足时，按该节点自己的衰减安排检查。

局部检查仍落在原有的内部时间网格上，默认间距0.1秒。同刻输入、局部新颖性和发送先完成，删除随后执行。若最后一条连接消失时节点也已满足删除条件，节点在同一删除阶段清除。内部时钟的推进负责触发到期事件；观察、保存及墙钟等待均不触发模拟推进。

`deletion_strategy` 有两个值：`local` 为默认；`global-scan` 每个网格时刻检查全图，供明确选择的对照使用。该配置可通过已声明的暂停参数干预切换；切换时一次性结算并重建必要期限，不把这次干预冒称被动观察。其他机制（如明确选择的 `scan-control` 传播对照）与删除策略分别配置。

局部期限按四种单年龄曲线直接求解，不使用强化历史求和、二分搜索或周期性的全边检查。例如逆对数曲线中，令当前权重为 (w)、删除阈值为 (q>0)、年龄为 (a)、(k=e-1)，则到达阈值所需的年龄增量为

\[
\Delta a=(a+1/k)\operatorname{expm1}[(w/q-1)(1+\ln(1+ka))].
\]

保持尺度固定时，所需内部时间为 (H\Delta a)。开启原有尺度回落时，对原有年龄积分作解析反解。计算出的时间向上取到既有网格，实际删除仍以严格的“小于”比较为准。极远、超出安全数值范围的期限每至多 (10^{12}) 内部秒重新检查该对象；这是远期数值保护，不是全图扫描。删除阈值为0时，不安排按权重删除。

## 激活与抑制分别决定是否继续发送

| 参数 | 默认值 | 比较对象 |
| --- | ---: | --- |
| `activation_send_threshold` | 0.004 | 源节点的激活强度 |
| `inhibition_send_threshold` | 0.002 | 源节点的抑制强度 |

低于相应门槛时，节点不提供该类信号；两类活动都不足以发送且没有待处理输入时，不再安排重复发送。新刺激或新到达信号可重新启动发送。0关闭相应门槛，但活动必须为正才安排发送。

这两个门槛与节点激活归零门槛、连接端信号量门槛分别控制。既有 `propagation_activation_min` 仍有效，默认0；既有 `inhibition_sender_gate_enabled` 默认关闭，开启后额外限制提供的抑制信号量。连接的短时资源、传导、学习及能量规则不随本次改动改变。发送门槛会减少弱活动引起的发送、耗能及学习机会，属于明确的新版本动力学变化。

## 等价的实现优化与兼容检查

Rust在构造和明确重配置时解析常用选项，运行时直接访问类型明确的值。连接的短时资源和短时增强状态使用数值时间戳；序列化仍输出原来的字符串时间，并保留已接受存档中的前导零。发送减少状态重复查询和复制；只有真正产生激活信号包时才分配特征向量，其数值仍取自原来的时刻。

Python与Rust使用同一版本协议。6.1选择全图扫描、两个新增门槛都为0时，用完整轨迹核对6.0原行为；这不关闭原有的连接端门槛或节点归零机制。两种删除策略的内部记账和惰性结算时刻可能不同，分别保存各自真实状态，不混称字节相同。

6.1沿用 `threemind.birth/2`：默认继承持久状态与衰减年龄，年龄归零是明确的另一选项；后代快速状态与内部时间重新初始化。
