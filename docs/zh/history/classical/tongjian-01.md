# ThreeMind 通鉴 · 卷一　肇始与定名

今撰文言史，成于 2026-10-01。借古书体例，不托古人之名；正文为改写，原话与数据以所引史料为准。日期皆公历，不拟造帝纪、干支或私史。

## 七月二十三日

夜，研究者于 Codex 开问，以 BlueBox 为空目录，欲试一 AGI 之说，问语言与层次。助手议先用 Python 便于验思，后视瓶颈取编译之具。今可考项目之始在此，思想何日初萌，未详。

## 七月二十四日

子夜后，陈连续自我、可塑、联想与遗忘之论，以人所感之绿、内外之概念、梦中易身明其意。谓结构之内义可异，而世界之所指可通。又请图形与命令并备，模型可存，变化可选记录。继明联想亦为刺激，传播应如多米诺，不得预设无由之内驱。

是日，文字为节点所藏之弊起议。研究者令以匿名映射为本，明文仅作对照。又见图像在后端止后仍动，遂辨布局之动与意识之动。日暮更定内核、模型与工具之分，存旧 BlueBox，别治 bluebox-next。

## 七月二十五日至二十八日

二十五日，三通道背景生近三角之局。下午，议强刺激留深痕，改联系属性，不另设保护者；讨论一次巩固之限，免成不朽。二十六日，研究者详责前置注意与新颖评分，不欲门外之过滤先替内核选世界；局部新颖当有既有之邻域及真实联想。

二十七日前后，固定背景易成密网，长文本一并递送又致阻塞，遂明感官多样性与时序分帧。二十八日札记见重复短句再触匿名子集，亦揭外标字节共享之误。原记与追记日期不同者，各据其册，不强一之。

## 七月三十一日

午后，议名 ThreeMind，以连已有 ThreeJSON、ThreeBox。十三时三十六分，命改正在开发之新版，旧 BlueBox 不更。此为定名日，不取后来的 Git 根为创生日。
