# 凡例、异说与续写规则

[简体中文](editorial.md) · [English](../../en/history/editorial.md)

## 本书的四种读法

现代中文本与英文本按编年分卷讲述因果经过，再用思想、器物、机制列传追踪跨时段问题。文言《ThreeMind 史记》借本纪、书、列传组织；《ThreeMind 通鉴》按公历年、月、日组织。两者都是 2026 年今人文学改写，不是假托古人原作，也不是额外实验报告。

## 史料层次与取舍

优先保存带日期的原始对话、固定提交中的代码、实验设计及结果；后来的回忆、总结与编者推论分开署明。对话中“已完成”只证明当时作过该报告，代码实际状态须另核。日期分别标明事件、记录、提交、收录；实验目录名不必是整批实验完成日。北京时间只用于已知时间戳换算，不给缺日材料补生日。

本次检查现有 `docs/`、`lab/` 文档及当前 Git，并读完首期对话 314 轮；不遍历大型 `data/`，不宣称数据库内每一条证据都已复算。现有 lab 札记、实验报告、验证日志、计划与原话附录已经承担部分史书职责，但此前没有贯通的通史。`archive-catalog` 主要是存储归档，不等同项目思想史。[重点史料索引](sources/source-register.md) [文献盘点](sources/inventory.md)

原件留在原处。引文逐字保留并注明删节；摘要不可加引号冒充原话。找不到附件、时间、实现动机就写明。当前 Git 根前的代码历史不可凭空补齐，首期对话提供的是独立史料。8 月 24 日的大文件推送失败与重建仓库讨论解释了这一边界；本次没有取得当时备份的完整旧仓库。[Git 边界](sources/git-register.md)

## 异说与更正台账

| 问题 | 原记载／解释 | 后来更正或并存解释 |
| --- | --- | --- |
| 诞生日 | 仅看 lab 最早为 7 月 25 日，Git 根为 8 月 24 日 | 对话确认 7 月 23 日项目起点、7 月 31 日定名；思想更早萌生不可考 |
| 死亡 | 输入中断或结构不再改变 | 激活活动停止；存在宽限期及首次激活前状态 |
| 强刺激来源 | Git 根以前动机不明 | 7 月 25 日请求和上限动机已找到；精确数值理由仍缺 |
| 配对与家系 | 可读片段像回答 | 标签、探针、末态、组合泛化分别验证；部分配对有证据，家系尚无稳定优势 |
| 保持全角标点 | 改感官规范化 | 用户只约束教学原句；恢复默认映射，旧实验单列 |
| 固定接线足以产生偏好 | 被误读为现象无价值 | 机制解释不取消现象；后来选择性消融定位内部贡献 |
| 自主活动标准 | 达标后仍可能继续争论意识含义 | 固定标准下明确通过；其他理论或主观体验另列问题，不撤销该通过 |
| 无读出 | 当作无活动 | 过程积分和轨迹可能检出，不能无声改变旧主判据 |
| 300 秒无响应 | 全部记忆消失 | 结构保持、表达门槛及真正遗忘应分开 |

各项完整依据见相应编年卷与主题卷；本表不另造一种“最终解释”覆盖原件。

## 以后怎样续写

1. 完成有价值的讨论、实验、内核／协议变化或纠错时，追加事件：发生／记录日期、提出者、问题、原有状态、候选、决定、理由、适用版本、证据、未结项。
2. 先保存可公开的原话或链接，再写连贯叙事。用户回忆与代码、实验不一致时并列，不擅自裁成唯一版本；不得收录密码、私人无关材料、内部推理或大体积原始数据。
3. 同步中英文、里程碑表、相关专题和史料登记。重要新阶段增加编年卷；文言两书追加对应记载，不能为了押韵改事实。
4. 更新 `docs/history/catalog.json`；新章保持稳定 ID，旧链接继续有效。正文直接由 Markdown 提供，无须往实验数据库另存一份。
5. 用 `tools/validate_history.py` 检查目录、双语与本地链接；前端涉及改变时做构建和阅读测试。局部术语澄清、改错字无需新建一场“里程碑”。

结论允许被新证据修正，但应追加“何时、为何、对哪些条件有效”。复现与旧意识身份不得因编史被改动。
