# 卷十　让各点自为，而不以改架构冒称记得更久

[English](../../../en/history/chronicles/10-local-events.md) · [前卷](09-adaptive-retention.md)

2026-10-09。前一文字试验中，默认 H 保持弱于旧稳定度和完整 `/2`，用户追问遗留全图计算的作用。其要求不是停止模拟时间，而是把衰减、传播和消失交还给各自对象；时钟可以递送已有局部事件，不应另作全图裁决。能源亦拟改为邻近区域的资源摄取，外入与联想默认同等处理。评估后用户授权新 `/4`，复明 `/3` 仍可创建与运行，共用代码可改。[原话与边界](../sources/2026-10-09-local-events.md)

核查先纠一说：修复后的 `/3.1` 已有局部失效回收，不能把更早的全图修剪当成其保持退化的既定原因。新核独立实现各对象的时间锚点、传播/失效队列与局部索引；全图访问只留显式扫描对照和观测/保存等工具范围。统一接收、异步相位、逐条接收均有声明的对照，接触学习限真实包到达，不索全图共同激活。短时资源与 H 数值未偷偷调整，节点/边唤醒仍默认关闭。固定出生区域的能源按缺额比例摄取，默认能量模型是局部场，但能量总开关仍关闭。[计划](../../plans/local-events-v4.md) · [执行约定](../../local-events-v4.md)

工程验相关回归352项过、11项因隔离数据库未运行而略；Rust六项单元测试和前端构建过。`/3` 冻结轨迹、旧保存和可创建能力均留，新 `/4.1` 则完整保存自身时间、消息、资源与随机状态。普通二进制模型原有列曾不足以容纳新对象字段，实施中补为明示扩展，再验两后端与独立 Runtime 往返。没有启动或接管用户服务，也未声称实机 Lab 数据库/UI验收已过。

另登记十二条件，各生空白 Core，固定文字感官，每帧二字，两句或一遍、或十二遍，实测物理遥测前44秒为背景。相同十条文字边为各组基线。闲置约120秒，`/4` H只余二边、权重1.71%，稳定度余十边、20.37%；完整 `/3` 分别余四边、3.18%，十边、33.96%。至300秒，新版皆空，旧稳定度仍余二边。重复确有益，却未形成足够长的 H 保护；这些同帧字边也不是颜色答案，文字与背景未生交叉边。[实测](../../../../lab/explorations/2026-10-09-local-events-v4/report.zh.md)

主批之后另登记只读诊断，10ms采样见 H最高30.0035秒，七十个边发出时刻，重放末态与原线同。故不能说从无传导或从未增长；可说增量甚微，回落太快。新版初成权重、稳定度亦弱于旧版，对具体学习机会及时序尚缺独立消融。不能再以工程局部通过，遮掩保持目标未达。

无关点从二增至万二，局部对象访问不增，扫描对照徒增枚举；然而小型密集遥测图中新核更慢，逐边离散稳定度事件尤费。局部原则已落实，并不保证所有规模都更省算力。遂存其负结果，不改默认数值，不把长教提前，下一步先校准剂量与 H 回落，再查学习时序。新建仍以 `/3` 为默认，`/4` 作可选研究；R07/R40/R41、两种今文史和文言两书同时续记，旧实验原件不改。
