# 卷二　重构的收益与失而复得的机制

[简体中文](02-reconstruction.md) · [English](../../../en/history/chronicles/02-reconstruction.md)

## 从单机原型到研究平台

8 月的先行工作把“背景”拆得更清楚。13 日计划使宿主物理遥测成为默认来源，随机环境与进程遥测分别保留开关；16 日批准新增实例运行代价反馈，并关闭默认全局稳态钳制。宿主、共享服务进程、单意识运行时测到的不是同一种量，真实 CPU 时间也不等于 Core 能量。反馈仍经适配器进入输入总线，不能直接将 OutputBus 回灌。[八月原始计划](../sources/august-adapters.md)

8 月 24 日的根提交保存了旧 Python 运行时、前端和既有文档，成为后来恢复 V3 的代码依据。此前巨型测试数据进入旧 Git 历史，推送被拒后讨论了备份重建；这解释当前仓库的起点，但本次未取得更早备份。8 月下旬还可见耳朵等外围功能的修订。9 月初的架构评估则面对更大的问题：动态图长期运行会卡顿，大 JSON 模型文件、图形全量复制、队列与研究证据混在一起；快照共享引用也会破坏同源副本比较。[A01 · 第二代评估](../../second-generation-architecture-assessment.md) [提交记录](../sources/git-register.md)

这次重构选择区分三个对象：内存中真正演化的模型、Runtime 的接入与恢复能力、Lab 的实验与证据服务。PostgreSQL 成为工作台事实存储；Arrow 是列式内存／传输工具，Parquet 是证据文件格式，DuckDB 是分析工具，不能把它们统称为互相竞争的数据库。模型导出按需进行，不能每次激活都重写大文件。独立 Runtime 必须可以脱离工作台数据库。公开平台的账户隔离与本地工作站的自主部署也必须并存。[A01 · 存储与部署决策](../../second-generation-architecture-assessment.md)

ThreeJSON 原先处于渲染路径中，后来决定默认使用 Three.js 批量点线与实例化。这个决定针对实时图形更新链路，不是对 ThreeJSON 全部用途的否定。后来的视频或解释可视化仍可以另行集成。现有史料不足以提供两库在全部负载下的普遍性能排名。

## 时间架构获准改变，其他机制没有因此获准删去

研究者接受时间戳递送和模拟时间，使加速训练不必等同真实墙钟等待；同时要求内核保持刺激历史与局部规则的意义。后续区分数值步长、传播节律、显示刷新率与墙钟速度。统一时间并不意味着每个离散非线性步骤都可以在更小数值步上重复施加。[D01 · V3 恢复计划与换算规则](../../plans/v3-restoration.md)

重构却曾同时丢失或改变若干关键能力：创建参数退为 JSON 为主的入口，普通意识被加上必填时长，聊天与被动明文读出变得难以操作，重要标记模式藏入深层参数；旧 V3 的生边、局部可塑性、新颖性、抑制与遗忘，也被新简化规则替换。研究者明确指出，这不是获准优化的当然代价。恢复工作因而转为以旧源码为准，逐项列出保留、恢复与待议项。[A03 · 能力恢复清单](../../v2-capability-restoration.md) [A04 · 动力学行为核查](../../v2-kernel-behavior-audit.md) [D01 · 恢复依据](../../plans/v3-restoration.md)

## 恢复不是返回旧帧驱动

恢复采用 `97d8592` 的实际 V3 公式，不恢复 V1、V2 预设；保留已确认的新时间架构和实际非零传播能够独立巩固经过连接的改进。逐边弱信号先过门槛，饱和接收端不能取消已发生的传输消耗。生边要保留共同激活、巩固和新颖性；孤立点与独立小网络合法，不能为了画面好看强制接网。修剪恢复多条件联合，而不是一安静就删除。`c42baed` 记录了这次恢复。[D01 · 逐项决定、参数与验收](../../plans/v3-restoration.md)

新恢复版使用 `causal/8`、`state/6`，随后活动死亡规则再形成 `causal/9`。版本号用于保证旧意识的身份，不应把今天默认设置反推成当年的配置。原来联想巩固位于候选生边分支的事实可查，但作者当初为何如此组织，现有初始导入历史无法回答。

## 工具也属于研究能力

参数图形界面与 JSON 同步、器官采集、实验比较、先天版本、生态训练、文档、笔记与报告相继补全。统一适配器意味着共同的身份、采样和收发边界，不意味着把每个设备削成同样的能力。评估用独立出生副本，测试中新学结构不写回父本。运动出口当时仍有固定投影，不能说功能脑区已经训练涌现。[A02 · 分阶段验证记录](../../v2-validation.md) [A03 · 功能恢复台账](../../v2-capability-restoration.md) [P04 · 功能分化边界](../../embodied-functional-differentiation.md)

这段历史留下的教训很具体：能够构建、接口能够返回，不等于旧操作已经复原，更不等于动力学等价。后来还发生聊天布局的再次纠正，本书在下一卷续记，不把一次“验收完成”当作永不需要复查的结论。
