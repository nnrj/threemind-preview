# 2026-11-18：相同刺激的两次出现与时间寻址

## 作者提出的问题

在讨论新的寻址函数时，作者指出，即使内容相同，不同时刻到来的刺激也是不同事件。他以两次相同画面之间发生闪烁为例，询问是否应将内部时间或随时间演化的量加入节点映射，同时担心这会使相同刺激不能再次到达同一节点。作者又联系AX、BX共享刺激的实验，提出共用刺激与不同背景或许已经能够兼顾关联和区分。

以上为本次对话的概述，不是逐字引文，也不是已经批准的内核改动。执行者建议区分稳定输入地址与整个网络形成的经历映射：保留共同输入，让变化的内部状态参与活动和连接形成，并先检验现有6.3能否区分重复呈现和间隔。

## 明确授权

作者随后要求：

> 好的，对你认为需要检验的这三个问题，在6.3内核上进行简单的实验检验。

三项问题分别为连续与分次呈现、重复间隔，以及激活消退后的连接保持及再表达。此授权不包括修改内核或寻址函数，也不自动恢复其他暂停实验。

## 设计与测量

RT63-01在运行前固定了两档输入强度、四套匿名编码、三种等剂量课表和判定门槛。所有条件最后200毫秒的输入相同。24条主线连续运行到34秒，再建立120份有提示、无提示、假操作和仅权重交换的单次诊断副本。原主线完整保留。

测量确认，两档强度下均可区分连续呈现、0.2秒间隔及1秒间隔；30秒后两档均保留连接权重差异，强度0.2条件还再次表达差异，并通过权重交换确认因果作用。强度0.05条件未在固定测试刺激下再次表达，未改变测试来覆盖该结果。四套编码数值相同，其意义是编码重命名下一致，不能夸成随机总体重复。

关于“无需每次更换输入地址”的判断，是基于本批结果作出的范围明确的解释；本批没有测量语言报数、精确时间报告或一般情景记忆。
