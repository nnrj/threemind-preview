# 时间区间收敛读出

[中文](temporal-window-readout.md) | [English](../en/temporal-window-readout.md)

## 目的与边界

ThreeMind 保留原有的**单 tick 截面读出器**，同时增加并列的**时间区间收敛读出器**。前者回答“这个截面中哪些结构或触达最突出”，后者回答“某次刺激之后，哪些节点在一段时间内持续占据活动舞台，响应是收敛、振荡、残留衰减还是短暂消失”。二者都是 `OutputBus` 的只读适配器，不修改节点、连接、激活、抑制或学习规则。

时序读出不能在匿名模型中凭结构断言语义。它可以证明某个输入包稳定引发了可复现的动力学响应；只有模型带有外部观察标签，或另有经过对照验证的解码映射时，界面才可把候选节点显示成字符。匿名结构与原始指标始终是科学记录的主体。

## 因果窗口

输入总线已经为一个完整载体生成 `envelope_id`，并把长载体拆成有序帧。Core 现在只把以下审计上下文随匿名 `OutputFrame` 向外投影：

- `envelope_id`；
- 当前帧序号与总帧数；
- 输入适配器 ID；
- 外部来源。

这些字段不进入任何动力学函数，也不包含载体明文。读出器在首帧到达时开启响应窗口，在末帧到达后继续观察尾段，因此不会把长文本的传输过程误当成已经结束的网络响应。重叠载体会被显式记录，而不是偷偷归到同一因果解释中。

## 统计与判定

每个窗口先保留刺激前若干 tick 的节点激活均值与自然波动，以此扣除既有背景活动。随后为所有候选节点记录：

- 高于基线的激活持续 tick、最长连续持续时间与再次进入次数；
- 激活积分、高于基线的激活积分、峰值与平均值；
- 直接触达、联想触达、抑制与稳定度；
- 刺激传输结束后的持续时间；
- 活跃候选集合的相似度与归一化激活分布漂移。

默认候选范围是“受到联想触达，或在输入结束后仍持续激活”的节点，以避免读出器只是复述输入感官节点。用户可以改为仅联想触达，或纳入全部高于基线的节点。

读出器按可审计规则区分：

- **收敛：** 尾段候选集合稳定且激活分布漂移足够小；
- **周期振荡：** 尾段候选集合出现重复周期；
- **残留衰减：** 活动主要是单调消退而非稳定响应；
- **瞬态响应：** 活动在最短窗口内消失；
- **尚未判定：** 到达最长窗口仍未满足其他类别；
- **观测中断：** 读出功能在窗口完成前被关闭。

综合排序默认同时考虑持续比例、最长连续持续、尾段持续和高于基线的激活积分。“考虑激活强度”可以关闭；也可以直接选择按持续时间或激活积分排序。所有事件都会保存完整候选指标和当时的配置快照，界面显示上限只影响展示，不截断科研记录。

## 使用

在 **设置 → 观测、读出与记录** 中可分别启用截面读出和时间区间读出。时序模式默认只响应人工输入，AI 与背景刺激需显式开启，以免连续环境载体产生大量重叠窗口。完成的结果会：

- 出现在右侧刺激聊天历史中，显示 tick 区间和分类；
- 写入该意识的被动读出记录；
- 保存在模型包及已配置的历史持久化后端中；
- 在明文观察模式下附带外部标签，在匿名模式下只显示匿名响应标识和节点 ID。

详细动力学追踪仍是另一项独立功能。时序读出不要求开启逐 tick 追踪，因为它直接订阅实时 `OutputBus`；详细追踪用于事后重放和更细的科研审计。
