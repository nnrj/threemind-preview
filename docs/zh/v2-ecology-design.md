# 生态训练器实现设计

本页保留共享／独立栖息环境的实施设计。已交付的协调器、原子恢复与界面见[生态训练使用说明](v2-ecology.md)，剩余范围以该页为准。定向多代选择独立实现，不能将其评分排序改名为「自然演化」。

独立规则、共享物理与身体状态感官的实现细节见[基础组件说明](v2-ecology-foundation.md)。

## 已确认的边界

共享物理世界为默认，独立栖息环境也支持。当前遗传载体是被刺激塑形后的持久网络，沿用 `threemind.birth/1`；不增加 DNA 前置依赖、随机重连、语义连接或隐含的意识质量评分。生态个体的实际经历可以遗传；额外评估仍使用独立出生副本，评估学习不回流父本。

## 世界与策略

物理世界和躯体复用已实现的声明协议。共享运行必须由一个物理步进器统一处理多个躯体，每个躯体对应一个独立 Core 实例；不能让每个意识各步进一次所谓的「共享世界」。所有个体先提交当前动作，环境步进一个声明区间，随后递送各自测量。独立栖息方式使用隔离的物理状态与资源池，明示不存在个体间直接碰撞或竞争。

资源规则描述位置、范围、再生、容量、获取速率及分配策略；分配可以比较局部均分、按需求或按距离。群体接近条件可以形成需要多个个体同时到场的获取条件，但它不证明意识具有合作意图。「竞争」「合作」不能只是无效的名称，也不写入 Core 的奖励、道德标签或特定路径。

消耗和损伤作为外部躯体规则分别记录。初始方案使用明确的模拟资源单位，不能随意称为焦耳、CPU 消耗或 Core 能量。资源账本与已有 Core 能量账本分开；若以后需要耦合，要以显式适配器和换算协议实现。接触损伤与空间危险区域可配置，默认不把伤害竞争当作意识形成的必要条件。

繁殖依靠年龄、资源、冷却、出生支出和人口边界等声明条件。后代起始躯体资源从父本扣除，额外繁殖支出独立记录；不隐式无限复制资源。人口上限导致繁殖暂缓，不冒充个体死亡。共同达到条件时的机会分配必须确定可重放，不能依赖线程抢先顺序。独立栖息环境中新建资源池属于显式环境供给，不能宣称其总资源与共享有限世界相同。

## 时间、身份与恢复

群体有全局模拟时间，每个出生个体保持自己的 Core 时间及出生偏移。后代的感官身份和执行器映射沿用继承协议，物理对象的实例编号不应偷偷更换其已学习的接线。场景标签仍只用于观察。世界对象、资源状态、出生谱系及全部脑状态必须在同一逻辑恢复边界提交。

Lab 需要一个原子群体检查点：世界、资源、个体列表、出生事件及各个体恢复点要么全部可见，要么全部回滚。不能靠分别读取每个个体的「最新检查点」拼出一个从未存在的群体状态。复用现有增量检查点和输入证据机制；若扩展事务接口，需验证并发、租约、崩溃和重复提交。

个体仍应能从普通查询／模型工具查看和导出。共享实验统一暂停与继续，不能单独恢复一个成员而破坏共同物理时间。后台生态任务失败不是自然淘汰，资源耗尽导致的身体失效也不是 Core 意识死亡。身体失效后的输入关闭与 Core 后续活动需分别记录；未模拟的衰减过程不能被写成已观察到的死亡。

## 交付顺序与验收

先实现可独立验证的资源／损伤／繁殖规则，再接通共享物理步进、独立栖息方式、现有 Runtime 输入和记录工具，以及群体原子恢复。随后提供图形和 JSON 策略配置、实时世界观察、个体谱系、资源与存活／繁殖图表、全部事件和研究证据导出。关闭界面不改变任何科学结果。

验收检查资源收支、没有新增刺激时不会凭空改写网络、直接竞争仅出现在共享条件、出生状态清空活动而保留持久结构、评估隔离，以及相同世界／规则／种子的中断继续。采集全部个体，保留失败、未繁殖、灭绝、人口截断和观察期结束的右删失，不仅导出获胜者。

用户另外提出的演化观察与播报、运行预警、目标评估和统一适配器审计见[待议方案](v2-observation-and-adapter-plan.md)。它们复用这里的事件与证据，但未讨论的自动干预不会作为生态训练默认行为引入。
