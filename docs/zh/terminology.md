# ThreeMind 术语表（中英）

[中文](terminology.md) | [English](../en/terminology.md)

本表用于统一 ThreeMind 的中文写作、英文翻译与代码文档。它给出项目内的工作定义，不等同于对生物意识、神经科学或哲学概念的最终定义。

## 表述原则：先让人理解，再给出精确定义

2026-09-29，根据研究者要求补充。讨论、报告、文档和界面优先使用现实中已有、读者熟悉的概念和词汇；已有项目术语应保持连续。不要为了显得精确而不断另造名称，或用缩写、层层限定掩盖一个简单现象。先说明发生了什么、有什么意义，再在需要复现的地方列出参数、单位、公式和适用范围。

允许借用“能量”“记忆”“联想”“适应”等已有词汇，并在论文和技术说明中给出项目内的操作定义。借用不意味着已实现该词在生物学或日常生活中的全部含义。发现概念不完全对应时，应补充定义，而不是立即发明一个更难理解的新词。

只有现有词汇确实无法表达关键差别时才引入新术语；首次出现时用一句普通话解释，并给出已有术语与代码字段的对应。不能用同一个名称掩盖实际不同的机制，也不能通过改名偷偷改变机制。

### “能量”的用法

旧文档已经使用“能量”，包括[局部抑制与能量](local-inhibition-energy-and-dynamics.md)和[能量记账](v2-energy.md)。后续讨论沿用这个词。必要时用“连接上的能量”与“整个模型的能量”区分作用范围，不要求读者先记住“短时可用传输资源”才能理解。

| 日常表述 | 本项目中的确切含义与参数 |
| --- | --- |
| 连接能量有限，会耗尽并恢复 | 连续记忆研究核的 `depletion_enabled=true`；每条连接的可用份额随传递减少、随时间恢复，利用率另受易化影响。这里将这一有限传递能力称为能量，不宣称它等于生物 ATP 或焦耳。 |
| 取消连接能量耗竭／每次瞬时补满 | `depletion_enabled=false`，且短时机制 `stp_enabled=true`；每次释放前补满可用份额，易化仍生效。这是此前 D=0 的干预，不能等同于研究者要求的“无限供能”。 |
| 整个模型的能量记账 | 独立的 `energy_simulation_enabled` 及 `energy_*` 参数，管理整个模型的储备、供给和消耗；不是上述连接开关的别名。 |
| 无限供能／供应充足 | 外部储库不枯竭，不意味着内部储量无限或随用随满。连接仍消耗能量、按有限速度恢复，节点保留抑制和不应期。已有外部供给的 `total_supply_limit=null` 表示总量不限，`rate_per_s` 仍有限，`energy_capacity` 仍有限；这些字段不替代局部的 `depletion_enabled=true`。 |
| 重新开启能量消耗 | 对此前报告“恢复耗竭”的直白表述；指重新启用消耗机制，不是“补充能量”或“能量恢复”。 |

模拟能量是否受限由研究假设决定，不必照搬生物的供能条件。无限供能是合法的模型条件，不代表宿主机有无限电力、内存或算力；实验仍须遵守硬件预算。能量、感官刺激和激活不能互相冒充：供能不自动产生刺激或激活，意识死亡仍按全部激活停止并达到既定等待期限判定。

研究者的例子是：馒头一直有，不等于不需要吃，也不等于吃撑后还能无限吃。后续“无限供能”按这一含义使用。此前报告 D=0 的“无限补给”只指瞬时补满的特殊对照，原记录保留并加说明；不能在新实验中沿用这个含混称呼来关闭消耗或恢复过程。

当前局部恢复与全模型供给是独立实现；外部增加储备不会自动加快连接恢复。连续核的自身抑制与 LIF 核的显式不应期／适应电流也须按各自实现记录，不能把它们说成完全相同的公式。通俗用词不免除实现区别的说明。

## 术语

| 中文 | English | 中文释义 |
| --- | --- | --- |
| 人工意识 | artificial consciousness | ThreeMind 的长期工程目标；当前不是已被证明的系统状态。 |
| 工作假设 | working hypothesis | 可被实验支持、削弱或修订的暂定解释框架。 |
| 持续性 | continuity | 网络状态和环境接触跨 tick 延续，而非一次调用后即消失。 |
| 可塑性 | plasticity | 节点或边的状态会因触达和历史而改变的能力。 |
| 联想 | association | 激活沿局部既有连接传播，并以衰减形式触达相邻结构的过程。 |
| 直接触达 | direct touch | 外部感官帧直接作用于受体节点的状态变化。 |
| 联想触达 | associative touch | 由局部传播到达节点的、通常衰减后的状态变化。 |
| 巩固 | consolidation | 重复直接或联想触达使连接更抗衰减的过程。 |
| 遗忘 | forgetting | 未被充分维持的连接强度或稳定度随时间下降，并可能断开的过程。 |
| 匿名节点 | anonymous node | 不保存人类可读输入明文的 Core 节点。 |
| 明文字符节点 | literal-character node | 以稳定字符通道作为可读实验基线的节点；不是标准匿名模式。 |
| 节点标签 | node label | 外部适配器保存的显示注释，不参与 Core 动力学。 |
| 感官帧 | sensory frame | 适配器交给输入总线的匿名通道—幅值脉冲集合。 |
| 感官适配器 | sensory adapter | 将外部载体编码、过滤或投影为感官帧的外部模块。 |
| 听觉感官适配器 | auditory sensory adapter | 把上传或实时采集的物理音频采样，经非语义分帧与频带/波形编码转换为匿名感官帧的适配器。 |
| 视觉感官适配器 | visual sensory adapter | 把上传或实时采集的图像和视频像素，经确定性过滤与局部视网膜 patch 转换为匿名感官帧的适配器。 |
| 环境感官适配器 | ambient sensor adapter | 产生动态环境背景场的适配器。 |
| 躯体适配器 | body adapter | 对环境场进行采样、阈值、适应或噪声过滤的可选适配器。 |
| 输入总线 | input bus | 向 Core 传递感官帧的统一边界；不解释载体语义。 |
| 输出总线 | output bus | 从 Core 单向发布匿名活动与拓扑投影的边界。 |
| 被动读出器 | passive readout / structural readout adapter | 只读取输出总线中的结构活动，不向 Core 写回信号的观察器。 |
| 时间区间收敛读出器 | temporal-window convergence readout adapter | 以输入包为时间锚点，扣除刺激前基线并统计多 tick 激活持续、积分、抑制与收敛的只读输出适配器。 |
| 字符驱动器 | character driver | 使用外部节点标签把结构读出呈现为字符的输出适配器。 |
| 声音输出器官 | acoustic output organ | 只依据匿名节点身份和激活生成有限振荡器控制、不读取标签或执行 TTS 的输出适配器。 |
| 激活图像投影器 | activation-image projector | 把匿名节点身份与激活确定性投影为灰度像素的外部实验输出器件。 |
| 内容寻址媒体载体 | content-addressed media carrier | 按内容校验和去重保存的上传原始载体；与进入 Core 的匿名帧及实时原始流相区分。 |
| 结构指纹 | structural signature | 由节点活动、稳定度、触达计数和内部边概括出的匿名重复模式标识。 |
| 状态指纹 | state signature | 对单个 tick 的激活、稳定度和触达状态进行量化后的截面身份，不等于图结构身份。 |
| 精确结构身份 | exact structure identity | 由节点 ID 集合与内部有向边集合定义的结构 ID。 |
| 拓扑候选类 | topology candidate class | 忽略节点身份后得到的结构分组候选，不等于严格图同构证明。 |
| 出现身份 | occurrence identity | 某结构在某 tick 的单次观测身份，用于避免观测记录和告警重复计数。 |
| 可重复结构 | repeatable structure | 在给定窗口和阈值下重复出现、满足读出条件的结构性活动模式。 |
| 全局饱和 | global saturation | 多数节点进入同一稠密连通分量，导致新输入难以形成可分化新痕迹的状态。 |
| 局部共同触达 | local co-activation | 仅在同一感官帧的直接受体之间形成新边的默认策略。 |
| 时间关联 | temporal association | 将近期共同活动也作为新边形成候选的可选实验策略。 |
| 空间基底 | spatial embedding | 模型包显式启用的内部坐标、邻域和传播约束；不是默认图形布局。 |
| 空间邻域 | spatial neighborhood | 由内部坐标和半径定义的局部邻接关系。 |
| 空间竞争 | spatial competition | 可选的局部活动抑制/竞争机制，用于空间模型实验。 |
| 拓扑局部抑制 | topology-local inhibition | 默认开启且可关闭的局部负反馈；抑制势沿由既有有向边派生的物理邻接有限扩散，不反转兴奋方向。 |
| 抑制势 | inhibitory potential | 节点激活上升后产生、会衰减和饱和，并在下一 tick 降低邻近节点响应的实验性局部状态。 |
| 不应期 | refractory interval | 节点刚被激活后因自身保留的抑制而短时降低再次响应能力的状态；当前由局部抑制自然表达。 |
| 能量记账 | energy accounting | 默认关闭的实验性有限资源标量；开启时只能由初始条件和外部供应增加，尚不等同于物理能量。 |
| 宿主物理遥测感官 | host physical telemetry sensor | 默认开启，把可靠实测的宿主 CPU、内存、磁盘、网络汇总计数和供电状态编码为匿名外部刺激的适配器；绝不是 Core 能量来源。 |
| 进程遥测感官 | process telemetry sensor | 默认关闭，把整个服务进程的 CPU、内存、I/O、调度与运行时间编码为匿名刺激的适配器；多意识运行时不能归因于某一个意识。 |
| 实例物理自反馈 | per-consciousness runtime physical feedback | 默认关闭，把单意识实例真实消耗的线程 CPU 时间、epoch 墙钟时间与调度延迟在下一采样周期编码为匿名输入；不回灌输出语义。 |
| 动力学追踪 | dynamics trace | 显式开启后按 tick 保存节点激活、抑制、支持、触达及拓扑变化的非反馈观测记录。 |
| 注意/竞争门 | attention/competition gate | 位于输入侧的可选环境选择层；默认透明，不应预设求生或奖励偏好。 |
| 环境选择器 | environmental selector | 对注意/竞争门更准确的实验性称呼，强调外部压力而非内在认知偏好。 |
| 模型包 | model package | `.tmind` ZIP 包，包含声明式 manifest、状态、快照、遗照和日志，不包含可执行代码。 |
| 快照 | snapshot | 运行中意识状态的可恢复保存。 |
| 遗照 | portrait | 死亡或停止附近状态的保存记录。 |
| 实例 | instance | 同时运行的一个独立意识运行时。 |
| 随机种子 | sensory seed | 决定适配器投影或空间初始化的可记录随机来源。 |
| 消融实验 | ablation experiment | 关闭或替换一个机制，以测量其对现象的因果贡献。 |
| 临时功能沉默 | temporary functional silencing | 在隔离克隆的运行时边界阻止指定节点或边参与激活与传播、可撤销且不写入模型状态的干预。 |
| 结构移除 | structural lesion | 仅在明确的隔离实验克隆中永久删除指定节点或边并单独审计的干预。 |
| 配对对照 | paired control | 从同一次捕获状态创建对照与干预克隆，并给予匹配输入的因果实验设计。 |
| 历史依赖 | history dependence | 相同当前输入因过去触达顺序不同而产生不同状态或响应。 |
| 刺激—结构—输出映射 | stimulus–structure–output mapping | 外部刺激、内部结构反应和外部读出之间可测试的对应关系。 |
| 可证伪性 | falsifiability | 能明确说明何种观察会削弱或否定某项假设的性质。 |
## 本轮补充：刺激及物理参照

刺激元是一个匿名通道的输入量；刺激组是适配器声明的一次共同观测；刺激体统称两者；事件流是其随采样与递送时间的变化。本体感官是外设，不属于内核。来源、单位、坐标系与观察者标签属于证据，不自动成为输入。见[实施与边界](plans/stimulus-intensity-and-spacetime.md)。
