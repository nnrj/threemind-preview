# 感官与探针校准、实验存储检查

[English](../en/v2-probe-calibration.md)

2026-09-10：此入口现默认打开[时序观察实验](v2-temporal-research.md)，继承完整恢复状态、学习设置和读出配置，不预先等待。本页下述结构继承、固定窗口、无探针对照及投影积分，专指仍保留的“固定窗口探针与感官校准”标签页及省略 `mode` 的旧协议，不能与时序收敛结果混用。两类记录分开查询，旧结果不重算。

入口：意识详情 → 人工实验 → 感官与探针校准。选择已保存的恢复点（留空时提交瞬间固定最新点），填写探针文本、观察词及强度，提交到支持 `worker.probe_calibration_v1` 的 worker。所有结果和完整证据保存在数据库中，原意识不会被推进或改写。

默认用清空活动的结构继承副本，探针期间关闭学习；也可显式选择延续恢复点活动及在途事件。每个探针和无探针对照使用独立副本。感官版本、种子、所有输入帧、实际通道幅值、来源哈希、采样曲线、发送／接收／激活计数与最终状态均可核对。完整 ZIP 保留每个节点的零值与非零活动；评分才排除观察词间共享通道及任何探针直接触达的通道。没有剩余通道或副本已死亡时为无法评分，不是零。关闭的文本感官不会被偷偷开启。

曲线终点是指定模拟时间窗口内的梯形积分平均，再减无探针对照。它表示特定观察投影的激活，不能直接视为回答准确率、语义理解或因果发现。信号到达组可能包含多条已通过逐边门槛的边；工具不把到达组数误称为逐边通过数，也不推算未记录的拒绝次数。Core 公式、门槛和时间架构没有因此改变。

校准应使用独立词表和种子；依据实际传输、通道覆盖及饱和情况选测量条件，在正式验证前固定。不应反复根据目标词命中情况调整到出现正结果。一般先检查测量可观测性，再分别检验配对特异性和关系角色组合。

可独立于数据库使用命令行：

```powershell
.venv/Scripts/python.exe -m threemind_runtime.calibration_cli --model model.tmind --protocol probes.json --output calibration.zip
```

模型没有感官 profile 时须显式提供 `--seed` 和 `--sensor-config`。输出路径必须是新文件。协议例：`{"cues":["甲","乙"],"terms":["松子","铃铛"],"intensities":[1,2,4]}`。完整默认协议可从图形配置切换 JSON 查看。

工具预算：每次最多 2,000 节点、100,000 边、2,000,000 原始节点采样值、64 MiB 压缩证据、60 秒计算；Lab worker 的校准过程限 2 GiB RSS。超限会明确失败，不返回被截断的成功结果。预算限制工具采集规模，不调整内核动力学。长文本全部分帧，若最后一帧超过观测窗口，请调整协议窗口；未递送帧仍保留在最终状态和总线证据中。

设置 → 实验存储检查：主动扫描当前项目的元数据，分页展示“建议保留”“清理有风险”“空记录清理候选”，可下载本页 JSON。数据库事务是只读的。被谱系、校准、报告等引用，或项目含研究文档、实验及本人笔记时保守建议保留。失败和零结果同样有证据价值。

扫描不展开历史大数据、分析 JSON、媒体或笔记正文，不能证明所有自由文本引用都不存在。字节数不等于可回收空间。页面不发放清理令牌，不删除数据；用户仍须在模型档案检查完整清理预览后自行决定。归档不会释放磁盘。
