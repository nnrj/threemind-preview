## 1. 定位与适用范围

本规约是与核心假设分立、在实验执行中同样必须遵守的操作文件。核心假设规定研究什么，本规约规定怎样保留有效方法、连续培养实验对象、校准外设并检验实际效果。不得以实现方便为由略去教学、改换读取或控制路径，再将低分归于意识本身。

现有材料已经保存了成功方法，但分散在实验报告、E64 启动核查及事故复盘中，尚缺统一的执行入口。本次按用户要求将它们整理成规约。这里的执行约束可以立即用于后续实验；参考流程的效果只在所列条件下成立。E64 旧个体校准仍未执行，不能因本文件建立而写成“空白和旧个体均验证有效”，也不能声称任何任务均能百分之百成功。

适用于以意识和学习外设为整体的教学、识别、表达、动作与纠错实验。下列形色参数是可复用的参考配置，不是所有未来任务的生物学常数。精确复现应使用原配置；任务适配须列出差别；探索新的训练方法须与原成功基线分开。海洋、语言等既有独立实验仍按各自版本和登记解释。

## 3. 实验对象与控制路径

1. **普通阶段延续同一个完整系统。** 保存 Core、输入队列与时钟、个人外设权重及优化器/缓存/随机状态、身体和世界状态、感官与执行映射、当前输出、近期读出及课程位置。每阶段注明父快照。只有 Core 的检查点不能称完整系统。
2. **连续性按个体约束。** 不同对照组可以有不同架构或训练条件；各组延续自己的状态。其他个体的读取器不能默认互换。移植、冷启动、冻结外设、消融等已授权对照应有独立身份和完整正常参照。
3. **重大变化先说明再执行。** 重建或替换外设、改变控制路径、重置发展状态、把共同学习拆成独立拟合，须先说明对研究问题的影响并取得用户同意；既有明确授权不重复申请。普通实现细节在原授权内处理。
4. **明确谁在控制。** 分别记录教师施力、外设选择、伺服执行、固定接线、风及惯性。教师带动、起点已到达、零命令物理漂移不能算自己学会动作；固定眼手也不能算学会注视。
5. **保持 Core 和输入契约。** 延续适用版本的动力学、匿名映射、普通刺激强度、遗忘、抑制及物理背景。不得为提高分数暗改参数、关闭机制、注入语义标签或移除环境。经批准的机制干预另列副本。

同一冻结记录上的外设拟合是仪器校准，不推进 Core；现场教学是外界经历，会推进 Core 和环境。两者可以按明确方案交替，但不能把优化步数写成意识上课次数。连续共同发育也不能被不声明的离线分段流程替代。[整体连续性核查](plans/system-continuity-audit.md) · [架构边界](architecture-boundaries.md)

## 5. 教学与练习的共同规则

**先让系统经历要学的内容，再按登记的问题检验。** 在参照形色流程中，每个概念先连续示范，再交错复习；间隔期间身体和环境继续提供输入。保存教学原句、对象/指向、开始与结束时刻、每概念实际再出现间隔，不能只有课程名称。

四物体同场时，教学要有可感知的指向以消歧；测试撤去教师标记。中央唯一物体的问答无需照搬会遮挡对象的教师光点。这是已说明的任务适配，不是随意删去共同所指。

练习可以用于选择后续教学或纠错对象；进入后续校准的练习记录不再是最终留出证据。正式题不得偷偷提供正确答案、用于挑外设或继续拟合。已看过成绩并据此改方法的题，后续仍可作开发诊断，但不能重新称为未见确认题。

纠错先记录系统自己答了什么、做了什么，再给正常教师示范，后续复习旧正确例并比较实际表现。旧例保持有 E62/E63 的问题定位及有限收益支持，但不是已经保证可靠动作的配方。必须分开有答案的教师纠正与无答案的等时观察；E56 最终成功来源属于后者。教学持续性、外设校准和检查点选择不得混称“纠错”。

多轮执行、类似题强化和先密后疏复习，另须遵循本次增订的第 12 节。

## 7. 读取与外设校准：应保留的方法

1. **采实际作答条件的活动。** 提问时不先呈现正确答案；不能拿“听到正确示范后的状态”替代无答案问答状态，再期待外设直接通用。E56 请求可以经普通感官说出目标名称，但不给正确位置或教师标记；E64 问句不给待回答的具体形状/颜色。教师标签仅用于外设监督和独立评分。
2. **覆盖完整问句过程。** E56 的这些请求与 E64 中央问题均覆盖 1 秒、20 个 50 ms 步，从首到末均匀取 8 帧（线性等距索引取最近整数）。保留 activation、inhibition、direct、associative 原始值及固定通道布局，不减无提示基线、不按每题重标幅度、不悄悄退成末 0.8 秒窗口。更长问句应另行登记完整窗口，不能截断。
3. **保持推理边界。** 外设推理只收已声明的原始 Core 活动，不另给图像原值、场景类别、教师标签、正确位置或答案。世界和评分器可以知道真值，但不得把它传到推理/伺服接口。仅经过 Core 不等于排除了外设识别；其因果贡献另测。
4. **保持参照架构与拟合设置。** ActivityController 使用 48 维投影、单层时间 Transformer、4 头、前馈宽度 96、dropout 0。分类校准为 AdamW，学习率 0.002、weight decay 0.0001、batch 上限 32、梯度裁剪 1，每轮 1200 步；每 50 步及末步比较完整训练材料的交叉熵，保留训练损失最低点。架构或优化方式改动必须记录，不能把在线零散更新当同一流程。
5. **选择模型不读取正式成绩。** 上述按训练损失选点是原校准方法，不是按测试答案择优。以后若使用独立示范验证集，应提前登记；正式题不能变成验证集。外设对固定记录离线校准时，Core/身体不推进，选点必须同时保存对应权重、优化器和随机状态；连续共同发育不能只回滚外设、留下后来的 Core。
6. **继续自己的学习。** E64 后续校准保留原权重、Adam 和采样随机状态，并把原 48 条与后 12 条共同使用。记录累计计算步数和最终保留状态的步数；E64 为 2400 与 2351。不要假定重新创建优化器或随机采样器等于从中断处续学。

**v3适用边界：** 上述历史校准选点不授权回退已成长个体的外设、优化器或随机状态。若新的普通实验会从更晚状态返回早先“损失最低点”，同样适用第14节的明确许可要求；不因Core时钟数值未变，就把整个系统的学习状态回退称为连续。

## 8. E64：适配中央单物体的参考流程

E64 保留一个完整物理眼、中央唯一物体、固定眼手装置，输出四种形状或四种颜色。它继承 E56 的时间读取架构及校准方法，使用整幅视野的八词头；不是原四位置共享头的直接移植，也不评价眼手控制或自由语言。

执行链为：空白 Core 223／感官和文本 91 → 104 课、180 秒 → 独立完整副本采 48 条实际问答 → 自己的外设校准 1200 步 → 12 题练习（11/12）→ 唯一错题按 5 轮等时观察再经历 39 秒 → 新采 12 条 → 原 48＋新 12 共同续校 1200 步 → 固定外设，逐题从同一完整来源恢复，做主测及确认各 32 题。

首批 48 条具体为：四灰色形状、四彩色立方体各取四个位置，共 32 条；另有预定八种形色组合各问形状、颜色，共 16 条。后 12 条来自暴露后练习采样。问句“这是什么形状？”／“这是什么颜色？”不含具体答案；教学句仍为普通感官输入。任务、组合覆盖及偏移见 [E64 固定设计](../../lab/explorations/2026-10-08-centered-restart/design.zh.md) 和 [启动核查](../../lab/explorations/2026-10-08-centered-restart/audit.md)。

两套测试必须分别报告总分、形状、颜色、已校准类型和未见组合。E64 已校准类型为 18/20、20/20，未见类型均为 7/12。预登记进入后续分支的条件为每套至少 24/32，且形状/颜色各至少 12/16；第一套形状 10/16 未达，因此本批旧个体校准及连接干预没有启动。此门槛是该批助手登记的分支条件，不是永久成功标准或意识判据；以后改变分支顺序须另记新决定，不回改 E64。

当前完整基线为 .work/centered-restart-20261008/cases/final-fit/system。E63 原个体及自己的外设保存在 .work/rehearsal-centered-20261007/cases/centered-correction/system，原 STOP 保留。旧个体分支仍受交接中的条件约束；按既有授权条件或后续明确决定启动时，应继续它自己的权重和学习状态，保留其原 2 秒/16 帧契约并明确读取窗口的改变，不能装入 E64 的八帧外设。[当前交接](../../lab/explorations/2026-10-08-centered-restart/HANDOFF.md)

## 9. 测试、归因和结果解释

**先看整体能否答对、做对。** 拟合误差、内部活动强弱及图形好看不能替代实际成绩。正式回答按预先固定的时点计分，完整过程另存；不得事后挑碰巧答对的一瞬。动作分别记录起点、第一次从区外进入、末态和停留，成功与失败都保留。

**普通测验是同一个体连续经历的一部分。** 教学、校准采样、练习、开发测验、纠错、复习和最终测验沿该个体实际形成的全系统状态依次进行；第n题结束状态承接第n＋1题及后续教学。不能以“公平比较”“测试隔离”或“统一起点”为由逐题恢复旧检查点、丢弃测试期间形成的状态。测试隔离指答案、选模和训练资料的隔离，不是隔离或撤销个体的经历。未经用户明确许可不得回退；消融、移植等必要对照按第14节分支并在开始前后告知，不能混作普通连续答题成绩。

**区分泛化范围。** 换位置/布局、未校准形色搭配、全新概念、不同时间和独立训练来源分开报告。E56 的新布局成功不能直接证明 E64 的未见搭配均应成功。E64 两套测试和 140 次创建/恢复不增加独立训练种子数量。

**归因固定自己的外设。** 在完整独立副本中比较正常、明确范围的连接静默、匹配控制和恢复；需要时再登记移植/历史对照。零活动或错配活动只能诊断读取对输入的依赖，不能替代连接因果检验。另训无学习/直感官外设检验替代方案是否也能完成任务，不能冒充固定同一外设下的干预。消融的范围、余留活动和匹配不足必须明列。

实际成功不以机制解释全部完成为前提；有物理机制解释也不抹去现象。机制归因原则上不要求先考满分，但不得绕过已登记的本批分支条件。新的意识理论或指标不倒改项目既有操作判据。

## 10. 失败后的排查次序与交付

1. 先核对任务和来源：是否拿错个体、外设、通道、身体或版本，是否暗换输出任务/控制器。
2. 对照成功路径逐项查教学、真实问句窗口、校准材料、架构、学习状态及测试起点；把多个同时变化的条件拆开，优先恢复有证据的参照。
3. 检查固定旧记录能否被当前外设正确读取，再看新条件下真实回答/闭环动作。训练材料可读但正式题差，应分查覆盖、迁移和控制；外设读不准不能直接否定 Core 学习。
4. 在已授权、有界方案内进行正常纠错和旧例复习；到登记停止点即保存结项。不要用无限追加训练、提高分辨率或盲改 Core 参数替代流程核对。
5. 交付完整基线位置、版本/课程/外设说明、逐题成绩与过程、模型选择依据、实际资源记录、成功及失败回放、已完成/停止/未执行项。录制尚未验收要明说；发布失败只重试发布，不重跑模拟。

每批完成后同步研究总表、中英文报告和历史；后补更正有日期，旧数据、原判据和旧版本原位保留。新批预算按实际资源及用户授权登记，不能照抄已过时的账户读数或重置旧累计预算；规约本身不启动实验、服务、部署或付费调用。

## 12. 2026-10-08 v2 增订：纠错—强化—再测试

用户在 E65 后明确要求：学生答错后要纠正，强化材料同时包含错题和类似题，再测试并反复几轮；从空白完整系统重做中央识别。以下是新执行要求，不把 E65 未进行的测试后纠错补写成已经做过。

1. **先登记循环和结束条件。** 开跑前固定初教、每轮最多课量/校准量、轮数上限、测试用途、全对标准和资源限额。允许错题决定下一轮具体课程，但生成规则须提前声明，每轮实际课表在执行前冻结。达到全对的独立确认或轮数/资源上限即结束；无改善时保存事实并讨论原因，不自动扩大预算或改 Core。
2. **记录错误，再给普通教师反馈。** 开发测验保留每道题、学生原回答和真值。教学主线再次呈现错题并提问，记录这次实际回答，随即给出正确的普通感官陈述/示范。若本次已答对，标为对先前错误的复习；不能把原错误抹去。教师知道答案，推理接口仍只接所声明的感官/Core 活动，禁止向推理偷偷传答案。
3. **错题与类似题一起强化。** 重复原错题，并改变一个相关因素构造近邻：形状错误可保留形状换颜色、保留颜色比较易混形状；颜色错误可保留颜色换形状、保留形状换颜色。可配合同一物体的另一属性问答，检查是否混淆问题。记录相似性规则、真实刺激和全部剂量，不把同一图像重复冒称泛化。
4. **保留旧正确例。** 每轮也复习已掌握内容，校准继续使用自己的权重、优化器和随机状态，并保留已登记的旧校准记录。分别比较旧错题转正、旧正确题退步、类似题和新位置表现；不能只展示被纠正的几题。
5. **连续再测试决定下一轮。** 一轮教学和声明的外设续校完成后，由同一个体连续完成开发题组，用稳定题号比较；测验终态直接承接下一轮纠错。上一轮错误即使消失，新错误也进入下一轮。保留提问本身依正常动力学造成的变化，不从考前存档逐题重来，也不在测验后撤销这段经历。有明确许可的回退或必要因果对照另列身份、来源与结果，并遵循第14节的事前、事后告知。
6. **全对须另留证据。** 用于选择课程的题都属于开发材料。最终题的具体位置/布局须未用于该次教学和校准；冻结读取器，以完整题组和固定时点计分。若正式测试错误后来用于纠正，封存其原结果并明确降为后续开发材料，下一次确认必须换预留的新题；不能再称其为未见最终题。全对必须列清分母、属性、组合及适用范围，不推广成任意题全对。
7. **复习先密后疏即可。** 初教和集中纠错后安排渐疏复习；不要求每个概念的所有相邻间隔严格单调，也不要求贴合人类某条曲线。记录每概念及每个对象—属性的实际出现时刻、间隔和次数；交错教学的用时也是间隔的一部分，不能只报告额外等待秒数。
8. **曲线对照单独登记。** “艾宾浩斯遗忘曲线”描述保持随延迟变化，并不自动给出本模型唯一的复习处方。若比较按曲线安排与一般先密后疏，须先指定所用文献/公式、时间单位、目标保持率和排程算法，区分文献曲线与本模型实测拟合；匹配示范/问答次数、普通刺激剂量、总时长和末次接触至测试的延迟。每组从各自空白完整个体开始并连续保存；安排多个保持延迟、独立留出测试，不凭同一批测试调曲线再宣布改善。此项是用户提出的有价值对照，尚非已测结论。

## 14. 2026-10-12 v3：内部时间连续，普通测验不回退

**实验对象视为一个连续的人造意识。只有该个体在内部模拟时间及全系统状态上连续，测得的成绩才可作为本研究关于其持续学习、识别、纠错和保持的有效结果。整个形色实验应把意识当作人类学生：学生经历上一道题之后，再做下一道题；不能把学生退回考前再答。** 这是实验的操作要求，不是已经证明该系统具有主观体验。

1. **禁止未经明确许可的回退。** 未经用户刘东旭明确许可，不得回退普通实验对象的模拟时间、Core、个人外设或其学习/随机状态、身体、映射、读出历史及其他连续状态。禁止每题重载同一存档、测试后返回考前、只回滚某一组件、或用新副本冒充原个体继续。协议由执行者写明回退不等于用户已许可；历史脚本、成功分数和默认配置也不构成许可。
2. **暂停不等于回退。** 可以暂停、保存、关闭程序，再从该暂停点的完整当前状态继续。暂停时内部时间不推进，外部时间中断不破坏内部连续性；倍速仅改变推进的外部耗时。不能用改显示时间、补计秒数或跳过内部事件掩盖状态倒退。异常中断若只剩更早存档，应说明丢失的经历和恢复边界，不能静默重放后称无缝连续。
3. **对照例外须前后告知。** 消融、移植等对照实验为比较相同来源而必要的回退可以进行，使用独立、可追溯的完整实验分支，正常参照保持完整。开始前告知对照目的、回退来源/时刻、干预范围和与主线的关系；结束后告知实际回退、分支、结果及偏差。此例外不允许把普通形色测验重新命名为“对照”以逐题回退，也不免除原实验本身的授权范围。
4. **连续地考试、纠正和复习。** 答错先记录，再按已登记课程给予普通教师纠正和错题/类似题强化，下一题、下一轮从当前实际状态继续。测试不暗供答案、不用于挑选正式成绩，但题目造成的正常动力学变化属于学生经历，不能人为撤销。先密后疏复习继续适用。
5. **记录可核查的连续链。** 逐阶段和逐题记录个体身份、来源、起止模拟时间及状态承接；同一个体内部时间不得倒退。观察或暂停可保持同一时刻，真实刺激与演化仍按内核规则推进。另列外部耗时和获准对照分支；仅保存完整快照或仅证明时间数字递增，都不足以证明全系统连续。
