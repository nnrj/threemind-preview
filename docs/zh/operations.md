# ThreeMind 操作指南

[中文](operations.md) | [English](../en/operations.md)

## 本地启动

启动 Core 前先安装 editable Python 项目：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m threemind serve
```

另开一个终端启动 UI：

```powershell
cd threemind-ui
npm install
npm run dev
```

Core 默认监听 `8877`，Vite 通常监听 `3001`。若 Core 提示端口已被占用，可先检查：

```powershell
Get-NetTCPConnection -LocalPort 8877 -State Listen | Select-Object OwningProcess
Get-Process -Id <PID>
```

确认该进程确实是废弃的 ThreeMind 服务后，再停止这个明确的 PID：

```powershell
Stop-Process -Id <PID>
```

## 创建意识实例

在 **意识图像 → 开启新意识** 中创建。弹窗提供默认值和可展开的高级设置：

- 默认是 V3 匿名空间模型，默认开启空间基底；
- V1 是带外部符号字典的兼容基线，文字仍不保存在 Core 节点中；
- V2 是没有空间基底的匿名感官模型；
- 高级参数会写入新模型包的 manifest，包括注意预算、联想窗口、传播、学习、遗忘、固化和最大节点数。

运行中的实例可在 **设置 → 模型与空间** 调整支持的运行参数。某些 manifest 能力，例如为原本无空间基底的包直接开启空间基底，需要创建新包。

## 刺激、躯体与生命周期

右侧面板分为观测、控制和刺激。

- 手动文本先经文本适配器编码才进入 Core；
- AI 生成文本同样属于外部输入，遵循相同输入边界；
- 默认背景输入是宿主计算机的实测物理遥测；它在 Core 外按真实时间采样，并映射为匿名感官通道；
- 随机环境场仍然保留但默认关闭；躯体适配器可选择性地对它进行采样、阈值、适应和噪声处理；
- 整个 ThreeMind 进程遥测与单意识实例物理反馈都默认关闭，因为开启它们会形成明确的自状态反馈路径；
- 关闭最后一个仍启用的刺激来源需要确认，因为这会结束当前运行实例。

在 **设置 → 运行环境** 管理刺激来源或设置某来源绕过注意预算；在 **躯体与注意门** 调整躯体过滤。在 **适配器管理** 中可调整全部背景输入许可、物理设备开关、意识实例绑定、水平／变化通道、增益与高级归一化。有限代谢能量供应独立且默认关闭；物理遥测只产生普通匿名感官帧，绝不供应能量。详见[物理遥测感官适配器](physical-telemetry-sensory-adapters.md)。

在 **设置 → 模型与空间** 可独立控制拓扑局部抑制或实验性能量记账。局部抑制默认开启，能量记账默认关闭；能量记账开启后没有内部自动恢复，是否启用外部供应适配器由实验者另行决定。规则见[局部抑制、可选能量记账与动力学追踪](local-inhibition-energy-and-dynamics.md)。

## 观测与解读

- **单 tick 截面读出** 保留原有结构输出适配器的行为，观察一个匿名 `OutputFrame` 并把触达活动或可重复结构写入日志；
- **时间区间收敛读出** 以一个输入包为锚点，在多个 tick 内统计节点持续时间、激活积分、抑制与候选集合稳定性；它与截面读出并列，结果同样只读并写入被动读出历史。完整指标和判定边界见[时间区间收敛读出](temporal-window-readout.md)；
- **意识解读** 是可选外部 AI 观察器，读取由输出帧形成的快照并保存解读文字，不会自动变成 Core 刺激；
- 刺激标签页中的聊天式区域是呈现与日志界面；在其中隐藏消息不会停止刺激，也不会删除历史。
- 开启 **详细记录** 后，意识详情中的 **动力学追踪** 会按 tick 显示节点激活、抑制、触达和可选能量的稀疏变化；关闭后不会继续生成该高密度记录。

重复结构、短语或视觉聚类都是值得记录的实验信号，不是意识结论。应使用对照刺激和重复运行进行比较。

## 快照、遗照、实例与历史

- 快照保存带名称的模型状态；
- 遗照是与停止/死亡实例相关联的导出状态；
- 继续会替换当前活动实例；克隆会从包状态产生新身份；
- 管理页提供实例列表、模型包操作以及带分页的刺激、读出、事件和解读记录。

默认数据目录是 `data/`。除非明确要共享实验数据，不应提交 `data/.threemind.key`、加密的供应商凭据、加密网络令牌或实验 `.tmind` 包。

如果 `data/ui-settings.json` 不存在，后端会在首次启动时按规范默认值创建一次；启动过程不会替换任何已经存在的文件，包括用户预先手工准备的配置。受版本控制的 `data/ui-settings.example.json` 是完整的公开配置参考，其中不包含秘密值。

## 可选 AI 供应商

在 **设置 → AI 环境与解读** 配置供应商。API Key 仅发送到本地 Core 加密保存，保存后不会回传浏览器。启用环境刺激生成器或 AI 解读器前，先使用供应商测试按钮。

## 可选网络传输

在 **设置 → 网络适配器** 中：

1. 设置至少 16 位的共享令牌；
2. 启用网络传输；
3. 如实验需要，再单独开启受限远端调制。

Core 默认只监听本机回环地址。只有确实需要远程访问时才使用 `--host 0.0.0.0`，并应置于 TLS/反向代理保护之后。协议与限制见[架构边界](architecture-boundaries.md)。

## 持久化后端

设置面板可为目录/管理数据选择文件、SQLite、MySQL 或 Cloudflare D1。运行中的动力学状态仍以模型包为中心。切换后端前，建议先导出或拍摄快照，并在模型包与历史页中确认迁移结果。

与这个可选的应用层后端相互独立，本地归档目录始终使用 `data/archive-index.sqlite3` 建立索引。它让模型包、快照与意识列表保持快速，而不会把归档扫描放进 Core 热路径；完整、可移植的实验记录仍然是 `.tmind`。已有模型包会在启动后渐进建立目录。有关重建 API 与备份建议，参见[归档目录与非阻塞持久化](archive-catalog.md)。
