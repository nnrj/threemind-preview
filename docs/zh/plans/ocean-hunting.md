# E34：完整海洋中的捕获归因

[English](../../en/plans/ocean-hunting.md) · [研究总表](research-backlog.md)

2026-10-03讨论，2026-10-04凌晨登记。用户指出意识组捕获次数更多，应单独定位经历和内部联想的贡献。E32已测焦点的局部活动会改变动作，却未改变该次捕获，尚不足解释群体优势。

从E32两个完整海洋60秒状态出发，自然积累3秒历史；按身份顺序选出接近较弱邻体、尚未钳制、存在可测内部活动的个体，每世界最多两个。选择不看未来结果。每来源保持全海，做20秒原样、目标/匹配静默、单体随机、经历/空白及目标/匹配移植。观察接近、接触、钳制、脱离和捕获，并定位内部活动；不把有动作差自动当作有收益。

全部新分支启用用户批准的亲子双向保护，成熟前亲子均不得互吞；配置随完整世界保存恢复。旧Ocean/3和E32保持单向原义。本项定位新环境规则下的捕获过程，不能直接按比例解释旧34/43次总捕获。

最多2次选样、32次分叉，单worker、4进程小时、3GiB停止扩展/6GiB硬限；完整登记说明其余资源边界。先完成E33，再执行本项。原始状态、输入和影片仍本地留证，设计及报告进入独立研究项目。
