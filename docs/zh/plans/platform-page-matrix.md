# 平台层级与页面矩阵

2026-10-11，配套[最终计划](platform-hierarchy-navigation-workbench.md)。这里登记实现边界；页面出现不等于功能已经验收。

| 页面／入口 | 浏览范围 | 配置层次与操作对象 | 权限／状态边界 |
|---|---|---|---|
| 意识工作台（首页） | 全部授权意识；打开后按自身身份定位 | 当前打开实例、选中节点、本页采集／播放 | 看图不运行；暂停／继续／刺激／配置分别授权；研究受管对象继续受协议限制 |
| 研究总览／项目 | 全部授权研究，项目只是筛选 | 项目归属、成员、显式预设、项目通知规则 | 对象权限与项目筛选分开，不自动选择首项目 |
| 实验／训练／比较／世界 | 全部授权列表及稳定对象详情 | 研究协议、条件和实际运行对象 | 原冻结、谱系和连续性要求保留 |
| 资料中心 | 全部授权记录、原件及个人资料 | 报告、笔记、证据、数据操作 | 私人资料按授权；超级管理员全局；位置筛选不扩权 |
| 新建默认／模板 | 与项目无关 | 按内核版本保存默认；一份显式模板 | 只影响以后新建；无引擎的纯配置校验 |
| 新建意识 | 先配置，保存时明确项目 | 实际完整配置、模板身份／修订／来源 | 默认创建并准备；旧调用缺省立即开始；开始初始化一次 |
| AI 服务 | 平台统一目录，授权可用服务 | 多份服务凭据、目录管理、项目使用授权 | 查看／管理／调用分开；既有项目授权不自动全局共享 |
| 邮件服务／通知 | 系统发送服务；个人全局收件箱 | 发送配置与密钥；项目选择服务并保存事件规则 | 服务修改不重发旧队列；不在系统页要求研究项目 |
| 设备／适配器 | 安装能力和创建默认目录 | 宿主能力；实例接线在实例中 | 打开页面不申请设备权限，不创建引擎 |
| 执行／存储 | 授权宿主队列、进程、数据位置 | 宿主资源和保存策略 | 与 Core 能量／模拟节奏无关，固定配置显示重启要求 |
| 用户／角色 | 本部署账号 | 多角色的动作与范围授权 | 后端重复检查；保护最后超管；撤销及时生效 |
| CLI／MCP／Python | 同平台接口与实验对象 | 受保护复用会话或有限委托 | 非交互，不隐式退回本机超管；不将身份注入 Core |
| 文档／帮助 | 当前公开项目文档 | 使用与操作目录 | 无项目门禁；原史料及原始实验不改写 |

显示布局和浏览器偏好属于本浏览器、当前用户；模板不包含成长权重；历史恢复读取实例原版本与完整系统状态。
