# 脉冲候选 lif/1：方程、身份和验证边界

[English](../../en/plans/lif-candidate.md) · [实施记录](multi-kernel-implementation.md)

科学身份 `threemind.lif/1`，恢复格式 `threemind.lif-state/1`，假设身份 `threemind.hypotheses/lif1`。这是独立候选，**不替换 causal/9 或 continuous/1，也不自动转换现有意识**。配置、算子顺序及其哈希进入每个状态文件。2026-09-28 已有 Python/Rust 实现；阶段验收以实施记录为准。

## 局部物理模型

每个受体保存膜电位 V（mV）、突触电流 I（nA）、适应电流 A（nA）、不应期截止和自身发放历史。MΩ × nA = mV。两次事件之间使用解析解：

```
τm dV/dt = −(V − Vrest) + R (I − A)
τI dI/dt = −I
τA dA/dt = −A
```

阈值只在固定模拟格点检查，默认 250 μs。达到 −50 mV 则发放，复位至 −65 mV；默认不应期 2 ms，期间电位钳于复位值，但到达电流仍累积和衰减。每次发放令 A 增加 0.01 nA。默认膜常数 20 ms、突触电流常数 5 ms、适应常数 100 ms、电阻 100 MΩ。初始及静息电位 −65 mV。这些是可配置的现象学示例参数，不是已标定的人脑参数。可分别关闭泄漏、电流衰减、适应增量、时序学习和短时突触，用于消融。

依据：[被动 RC、阈值与复位](https://neuronaldynamics.epfl.ch/online/Ch1.S3.html)，[带适应电流的漏积分模型](https://neuronaldynamics.epfl.ch/online/Ch6.S1.html)。采用后一模型的线性泄漏、仅由发放增加适应电流的特例；没有冒称实现全部离子通道或生物机制。

## 输入、连接和学习

输入继续使用现有匿名通道、感官映射和分帧，未改变文本规范化。实际正输入注入 `幅度 × 强度 × input_gain_na` 电流。新通道按需生成受体。同一输入帧实际触达的受体间可形成有向连接，初始权重为 `birth_weight × min(1,a×强度) × min(1,b×强度)`。默认系数 0.05。没有随机预造网络、语义标签或预设脑区。共同触达生边是沿用 ThreeMind 输入映射的建模选择，不是文献已经证明的神经发生机制。

连接学习使用本连接的突触前到达迹 p 和突触后发放迹 q，分别按 20 ms 指数消退：

```
实际到达：w ← max(0, w − A− q)；p ← p + 1
目标发放：w ← min(1, w + A+ p)；q ← q + 1
默认 A+ = 0.01，A− = 0.0105
```

到达先于同刻阈值检查，因此零时差配对按先到达再发放处理。此离散边界约定进入版本契约，可用步长收敛实验检查影响。依据为[局部时序学习示例](https://brian2.readthedocs.io/en/stable/examples/synapses.STDP.html)；未采用示例中的随机初始权重或全连接拓扑。

一次格点先确定全部发放节点，再完成其局部突触后更新，最后发出信号，避免节点遍历顺序决定谁先学习。发射量为 `权重 × spike_gain_na × 短时资源释放比例`；默认传输增益 0.3 nA。源节点不查询目标电位、饱和或所谓正确答案。短时资源使用[连续候选的同一 TM 三池原语](candidate-mechanisms.md)，但这里每次释放对应一次实际脉冲。默认延迟 1 ms。

STDP 只更新实际经过的连接或目标发放时的入边；被动演化只遍历活动受体。观测和显式重新配置可以遍历全状态，但不会成为默认动力学每步的全图计算。共同输入生边的成本随该帧通道数平方增长，有明确节点／边容量和拒绝计数。

## 与原核不同的假设

| 项目 | lif/1 的明确选择 |
| --- | --- |
| 活动 | 电位偏移、突触电流和适应电流是物理状态；发放是事件，不是唯一活动证据 |
| 抑制 | 只有本节点发放后的适应反向电流；本版没有引入抑制性细胞类型或原核的拓扑抑制扩散 |
| 结构 | 受体和连接不因静息自动修剪；权重受 STDP 改变，可达到零。显式删点／断连仍可用 |
| 长期保持 | 暂无 causal/9 的稳定度、支持度、资格迹保护及默认遗忘公式；它们没有被移植成假的同名能力 |
| 能量／空间 | 暂无 causal 能量账本、输入调制端口和因果空间；请求会明确拒绝，显示布局不冒充物理空间 |
| 随机性 | 当前方程不使用随机造边或自发噪声；身份种子仍保留 |

这些差异使它成为可比较的另一套假设，而非“已经验证优于原核”的升级。默认系统仍选择 causal/9。

## 生命和观测

LIF 不能以“本格点没有脉冲”判死：阈下电流和电位演化也是内部活动。本候选以非零电位偏移、突触电流、适应电流任一超过各自容差为物理活动。三者都消退才归静息；默认电位容差 10⁻⁶ mV、电流容差 10⁻⁸ nA。容差为 0 撤去该数值截断，可能长时间不静息。第一次活动前为待接入；之后全体静息持续默认 1 模拟秒则死亡。同刻先处理到达和发放，再判死亡；暂停不耗模拟时间。死亡不自动复活或清结构。

这是 `lif1` 的物理活动判据，**不把该判据回写到 causal/9**。特别是适应电流在此是有自身演化的物理量，不等同于原核的抽象剩余抑制标量。若研究上要求只计某些物理过程，应提出新版本或明确对照，而不是静默换定义。

图形和现有时序读出可使用投影 `clip((V−Vrest)/(Vthreshold−Vrest),0,1)`，名称为 `normalized-depolarization`、单位为 1。它不是原核激活强度，也不是放电率。读出记录带公式及内核身份。模型状态保存完整 `membranes`、`synapses`、资源及在途信号；`/physical-state` 提供按检查点、分页的原始电位、电流和累计发放。兼容表中的稳定度等占位零值不是可用于此核科研解释的测量量。

100 ms 的旧读出默认间隔可能漏掉短脉冲。Lab 默认以 `record_spikes=true` 独立记录真实发放时间和节点；动力学页、`/spikes` 分页接口及原始事件导出可查询。CLI ReadoutSession 存在 event sink 时也递送脉冲。关闭该记录不改变状态哈希；不会为了记录脉冲而复制每个突触到达事件。缓冲和预算见[使用指南](../v2-kernels.md)。不能把“时序图没出现某字符”等同于此核没有物理响应。

## 恢复、继承和损伤

精确恢复保留全部物理量、STDP 迹、短时资源、传输队列、格点和死亡计时。结构继承是另一个操作：只保留受体身份和慢连接权重，重置电位、电流、发放、时序迹、资源、队列和时钟。原父本不变。

断连不撤回在途信号；同一对端点重建的连接有新连接身份，旧在途信号会递送但不能训练新连接。删点后同通道新受体得到新节点身份，不接收旧目标的在途信号。临时静默清该节点活动并阻止新接收，解除后可接受新刺激。

验证应包括 RC 解析解、固定格点阈值误差、STDP 正反次序、不同推进批次、双向跨后端恢复、生命周期截止到达、结构损伤、模型包和独立 Rust 运行时互操作。工程一致性不等于配对记忆、关系组合或 AGI 能力证据。
