# E32：保留完整海洋的原位对照

[English](../../en/plans/ocean-community.md) · [研究总表](research-backlog.md)

2026-10-03。用户指出E31局部装置抹去了形成行为的环境。本期纠正实验设计：1.2米水域、53个初始个体、360颗营养和持续随机刷新，有限能量、变异、吞食、水文、本体与接触感官继续存在。所有消融与移植都从完整海洋状态分叉，只改焦点意识；保留周围个体及其意识、位置、食物、身体状态和同一物理规则。

两个世界种子分别比较正常意识控制与独立随机控制。正常意识的输出不加任何匹配节律限制。60秒时按固定身份次序选一个可测的意识，再做目标/匹配通路静默、单个体随机驱动、保留经历/空白/目标移植/匹配移植。后四者使用同样的即时状态重置与当前有限储备，不重置身体年龄或幼体保护。

观察重点是：内部通路是否改变行动，改变是否造成具体摄食、追捕或逃离后果，以及经历能否转移相应模式和收益。总摄食、存活和耗能仍报告，但不能代替原因定位；静止和转圈不自动视为异常。完整海洋全景是主要演示，近景仅为辅助。

登记时账户使用17%，单worker，6进程小时，4GiB停止扩展/8GiB总硬上限，保留2GiB内存和C5GiB/E15GiB余量。原始证据本地保存，设计/报告/影片进入独立本地研究项目。无Core改动，未清理或覆盖旧证据。
