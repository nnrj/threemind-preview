# 输入输出总线与表达器校准

2026-10-05，E49。状态：获准、登记后执行。[English](../../en/plans/bus-and-expression-calibration.md) · [E48](../../../lab/explorations/2026-10-05-temporal-state-expression/report.zh.md)

## 本轮讨论与决定

用户明确允许表达器训练阶段使用教学标记，但意识交互时不能附加答案或人为语义标签。希望表达器与ThreeMind共同发育，并提出输入/输出总线可能遗漏或改变信息。批准先定位表达器对已有材料翻译不可靠的原因，再讨论复述经历、未见关系迁移与逻辑。共同发育不必等同于无监督：可以通过环境和教师的可观察交流训练外设；测试答案不能混入交互。

原话节录：

> 训练表达器时进行一些标记没什么，与意识交互的时候别这样就可以了。

> 是否是输入总线和输出总线本身丢失或改变了什么信息呢？

> 先解决**表达器对已有训练材料的可靠翻译**，再判断未见对应和关系迁移。

## 执行顺序

1. 追踪编码→输入总线→Core→输出总线→特征提取→表达器。分开传输、观察采样和有损压缩，不把框架名称当成增益。只对代表性案例验证同输入/同演化，不重复扫描大数据。
2. 提供只读原始活动输出接口，复用OutputBus，原始节点量和模拟时刻完整保留。历史、局部资源及快照仍作为显式研究读法；不将工程时间或语义标注送入Core。
3. 重用E47/E48固定资料。先查重复输入异标签、数值量级、训练和生成差异，再对照旧表达器、学习率/批次、可学习输入层的初始化；简单分类器仅用于诊断信息可分性。输入值不相减、不逐样本归一化、不删背景。
4. 候选必须先拟合16条原/反对应教学样本至少15条，才扩展到其他来源与新对应；无提示不教成空白、不计作必错。选择依据只用训练/独立校准，不按未见对应的答案选择模型。
5. 冻结后分别看同经历新视角、晚期、反转和未见循环对应；合格表达器如出现明确阳性，再做已有跨感官通路干预。共发育/持续校准只用实际教过的样例；与同资料冷训练区分外设重训和Core学习。

## 边界与停止条件

Core公式、旧默认、映射、旧记录不改。先证明工具可靠，不能把分类器或表达器自身学会关系当作内核推理。本批最多256个新观察副本、24个模型训练、累计计算3小时、单worker；RSS4GiB/GPU3GiB，保留2GiB可用内存、C5/D15/E15GiB。新工作2GiB停止扩展，含归档/数据库8GiB硬限。共享额度从48%起，+5个百分点停止扩展、+8停止新计算；旧数据不删除。具体注册见[E49](../../../lab/explorations/2026-10-05-bus-expression/design.zh.md)。

## 当日用户补充：纠错和增益不能丢失

用户认为人类的复述本来模糊，儿童需要反复教学，因而应记录错误是否能被后续教学纠正，而不是要求首轮逐字完全正确；提出可在证据支持时降低遗忘并检验背景积累等副作用。此为获准的候选方向，并非本轮已修改遗忘。

原话：“不能把好不容易实验出来的增益丢掉。”

据此把内核机制、条件性参数收益和观察/外设收益分开核对：已生效者记录实际配置；条件性收益保留预设；新增工具收益落实到工具，不冒充Core机制。未见默认遗漏，晚期状态的再校准已恢复表达，因此本轮没有盲改遗忘。下一步实验可接受片段和近义，但四个名字的小型标定仍如实记录逐词是否相符。
