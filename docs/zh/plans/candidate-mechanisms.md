# 候选机制的原语规范与验算

[English](../../en/plans/candidate-mechanisms.md) · [实施记录](multi-kernel-implementation.md)

2026-09-28：以下是独立原语规范。原语通过不等于完整新内核已经接通，更不等于配对、推理或 AGI 能力已经改善。当前 causal/9 不调用这些原语。所有时间都为模拟时间，界面帧率与宿主速度不进入方程。

## 短时突触资源：threemind.tm-synapse/1

每条连接保存可用份额 x、活动份额 y、利用率 u 和最后更新时间。失活份额 z=1−x−y，三种资源总量为 1。事件间：

```text
dy/dt = −y/τI
dz/dt = y/τI − z/τR
x = 1 − y − z
du/dt = −u/τF             （启用易化时）
```

预突触事件先恢复到事件时刻，再计算 u←u+U(1−u)（无易化时 u=U），释放 r=ux，然后 x←x−r、y←y+r。U=0 关闭释放；τF=0 明确表示关闭易化。禁用整个算子则绕过，不能用 U=0 冒充中性消融。采用指数的解析解；τI=τR 的极限单独处理，避免除零和近似相等时的相消误差。

这是[已发表短时突触模型](https://brian2.readthedocs.io/en/stable/examples/frompapers.Tsodyks_Uziel_Markram_2000.html)的局部原语。校准配置 U=0.5、τI=0.003 秒、τR=0.8 秒、无易化，来自该示例的一个突触类别，**不是所有生物的统一默认值**。易化校准使用 U=0.04、τR=0.1 秒、τF=1 秒。没有采用示例的随机拓扑、固定兴奋／抑制群体比例或人工调高的背景输入。

连续内核以一次合格的连续发射尝试调用此算子，属于 ThreeMind 对原模型的离散释放抽象，不能称为生物脉冲复现。具体阶段见下文。

## 快变化迹：threemind.leaky-fast-trace/1

每条连接保存 f∈[0,1] 和最后时间。事件间 f(t+Δ)=f(t)exp(−Δ/τf)。实际通过的传输量 q 更新：

```text
f ← f + (1−exp(−ηq))(1−f)
effective_weight = min(1, slow_weight + g*f)
```

原语不修改慢权重；也不读取目标瞬时状态、答案或奖励。η=0 关闭新增，g=0 关闭对传输的影响。默认 τf=2 秒、η=0.1、g=0.1 是显式候选尺度，未声称从生物实验估计，也未根据语言测试调优。它是有界的局部泄漏积分模型，可用 RC 类模拟系统表达；实际生物对应关系尚未确认。

[线性 Transformer 与快权重研究](https://proceedings.mlr.press/v139/schlag21a.html)启发快慢状态分离，但这里的单个局部迹不是论文的矩阵记忆、学习控制器或 delta-rule，也不能宣传为与 Transformer 等价。完整的小 Transformer 对照另行实现。

## 接收端局部寻址：threemind.local-context-attention/1

对同一接收节点已实际到达的消息，给定其本地查询 q、消息键 kᵢ、原始幅度 aᵢ：

```text
sᵢ = dot(q,kᵢ)/(sqrt(d)*T)
pᵢ = exp(sᵢ−max(s))/sum(exp(sⱼ−max(s)))
response = sum(aᵢ*((1−m)+m*pᵢ))
```

m∈[0,1]，m=0 是保持原始和的中性消融。T>0，默认 1；默认混合量 1 为原语校准值。输入维数有界。一个到达时结果就是该幅度；多个到达时是显式局部分配，不能偷偷把结果称为未加工读出。原始到达、分配系数及发送成本均须保留。

本原语不创造、训练或全网寻找 q/k，调用方必须给出它们的真实局部来源。它不是人为因果识别器。连续候选绑定的特征来源、时序和保存方式见下文。

## 连续候选的完整执行顺序

`threemind.continuous/1` 使用 `threemind.continuous-state/1`，不更换 causal/9 的身份。三个新算子均有独立开关，全部关闭时原有状态转移不变。启用时仍保留 V3 出生、共同触达学习、抑制、遗忘及死亡规则。

1. 源节点用自身激活、抑制响应、连接的慢权重加快迹及可选空间衰减计算发射量；先检查原来的逐边门槛。
2. 传播预算拒绝时不释放突触资源。允许尝试才更新短时资源、乘以释放比例。
3. 按释放量结算一次可选能量消耗；实际量计入 `transport.sent`。若此时低于逐边门槛，记入 `discarded`，不进入在途消息，不以汇合挽救。
4. 合格量进入原有延迟消息并按原规则巩固慢连接。快迹只在可塑性开启时按实际发送量更新；不再读取接收者。短时耗竭属于传输状态，即使停止长期塑性仍可发生。
5. 接收时才做局部上下文分配。发送快照键为源的 `[激活, 触达迹, 抑制/(1+抑制), exp(−距上次触达时间/τcontext)]`；接收查询是接收者自己的同四项。维数固定为 4；不按名字、词义、答案或奖励编码。这是显式候选的局部相似状态寻址，并非已验证的最佳特征或特定神经细胞模型。
6. 仅同一发射批次到达同一目标的消息参与竞争，不跨批次偷做全网归一化。记录原始消息、分配系数和响应量；原始接收账本仍记全部到达量，响应再经过接收者的抑制与饱和。观察端不据此筛掉原始激活。

状态保存完整定义及哈希、逐边短时资源与快迹、时钟和带发送快照键的在途消息。断连删除局部连接历史但不撤回在途消息；删点后旧消息不能投给新身份。参数更改先按旧参数推进局部历史到更改时刻，再启用新参数；这些懒更新时间独立于基线数值求解格点。所有开关和尺度在配置中显式记录，未做语言效果调参。

## 被动膜电位：threemind.rc-membrane/1

独立膜电位核的数值基础来自[泄漏积分电路模型](https://neuronaldynamics.epfl.ch/online/Ch1.S3.html)：

```text
τm*dV/dt = −(V−Vrest) + R*I
dI/dt = −I/τs
```

单位为 mV、nA、MΩ、秒，MΩ·nA=mV。解析演化保留亚阈变化；无输入时按 τm 回到静息电位。τm=τs 使用解析极限，不用不稳定的两个指数相减。校准值 Vrest=−65mV、R=100MΩ、τm=20ms、τs=5ms 是显式模型参数，不宣称拟合某个具体细胞。

此原语**没有偷偷加入阈值、复位、不应期或突触可塑性**。完整 LIF 内核必须单列这些规则及脉冲调度误差，并验证亚阈活动和无脉冲间隔不会被误判为死亡。不能把输出电压直接替换旧版 activation 而声称兼容。

## 已验证与未完成

原语、连续候选及冻结基线共 75 项测试通过，覆盖 Python/Rust 原语与完整状态、资源守恒、耗竭／恢复／易化、时间常数极限、分段与跨后端恢复、逐算子消融、原始到达与发送耗能、不可读取目标的发送、断连／删点和损坏状态拒绝。浮点跨后端沿用原核 libm 误差容限；同后端恢复严格保持哈希。

后续已完成模型包、Lab 创建／恢复／导入导出、时序读出和小规模工程比较；详见[实施记录](multi-kernel-implementation.md)。完整独立 [lif/1 候选](lif-candidate.md)已经实现，此处 RC 原语仍只负责被动数值演化，不能单独等同于完整脉冲机制。研究收益未由工程验收证明。
