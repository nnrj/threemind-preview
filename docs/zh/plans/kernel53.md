## 已冻结的实现规则

节点支持度和连接基础权重均保存一个当前值和一个无量纲衰减年龄。若内部时间经过Δt，固定尺度H时，年龄增加Δt/H，当前值乘以F(a+Δt/H)/F(a)。可选的线性尺度回落开启时，年龄增加量按∫dt/H(t)计算。实际强化增加当前值；默认年龄继续累计。重置选项仅在强化确实使值增加时生效，达到上限、观察、保存和损伤均不重置年龄。

| 曲线 | 剩余比例F(a) |
| --- | --- |
| 指数 | 2⁻ᵃ |
| 幂律 | 1/(1+a) |
| 逆对数 | 1/[1+ln(1+(e−1)a)] |
| 幂律后接指数 | a≤A时1/(1+a)；a>A时exp[−(a−A)/(1+A)]/(1+A) |

初始工程参数：H=30内部秒、A=10、默认幂律；这些是待比较的起始参数，不是生物学常数。H是速度尺度，不是检查间隔。结构每100000微秒检查一次；同刻输入、联想发送和强化先发生，再按当前值检查连接删除门槛0.008和节点支持度门槛0.006。休眠、唤醒保持独立且默认关闭。两个方向分别保存、强化、衰减和删除；共同外部刺激通常同时建立两条有向连接。

节点按既有激活、抑制、疲劳规则产生发送量；同一节点向各出边提供信号并按尝试量付费。能量不足时，两类信号和各出边同比例缩减。连接根据有效权重、发送量、突触资源释放比例以及已启用的空间因素计算实际传导量。激活与抑制在同边同次发送共用一次资源释放，以强化前的连接状态分别判断，之后再强化。传导失败不退还已消费的节点能量或突触资源。

联合传导最小量初始为0.0004，可关闭；独立权重门槛默认关闭，开启时不得低于删除门槛。节点弱激活归零仍为0.004，与传导最小量分开。旧抑制发送门槛只作为默认关闭的独立对照选项，不影响正常5.3传导。禁止仅凭一条入边反向传导抑制；不再按邻居总权重归一分配抑制。

保持时间增长与回落开关独立。开关关闭不取消基础权重强化。抑制学习开关关闭仅排除抑制对基础权重、短时增强及保持增长的贡献，保留其传导和耗能。
