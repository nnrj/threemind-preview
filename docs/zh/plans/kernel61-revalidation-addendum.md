# 全面复验计划v2的6.1接续说明

2026-11-13。作者明确要求：“6.1构建完成确认符合优化的预期后，继续按此前制定的《ThreeMind 6.0 全面复验计划 v2》在6.1上推进。”本说明记录这一决定，不改写[原计划v2](kernel60-revalidation-v2.md)及其历史结果。

R51c已验证6.1的局部删除、两类发送门槛及发送实现优化。两种规模下耗时分别为5.1的0.8073和0.8234倍，存档实际占用约1.10倍，通过原计划的两倍停止线。双后端与历史兼容检查通过后，新增个体明确选择`threemind.continuous-memory/6.1`，默认逆对数衰减、删除阈值0.008、局部删除、激活/抑制发送门槛0.004/0.002；繁殖沿用出生规则2，默认继承衰减年龄。

各批独立来源数、对照、连续教学、复习与纠错、有效分母、数据保全、资源保留量和停止条件继续按v2执行。旧6.0工程批、旧STOP、E67/E68/E69及旧科学批不恢复。后续批次独立登记版本和父状态，不能把历史结果改名为6.1结果。

顺序从刺激体、分组输入及连接形成开始，随后完成身体过程读出、局部资源、事件顺序与主要机制确认，再开展形色、具身和其他批准任务。每批启动前完成对应旧规模核查、冻结科学目标、材料、指标和预算。正常完成后继续下一项；预定的不利机制矛盾、严重成本下降、资源不足或不完整状态触发保全和报告。

已知衰减曲线与历史版本不同，保持时间不能要求逐秒相同。新协议须同时报告结构残留、可唤起响应和删除，预先区分预期延长与重要机制失效。任何新的核心修改仍另行取得授权。现阶段不改论文；所有批准实验和截图交付后再生成r3，空间导致的延期规则保持。
