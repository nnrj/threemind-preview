# 全局资料浏览调整

2026-10-10，用户批准实施。项目继续承担资料归属和权限边界，不再作为所有菜单默认的隐含筛选。

- 研究概览默认汇总全部有权访问的项目，展示项目列表及资料数量。
- 实验、比较、世界、对话、数据、模型、笔记、报告和数据管理提供跨项目、分页、可搜索的资料列表；每条资料显示所属项目。保留具体项目中的现有编辑器及操作工具。
- 侧栏改为明确的浏览范围，默认“全部项目”，用户可主动选择一个项目。旧浏览器保存的当前项目不自动收窄新默认范围。
- 打开具体资料携带其所属项目；旧运行链接按对象身份查找已授权的归属，不依赖当前筛选。创建时明确选择归属项目，不自动选择列表第一个项目。
- 统一只读查询服务仅返回元数据；项目成员权限、私人笔记作者边界、私人包及载体保护继续执行。查询不产生默认笔记本、不推进模拟、不加载原始大文件。
- 数据库以显式迁移增加元数据的跨项目只读策略，不放开跨项目写操作和原始数据表。测试先使用隔离数据库；不接管用户正在运行的服务。
- 验收跨项目分页、筛选、权限、私人资料、直接链接、创建归属、中英文与窄屏。同步使用手册、研究工具进度及既有历史条目的 dated correction，原记录和实验资料保持。

来源：用户指出大多数菜单因“当前项目”显得空白，接受项目作为字段、筛选与总览列表；批准上述合理调整。上期新增的实验总览解决统一索引，并未使全部菜单支持全局浏览。

## 2026-10-10 实施与验收补记

本期已实现 `browsing.py` 的统一元数据查询、全局页面、明确归属选择与旧链接定位，显式迁移本地库至 schema 63，前端已构建。使用说明见[全局浏览与项目归属](../global-resource-browsing.md)。没有启动或停止用户工作站；现有服务需正常重启才能加载新接口，页面刷新从全局开始。

迁移新增 24 项元数据 SELECT 策略；既有策略逐条保持，原始轨迹、检查点字节与写入策略未放开。身份见证核对 20,581 个运行、24,821 个检查点、84 项索引、442 份文档／500 修订、635 份笔记／719 修订、19,417 过程条目、59,118 证据引用、3,615 附件的 ID、已存状态／内容哈希、时间及修订等字段，前后均一致。本次没有复制原件或修改科研结果。

实际本地全局查询显示 573 个可访问项目、20,574 个未归档运行、84 项实验索引、442 条记录／报告、635 条本人可见笔记。7 个已归档运行在归档筛选中保留。每页最多 100 条元数据；默认资料页 50 条、项目页 12 条。一次本机测量：文档 10 ms、笔记 37 ms、附件 118 ms、概览 132 ms；首次运行查询含连接池建立约 828 ms。这些是单次工具查询耗时，不是 Core 性能实验或普遍性能保证。

隔离工程验收共 45 项不同的后端用例通过（两批 35／14 项，4 项重叠）；覆盖权限、私人载体、只读事务、分页、报告／笔记／包和实验索引。6 项 Edge 浏览器用例通过：全局默认与旧偏好忽略、9 个资料菜单、跨菜单主动筛选、笔记重载／报告预览、旧链接独立归属、新建明确项目及英文 390 px 页面。`npm run build`、Ruff 与历史校验通过。新增浏览字符串无缺译；全站翻译审计另有既存缺译，不将局部验收说成全站翻译完整。

测试数据与截图保存在忽略目录；`tools/browsing_acceptance_server.py` 提供可复现的合成资料服务，不启动模拟 worker。临时服务与数据库在验收结束清理。原内核、旧个体、实验报告与阴性结论保持；T12 宿主问题仍待用户决策。
