# 观测影响与延迟选择的可行性评估

[English](../../en/plans/observation-backaction-20261001.md)

2026-10-01。状态：用户提出设想后的可行性评估与候选方案，**未获执行决定、未登记新实验、未运行新模拟**。不改变现有内核、背景映射、意识判据及历史证据。

## 要区分的三个问题

1. 读出程序是否通过软件副作用或执行调度改变 Core 演化？这是可以直接验证的工程问题。
2. 观察造成的 CPU、内存、I/O 等负载是否经真实遥测重新成为输入，进而影响意识？这是可测的环境反馈问题；不因其属于普通因果机制而否定现象的价值。
3. 晚些时候选择是否探测，能否在没有向前信息通路的情况下改变此前的结果分布？这属于另一项非常不同的假设，不能用前两种影响替代证明，也不是标准量子力学对本软件系统的预言。

## 文献与当前实现

延迟选择量子擦除涉及量子态、纠缠、测量装置及两端结果的关联。在 Kim 等人的实验中，按另一端探测结果分类可见相位相反的干涉图样；不分类的总统计不会因此成为可读取未来选择的信号。装置产生物理关联与人后来查看记录是不同操作。[原实验](https://arxiv.org/abs/quant-ph/9903047) [标准量子力学下的分析](https://arxiv.org/abs/1908.03920)

Ma 等人的实验使用因果上分离的测量选择和纠缠光子，隔离条件具有明确的物理实现。软件实例之间不传递消息，与光学实验里的类空分离、量子测量条件并不等价。相关实验没有证明人的注意或未来查看记录会改写已发生事件。[实验论文](https://arxiv.org/abs/1206.6578)

当前 Core 按输入事件、保存状态与模拟时钟推进，不把宿主墙钟和读出器结果作为直接动力学变量。同配置、完整状态、相同输入时刻及同一后端应复现相同结果。E22 已有九个关闭观察工具的代表案例完整哈希复现；这支持那些条件下的观测无扰动，不能当作所有观测路径都已穷尽。[E22 报告](../../../lab/explorations/2026-10-01-recovery-reference/report.zh.md)

实现核查发现，宿主、进程、实例遥测可编码 CPU 占用、内存压力、I/O 和执行耗时。因此“读出没有写入 Core”并不保证完整系统没有反馈：读出负载可能改变下一帧真实测量。这是本次最值得优先隔离的具体通路。两个软件快照副本只有相同初始记录；这本身不建立量子纠缠。

## 建议顺序与候选设计

### 第一阶段 固定输入检验读出影响

选取 16 个既有完整快照，覆盖活动、恢复中、在途信号等状态。保留所有内核参数、抑制、遗忘、能量机制、队列和时钟；如涉及伪随机输入，保存完整状态或实际生成的输入流。三路遥测均使用同一份事先记录的带时间戳输入重放，保留维持活动所需的刺激，不把“固定输入”偷换为“关闭背景”。不修改映射。

| 条件 | 运行期间操作 | 用途 |
| --- | --- | --- |
| A | 无额外过程读取，结束时统一保存状态 | 最小观测基线 |
| B | 高频只读并保存读出 | 检验完整读出路径 |
| C | 同频率读取，但不保存读出正文 | 分离读取与输出处理 |
| D | 不读取模型，施加尽量匹配的独立计算／I/O 负载 | 检验负载及调度影响；负载匹配程度也需记录 |

每组重复两次，共最多 128 个短复演。所有条件使用相同推进边界、输入序列和停止时刻。主要判定是结束时完整 Core 状态一致性；有差异再用新副本定位最早分歧，并检查输入、队列、随机状态、数值更新与读出副作用。外部报告元数据不混入 Core 哈希。

每个条件都必须有共同的最终记录手段；A 不是“物理上从来没有被测量”。同一个确定性副本反复执行，不算大量独立概率试验。完全一致是这里的工程预期，不预设 50:50 概率。建议单 worker、最长 20 分钟、新增证据 512 MiB、沿用现有内存和磁盘保底；发现首个可复现分歧即暂停扩展并定位，不为了显著性堆样本。

### 第二阶段 实时遥测反馈

仅在第一阶段完成后另行登记。随机交错安排实时观测／不观测，记录三路遥测的原始量、编码值、递送时间、外部负载与目标活动。各次产生的实际输入再放到无读出副本重放，检查是否重现相应 Core 结果。

若差异可被对应输入重放复现，说明实测反馈足以产生差异；不直接声称所有影响都已排除，也不把它称为量子坍缩。关闭实时采样只用于隔离条件，保留原刺激的重放。不得把不同输入下的响应差异当成同输入下的观察效应。

### 第三阶段 可选的延后选择对照

单独定义早期窗口的结果，例如 A/B 目标活动积分之差，并预先冻结计算规则及全部样本的保留方式。先结束该窗口、保存原记录及校验承诺，再由不读取模型结果、不共享模型随机状态的独立程序产生新的随机选择：稍后开启额外读出或不开启。选择不可事先交给模型或由模型结果决定。

检验后来选择的两组中，**全部已经固定的早期结果**是否存在可复现的统计差异。不得用后来读出的内容挑选“成功”样本，也不以单个显著值下结论。结果分布必须有可审计的变异来源，样本量按预先指定效应量、功效和停止规则决定；第一阶段的 128 个确定性复演不能自动当作这个概率试验的充分样本。

共同的早期记录本身已经是观测，因此该设计检验的是后续额外探测选择与过去记录的独立性；它并不复刻量子擦除。若出现偏向，应先保存现场并核查分组、时间戳、共享随机源、选择偏差、软件和硬件通路，随后独立复现。不能事先承诺任何差异都属于 BUG，也不能仅因暂时未找到普通原因而将其命名为量子效应。

## 可行性与优先级建议

第一阶段本机可做，价值在于检验工具可靠性；第二阶段可验证 ThreeMind 与物理宿主之间真实的反馈。两者建议小规模开展。第三阶段可作为独立一致性检查，尚不建议投入大规模统计。

真正研究非经典量子效应，需要可控的物理量子系统、适用于具体装置的非经典检验及其假设检查。普通概率输出、软件随机数、量子随机源输入或两个经典副本相关，都不足以单独证明 Core 存在量子效应。未来可经适配器接入真实量子实验；届时量子装置与 ThreeMind 各自贡献必须分开。当前没有引入量子硬件或改写动力学的决定。
