# 整组同源对照与共海竞争

2026-10-04用户批准，[E35–E36已登记](../../../lab/explorations/2026-10-04-ocean-groups/design.zh.md)，在E34之后执行。主项比较**同一整组**的副本；不是只挑不同个体比较。用户也允许单体实验作为额外机制研究。

- E35：两个完整世界第60秒的实际快照，各分正常意识、随机但保留Core耗能、随机且停用Core三组；全部意识/躯体、营养及环境状态同源，继续60秒。群体成员的后代继承控制方式。
- E36：海洋面积翻倍，每组53个初始身体，营养/个体密度保持；两组共海，只能吞食另一组。身体/初始意识成对一致，两个新环境种子分别交换控制方式与初始位置的对应，观察120秒。
- 组别是外部实验条件，不作为敌友标签送入内核。保持真实感觉反馈、有限能量、身体变异、外壳和双向亲子保护；无融合、无合作策略、无意识动作限速。
- 停用Core不把它的储备赠送躯体。现有身体没有独立的不可逆饥饿死亡公式，因此分别报告物理存在、仍有储备、维持供能不足；不得把停核后不会发生神经死亡误报成寿命优势。
