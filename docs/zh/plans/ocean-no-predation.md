# E33：禁止吞食的种群与摄食对照

[English](../../en/plans/ocean-no-predation.md) · [研究总表](research-backlog.md)

2026-10-03。用户指出意识组可能更擅长吃掉其他个体，造成存活数下降，不能仅凭最终个体数判断控制能力。批准在完整海洋中补充关闭相互吞食的意识/随机驱动对照。

本轮使用E32相同的两个世界种子、1.2米海域、53初始个体、97在世上限、360颗初始营养和随机刷新；每世界120模拟秒。只关闭已有`predation`环境选项：碰撞和感官反馈仍在，捕获/吞食链及其附带的钳制过程停用。比较摄食、存活、出生、累计活体时间和首次触及种群上限；没触及时明确写观察窗口内未达到。

四个新增世界，单模拟worker。内核、输出节律和旧证据保持。允许吞食的E32作为既有参照，不重跑；未来双向亲子保护的决定保留，但本轮没有任何相互吞食，因此不影响该对照。
