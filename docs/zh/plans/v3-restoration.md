## 固定依据与复现方法

恢复脚本从 Git 直接读取旧文件，不读取 `data/`，不把现工作区中后来修改过的旧文件冒充基线。记录 SHA-256 和小型样例：连接出生、重复触达、局部新颖、遗忘、饱和直接触达、两阶段抑制等。再次运行 `python scripts/freeze-v3-restoration.py` 应产生相同内容。

本轮验证局部操作公式，不要求旧帧调度和新时间戳调度产生完全相同的整段轨迹。新生连接只走出生分支；旧整帧流程在同帧末尾立即遗忘，新版在下个明确传播周期执行慢变量更新。此相位差被明确保留，不能通过调整样例数值掩盖。

## 公式与执行相位

记激活为 $a$、抑制为 $q$、节点稳定度为 $s_n$、支持度为 $u$、局部可塑性为 $p$；边权为 $w$、边稳定度为 $s_e$、资格迹为 $e$。参数符号下列取默认值时对应旧 V3。所有上限和增量仍由实际可执行配置决定。

1. **触达**：抑制软饱和 $S(q)=c\tanh(q/c)$，响应比例 $R(q)=1/(1+g_rS(q))$。直接输入先按可负担到达量记账，再得到触达量 $d=\text{arrival}\,R(q)$；激活增量 $\Delta a=\min(1-a,d)$。`received` 记录抑制前到达量，`activated` 只记录实际激活增量，`sent` 记录已发出的兴奋量。接收不重复扣发射能耗。信号已扣费后因能量缩减而低于门槛的部分计入 `discarded`，没有退款。
2. **直接巩固冲量**：$I=\min(I_{max},\text{drive}\cdot\text{affordable fraction}\cdot p\cdot(g_{first}\mathbf1_{first}+g_{repeat}+g_{intensity}\max(0,\text{intensity}-1)))$。节点触达后 $s_n\leftarrow\min(1,s_n+0.5g_sa)$，$u\leftarrow\min(1,u+g_ud)$，$p\leftarrow\max(0.12,1-0.72s_n)$。饱和不会取消非零触达。
3. **出生**：共同激活分数 $C=a_i a_j$，合并冲量 $I_{ij}=\min(I_{max},I_i+I_j)$。$w=\min(1,b(0.5+C)+0.18I_{ij}+N)$，$s_e=\min(1,I_{ij}+N)$，$e=I_{ij}$，边历史触达数初始为 0。新颖项 $N$ 只在原有邻域且 $A=\max(assoc_i,assoc_j)>0$ 时取 $g_N\max(0,1-\min(1,A/A_{ref}))$；默认 $g_N=.018$。
4. **已有边共同触达**：$w\leftarrow\min(1,w+\eta C h(1-w)+.08I_{ij})$，$e\leftarrow\min(1,e+.3C+.25I_{ij})$，$s_e\leftarrow\min(1,s_e+g_sC(1+\log(1+touches))+I_{ij})$，其中有经过历史时 $h=1$，否则 $.45$，$\eta=.055$。触达历史再加一。已批准的独立传播巩固不再在这里重复增加旧联想项。
5. **发送**：$x_{ij}=a_iR(q_i)w_{ij}g_{prop}\Delta t_{prop}$，仅显式启用空间规则时再乘空间衰减。默认 $g_{prop}=4.2\,s^{-1}$，$\Delta t_{prop}=.1\,s$，恢复旧单次 `.42` 幅度。逐边检查 $x_{ij}\ge .004$；接收方状态不参与发送量。合格信号在 `delay_us` 后到达。默认传播周期与延迟分别为 100,000 和 10,000 μs。
6. **独立传播巩固**：对真实发出且通过门槛的 $x$，$w\leftarrow\min(1,w+g_{assoc}x)$，$s_e\leftarrow\min(1,s_e+g_sx)$，$e\leftarrow\min(1,.7e+x)$，更新经过历史。显式研究预算或全局可塑性开关可以限制此路径；默认不限制。
7. **抑制相位**：先对衰减后的旧势与已到达待处理势做 $S(q+q_{pending})$，兴奋发送使用此时的源响应；然后对累积激活上升产生的局部势执行 $S(q+q_{generated})$。按现有双向邻接的最大有向权重分配有限池，默认每周期转移 `.35`，源头扣去实际转移量；目标合并抑制包再做一次软饱和，延迟递送。门槛默认 `.002`。待处理势和本周期生成势均随状态保存。两次到达之间的自然衰减保持真实模拟时间意义。
8. **随时间变化**：$a\leftarrow a\exp(-\Delta t/\tau_a)$，节点痕迹和抑制同理。默认每 `.1 s` 分别保留 `.72/.82/.65`。连接资格迹每传播周期保留 $\exp(-\Delta t_{prop}/\tau_e)$，默认 `.78`；$s_e\leftarrow\max(0,s_e-\Delta t_{prop}(1-e)/\tau_s)$，$u\leftarrow\max(0,u-\Delta t(1-s_n)/\tau_u)$，默认 $\tau_s=\tau_u=.1/.00015$，后两者是线性损失尺度。节点稳定度不再套用新版独立指数损失。
9. **权重遗忘**：无本周期经过时，$w\leftarrow w[\max(0,1-.1f(1-(.08+.92s_e)))]^{\Delta t_{prop}/.1}$，默认 $f=.025s^{-1}$，恢复每参考周期 `.0025` 系数。资格迹先变化，再作用于稳定度，再影响权重；经过边豁免这一分支是旧规则，是否更简洁另行研究。
10. **修剪**：低于 `prune_weight` 的边可删；节点必须同时孤立、激活为零、支持度低于 `.006`，且 `time-last_touch > 80,000,000 μs` 才可删。全局可塑性关闭时停止学习、遗忘和这种自然修剪。

默认求解格点 `step_us=10000` 保留；它决定衰减归零等数值边界，不能被传播幅度或每事件学习率冒用。调整观察批次不新建格点。显式修改传播周期从该生效时刻开始新相位；空模型快速跳过等待、导出和恢复都保留此相位。显式资源预算采用传播周期长度的固定时间窗，改变周期会重置当前用量，并在配置说明中标出。

现有可选空间比较竞争仍按 `step_us` 数值格点执行，保持先前公开的语义；本轮没有将它改为拓扑抑制，也没有把它默认为开启。相关回归同时验证了边遍历顺序不改变竞争结果。

## 生命、损伤与模型文件

首次非零激活之前为待接入，不能因为等待 1 秒而死。出生后连续无激活才计时；同一时刻先处理全部已到达事件，再检查期限。在途信号、外部输入存在、接口开启、剩余抑制或连接均不能代替真实激活。暂停不推进模拟时间。死亡不会清空结构，不接受原意识自动复活。

独立损伤动作是 `silence`、`unsilence`、`disconnect_edges`、`delete_nodes`。断连只删边，保留已发出包；删点清理受体映射及相关边，后来的同通道受体取得新 ID、空白历史。在途包引用旧 ID，不能转投新节点。恢复静默不凭空产生激活。协议中的旧 `lesion` 仅作显式旧调用别名，不参与默认行为；新图形界面使用上述四项。

模型状态版本为 `threemind.state/6`，动力学为 `threemind.causal/8`，新增节点出生时间、局部可塑性、待处理／本周期生成抑制、传播时钟、经过历史、收发账本及无激活计时。Python、Rust、JSON 和 `.tmind` Arrow 二进制使用相同字段。JSON/二进制转换要保持状态摘要；出生继承清空活动及这些运行时相位，不是原意识复活。

旧 causal/1–7 可读、可按原摘要导出，不能套新版本号继续执行或继承。数据库只加新列，新列允许旧投影为空；不扫描或转换大 `data/`。应用升级需按停止流程停服、执行数据库迁移、重建原生扩展与 UI 后启动。

## 参数与聊天边界

- 创建第一层“节点标记／感官模式”、高级“文本感官编码”和 JSON 共用 `text_sensor.encoding`；创建后不可更改，校验和保存均检查。
- 强度、速率的 0 表示相应作用关闭；六种时间损失另有明确开关。时间常数仍必须为正，不能把 0 偷换成无限衰减。`quiescence_death_us=0` 表示同刻事件之后立即判死，**不是关闭死亡**。
- 聊天直接呈现实际非零活动和外部标记；没有标记则显示节点 ID 与幅度。按记录中的节点顺序显示，不按语义、联想是否“合理”或候选分类裁剪；单条预览最多 128 个活动节点，溢出有提示，原始证据不被修改。
- 被动读出、时序读出、输入和已启用的外部 AI 解读有不同身份。关联信封只做审计，不参与 Core 动力学。
- 成功发送清空，失败保留；支持 Enter、Shift+Enter、中文输入法组词和强度调整。列表每页至多 20 条，旧页冻结范围；上翻暂停跟随并保留列表及阅读位置，长消息跟随到开头而非证据页脚，不无限累积 DOM 或查询缓存。
- 图片、音频、视频入口复用既有媒体存储与解码；耳朵／眼睛复用连续采集；嘴巴／图像复用已有输出器官。开关有运行时提交确认和模拟生效时间。停止采集后不接收新帧，已接收帧保留原递送协议。浏览器播放或采集失败要显示错误，不能假装开启成功。
