## 5.2 实际实现：对象自有状态与按需结算

节点、连接各自保存 H 与结算时间。节点只按自身实际接受的有效量计 D；连接只在真实通过门控、资源处理并发出信号时记一次 D，不等待目标反馈，不查询两端激活、H 或显著性。剂量换算固定参考 0.1 模拟秒，不绑定求解步长；无固定“每次事件奖金”。节点强刺激显著性及疲劳只作用于本节点。学习关闭期间不累计以后补发的奖励。

已删除全图保持更新、事件后的全图同步、全边维护列表/排序、Rust 修剪时无条件全图重建索引，以及新颖性奖励撤销转 D 的适配。普通权重、稳定度强化和新颖性奖励恢复原路径；不再清零节点稳定度或将可塑性强置为 1。`memory_weight_learning_rate=0.55` 只学习自动节点支持度 S。

对象在自身触达、传导、连接变化和失效时结算；自己计算下一失效时刻，执行器通过稀疏到期队列递送，保留既有传播后的结构处理阶段。同刻输入先于失效检查；没有输入也会到期。Python 使用可更新的索引堆，Rust 使用时间有序集合及对象索引，不积累失效旧任务。映射查询用于寻址，队列用于递送，不分配全局学习机会。

完整重建只在载入、明确参数干预等一次性操作发生。Rust 删边局部更新索引；删节点因原 Vec 布局保序而更新被移动元素的位置索引，这是删除时的存储成本，未变成周期全图同步。观察、图与统计按时间投影，不写回 H、S、权重或队列；保存原锚点及队列，继续运行时自行结算。

## 5.3 公式与暂留参数

连接 q 为权重；自动节点 q 为 S。闲置时：

\[
H(t)=\max(H_{min},H_0-r\Delta t),\qquad
q(t)=q_0\exp\left[-\ln2\int_0^{\Delta t}\frac{du}{H(u)}\right].
\]

积分及阈值到达时刻使用解析式，不逐步轮询保持。D 到达后，令 \(x=\ln(H/H_{min})\)、\(x_{max}=\ln(H_{max}/H_{min})\)，默认增长为：

\[
H'=H_{min}\exp\{x_{max}-(x_{max}-x)\exp[-gD/x_{max}]\}.
\]

线性对照为 \(H'=\min(H_{max},H+H_{min}gD)\)。半衰期衰减积分、支持度学习和疲劳恢复继续采用指数/对数；没有增加全套线性替代。H 下限 30 秒、上限 30 模拟天、回落率 0.125、增益 0.2 暂留，属于待复验工程值，不对应人类时间。

**实测限定：**在重复输入 120 秒后，默认连接 H 最大约 40.33 秒；闲置 300 秒后两条边全部消退，而旧稳定度对照仍保有平均权重 0.21256。增益 2/4 的登记校准对照保有约 0.97053/0.99832。它们只测了重复案例，未验证长期背景和反转代价，因此没有升为默认。节点与边的实际剂量不同，不能用节点 H 很长替代连接保持通过。

## 1. 当前决定与版本边界

新增独立的 threemind.continuous-memory/3、状态版本和假设标识，Python 参考内核与 Rust 原生内核行为一致。旧版保留实际执行路径及冻结见证，不以重命名快照冒充升级。普通新建在新版验收后采用新版；保存的旧实例、历史协议和显式选定的旧配置不静默迁移。

本轮首先解决保持尺度、学习剂量及可恢复疲劳；永久留点、休眠痕迹、复活均为独立选项。已实现的新建默认如下：

| 选项 | 候选字段 | 默认 | 含义 |
| --- | --- | --- | --- |
| 不自动删除节点 | retain_nodes | false | 开关关闭，仍允许符合条件的节点自动回收；开启只禁止自动删点，不阻止显式研究干预 |
| 保留休眠连接痕迹 | dormant_traces_enabled | false | 关闭时低权重连接按正常修剪清除，不生成隐藏历史连接库 |

| 节点回收模式 | node_retention_mode | automatic | 复用支持度和其使用历史半衰期；manual 才使用阈值/固定等待 |
| 旧稳定度固化方式 | consolidation_mode | adaptive-half-life | 默认使用半衰期机制；legacy-stability 保留为兼容研究选项 |

### 1.1 自动支持度保持与手动回收（修订 4）

用户在修订 3 后提出自动模式，并明确选择“统一支持度自动模式”。支持度 S 是局部使用形成的保留余量，不是语义重要性。复用 S，另保存它的半衰期 H_node；实际接受的直接/联想触达和持续激活形成时间剂量，按第 2 节更新 S 与 H_node。没有另设第三个“重要性分数”。

- 默认 node_retention_mode=automatic：仅无活动、无活跃入出边且 S<0.006 时回收。0.006 是版本固定的数值下限，不是第三个用户调参项；S 与 H_node 完整保存。
- 自动模式忽略 prune_support、node_prune_after_us、dead_node_retention_us，界面显示禁用。更充分的实际使用使节点断连后通常保留更久，但不会辨别重复背景的语义价值。
- node_retention_mode=manual 才启用下述两种实验策略。S 是状态，阈值/等待是互斥策略参数，不能合为同一个量。
- retain_nodes=true 优先禁止两种模式的自动删除。模式切换先结算旧规则时间，清除未消费节点剂量，保留已学 S/H_node。

以下是仍保留的手动模式规则：

2026-10-08 用户确定取消正负合一的表示，采用两个非负量，以阈值模式优先。当前节点的量实际叫支持度，并非连接权重；保留字段 prune_support，界面名改为“节点回收支持度阈值”。连接修剪阈值 prune_weight 独立保留。

- 手动且 prune_support > 0（默认 0.006）：沿用阈值模式，仅无激活、无有效入出边、支持度低于阈值且距上次触达超过 node_prune_after_us 的节点可回收；忽略死节点保持时间。
- 手动且 prune_support = 0：切换至死节点保持时间模式。新增 dead_node_retention_us（“死节点保持时间”，默认 80,000,000 微秒，即 80 模拟秒，必须为正）。节点无激活、无有效入出边且连续未触达的孤立时间达到该值后可回收，不再要求支持度低于零，也不叠加旧 node_prune_after_us。
- retain_nodes=true 优先禁止上述自动删点；显式删点研究干预仍可执行。
- 孤立时钟从最后一条活跃边消失开始，从未连边的节点从出生开始；新连接取消计时，孤立期间真实触达重置等待。完整保存计时状态，不按宿主时间或恢复时刻重置。
- 删除节点时清理受体索引、休眠痕迹、击穿累计和轮转索引；休眠不暗中豁免删除。同通道日后创建的是新节点身份。
- 旧版继续使用原参数、公式和执行路径。本节取代修订 2 的负模拟秒建议；该建议的历史记录不回删。

### 1.2 休眠与复活的联动

配置必须满足：revival_enabled 为 true 时，dormant_traces_enabled 必须为 true。

- UI 关闭休眠时联动关闭复活并禁用该控件；API/CLI 使用同一规则，返回实际生效的配置及联动变更，不能只改界面。
- 重新开启休眠不会自动开启复活；不存在“隐藏记住上次开启状态”。
- 暂停后的显式配置调整先保留完整检查点。关闭休眠同时清理当前工作副本的休眠记录、索引、击穿量和待复活任务，不改变活跃连接或历史检查点；之后重开只记录新的休眠事件。
- 仅关闭复活时，清理复活累计量及待处理任务，休眠痕迹继续按正常遗忘演化。
- 恢复快照忠实使用保存的状态，组合不合法或缺失关键状态时拒绝恢复，不能在恢复时静默修正并改变个体。

## 2. 由遗忘速度表达固化

每条连接保存权重 w 和当前遗忘半衰期 H，不设置永久固化状态。候选工程目标是未充分重复的弱连接约 30 模拟秒半衰，充分学习后逐渐达到小时至天级，上限先设 30 模拟天；这些数值没有人类时间换算。

| 参数 | 首版候选 |
| --- | --- |
| Hmin / Hmax | 30 秒 / 2,592,000 秒 |
| 半衰期自然回落 | 每经过 8 秒，H 回落 1 秒，最低为 Hmin |
| 半衰期学习增益 | 每有效剂量秒 0.2 |
| 普通权重学习速率 | 每有效剂量秒 0.55 |
| 活跃连接修剪阈值 | 保留 0.008 |

令 x=ln(H_passive/Hmin)、xmax=ln(Hmax/Hmin)，先结算被动阶段，再按有效剂量 D 强化：

    H_passive = max(Hmin, H - 0.125 * dt)
    w_passive = w * exp(-ln(2) * integral(1/H(t), dt))
    x_new = xmax - (xmax - x) * exp(-0.2 * D / xmax)
    H_new = Hmin * exp(x_new)
    w_new = 1 - (1-w_passive) * exp(-0.55 * D)

每个固定求解间隔先精确积分被动衰减，再用 H_passive 求 x 并结算正向剂量；不是同时微分方程的无误差解。节点 S 使用相同形式。剂量内激活消退作解析积分，资源/显著性取间隔起点状态；正向边学习服从 edge_adaptation_limit，预算不足仍遗忘且不积欠奖励。观察与推进分批不改求解格点；数值步长收敛仍可另验。

D 为 q 在模拟时间上的累计。局部共同激活按时间积分、乘以局部可用资源；成功到达的联想按实际接受量归一为相同剂量单位。重叠贡献取较大值，同一次传输只记一次，不按输入事件个数直接加分。拒绝、低于实际传导门槛或未到达的候选不能冒充成功触达。

半衰期回落与活动强化分别结算；去除“本步经过就完全免于遗忘”的特例。节点旧累计稳定度只增不减造成的永久可塑性门控不沿用到新模式，学习由可恢复的局部状态调节。所有机制遵守统一物理时间与事件顺序，观察采样或 advance_to 的分批不改变结果。

这些已实现参数是初版工程默认，尚非最优值。双后端夹具验证初始 H=1 小时、无强化 5 分钟约保留 94.4% 权重。独立双节点重复刺激后，新版 300 秒时平均权重 0.99533，旧版 0.21198；单次普通/强刺激均在 300 秒时回收。强刺激有增益，但强度 4 的一次刺激未直接达到长期保持；没有为此添加永久保护。以上不是答题保持率，详见验证报告。

## 3. 两项默认关闭的研究机制

### 3.1 休眠痕迹

仅在 dormant_traces_enabled=true 时，低于活跃修剪阈值的连接转为不传导的休眠痕迹，保存端点、残余权重、半衰期和必要历史。残余权重继续按同一公式消退，低于候选阈值 1e-8 后清除。节点提前被回收时同步清理关联痕迹，不留悬空引用。

休眠存储不等于活跃邻接关系，不参与普通传播或凭存储维持意识存活。关闭时没有隐形副本。max_edges 计入活跃边与休眠痕迹的并集，同一接触重学可替换痕迹；复活累计另存；候选上限限制每周期检查工作量，不是累计状态的全局存量上限。改变修剪阈值不自动复活旧痕迹；提高休眠清除下限会清除工作副本中不足下限的痕迹。极大图成本与长期累积仍待验证。

### 3.2 历史拓扑复活

仅两开关都开启时测试。采用历史拓扑邻近作为首版候选定义；完全没有共同历史的孤立节点不会凭屏幕距离被找到。

- 目标为没有活跃入边或出边的休眠节点，不改变整个意识的死亡定义。
- 邻近为 1～2 跳历史接触；两跳必须经过一条活跃连接和一条休眠接触。残余接触强度由残余权重相对 0.008 归一，两跳额外衰减 0.5。
- 实际邻近活动积累有泄漏的击穿量，候选恢复常数 2 秒、阈值 0.2 激活·秒；达到门槛建立权重 0.04 的弱边。旧接触继承剩余 H，新的两跳连接从 Hmin 开始。
- 每活跃源每传播周期最多检查 64 个局部候选，确定性轮转，最多新建一条弱边，服从现有资源预算。索引、轮转和累计量完整保存。
- 后续命运只由正常传导、学习和遗忘决定，不重复领取首次接触、新颖性或年龄重置奖励。静默/断连/删点干预不能被后台复活抵消。

上述规则为研究假设。已验证复活弱边在充分激活时实际传导、无历史接触不造边，以及容量和恢复边界。120 秒弱背景的三组比较未触发复活，停输入 300 秒后均清理完；不据此宣称长期真实噪声下有益。完整系统收益与大规模成本仍待验证，默认继续关闭。

## 4. 强刺激、新颖性与历史有效机制

强刺激新增默认开启的局部疲劳候选，初始恢复常数 5 秒。按实际接受的有效刺激量计算额外消耗，强刺激造成更深的疲劳及更长恢复时间；没有收到的量不产生学习或疲劳。全局能量账本开启时记实际费用，账本关闭不取消局部耗竭。强刺激通过实际活动影响 H，不给旧稳定度直接加分；旧强刺激收益必须单列回归见证。

暂保留 arrival-window 的局部新颖性触发依据，称为结构新颖性，不添加“首次认识某物”的语义判定。增益调节当次局部塑性，不赋予永久保护；复活旧接触不算首次新经验。

已核查的主要机制并未完全漏接。耗竭/恢复、快痕迹、局部竞争、抑制、正常学习及延迟触达新颖性保留。易化 1 秒有条件性收益，保留研究预设；加倍学习率、加快恢复和增强抑制没有足以普遍替换默认的既有证据。均衡外设校准、完整过程读取、纠错和先密后疏复习属于外设/规约，不伪装成 Core 机制。[E49 核查](../../../lab/explorations/2026-10-05-bus-expression/report.zh.md) · [E20 对照](../../../lab/explorations/2026-10-01-priority-memory/report.zh.md)

交付“实验依据—实现—实际默认—新版处理”清单；若发现已有有效机制遗漏，连同适用条件补回。候选在单项任务有收益不自动成为普通默认。

## 5. 通道、多连接与分叉的范围

通道是外设到 Core 的编号刺激入口。一帧携带多个“通道编号—幅值”，加递送时间和强度。当前实现用 receptors 将每个通道关联到一个受体节点，节点还可通过多条联想边接收其他节点的活动。通道身份、节点身份、节点之间的边是三种不同对象。

一个物体或一句话通常形成分布在多条通道上的活动；通道不是预写概念标签。同一通道重复到来通常复用原受体，非每次刺激都新建节点。节点删除后同一通道可获得新节点身份。默认文字编码使用有限通道库，但其他适配器的通道域各不相同，不能把该上限推及所有输入。

一个节点已经可以拥有多个出边和入边，例如 A→B、A→C、A→D；这些边各有权重、历史和传导状态。当前每条边有一个源和一个目标，不是多目标超边，也没有连续空间中的“线段生长”。

若“分叉”只表示一处活动影响多个节点，现有图已支持。若要模拟轴突/树突延伸、分支共享资源、距离相关延迟、局部接触和撤回，需要独立的几何与形态动力学版本。当前可选空间嵌入也不等于此种生长机制；屏幕布局不能作生长坐标。本轮只登记为后续研究问题，不纳入记忆改进实现。

## 7. 修订依据与文献边界

首次会话方案拟默认永久留点、保留休眠并复活；用户随后提出背景积累风险。助手修正判断：两者有生物学启发但非修复快速遗忘的必要条件，静默记忆不等于完全断连节点靠邻近恢复。用户本轮明确要求留点开关默认关闭、复活默认关闭、休眠也作为待验选项，休眠关闭联动关闭复活。此节保留原建议到当前决定的变化，不把旧建议写成已实施默认。

神经元可长期存活，不能推出所有连接应永久保留；静默记忆的实验仍涉及功能连接；突触清除也参与遗忘。文献提供启发，不是上述半衰期、负阈值或两跳击穿公式的证明：[Spalding 2005](https://pubmed.ncbi.nlm.nih.gov/16009139/)、[Roy 2017](https://pubmed.ncbi.nlm.nih.gov/29078397/)、[Wang 2020](https://pubmed.ncbi.nlm.nih.gov/32029629/)。分支更接近轴突/树突结构，突触是接触处：[Neuronal Dynamics 1.1](https://neuronaldynamics.epfl.ch/online/Ch1.S1.html)。
