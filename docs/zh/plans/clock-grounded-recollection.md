# 时钟教学与经历复述

2026-10-05，用户在 E50 执行中提出；属于 E50 之后另行登记的实验，不改变 E50 判据。

## 两个不同的问题

E50 的“跟随变化”指已校准的表达器在意识继续活动后，是否仍能解读已教对应；它不是要求未受时间教学的意识回答“昨天发生了什么”。后者还需要可感知的时间参照、经历与参照的共同发生、时间词和复述句式的教学。本计划接受这个补充，不用未经教学的失败否定时间概念学习。

用户原话节录：

> 首先要教会意识时间概念，让教师和模拟场景教会意识认识要给简单的时钟（未必与现实始终一致，也不必那么复杂，但要能体现出计时），然后让意识把模拟时间的流逝与钟表的计时对应起来。

> 至少要教会时间概念和复述经历的句式。

这里的时钟是可观察的环境装置：表盘、指针或周期性亮灯随模拟环境推进而改变；它经过感官与输入总线。Core 的调度时间、文件时间和探针编号不能作为答案特征注入。教师说出的时间词和例句是合法教学内容，不等同额外标记内核。

## 分期验证

1. **短时间概念及句式**：保持多物体环境，观察可变化的简易钟。在物体先后出现时反复示范“现在看见……”“刚刚看见……”，初始每个示范至少连续十次，随后交错、间隔逐渐加长。先要求区分当前与刚刚，再考虑一个周期以前。输出接受同义、遗漏和可纠正的错误，原话仍完整保留。
2. **经历来自哪里**：同一当前场景、同一时钟读数，采用不同的先前经历；表达器冻结。感官直读组、无学习副本、目标关联屏蔽／恢复与匹配屏蔽分别检验。若答案只依赖当前表盘或物体，不能称为复述过去。
3. **实际经过时间**：比较顺序反转、等剂量但不同间隔、改变计时起点与表速。保留刺激实际时间过程，不能把所有时间片压成同一时刻。观察通过钟学习的参照与 Core 内部状态本身提供的先后信息各自贡献。
4. **更长经历与词汇**：短尺度通过后，教“一小时前”“昨天”及日周期。模拟环境的一天可短于现实一天，但换算必须登记、前后一致。不能把学会“刚刚”直接写成理解昨天；也不能要求未教过的词自动有意义。

先完成正在执行的 E50。新批次开始前固定教学材料、独立测试课程、表达器训练／冻结边界和资源上限；若工具连已教例句都无法稳定表达，记录该障碍，先定位工具，不无限扩大 Core 教学。保持背景输入及原动力学；禁止无提示副本相减、按预期答案筛活动或给 Core 人工贴“过去／现在”标签。时间显示的物理量与教师的语言都通过正常感官。
