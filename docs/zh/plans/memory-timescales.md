# 耗竭、易化与连接巩固实验

[English](../../en/plans/memory-timescales.md)

2026-09-29：**已完成独立研究内核与 598 个实验实例，旧内核和旧数据保留。** 八组控制、旧结果复现、跨时间尺度保持和有限机制核查均已执行。

采用 000、100、010、001、110、101、011、111 八组合，D/F/L 分别表示耗竭、短时易化和既有连接正向巩固。先比较相同已训练网络上的短时响应，再比较重复训练后 1／30／300 模拟秒的保持。遗忘、抑制、快痕迹等机制保持原值。
