# 6.2：稳定度保持与分类型连接门槛

2026-11-14。作者明确批准在6.1基础上实现6.2，并同意R51t6后的候选建议。本文件在实施前登记改动、默认选择和验收范围。

## 已确认的范围

- 使用独立版本、定义与状态身份；保留6.1及更早实现。仅共用已有通用数值、消息、存储协议和局部队列基础设施，不改历史转移规则。
- “旧式连接保持”正式称为**稳定度保持（stability-based retention）**：连接的稳定度随经历增加、随不用而回落，稳定度越高，权重遗忘越慢。配置名为 `consolidation_mode="stability"`。这是恢复已研究的规则，不再用“旧式”作为6.2候选名称。
- 稳定度保持自身的增长、回落默认开启，可分别关闭；实际传导对基础权重的强化保留。H时间尺度增长、回落仍用于单年龄曲线，不与稳定度保持捆绑。稳定度规则使用连接局部周期事件，不恢复全图扫描默认。
- 单年龄指数、幂律、逆对数和幂律转指数继续可选；逆对数仍是该类的默认。强化年龄默认继续累积，重置仍可选；H增长、回落保留当前默认关闭。
- 即时新颖性作为优先默认候选，到达窗口继续可选。稳定度保持先作为可选候选，默认选型与功能验收分别记录；不把新研究实现的成功冒称6.2已通过。
- 保留抑制。增加已有短抑制时间常数的研究预设（0.0580338705786432秒），默认不启用；原实测为恢复低幅度持续活动且配对选择不劣于参照，并未证明额外决策收益。
- 惯性感官反向实验预设将连接信号量门槛设为0.004，默认不启用，使用展开后的实际参数。预设不检查答案、不直接翻转输出。
- 增加可空的 `activation_signal_threshold`、`inhibition_signal_threshold`。每类未配置时回退到公共 `signal_threshold`；0是明确关闭该类数值门槛，不当作未配置。两类均配置且相同也保留配置来源。总开关 `signal_threshold_enabled=False` 关闭两类连接信号量门槛。
- 节点的激活/抑制发送门槛、连接信号量门槛、权重门槛和删除门槛分别定义。节点发送默认仍为0.004/0.002，公共连接门槛0.0004、删除阈值0.008；硬权重门槛默认关闭。
- 保留固定函数寻址、按地址接收在途信号默认及同出生身份选项、局部删除默认及全图扫描选项、短时资源、抑制学习及有限能量机制。
- 沿用完整结构繁殖规则：持久状态和衰减年龄继承，快速活动及后代时钟归零；年龄归零对照可选。保存恢复、观察和宿主等待不推进模拟。
