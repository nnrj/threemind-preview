# 个体内部模式与语言表达

[English](../../en/plans/native-expression.md) · [研究总表](research-backlog.md) · [E46实验登记](../../../lab/explorations/2026-10-05-native-language/design.zh.md)

2026-10-05，用户批准进一步调优和实验。本页记录决策，不替换E45结果。

用户提出：感官引发的内部模式未必像输入图像；表达器可能需要学习每个意识的表达方式，与其共同发育。另一种候选是吸收Transformer原理、建立更适合这类活动的通用解码器。二者可以结合：算法、语言生成部分共享，个体模式校准保存在各意识的外设配置中。当前证据没有决定必须为每个意识从零训练完整Transformer。

## 本轮采取的顺序

1. 重新分析E45六种输入路线的内部模式，而非仅与直接感官模板比较。原始输入和旧结论不改。
2. 输出外设学习真实教学后活动，比较共享、个体专用、分阶段继续训练和相同历史资料冷训练。Transformer和有限词表的注意力式样本读出同时尝试。
3. 冻结所有表达器，让Core继续原教学、接受反转教学或只接收背景。回答必须跟着Core的新经历变化，不能只证明输出器能记住旧配对。
4. 用内部传递的针对性静默和匹配静默定位有效来源。基础对应成立才扩大未见关系组合；不过关时报告具体瓶颈，不盲目堆语法。

“共同发育”本轮是交替更新：Core按原动力学受教，输出器按阶段学习它的活动，输入Transformer固定。端到端梯度、语言任务奖励写进Core、由输出器代替Core推理，都不在本轮范围。共用感官接线下的共享效果与跨接线迁移是不同问题；先排除接线不同这一混杂因素。

E45校准成功而正式表达下降，可能来自直接刺激和联想的分布不同、个体经历、输入编码或所需信息没有充分形成。不能先把失败全部归为解码器，也不能因旧解码失败否定内部信息。Transformer可作为候选，因为它适合学习序列间映射；原先用于翻译不意味着天然能读懂任何内部模式。[原论文](https://arxiv.org/abs/1706.03762)。脑活动语义解码中的个体校准提供方法启发，不是ThreeMind已经具有人类语言能力的证明。[Tang等，2023](https://www.nature.com/articles/s41593-023-01304-9)。

## 2026-10-05 实施结项

E46完成：723来源/副本、30个从零输出头。个体联想校准的视觉→名字7/12，共享2/12；只学直接感官的头能识别直接物体和裸名字，却跨感官0/36。随发育训练未胜相同资料冷训练。冻结后新经历门槛未过，未展开组合题。目标静默消除13个初始特异正确回答，匹配仅保留4个，故整体强归因条件未过。连续观察未见晚期感官再入，吐词也见于不学习对照。内核和默认未改。
