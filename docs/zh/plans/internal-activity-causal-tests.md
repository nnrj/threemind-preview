# 内部活动与行为：已完成的因果对照

2026-09-29，180 个实例完成。详见[通俗结果与完整报告](../../../lab/explorations/2026-09-29-internal-activity/report.zh.md)、[执行登记](../../../lab/explorations/2026-09-29-internal-activity/design.zh.md)与[操作说明](../../../lab/explorations/2026-09-29-internal-activity/README_CN.md)。

本轮确认：相同先天状态经过不同共现经历后，同一提示引起不同未提示节点活动和运动输出；出生清空短时状态后仍保留；关闭测试期内部通信，本次出生副本的两项经历差异归零。四父本来自两个相关接线家系，不冒称四个独立种群。

旧报告已经追加[讨论与解释修订](../../../lab/explorations/2026-09-29-input-rate-and-autonomy/discussion-addendum.zh.md)。不以断开全部输入后无限活动为成功门槛；不将静止和绕圈判作异常；机制解释不否定现象；测试期某个指标不变不能推广为形成过程和全部行为都不依赖通信。

已实现：同状态、同输入回放的可逆通信及连接静默对照，训练/测试通信交叉，等剂量不同经历，出生保持验证，原始时序窗口和末端激活排序，双语平台报告及证据。Core、映射和默认机制均未改变。

后续待讨论：将经历依赖的动作差异带回自由闭环，检验它如何改变之后的感知与学习；用特定连接和强度/度数匹配对照定位作用；区分连接与长期节点历史；在有接口对应依据后再考虑移植、共同环境和群体交互。本轮没有据此判定主观意识。
