# 单物体认识与身体校准

2026-10-07，R39。用户批准作为E61之后的分阶段方向，**尚未执行**；不是已经确认有效的改进。

## 先让身体不被微风轻易推动

用户要求后续手臂有足够重量，或将过大的风减为微风。下一批先固定眼手身体的物理参数，再教学。分别记录质量、驱动力、阻尼、风的施力方式和单位；不能只把一个没有物理单位的系数命名为“重量”。

先测无指令时的手臂漂移、已有控制器能否到达和保持、强弱风下的响应。选择使微风仍能提供感官变化、却不会主导手臂位移的配置。加重后的惯性和主动移动代价也须如实保留，不能暗中放大动作补偿。数值范围由现有模拟身体的量纲核查和小规模校准决定，先登记再教学。

已核查现有`advance_physics`沿用单位质量滑块：速度变化项含`4×动作 − 3×速度 + 0.15×(风速−速度)`，尚无独立手臂质量参数。持续外力与黏性阻力平衡时，单独增加质量主要改变瞬态，不保证降低最终漂移速度；因此质量、阻尼与风力必须一起核查。玩具已有各自质量，不能将玩具质量误认为手臂质量。

现有风的两个分量分别不超过0.8和0.5米/秒，合速度上界约0.94米/秒。因此不是模拟了狂风；需要核查的是简化滑块对微风的机械响应和长期漂移，不能只看视频就判定外界风速过大。是否引入静摩擦或实际支撑结构，留待下一批物理方案比较，不当场改变原世界。

E61的静置组保留了风，因此有被动移动和碰触；这不是“完全没有身体经历”。已登记的E61不途中改重力、质量、风力或感官映射。下一批物理变化采用明确版本和保存参数，旧世界照原规则恢复。

## 暂时绕开手眼协调，单独测认识与表达

若协调仍无明显改善，教学和提问时只放**一个居中对象**，先识别颜色、形状，再尝试组合与“这是什么？”等已教句式。保持可感知的环境和本体背景；反复教学采用先密后疏的复习，并对错误追加示范。此分支不要求先学会扫视或指出答案。

同一表达器须与未经教学、反向对应、Core连接干预及恢复比较，推理时不读取教师答案或对象类别。必要时保留非语言的原始活动模式判断，以区分认识内容与表达失败。读出只翻译真实活动，不减去无提示副本、不按期望答案筛选输出。

若单物体明显好于多对象，说明视觉选择、眼动或手眼控制是需要重点定位的限制；不能仅凭这个结果认定它们是唯一原因。若仍失败，检查教学、内部模式和表达器，不直接宣布Core不能认识。

## 顺序与停止条件

1. 完成E61原有比较、归因和报告，不临时加入新的大型网格。
2. 校准身体物理；冻结下一批配置、预算和原始输入。
3. 单物体居中认识与回答，并核查回答归属。
4. 有明确效果后回到多对象选择与协调；不规则形状、完整具身、NPC、先天选择和能量奖励仍单独登记。

回到身体学习时，另比较“同一运动中枢从学前到教学持续校准”与E61的“学前固定接线、教学后另训Transformer”。后者是当前代码事实，可能限制身体经验沿用，但尚未被因果实验证实。保留旧流程作对照，不能把再次换外设宣称为同一个中枢自然成长；已验证有用的共享视觉读取思路也保留，按实际任务比较，不改成预先替模型选物体。

目标是定位瓶颈，不追求所有组都成功。实验规模和具体阈值在启动时登记；本文件不把尚未运行的候选写成已验证方案。
