## 结论与适用范围

新增 `threemind.continuous-memory/5`，默认采用 `/2` 的接收与学习规则；保留已批准的局部事件执行、H／旧稳定度两种保持、节点支持度回收及可选能源、休眠机制。**它是另一个明确的内核版本，不是 `/2` 的改名，也不是 `/4` 的静默修补。** 应用默认仍是 `/3`，本次没有自动迁移已有个体。

本次恢复规则与消除重复工作后，已测稠密小图的 `/5` 显著快于 `/4`，但仍慢于 `/2`。不能据此断言正式形色成绩、长期记忆或所有图上的性能更优；这些尚未进行新实验。H 没有被删除，数值默认没有顺便调优。

依据依次是[用户批准及原话](../history/sources/2026-10-13-kernel-performance-audit.md)、[实施登记](local-events-v5.md)、[原始差异审计](kernel-delta-decay-audit-20261013.md)及[历史基线核验](memory5-baseline-verification.md)。助手写出的契约或测试不能倒作用户授权。

## 具体改动、理由与影响

| 已实施改动 | 理由 | 对动力学的影响 |
|---|---|---|
| 内部传入包不再令下游接收者两两建边／强化，所有 `/5` 选项均禁止这种互配 | 纠正对“统一接收”的未经说明扩张 | 会改变 `/4` 的学习机会与轨迹；这是新增版本的主要原因 |
| 外部共刺激仍可关联，评分使用端点当前激活；强化系数依据真实最近传播轮次 | 恢复 `/2` 原有规则；不能以局部执行为由换成本包量或同刻通过判据 | 保留共刺激与真实传导两种已批准学习，不禁止正常生边 |
| 新颖资格在包内配对前冻结，起点计已有联想，截止下个对齐传播加延迟；到期奖励先于同刻发出 | 恢复 `/2` 的资格、窗口及先后关系 | 新颖奖励保留，消除包内建边顺序带来的额外资格 |
| 恢复直接输入限幅、强度及有效能量比例，零实际接受不增加接收经历 | 恢复已批准强刺激路径 | 不撤销发送端已经发生的传导、消耗和强化；发送仍不查询目标当前状态 |
| 同轮抑制按目标汇总后作原软限幅；支付能源后仍检查发送下限；空间衰减遵守邻域开关 | 恢复 `/2` 非线性位置及遗漏门控 | 相应可选条件下与 `/4` 有实际差异，不称作单纯索引优化 |
| H 模式下辅助资格迹／稳定度以原离散递推按需合并，不再替换成连续积分 | 普通学习／读出使用这些量；H 不授权改变所有辅助量的规律 | 闭式合并保持数学递推，跨后端浮点按既有容差比较；不是取消这些观测量 |
| 关闭学习时推进相应锚点，不储存后来补发的学习／辅助退化 | 遵守消融开关 | 重新开启不会补算关闭期间的奖励 |
| 增加第五版独有的发出／结算相位锚点 | 合法同刻追加输入必须知道该轮发出是否已执行 | 避免重复发出、强化误判和错误新颖截止；记录执行次序，不扫描全图或分配学习机会 |
| 期限去重、特征复用、禁用路径提前返回、待新颖索引等 | 消除重复实现工作 | 由修改前后状态见证约束，不故意改变模拟轨迹 |

新状态格式为 `threemind.continuous-memory-state/5`。节点 `last_emit_us`、边 `completed_period_us` 及执行器 `completed_emission_us` 完整保存与恢复；最后一项只是已完成的传播相位标记。它们不进入 `/4` 的序列化。不能修改旧存档的版本字符串后当作 `/5` 继续。

## 默认与研究选项

| 配置 | `/5` 默认 | 说明 |
|---|---|---|
| `reception_mode` | `legacy-source` | 按 `/2` 区分直接输入与内部联想的原接收语义 |
| `arrival_mode` | `sequential` | 外部观测包分别处理；同轮真实内部消息保留原接收上下文 |
| `propagation_phase` | `aligned` | 节点自行预约，但保留原对齐传播相位 |
| `propagation_mode` | `local-events` | `scan-control` 只作第五版扫描执行对照，不等于 `/2` |
| `consolidation_mode` | `adaptive-half-life` | 可选 `legacy-stability`；后者替换连接遗忘，自动节点支持度仍有自身 H |
| 能源总开关、休眠、唤醒 | 关闭 | 沿用批准状态，不为提速另行关闭已启用机制 |

`unified` 与 `asynchronous` 是用户批准保留的研究选项，界面和参数说明标明它们不同于主基线。出生固定项不能在一个个体中途切换。

`coincident` 沿用的研究组合尚有已识别限制：同一节点的外部和内部量会合为一次接收，其来源标志可能影响新颖量归属及直接学习冲量。默认 `sequential` 不走这条路径；双后端相等不代表这条研究规则已充分论证。已单独请用户决定是否在 `/5` 撤下该选项，未获答复前没有擅自删除或设计新混合规则。**该研究组合不能被称为完整 `/2` 接收语义。**

## 性能测量

原生 Rust release，种子223，新样本分别16／32／64通道，40次固定输入，2模拟秒；六组各重复3次并交替顺序，报告中位数。计时排除注入、全图观察、保存与编码；重复样本的组内状态哈希一致。各组最终均为对应通道数节点与全有向连接，64节点时4032边，没有靠删图获得加速。

| 节点／连接 | `/2` | `/3.1` | `/4` H | `/4` 稳定度 | `/5` H | `/5` 稳定度 |
|---|---:|---:|---:|---:|---:|---:|
| 16／240 | 0.017284 | 0.031883 | 0.115950 | 0.124179 | 0.062072 | 0.059947 |
| 32／992 | 0.068523 | 0.133278 | 0.803665 | 0.858445 | 0.232474 | 0.259282 |
| 64／4032 | 0.306816 | 0.568225 | 6.326596 | 6.236865 | 0.928643 | 0.972116 |

单位为推进所耗物理秒，当前表来自 `costs-r3`。64节点时，`/5` H与稳定度相对 `/4` 分别减少85.32%／84.41%耗时，约快6.81／6.42倍；`/5` H仍耗 `/2` 的3.03倍、`/3.1` 的1.63倍。对应边结算访问为 `/4` 2,590,733／2,750,437，`/5` 399,168／479,808。`/4` 和 `/5` 的局部主路径扫描计数均为0，说明“没有全图扫描”仍不足以说明便宜。

加速同时包含规则纠正和实现优化，不能把全部收益归给某个单项。当前测试是全连接小图的有界工程负载，不能外推所有稀疏网络、异步模式或完整形色课程。观察／保存原始分项在回执中：64节点捕获状态约19～25ms，编码约7～11ms，指标约0.1～5ms；这是Core JSON，不是带外设的完整个体占用。

入口：[成本程序](../../../crates/threemind-core/examples/memory5_costs.rs)、[编排工具](../../../tools/benchmark_memory5.py)。原始输出留在忽略目录 `.work/memory5-validation/costs-r3/summary.json`，记录配置、源代码及可执行文件哈希；不复制到Git。`costs-r1` 保留为构建并行期间的早期测量，不用作主结论；`costs-r2` 是末轮纯性能清理之前的回执。r2与r3所有18组终态哈希一致，末轮没有改变这些轨迹。
