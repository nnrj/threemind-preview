# 具身交流：先互相产生作用，再研究人类翻译

2026-10-06，用户批准实施E53。[English](../../en/plans/embodied-communication.md)

自然语言表达器暂缓。学习、复述与推理不以人类词语为必要条件；但分别需要检验，不因外部信号改变行为就一并宣布成功。

沿用完整海洋、有限供能、三个历史候选来源、自然变异、种群内相容与异种群吞食。新增嘴巴→输出总线→环境声场近似→双耳→输入总线，传递匿名频带，不传对象名、身份或食物坐标。内部活动可被研究者观察；外界只能听见身体发出的信号。现有嘴巴是固定的被动发声器，尚未证明实例自发决定何时对外说话。

接触后分享摄入营养/猎物所得提供合作机会，不预写寻找同伴、共同狩猎策略。新环境不冒充完整流体声学或合力抓捕仿真。之后若有交流收益再逐步增加复杂任务，避免本次混进太多新的物理规则。

按序核查声音是否改变他者动作、已形成连接是否参与、交流是否在不同环境有益，然后再检验所指、不在场事件、延迟记忆与组合。静音保留自听及发声成本；每次重新打乱频带保留单次功率；消融、匹配、救援均保留全海生物、营养和原始状态。

本轮不使用Transformer，不改内核和旧实验。用户关于人与人不必有同构内部语义也能交流的假设保留。通过实验判定“有效交流”不等于宣称人类语言、一般推理或主观体验。
