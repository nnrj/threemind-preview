# 从零 Transformer 语言中枢与自发活动转译

**当前执行顺序（2026-10-04，实验开始前用户补充）：先用冻结预训练 Qwen 验证双向映射、经历相关回答和无输入活动转译；达到可行性条件后才开展从零小 Transformer 的配套训练。下文从零路线保留为最终目标和后续设计，不再是 E42 的首个执行条件。**

2026-10-04，用户批准开始；E42 是本计划的第一批有限实验。浮游生态实验暂告一段落，原数据与物种保存不变。最终目标：与 ThreeMind 配套从零训练的小 Transformer，能否成为自然语言输入、表达以及内部活动观察的外置中枢。该目标尚未实现；不能把接口打通或校准词复述当作完成。

## 边界与既有证据

- Core 沿用 `continuous-memory/2`，使用保存的完整参数；不改方程、默认值、感官规范化、死亡规则或既有实例。
- Transformer 是总线外设。主实验不使用预训练权重、预训练分词器、Qwen 或在线供应商。字节级小模型可训练；正式评估固定其权重和映射。原文本输入、随机冻结输入与经独立语料训练的输入模型分开。
- [E26](../../../lab/explorations/2026-10-02-robot-language/report.zh.md) 的四词校准成功，但新对应未优于空白。四段有符号桶平均可能丢失过程信息，单词校准未覆盖经历后的状态，这是待验证原因，不预先判定 Core 无记忆。
- 已有自主活动标准和生态结论不在本轮改写。无新刺激后仍存在活动时持续观察；真实活动消失就记录静默或死亡，不伪造无限持续活动。

## 输入、教学与划分

保留短句、说话人及标点。第一批从“甲是松子。”“乙是铃铛。”及同句式词表开始，每个新句先连续 12 次，再复习 6 次及 3 次；其他顺序按固定种子平衡。教学强度 1、提示 0.5；额外强刺激项保持现状。首先记录 0.5 秒旧观察窗及其后连续活动，不把旧短窗视为全部响应。若调整间隔，只能在明确标记的校准阶段决定，正式测试不追着答案改参数。

外设校准用独立的词活动、强度及活动恢复阶段。测试对应关系及答案不进入输出转换器训练；所有副本测试从同一教学终态分叉，避免前一提问改变后一提问。先用已知词的新关系，再单列未见词。词面共现、角色方向、教学顺序及近期残余活动要能分开解释。

从零输入模型的独立语料只包含单词或不包含正式配对答案的材料；随机权重和训练后权重均保留。当前输入归一化/匿名接线照原协议执行，记录实际入射总量，不为某路线临时配答案式通道。

## 自发活动与“内心独白”

“内心独白”在本计划是活动的语言转译界面名称，不假定每段文字忠实对应已存在的语义思想。必须保存完整原始活动、窗口时间、输入是否为空、投影、转换器版本、文字/原始字节、空结果及错误。

1. 新增显式无输入观察操作。它推进模拟时间、正常处理已经在途的事件，不发送空字符串、BOS、假问题或隐形唤醒刺激。无新输入与在途外部输入全部递送后分开标记。
2. 连续窗口逐个产生结果；CLI 流式 JSONL，UI 与 API 使用同一操作。解码慢时标明实际墙钟延迟，不为赶显示改变 Core 时间或丢弃活动。
3. 输出器只接收当前窗口的活动及固定语言校准。窗口之间不继承 Transformer 的自回归缓存或自己生成的文字；关闭自动输出回灌。回灌与持续 Transformer 自身记忆是未来独立实验。
4. 不用流畅度过滤“杂乱独白”。无可读文字、重复、乱码及无法校准的活动均可查看。活动为零时记录静默，不让语言模型凭空续写。
5. 同一记录活动用于不同训练阶段的输出器，区分语言表达训练进步与 Core 活动变化。原始活动相同、文字变流畅，不能据此声称 Core 逻辑进步。
6. 完全无输入分支为主要观察。若该实例自然沉寂，另列可重放、与答案无关的弱环境背景分支；不能把带背景条件称为完全无刺激。当前第一批不接实时 CPU 遥测。

## 对照与预定分析

- 输入路线：原文本、随机冻结小 Transformer、独立语料训练后冻结的小 Transformer。输出从随机权重训练，不用大模型裁判。
- 经历：普通配对、反转配对、无教学；同一副本正常学习与学习关闭按需定位。配对失败也报告，不只展示成功种子。
- 读出：旧有符号平均保持原协议；无抵消/保留峰值的新观察配置另有版本，不能静默改变旧映射。完整节点轨迹始终保存。
- 因果归因：真实活动、全零、桶顺序打乱、交换不同经历的活动；若出现明确关系，再做目标连接静默/匹配静默及持久连接移植，不用全局破坏作为唯一证据。
- 主要结果同时呈现预先规定窗口的目标响应和文字准确率；不因全局未稳定而忽略短暂清晰响应。候选词峰值/积分作定位工具，不能事后任挑时刻宣布逻辑成功。
- 自发输出报告活动持续时间、可读比例、词分布、重复、转换器变化、经历可区分性，以及活动扰动后的变化。非提示目标再入与残余衰减分开；出现新词或连贯语句仅列现象，关系正确性另做测试。
- 原始轨迹含关系而投影没有：改观察器；投影含关系而文字没有：改转换器；两者都没有：记录该教学条件的边界。不得为修饰输出修改 Core。

## 预算与停止

2026-10-04 预检：GTX 1650 可用，Torch CUDA 可用；可用内存约10.6 GiB，E盘约62.8 GiB，C盘约8.9 GiB。使用 E 盘现有环境，无新模型下载。单 worker；初始4独立种子，最多256个Core实例；实际训练/模拟计算累计4小时。进程树内存6 GiB（研究主进程沿用4 GiB守卫）、GPU预算3 GiB；至少保留内存2 GiB、C盘5 GiB、E盘15 GiB。新增证据3 GiB停止扩展，4 GiB硬上限。

账户用量起点31%；增加3个百分点停止扩展，增加5个百分点停止新训练/模拟，保留整理时间；共享账户变化保守计入。每批留检查点，网络中断不重复完成样例；不清旧数据，不扫描旧大证据，不重复全量哈希。首次验证观察不改变动力学后，仅在相关代码改变时重验。

### 2026-10-04 校准期间、正式教学测试前的判据澄清

原机器登记把所有留出窗口都计入词语正确率。首批原始轨迹表明，每个词的后两个窗口已无激活；这些窗口正确行为应是静默，不能要求译出词语。保留原始分母与结果，另报有活动窗口的翻译准确率（75%门槛）及无活动窗口的静默正确率，不删掉衰减末段。此澄清依据原始活动、不是依据哪一个翻译结果好看。正式提示仍固定第二个500ms窗口，不重新选有利时刻。空白对照先无输入等待42模拟秒，与教学组保持相同测试起点；等待期无隐形唤醒输入。

### 2026-10-04：E43间隔复习留下持久结构，语言检索仍待校准

用户要求普通强度、逐句先密后疏，并指定真实物理遥测背景，也允许模拟背景对照。E43从空白意识以强度1、每句57次教学，与等剂量、等总时长、等最后复习的集中组比较；真实宿主及采集进程遥测被逐项等时重放。两套接线中，间隔组通过逐边门槛的累计量为集中组5.4～5.7倍；300秒后均保留157条语言内部连接，集中组均为0。少数强边与稳定度的差异不能被平均边权遮盖。

主文字回答未形成可靠的新配对，反转双重正确均为0/8；普通组在教学结束及60/300秒后的译文与关闭学习逐条相同。结构结果出来后追加40个普通强度1的提示分支，仍未测到相对无提示的额外合格传播。背景维持整体存活，却未在检查点上与语言子网连边；未教学背景也被旧四词转换头译出熟悉词语。遂把结构保持增益、提示未能带动、输出器混合背景校准分开记载。500个来源及分支完成，Core不改；从零联训未启动，下一步感官/检索校准为建议。
