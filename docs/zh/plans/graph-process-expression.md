# 图与活动过程表达器：共同所指与回答归属

2026-10-05，获准执行E50。保留旧表达器、旧Core和旧证据。[English](../../en/plans/graph-process-expression.md) · [执行登记](../../../lab/explorations/2026-10-05-graph-expression/design.zh.md)

用户原话：“可以对同一个概念进行不同角度的教学，如果表达器对这些不同角度的说法所指向的仍然是那个共同所指的事物，就像被多条线交叉定位了”。

整理：共同所指提供多条互相约束的证据。需要同时看组内一致、对象间区分、未教说法、反转和内部干预，避免由外设直接识别、固定答词或任意标签记忆造成表面一致。监督校准不天然违规；词汇名称可由外设学习，特定经历的事实及关系必须通过因果对照定位。

对E49解释的补充（原报告不改）：重新校准恢复正确命名，证明状态仍有可用于区分的信号；单凭该结果不能证明已读出Core独立形成的语义，也不能排除“状态指纹→教学标签”。新方案新增图/时间编码与交叉注意力表达，训练及观察在内核之外，现场互动不夹带答案。目标是既能追随变化，又能定位谁提供了回答依据。

先工具与原资料比较，再共同所指新教学及归因。持续校准用于共同发育；阶段性冻结用于归因，两者分别报告。复杂语言、独白与推理不预告成功，亦不因读出失败否定未被工具覆盖的内部模式。
