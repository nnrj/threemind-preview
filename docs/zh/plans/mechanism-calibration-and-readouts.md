# 机制校准、时序活动读出与运行时边界

状态：本轮实现与校准已完成（2026-09-30）；基线 `c57bb1d`（2026-09-29）。旧研究、原始证据、已存意识及其内核定义不改写。可选沙箱已提供配置，容器运行验收尚未执行。

## 本轮约定

先完成运行时与观测工具，再校准强刺激、新颖性和长期遗忘。新机制采用独立内核／状态版本；验收后才切换新建意识默认值。旧内核仍可明确选择。保留时间戳递送、感官映射、局部可塑性、抑制、不应期、遗忘和能量消耗。无限外部供能不等于关闭局部耗竭。

**时序活动读出器**是总称。原算法命名为**活动稳态判定**；新分析分别给出**响应模式收敛、幅度变化、周期活动、响应结束**。界面不以 V1/V2 区分这些不同问题。旧 `residual_decay` 保留在历史协议中，显示为“幅度衰减”。比例稳定与幅度下降可以同时成立；全零不能归一化为有效响应。有限采样的收敛不等于证明全网吸引子，响应结束不等于意识死亡。主要排名采用判定窗口结束时的激活强度，同时保存峰值、积分和旧综合排名。

旧、新观察独立开关与独立结束，共享只读节点采样。旧算法提前结束不终止新分析。不改写旧分类；新证据保存分析版本与参数。UI、CLI、API 和导出使用同一结果。

## 实施与验收顺序

1. 冻结旧源码、定义与基线行为；基线测试 84 通过、1 跳过（原生测试环境，跳过项须保留原因）。
2. 分离可独立安装的 Runtime 与 Lab 依赖；检查快照、临时干预声明与可选部署沙箱。不让研究工具改变核心状态演进。
3. 新读出工具：检验稳定比例衰减、总量稳定但节点轮换、周期、低幅度、全零、重叠窗口、恢复与读出开关的动力学等价性。
4. 强刺激：0.4、1、1.5、2、4；单次 4 对比 0.4×10，集中／间隔重复与无训练。1／30／300 模拟秒独立探测。核对实际接收、耗能与巩固；不能用最终漂亮的行为代替机制验证。
5. 新颖性：先比较当前立即计算、冻结旧操作顺序、按实际延迟触达结算的候选方案。记录局部邻域、真实再入量与增益何时产生。不得为得到正结果虚构语义新颖度。没有明确收益时保留现状默认值。
6. 300 秒保持：同一训练状态分支为正常遗忘、仅关闭权重遗忘、关闭慢结构衰减；不关闭激活／抑制衰减、学习与局部资源恢复。1／10／30／100／300 秒各自独立副本，无提示／0.5／1 提示。区分结构丢失、修剪、阈值和读取失效。另测新环境适应与饱和。
7. 更新中英文说明、结果与测试证据；按阶段本地提交，不推送。

## 实施前已核查事实与待验证项（保留原记录）

- 强刺激额外巩固项仍在，系数乘以 `max(0, intensity - 1)`。此前强度 1 的“强刺激”没有触发这一项；尚不能据此认定额外增益无效。
- 旧、新实现均保留局部新颖性公式。旧时序为直接刺激→传播→候选连边；当前立即连边可能早于延迟联想到达。公式存在不代表自然输入下已经被验证触发。
- 既有 `autonomy-criteria/1` 四项操作标准已通过，本轮不改变标准或否认已有结果；它不是已获学术验证的主观意识检测器。以前完成的是消融、恢复和出生副本对照，没有完成联想区域移植。
- 300 秒读取不到新配对并不能单独区分遗忘与读出阈值问题；这是本轮要查明的问题。

## 资源与停止条件

新实例最多 1000；累计模拟墙钟预算 120 分钟；单进程不超过 4 GiB，可用内存不少于 2 GiB；C 盘余量不少于 5 GiB，E 盘不少于 15 GiB。新证据（含数据库与归档）总预算 4 GiB，达到 3 GiB 停止扩展并封存。实验开始记录账户用量，增加 5 个百分点停止扩展，8 个百分点停止新模拟；共享账户用量不归因于本任务。运行脚本自身执行内存、磁盘、时间检查。旧证据不删除、不覆盖；新实验使用独立目录和研究项目。

## 第一阶段验收（2026-09-29）

运行时拆包、干预声明、可选部署沙箱配置、时序活动读出和接口/UI 已实现。独立安装 Runtime 后，在不加载 Lab、Web、数据库包的隔离 Python 进程中，四类既有内核的保存与继续运行校验一致。相关核心／工具测试 92 通过、1 数据库项跳过；该数据库项已在独立数据库套件中验证，相关数据库测试 22 通过。前端生产构建通过，1440 与 390 像素浏览器实际交互均通过；聊天只出现一条主要读出，旧判定仍可查询。Docker Compose 配置校验通过，尚未构建或运行沙箱镜像，不将此视为容器实机验收。此阶段未改变内核动力学。

## 最终验收与默认选择（2026-09-30）

完成 786 个有效实例与 12 个旧顺序小型见证；原始证据、四项实验记录、中英文报告已保存到独立研究项目 `d27d28d0-55f1-4783-99fd-e3a503ec1573`。空白启动失败记录另外保留。模拟累计 15.83 分钟，新增本地与数据库证据含归档约 1.407 GiB，未触发资源终止。786 份最终状态逐一核对数据库与本地一致，六份历史父状态未改写。

- 强刺激额外巩固项有效；输入强度 1 不能检验这个仅在大于 1 时工作的项。本轮校准参数和说明，保留公式。
- 延迟触达新颖性在强度 0.4 的校准组中提高目标短暂净响应积分 40.66%，强度 0.8 组为 2.26%；不把它写成最终收敛命中或普遍增益。两组都开启 1 秒易化，新建默认仍关闭额外易化。
- 新建默认切换到 memory/2＋arrival-window，原四类内核和新版立即计算模式保留；历史协议、状态恢复和已保存项目默认值保持原义。
- 300 秒正常组的新连接已被修剪；关闭权重遗忘能保留，但提示 0.5 仍可能不触发，提示 1 可引出短暂响应。结构遗忘与提示门槛共同解释原来的零结果。
- 关闭遗忘后仍能学到新响应，旧响应也更强；本轮未见饱和，不能把新旧并存直接写成适应性变差。

最终验证包括：153 项内核／配置／读出／部署集成测试，45 项跨后端／LIF／构建测试，随后显式开启编译的 2 项独立构造测试，27 项 API／生态／报告／探针测试，5 项 Rust 核心测试，3 项实验工具测试；这些是分组执行记录，不表示互不重叠的合计数。前端构建及 1440／390 像素浏览器交互通过。独立 Runtime wheel 在无 Lab、Web、数据库客户端的环境验证五类内核；实际编译的 Rust 程序保留可塑性。`doctor` 确认本机数据库及新原生后端可用。
