# E31：从摄食差异到行为原因

[English](../../en/plans/ocean-behavior.md) · [研究总表 R09/R10](research-backlog.md) · [事前设计](../../../lab/explorations/2026-10-03-ocean-behavior/design.zh.md)

2026-10-03。用户要求继续查明：意识组的觅食优势是否来自经历和内部活动，是否会根据食物、猎物和威胁的位置调整动作；用局部消融、匹配消融、移植及更换环境检验。旧 E30 证据保留，不能用“影响了动作”直接代替“学会了有目标的觅食”。也不为意识加动作节律限制。

本轮选两个旧世界中固定时点的八个来源，保留身体变异和运动投影。独立选区后在两个新方向评估，保持感官反馈、有限能量、学习、遗忘和抑制。把另一方向的实际动作逐点回放，作为不能响应当前对象位置、但保留动作连续性的对照。持久连接移植进入通道对齐的空白意识；随机控制器本身不读取意识输出，不能靠给它附上一张不参与控制的网络来检验移植。

主要观察固定时间段的动作、目标方向运动、首次接触/捕获/脱离；再看摄食、生存和有限能量。八个来源属于两个训练世界，不当八个独立种群。未见环境随机生成食物，食物随水流和混合变化，并继续在新位置补充，不是固定坐标一次性清空。

另在原共享世界里保存自然接近时刻，保持完整海洋做原位对照。无触发、无合适活动区及阴性都记录。内核版本、默认值、旧实验及既定自主活动判据不变。具体预算和完整执行细则见[设计](../../../lab/explorations/2026-10-03-ocean-behavior/design.zh.md)及[原位登记](../../../lab/explorations/2026-10-03-ocean-behavior/natural-registration.md)。

用户随后要求行为录像。工具支持真实轨迹 PNG/MP4 导出；意识图像和物理世界 UI 支持 PNG/WebM，标题、图例、可用世界/代次/模拟秒可选。录制不推进内核，也不把未采样运动插值成证据。录制电脑资源会有开销；本批实验没有实时宿主遥测反馈，离线视频不回写环境。[工具和操作说明](../../../lab/explorations/2026-10-03-ocean-behavior/README.md)

结果将在[本轮报告](../../../lab/explorations/2026-10-03-ocean-behavior/report.zh.md)中分别回答即时响应、持久经历、内部连接和移植收益，不将视频中的接触自动命名为主动捕猎。

## 完成与范围更正（2026-10-03）

本轮已完成。局部通路作用与动作转移有可重复结果；主批局部装置删去了塑造经历的群体环境，不能据此否定完整生态技能。用户已批准保留完整复杂环境的后续正常/消融/移植对照及全景视频。结果、原话和限制见报告与执行札记。
