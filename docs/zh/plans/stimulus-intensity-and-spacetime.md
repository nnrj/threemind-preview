# 刺激强度、背景输入与时空感官

[English](../../en/plans/stimulus-intensity-and-spacetime.md)

2026-09-30。状态：刺激、背景及本体感官已实现并完成工程和有限实验验收。基线 Git `6241016`，旧 V3 核查基线 `97d8592`。[实现说明](stimulus-spacetime-implementation.md)；[研究报告](../../../lab/explorations/2026-09-30-stimulus-spacetime/report.zh.md)。[Transformer GPU 实际任务及 CPU 回退验收](transformer-gpu-acceptance.md)也已完成。

## 决定与边界

普通文本强度 1、强刺激预设 4；合法范围仍为 0–100。预设不改变规范化、分帧或通道映射。新建默认 `continuous-memory/2`、arrival-window 新颖性、增益 0.018、参考量 0.2。普通配置不开额外易化；独立研究预设仅将 `stp_facilitation_tau_s` 改为 1 秒。

不调整遗忘、抑制、局部能量耗竭恢复、传播门槛或内核时间架构。保留旧意识、配置、映射、协议、证据。新默认不用于恢复旧对象。

本体感官与其他感官均为外设：环境／躯体 → 感官适配器 → 输入总线 → 内核 → 输出总线 → 执行器适配器 → 环境。内核不读取世界、坐标、重力、语义标签，不依赖 MuJoCo、界面、数据库。新增感官不得侵入内核；必要的内核改动必须先讨论。

外界物理量、编码输入、接收触达与实际激活是不同量。暂不增加可塑受体层。老茧改变实际感官转换有物理意义；当前相同入射量 `1×1` 与 `.25×4` 的额外巩固差异来自独立强度项，不能冒充老茧机制。保留此行为作为研究基线。

## 研究假设与待议问题

- 遗忘与记住同样重要。短时记忆消失、连接仍在但弱提示不足以触发响应，均不自动判为故障。“遗忘参与注意筛选”是待验证假设。
- 强刺激和新颖性未来可能由更基础的局部机制共同产生；本轮不把额外巩固公式称为已被生物学证实，也不改其动力学。
- 意义是实例内部形成的关系与过程，观察者的标签不决定意义。共同物理参照可能提供形成时间／空间区别的材料；没有外部时钟不等于不能通过内部状态区分时间。
- 门槛附近的顺序差异既可能是正常非线性，也可能暴露实现问题；保持双向解释，不为获得漂亮结果调门槛。
- 随机背景与物理遥测必须区分。现有合成场有固定慢／快／漂移通道，扰动在其寿命内重复采样，不能当作独立的一次性噪声。

## 实施顺序与验收

1. 固定源码 SHA-256 与小型状态、感官样例；登记研究设计。
2. 共用强度预设、只读诊断、研究预设、分范围遥测强度（新建 0.2；旧协议 1）。
3. 对照旧 V3 核查背景连边、钳制、过滤、通道复用与显示；增加可恢复的独立随机工具。允许偶然关联，禁止按背景标签删边。
4. 外设层引入 `threemind.stimulus-unit/1`：刺激元、明确共同观测的刺激组、统称刺激体及其事件流。独立来源不因同时刻而合并。API／CLI／UI 保留实际帧及来源证据。
5. 世界协议／状态 v2 增加本地坐标加速度计与陀螺仪，提供惯性滑车、重力摆体；保留 v1 路径。5 ms 物理步长、20 ms 采样不改变内核传播。
6. 工程回归后开展有限观察，保存独立研究项目、双语设计与报告。最后继续 Transformer GPU 实际任务／CPU 回退验收，不移植意识内核到 GPU。

主要判据仍为收敛窗口结束时激活排序，辅以轨迹、无提示和行为对照；未形成收敛不能伪造结果。对照普通与 1 秒易化；背景一次／重复／合成／物理重放，强弱及经历对照，完整／去本体／拆分／乱序／未训练的物理观测对照。

上限 384 个新实例、模拟墙钟 90 分钟、单 worker、进程 4 GiB；新增证据 3 GiB 停扩展、4 GiB 硬上限；可用内存至少 2 GiB，C 盘至少 5 GiB，E 盘至少 15 GiB。账户用量增长 3 个百分点停止扩展、5 个百分点停止新模拟；共享账户保守计入。不扫描或清理旧 data。

## 机制参考

- [Frey & Morris, 1997：突触标记](https://pubmed.ncbi.nlm.nih.gov/9020359/)：局部历史及可用物质参与记忆保持，不能直接证明现有强刺激公式。
- [Takeuchi 等, 2016：新颖性与记忆调节](https://www.nature.com/articles/nature19325)：新颖经历与神经调节联系；不支持在内核中人工评分内容重要性。
- [Karmarkar & Buonomano, 2007：无时钟计时](https://pubmed.ncbi.nlm.nih.gov/17270738/)：网络状态也能承载时序信息，外部参照不是唯一候选。
- [MuJoCo 加速度计](https://mujoco.readthedocs.io/en/stable/XMLreference.html#sensor-accelerometer)：实测感官输出与世界坐标加速度须区分，不额外注入全知重力向量。
