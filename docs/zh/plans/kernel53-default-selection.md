# 2026-11-11：5.3 新建默认改为逆对数衰减

[English](../../en/plans/kernel53-default-selection.md)

## 决定与依据

用户在比较幂律与逆对数的保持表现及性能后，明确要求将逆对数设为 5.3 的默认衰减机制，保留其他机制作为可选项；同时展示 5.2、5.3，并将 5.3 设为新建默认内核。这里按上下文转述用户消息中的输入笔误，没有补造原话。

这项决定优先采用已经表现出保持优势的曲线。R47b 的 48 个独立来源确认，逆对数在 300 内部秒的经历表达上胜过另外三条曲线。R47c 的完整个体探索中，逆对数的初学保持、新学并保留旧能力、重学原规则均为 8/8；幂律分别为 1/8、3/8、8/8。逆对数反转为 4/8，原定目标为 6/8；四条曲线均未达到弱经历 30 秒删除目标。此次选择不更改这些实验的目标、分数或结论。

较长的保持可能增加长期存留的连接数量，需要在后续大规模任务中继续测量总内存占用。此处采用的是现有逆对数公式，未增加新参数、未改动传导、强化、删除、保持增长或回落规则。

证据：[R47b 确认](../../../lab/explorations/2026-11-11-kernel53/confirmation/report.zh.md)、[R47c 连续共同培养](../../../lab/explorations/2026-11-11-kernel53/joint/report.zh.md)、[R48 完整个体比较](../../../lab/explorations/2026-11-11-weight-dependent-decay/joint/report.zh.md)。

## 改动范围

| 入口 | 新建默认 | 保留的选择 |
| --- | --- | --- |
| Python 内核注册表、科研 API、工作台 | `threemind.continuous-memory/5.3` | 全部历史版本，包括真实 5.2 |
| 5.3 配置、Rust 原生构造器 | `inverse-logarithmic` | `exponential`、`power-law`、`power-exponential` |
| 独立 Rust 运行时未指定内核时 | 5.3＋逆对数 | 显式 `--kernel`、配置及编译定义 |
| 语言实验新建窗口 | 读取接口中标记的默认版本 | 手动选择版本；从已有个体建立副本时保留其版本 |

5.2 的默认曲线仍为指数。5.3 强化默认继续计龄，保持时间尺度增长和回落默认关闭。用户保存的模板、显式配置及完整存档优先于工厂默认；新默认不替换其中已保存的曲线。恢复路径读取原身份与完整配置，不迁移历史个体。R48 仍是独立研究内核。

前端补充两版的中英文说明，并把 5.2、5.3 纳入已有休眠配置联动；检查点的局部能量显示补入 5.3。后者只读取已保存状态，不推进模拟。
