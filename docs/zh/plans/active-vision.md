# E59：视觉焦点、扫视与眼手配合

记录及授权日期：2026-10-07。状态：工程与首批有界对照完成；辨识、纠正教学及扩展任务待续。[English](../../en/plans/active-vision.md)

## 问题与边界

用户要求保留完整场景，减少单次视觉输入及连接开销；用中央清晰、外围粗略和真实转动的眼睛替代按已知物体裁分视场。扫视与手臂可有共同目标，但不在程序中强制看向手臂答案。用户预测扫视期间联想触达会活跃：此为待验证预测，不是已经发生的新结果。

E58的外设继续学习和完整视野退化属于不同实验。前者由监督纠正更新外部读取器，后者形状指认在Core活动和直接感官两组均较差，尚未定位为单一注意力缺口。旧四视场为同次采样，不是真实四次扫视。E58的原报告、标准及数据保留。

三种机制分开：感官清晰度分布、身体眼球运动、内部信息竞争。旧按幅度取前K的注意力门继续默认关闭，保留研究用途；连续内核的局部竞争、抑制、遗忘、易化配置及时间架构不变。本期不新增全局Core注意力，不按语义重要性删除连接。

## 已批准的实施顺序

1. **眼睛与性能。** 新建版本化感官，中央精细、外围粗采样；完整场景、可见自身、教师实体指示和持续物理背景保留。固定视网膜通道身份，转眼只改变光学方向；提供眼位和眼速反馈。检查重复递送、身份增长、同帧生边、非零背景面和显示开销。不能以压缩为由漏掉不变但持续存在的刺激。
2. **固定、扫描与可控眼动。** 比较固定注视、与答案无关的扫描、由Core输出经过外设形成的闭环眼动。物理视场、角速度及采样时钟明确记录。教师目标只能用于教学损失和离线评分；测试不向控制器传对象ID、正确坐标或应选数量。眼与手独立输出，允许停留及不动作。
3. **形色辨识及归因。** 沿用短句、首次至少十次、后续间隔逐渐扩展的教学，背景持续。固定外设后，在未见布局上检验颜色、形状及组合；分别报告方向最近与实际到达。直接入射对照、空输出、内部连接静默及恢复区分外设识别、运动执行和Core贡献；先少量必要干预，不反复大范围哈希扫描。
4. **扫视过程。** 同步记录视线、手臂、输入、直接/联想触达、抑制及局部活动。查看活动相对眼动与选择的时序；有明确行为效应后才进行针对性屏蔽/恢复。活动上升可能来自新视觉输入，不能单凭上升判已完成内部决策。
5. **扩展任务。** 规则形状可用后测试扁球、圆角或歪斜方体等未见变形；颜色、位置、尺度交叉。先单目标，再“哪些是”，再“哪些不是”。分别测试不补课的迁移及教师纠正后的改善；错指、漏指、重复、结束均记录，不预设答案数量。前置能力未达时记录阻碍，优先修工具/教学，不盲目扩大后续任务。

## 外设、GPU与可复用工具

优先复用输入/输出总线、MuJoCo、现有局部活动流和个体运动中枢工具。视觉采样、控制、回放、增长诊断、联合活动记录、变形场景、多次指认评分应可由Python/CLI调用。GPU用于适合批量的读取器训练及分析，计入数据搬运和外设开销；Core不因GPU而改变方程、精度或节律。新工具须保存/恢复完整眼位及动作状态。当前世界编辑器尚无此装置，不能把CLI和回放写成生产UI已实现。

## 判据与预算

实验成功不要求预设某种意识现象。主要判断：相近视觉通道预算能否降低连接/时间/内存开销，同时保留或改善辨识；眼动选择是否依赖Core活动与经历。详细预登记见[E59设计](../../../lab/explorations/2026-10-07-active-vision/design.zh.md)。

单worker，累计计算180分钟，最多512新实例/分支，进程4GiB内存上限；本地证据与数据库新增合计6GiB停止模拟、8GiB硬上限。至少2GiB可用内存、C盘5GiB/E盘15GiB余量。共享额度起点80%，到85%停止扩展，到88%停止新模拟；30分钟刷新。授权允许合理放宽资源，但越界前必须登记补充，旧数据不覆盖/清理。按阶段本地提交，不push。

## 2026-10-07 · Measured update

E59完成工程与有界对照：10模拟秒，完整均匀眼1,080,548边/100.5秒，新扫描眼87,888边/11.5秒，接近旧四视场成本。旧核、默认与证据不改。中央光学可区分形状，但扫描目标仅约14%时间落在清晰中心；固定/扫描Core读取最近正确8/24、5/24，未达扩展门槛。完整60帧读取未改善新留出结果。闭环正常/静默/空动作最近正确4/12、5/12、4/12，实际到达均0；静默改变12个终点及4个选择，恢复重现原终点，内部连接影响存在而正确性收益未确立。两组各104课，教师没有被省略；复核发现轮间加等待不等于每个概念严格先密后疏，尚未针对错题补课。后续优先逐概念复习、教师示范注视与错误纠正，再验证基础辨识；变形、多指、否定仍待前置能力。工具、CUDA拟合、完整教学/对照回放已交付；生产世界编辑器及全局Core注意力未实现。
