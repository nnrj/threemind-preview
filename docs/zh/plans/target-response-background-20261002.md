# 目标响应与遥测背景对照

2026-10-02，已获执行授权；结果另行追加。保留现有内核、全局收敛定义和历史记录。

用户指出，全局未收敛仍可能存在清晰目标响应；E23 的旧主任务原本没有实时遥测，因而它不足以回答真实背景是否改变目标结论。这两项判断成立。现补充只读局部分析，并进行配平三背景与有限实时反馈试验。

## 决定

目标响应、局部模式稳定、局部幅度稳定、全局收敛分别报告，不将瞬间峰值冒充稳态。工具使用完整过程，可导出；UI、Python、CLI 和操作目录共用实现。历史记录只增加派生分析，不修改原分类。确认性实验目标须事先确定，事后目标选择属于探索。

真实遥测与随机背景逐帧配平输入量，区分全程背景变化与仅检验阶段背景变化。真实闭环用轻量／密集观察对照，再固定其实际输入重放。小的动力学变化但目标方向不变，属于允许出现的正常物理反馈，不自动判为故障；变化是否影响任务结论须分别查验。

[完整事前登记与用户原话](../../../lab/explorations/2026-10-02-target-background/design.zh.md)。上限 160 新实例，单 worker，1.5 GiB 停止扩展、2 GiB 硬上限；不做新的量子实验。

## 2026-10-02 交付结果

两项已实现并验收。目标分析接通 UI/API/CLI/操作目录，保留旧全局分类、完整轨迹与判定空值；47 项相关回归及 1440/390 像素浏览器检查通过。旧证据只读校准发现 16 个全局未定窗口仍有目标活动；这些活动没有持续到 800 ms，不改叫局部稳态。

160 例对照完成。遥测带与配平随机背景下，1/30 秒均保留顺序效应，32 组 A/B 轨迹逐点相同而全网不同；无背景早期相同、随后死亡，30 秒不可测。现场八条实际输入均完整重放，四对负载的全网状态不同、目标轨迹相同。随机负载次序恰好全为先轻后密，时序混杂保留，不把全部宿主变化归于负载。
