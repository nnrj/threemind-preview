# 普通强度间隔复习与遥测背景

2026-10-04，用户批准的 E43 补充实验。主计划为[语言外设](scratch-language-centre.md)。

依照用户纠正，从空白意识以普通强度1教学，每句先连续12次，再将每句复习间隔逐步扩展到2、4、8、16、32模拟秒。宿主和采集进程的真实物理遥测各以0.2强度接入；保存后逐项等时重放供公平对照。模拟背景获准作为对照选项，本轮先比较间隔复习与等量集中复习。

两种子分别比较正常配对、反转配对、集中重复、学习关闭和未教学。完整登记、预算、精确时间及原话见[E43执行计划](../../../lab/explorations/2026-10-04-language-spaced/design.zh.md)。原 E42 的数据、失败边界及门槛保留，不以新实验改写旧报告。自然语言中枢仍为研究目标，不宣称已经实现。

## 2026-10-04 完成

用户要求普通强度、逐句先密后疏，并指定真实物理遥测背景，也允许模拟背景对照。E43从空白意识以强度1、每句57次教学，与等剂量、等总时长、等最后复习的集中组比较；真实宿主及采集进程遥测被逐项等时重放。两套接线中，间隔组通过逐边门槛的累计量为集中组5.4～5.7倍；300秒后均保留157条语言内部连接，集中组均为0。少数强边与稳定度的差异不能被平均边权遮盖。

主文字回答未形成可靠的新配对，反转双重正确均为0/8；普通组在教学结束及60/300秒后的译文与关闭学习逐条相同。结构结果出来后追加40个普通强度1的提示分支，仍未测到相对无提示的额外合格传播。背景维持整体存活，却未在检查点上与语言子网连边；未教学背景也被旧四词转换头译出熟悉词语。遂把结构保持增益、提示未能带动、输出器混合背景校准分开记载。500个来源及分支完成，Core不改；从零联训未启动，下一步感官/检索校准为建议。
