# E48：让内核经历输入时间，忠实读取状态与过程

2026-10-05，讨论与执行决定。[English](../../en/plans/temporal-input-and-state-expression.md) · [研究总表](research-backlog.md) · [事前设计](../../../lab/explorations/2026-10-05-temporal-state-expression/design.zh.md)

## 问题与更正

用户要求先定位输入、观察、表达与内核各自的限制，不因表达失败断言内核缺乏语言或关系能力。助手核查发现：E46/E47选择的 stream-collapse 将句内各帧安排在同一模拟时刻；编码向量仍含前文，不能称完全丢失词序，但内核没有经历逐字间隔。该路线依据配对指标选出，并未证明适合关系组合。

E47的差值读法减去同状态无提示副本，并按本窗口绝对值总量归一化。这是外部工具处理，没有改写Core状态、学习或输入，但消除了共同行为与绝对幅度。将这种读法作为主要表达路径，不能满足忠实保留原始响应、观察自主活动的要求。本次纠正这一研究方法：主路径保留原始量；差值仅作明确标记的因果分析，不充当模型的原样表达。E47的48/48命名与24→0通路结果仍是该已声明仪器条件下的事实，不能直接推广到自然表达，须以原始读法复验。旧报告、数据、判据均保留。

## 已批准的执行边界

1. 表达器继续逐次从空缓存开始；不接收对话文本、问题、正确答案、实验分组、种子或教学计划。读取ThreeMind自身的连续状态过程，与表达器保存自己的对话记忆不同。共同发育的权重学习与推理时跨轮缓存也分开报告。
2. 主读法不用反事实相减、逐样本范数归一化、裁剪、按强弱选top-k或语义反向映射。提供全节点活动、抑制与更丰富的局部字段，增加连接、短时资源与快状态的只读观察。完整恢复快照另存；“动力学状态读出”不等于把含配置、外部队列、实验标识的整个容器交给语言模型。
3. 本轮保留continuous-memory/2及所有默认机制；仅在新研究副本中改变递送时间、教学或读出范围。直接感官排除只作为标记清楚的归因对照，全状态主表达不隐式删感官。未知节点不能被静默丢弃。
4. 普通教学1、探针0.5、校准0.4/0.6；保留原NFKC、通道映射、逐帧幅度、句子、复习次数、固定物理遥测重放。时序比较不偷换为更强输入。
5. 刺激体研究关注同一事物变化中的共同物理参照与时间过程；不向Core注入“谁先谁后”“正确关系”标签。独立语义迁移不以表达器重训后正确冒充。
6. 空间基底是内核内的几何约束，不等于海洋的物理导航，也不等于TEM所学关系结构。本轮先核查已有参数和海洋归因依据，不将其与时序、读出一起开关。若仍需空间对照，另行登记，保留基线。

## 执行顺序

旧证据原始读法复验 → 句内0/1/5/20/100ms → 更丰富状态与个体/共享表达器 → 共同参照事件及未见组合。每阶段报告失败与成功，依据预登记条件确定扩展；不把尚未开展记成失败。非语言内部过程可单独测试关系，不再要求冻结的命名器先通过才能研究内核。

参考线索：表征漂移与读出共同适应（[Rule与O'Leary](https://pmc.ncbi.nlm.nih.gov/articles/PMC8851551/)）；空间与关系结构（[TEM](https://pmc.ncbi.nlm.nih.gov/articles/PMC7707106/)）；组合教学（[Lake与Baroni](https://www.nature.com/articles/s41586-023-06668-3)）。它们是候选启发，不是当前公式已经正确或即将获得通用语言的证明。
