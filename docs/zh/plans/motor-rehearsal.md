# 运动中枢纠错时保留已学翻译

2026-10-07，R41。用户建议“每次纠错后，让运动中枢不仅学习纠错后的，此前正确的也重新学习强化一下”。助手评估采纳为下一批优先对照；**尚未实施，也未改变E62的权重、学习规则或结果**。

## 依据

E62当前外设已会抽取旧样本复习，但采用最近256项的先入先出缓存，并非长期均衡保留。固定同一批旧活动记录，纠错前后权重的姿态MSE为0.0430→0.1365；新缓存则0.3752→0.00553。这明确说明新拟合伴随部分旧翻译退化，而不是仅靠Core重跑变化解释。缓存淘汰、样本覆盖、步长和模型容量尚未分开归因。[完整报告](../../../lab/explorations/2026-10-07-continuous-development/report.zh.md)

## 下一批最小对照

1. 从同一个体的完整系统快照分出现有最近缓存、历史随机保留、历史代表样本混合三支；各支持续使用自己的原权重、优化器、Core、身体、窗口和随机状态，不换头。不同组允许不同的已声明训练策略。
2. 纠错后混入过去已正确翻译的教师样本；同时保留各类教师动作、方向与阶段的代表样本。先试新旧1:1作为外设训练安排，不注入Core、不赋予语义脑区、不强制行为偏好。
3. 训练步数、每批样本量和缓存总容量相同；另列容量增大的对照，不能把更多训练/更多存储的收益算给混合策略。旧样本的正确性由当时教师监督与独立输出误差确定，不把教师辅助推到目标当作自身已学会。
4. 当前教学若明确纠正了旧错误，则错误标签不因“保留记忆”而被强化；保留来源和纠正记录。正式测试题及其答案不进入复习池。
5. 同时测固定旧/新样本翻译，以及无辅助闭环的实际动作。不能只报告缓存拟合。若行为可靠，再用同一冻结外设的连接静默/恢复定位Core贡献。

这是保持运动外设已学映射的训练机制，不是干预Core遗忘、强刺激或可塑性。普通成长使用最后的完整状态，不选择一个最好外设回滚。旧E62作为原规则基线，新增缓存策略需明确配置、协议及完整保存恢复。

## 与中央单物体的关系

R39先把认识与扫视寻找分开：新单物体教学仍从空白意识及自己的新外设开始，不移植E56或E62的知识。可以沿用已验证的共享读取和本方案的训练流程，但必须事前说明用哪种策略。R41先行小型翻译保持对照可使用完整E62副本；它是外设训练诊断，不能冒称新单物体个体的成长经历。
