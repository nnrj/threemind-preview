## 3. 去掉什么：三种不同问题

### 3.1 去掉“自适应 H”不等于去掉遗忘

半衰期只是衰减快慢的一种表示。真正增加的机制是**为每个对象维护可学习、会回落的H**，并据此积分、求到期时间。只去掉这个自适应层，仍可保留普通权重强化，再使用固定衰减率或其他明确的局部遗忘规律。旧 `/2` 即是无需H也能强化和遗忘的例子，虽然它另有稳定度保护。

目前 `legacy-stability` 只替换连接遗忘：自动节点支持度仍使用H。`memory_half_life_decay_rate=0` 只是不再降低H，权重仍按固定H消退；`forgetting_rate=0` 只作用于旧稳定度连接路径，不关闭默认H遗忘；`plasticity=false` 会连学习一起关闭。没有“保留所有学习，只关闭所有结构衰减”的干净现成开关。

### 3.2 若去掉全部结构减弱，普通增强不会自动产生遗忘

默认关闭能源、关闭可选空间竞争、没有显式干预时，普通共同刺激强化、实际发出强化和新颖性奖励均为非负增量。若再取消权重衰减，已高于修剪线的连接权重只增不减，直至上限。活动、抑制、快迹与突触资源会起伏，但不能因此推定长期连接结构已经忘记。

节点支持度就算下降，有活跃连接仍不满足自动删点条件。容量上限默认无限；配置有限容量主要拒绝新建，并不会自然替换旧记忆。能源匮乏损伤和明确删除可以减弱/删除，但前者是默认关闭的另一机制，后者是人工干预；不能算作普通闲置遗忘。

因此：**保留增强即可保持记忆，但仅有增强不足以产生“长期不用最终遗忘”。** 表达器学习改变、读出受抑制或资源暂时耗竭可能造成答不出，须与Core结构遗忘分开。关闭激活/抑制/资源的所有消退更会改变振荡、响应和不应期，不能把这些不同衰减打包删除。

### 3.3 “自然消退”可以低计算，但软件不能凭空失去存储值

生物类比不能直接给出宿主CPU成本规则。在数字模拟中，内存中的浮点值不会因客观时间经过自动变小。可以保存值和时间锚点，在实际访问时才计算当前值，闲置期间不逐步刷新；需要准确删除时再安排一次局部到期。这样没有全图观察者，且无需空转计算。

`/4`已采用这一方向，问题是热路径反复对同一对象计算，且变动H使每次更新/到期计算更复杂。最小候选是“普通增强+固定局部消退+按需结算”，而不是“取消一切消退”。固定指数消退时，从w降到阈值θ的时间为 `ln(w/θ)/λ`；增强w自然延长可达时间。但w有上限时延长幅度有限；若仍要很宽的保持层次，就需要另有可累积保护、可变速率或结构冗余，不能同时要求取消全部历史状态又保留任意长层次。

直接只保留到期日、到期前不减权，或线性衰减，计算可能更简单，但阈值前的传导强度会不同，是新动力学候选，不是透明实现优化。本轮没有选定或启用任何候选。

## 6. 建议与未授权事项

先保留原 `/2`、`/3.1`、`/4` 身份和证据，撤回“统一接收必然要求同源下游互配”的解释。优先做可证明的实现优化；另拟简洁局部学习规则：节点响应自身实际接受量，边按自身真实通过量强化，首次无边接触如何发生必须明确，而非借内部包偷偷引入互连。

对遗忘，建议把“是否使用可学习H”“是否有被动结构消退”“计算是否按需”分成三个问题。可以讨论以普通增强和简单局部消退作为新基线；本轮未批准删除H、删除全部消退、修改强刺激/新颖性判据、发布 `/4.1` 或重开实验。所有机制改变须明确新身份及Python/Rust一致性；验收同时覆盖Core状态、完整个体读出和时间连续性。
