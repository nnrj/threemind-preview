# 刺激强度与时空感官：用户原始讨论

原文保留，不修改笔误；整理与决策见[实施计划](stimulus-intensity-and-spacetime.md)。

①和② 强刺激改为有效的默认值，新颖性也改为合适的默认值。不过我在想，当前的强刺激是一个门槛，决定了传入的刺激到达何种强度后，才会算强刺激，引发强刺激的后果。我其实对这个设计也有些犹豫，它是一种预设偏好，包括新颖性也似乎更像在预设偏好。我更希望强刺激能通过连接本身的属性、其他有依据的机制自然地、综合地达到、显现。因为目前没证据表明强刺激是一个“原语”，人类受到重大刺激后的创伤记忆或者遭遇新鲜事物的时候，所形成的稳固的、难以消除的记忆或响应模式，不像是有什么开关或基本的生物、物理化学机制，不像是大脑预设了一个这样的接收器、判别机制，更像是某些更平常的、根本的机制，在某些阈值下的表现。阈值范围内正常，超出阈值则产生这类创伤记忆或持久模式。这和重复带来的稳固记忆不同，这种稳固记忆几乎是瞬间完成的。以后你可以看看这块如何改进，与我讨论。本期可先只改好默认值，并把我提出的待探讨的改进方向写入 docs 的适当位置备忘。
③ 记忆消失符合预期，大部分短时记忆本来就该消失。来凝结还在，提示不足以引起响应，也符合预期，与人脑的某些机制类似。这属于非常好的结果。ThreeMind 不追求记住一切或者保证所有经历永远能响应，遗忘是 ThreeMind 要实现的，它和记住一样重要。因为我猜想，注意力无需一个特别的机制，遗忘会让意识自然知道哪些是重要的哪些是不重要的，哪些需要关注哪些可以忽略。如果脑袋里塞满了记忆，意识就会失去自己。就像一个雕塑，遗忘便是那把在石头上雕刻出女神的刻刀。没有遗忘，意识将变成石头。所以我认为遗忘这块没有啥大问题，如果我理解错了，你可以继续与我讨论给我建议。
④ 跨时间建立新关联，我想到一点。或许单个字符作为刺激输入本来就是没有关联的，时间的流逝也是人类的一种本体感觉。人类会通过各种参照物来确定时间流逝（可简称时移，空间或者说位移也是如此），如果被关在没有钟表和回声的密室里，人会度日如年、无所适从。说明生物需要外界的刺激来构造有关事件先后顺序下的记忆。因此我们实验中发现没有共用的刺激没有先后区别，这似乎是正常的。有共通刺激后产生关联，恰恰使我们找到了映射时间的方法。这里的确有关键缺口，但是解决办法已经在题面中了。甚至内核无需做什么，它已经能区分时间先后了。需要改进的是刺激的定义和映射。当前的刺激似乎是纯粹的没有时空的，可以保留，但还应该有携带时空信息的刺激，这种刺激就类似我们在实验中构造的 A-B、D-B（以此前实验报告为准，我的描述可能有偏差），这里有两种解释，是等价的。为了说明方便，我们把 A、B、D称为刺激元素（简称 刺激元），把 A-B、D-B称为 刺激组。事物沿某个时空的变化我们定义未事件。在我们的定义中，意识的主观时间和其他刺激一样，也是一种映射，没有这种映射就没有时间先后（一块石头无法感知时间先后，时间感乃是模型内部对客观世界某种关系的映射，这种关系是客观存在的）。说会我所说的两种等价解释。如果我们把刺激组视为 时间-事物，则 A-B、D-B描述的就是：事物B 在A时刻和B时刻的两种状态，A和D存在顺序（顺序的方向不是预设的，正反都成立，不过这不是我说的等价，这只是物理法则在T上的对称的体现）。如果我们把刺激组视为 事物-时间，则A-B、D-B描述的就是 A、D两种事物在B时刻同时发生了。注意以上两种是没有区别的，我不是说客观世界没有区别，我是说，模型不会预设这种组合的顺序，也不会像我们观察和分析这样去解释它们的含义，没有实例去映射这种关系的时候，它是没有意义的。实例内部，如果存在一个主观体验的话，它会体验到这种不同带来的规律、秩序。这种规律和秩序未必需要人类能理解的，因为由于塑造意识的环境不同，甚至我们虚拟出的物理法则不同，会让内部形成的结构异构，不可由观察者理解。但能够确定的是关联与差异，至于关联的意义是  时间-事物还是 事物-时间，差异是时移还是位移，甚至是其他什么人类语言未定义的如同光怪陆离的梦境的体验，观察者不得而知。使得彼此互相理解的是这些关系和差异来自同一个客观世界映射。即使是相似的演化环境和物理法则，彼此也可能是异构的。当我与ThreeMind里的一个意识讨论彩虹出现又消失时，能够交流，却不会知道对方内部经历了怎样的过程。我想说的是，意义是意识内部的过程。就像人类坐在公交车上，旁白有个汽车与自己速度一样，如果没有其他参考（没有声音、马路旁的树木、加速度本体感觉），人会觉得车是停在原地的。人类的物理页体现了这一点，从人类的角度看，某些情况下，静止和匀速直线运动是一回事。如果此时旁边那辆汽车减速了，人脑会有两种不同的体验，都可能发生，会觉得自己所在的公交车突然加速，或者觉得对方突然减速。大多数情况下是前者。这说明，刺激是刺激，意义是意义。意义不是固定的、、不是定义好的。是那个体验本身带来的。基于我的设想，可能需要引入刺激体，这个刺激体对环境刺激和感官适配器而言的。原本的单个刺激元素，也可继续保留。为了定义更清晰，刺激体可以是刺激组合，也可以是刺激元素。叫刺激体还是刺激子好呢，有待讨论。内核没什么需要动的，需要改进适配器、背景刺激，以及相关的模拟环境模块，使之又刺激元素、刺激组合和刺激体的概念。基于刺激体中刺激元素本身的关联，在意识内部会自然涌现类似时间和空间的概念，我们后续可以设计实验去观察到它。同时也给模拟环境带来了启发，需要模拟一些基本的物理法则，比如重力等。需要一些引入一些能感受物理环境的本体适配器，比如感受重力、加速度变化等。这些引入后，需要做实验观察影响。我们期望的“记住的事件先后顺序”，首先需要让模型涌现时间。按照上面的设想，任何持续的有关联的刺激体都可以称为涌现时间的材料，但为了便于人类研究者理解，我们设计实验的时候，最好还是用物理法则、本体感觉的模拟作为涌现时间的材料。
⑤ 部分顺序效应过于依赖门槛附近的细小差异 ，目前看这是正常的。可以备忘以后再处理，需要进一步解释或者排查。可能是正常特性，也可能是BUG。
⑥ 你提到的背景刺激占据排名的情况，可能是一个长期偏离设计的BUG引起。最初设计中，由于遗忘机制的存在，背景刺激这种几乎彼此很少关联（引入刺激体后，可能会成为时间的组成部分，但它是与其他刺激没有直接关联不应该导致那么多的联想）。背景刺激本应方生方死。不过这里我又想到更复杂的状况需要区分。最初的背景刺激是随机产生的，这是我所说的应该方生方死，就是说，因为随机，所以几乎不可能由重复巩固，大多数情况下页不会与现有的连接图产生关联（因为随机了）又因为微弱，所以几乎不可能靠强刺激留下长久痕迹。那时候图像上能观察到，背景刺激像随机的光点和随机的连线，出现后又在几秒内淡去消失。而输入的有关联的内容，则在重复和积累下在区域富集成一团结构。但是后来，某次改动（旧内核时期就已经出现），导致所有刺激都会形成边，并且边总是与既有节点连接起来。这就形成了背景刺激会一直留下长久影响，包括联想到其他节点或被其他节点联想。然而，在基于真实物理参数（计算机软硬件性能指标等）构造的新背景刺激引入后，这种与既有连接形成连接或者自身形成联系持久存在的情形，似乎是正常的了。这更像是我上面提到的，由基于物理法则的关联刺激形成时间的过程（只不过我们没有引入刺激体，无法形成期望种的先后顺序差异）。所以这里需要解决两个问题，一是核查随机背景刺激下仍然总是产生边并与既有节点相连的这个情况是否还存在，存在的话排查原因并消除（或者默认关闭），我记得好像有个什么钳制机制，是重点怀疑对象。然后物理背景刺激形成关联是正常的，甚至我们引入刺激体后，这种关联会更显著。问题在于刺激的强度，作为背景刺激，不应该太强。但这又引发一个问题，刺激强还是弱，到底应该由刺激源决定，还是应该由模拟感官或感官适配器映射决定，还是应该由内核内部对某个值的处理来决定呢？我倾向于，刺激源产生的刺激本身有强弱之分，但刺激本身的强弱与该刺激能引发的激活强弱应分开。意识实例对哪些刺激敏感，对那些不敏感，不应事先写死和定义，应由环境压力导致的偏好决定，本质上是连接本身的特性积累的结果，默写连接通路更强（高速公路），即使触达的是微弱刺激，也能引起强烈激活；有些则连接较弱（羊肠小道），即使强烈的刺激也没啥波澜。当前的遗忘、不应期、能量消耗、重复巩固、强刺激、新颖性等会共同决定连接的强弱，实际上已经形成了这样的连接轻若机制。但我们此前似乎没有充分考虑到将刺激的强弱与刺激能引发的激活强弱分开。所以需要核查，当前是否存在刺激越强激活越强的写死的代码，如果有写死应取消，完全交由连接本身形成的内在性质去决定激发刺激的强弱。此问题排查和改进后，可再观察背景刺激占据舞台的情况是否还存在。
