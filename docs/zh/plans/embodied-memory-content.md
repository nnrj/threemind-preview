# E58：完整视野、动作反馈与记忆内容

记录日期：2026-10-07。状态：本批已交付；结果与未完成范围见文末及报告。[English](../../en/plans/embodied-memory-content.md)

## 本次讨论的修正

用户指出：“内核记住了完整的‘物体—名字对应’ 和 记住了最近教师指向的痕迹，似乎是同一件事？……是过往经历形成了一种内在的模式，成为了将来的认知模板。”这是对机制的解释，不是新实验结果。

答复接受：两者都可能是过去刺激留下、影响未来响应的记忆。不能因痕迹短暂、位于感官受体或激活中，就否认它的记忆资格。激活、抑制、连接快状态与持久结构都是可能载体；“认知模板”描述其后续作用，不预设必须有长期边。此前把“感官残留”与“真正记住”对立过强，本次追加澄清，原E57报告与数据不覆盖。

仍需研究记忆包含的关系与系统分工：Core可能保留具体对应，也可能保留教学情境，由已经学过多套对应的外设据此答题。后一种也是有用的记忆协作。未能表达新对应，不单独证明Core没有学到；干预敏感也不单独证明完整概念存于被干预部位。

## 已核实的装置事实

- 原指针已有位置、速度、加速度、运动功率和身体/天气反馈，不是毫无本体感觉。
- UI中的指针尚不在实际视觉几何中。四个固定观察起点分别看四处；共享读取规则并未变成一只眼睛观察完整场景。
- 原接触项是导轨接触状态，不能冒称皮肤的局部压力、摩擦和接触位置。
- E50部分命名依赖内部连接的证据仍有效。E57更换了外设监督目标，故需重新查这套选择器的分工，不能互相推翻或代替。

## 获准顺序与边界

1. 新建版本化单眼完整视野、真正可见的自身指针；物体仍共同存在，不按答案裁图。不改旧世界或Core。触觉只记录实际模拟接触，不能用“触觉”标签伪造作用力。
2. 分别检验动作引发感觉、感觉改变活动、活动改变下一步命令。固定录制的物理背景；主动/被动运动和反馈屏蔽分开。感觉被切断后相关活动消失，不等于Core无控制作用。
3. 在相反教学历史后加入完全相同的末段体验及等待，观察短时记忆的内容与保持。固定旧读取器与同量重新校准分别报告，避免把读出失准写成无记忆。
4. 固定与可继续学习的个体外设比较；新对应只在教学中有标签，检验不传标签。不创建融合内核，除非另有机制讨论和授权。

主要问题始终是能否指认、什么经历改变了选择、改变由哪里承担。不同视野、器官和读取器变化不得混作单一增益。先密后疏复习、持续身体背景、遗忘和抑制保留。所有对照是研究分支，不静默改变普通实例。

## 2026-10-07执行中补充：视野、扫视与注意力（R36，下一轮待议）

用户由连接数上升提出：清晰视觉应集中于一小块，外围较粗；视觉中枢可能需要筛选，注意力可考虑现有门或Transformer。允许评估时机，但不打断本轮。决定：E58按登记输入完成，本轮仅核查并保存下一轮设计，不中途开门或换采样。

代码事实：旧/2四个近距离视场每次采样同时进入同一刺激，不是已真实经过四次扫视。新/3单眼完整视野的两秒装置样例产生1,038节点、1,076,404边；“连接多所以需要注意力”是待验证解释，尚不能排除共同观测规则、持续背景面的相关性等贡献。

这份样例的无自环有向边最大数为1,038×1,037=1,076,406，实测已接近全连接。`restoration.py::_associate`按共同触达的源/目标候选及激活乘积生成边，默认`co-stimulus`、未启用空间限制；整幅灰色背景面也持续产生非零像素。由此应同时考察感官采样与共同观测粒度，不能只用“注意力缺失”解释，也不能仅凭边密就判这些权重不含记忆。这里是代码事实与待验证解释的区分，不授权修改旧连边规则。

现有注意机制不止一个：`attention_competition_enabled=false`，预算28，打开后按入射通道幅度取前K；这是可选输入竞争，不是由经历学成的视觉选择。连续内核的`context_enabled=true/context_mix=1`则已经开启，按接收节点状态与到达消息的局部特征作竞争；没有浏览整张视网膜、移动视线或按目标选物体。抑制、衰减也存在，故不能把缺少眼动选择表述为完全没有忽略机制。依据：[旧输入注意](../v2-attention.md)、`src/threemind_kernels/continuous.py`、`crates/threemind-core/src/mechanisms.rs`及本轮保存配置。

建议分期：①另版眼睛保留粗外围和小片清晰中央，明确物理视角、通道预算、实际递送时间及强度；先比较固定中心、与答案无关的扫视和当前均匀采样。②提供真实可控的视线及本体反馈，让环境后果有机会塑造选择；教师示范只能作为显式教学。③再比较既有局部竞争、外部视觉中枢和可学习Transformer门。不得由正确答案、对象ID或研究者重要性排名直接决定门控，不把缩小总量、增强亮点或缺失输入误记为注意力的学习增益。原始测量与经过门后的量分别留证，旧眼睛和Core版本保留。

若外部门只从完整图像选出少量区域，可减少Core负担，但外部门自己的扫描/计算和所学识别能力必须计入；Transformer的相似度加权并不自动等于这里要研究的视觉注意。若要更改Core默认或机制，仍须另版及独立对照。本轮未实施这些候选。

“视觉中枢适配器”的功能分类已在[中枢适配器](../reference/central-adapters.md)中声明，无须再造一层拥有特殊权限的Core接口。E58新增的共享视网膜读取器负责读取并选择输出位置，不是已经完成了视觉输入筛选。后续可在同一适配器体系中增加有版本、可关闭的视觉输入处理，分别记录真实光学采样、处理后入射量和内部响应。
