# 生态规则与共享物理基础

本阶段提供独立于 Core、数据库和界面的规则与物理组件，尚未接通完整生态训练任务、群体恢复事务或研究界面。规则产生的 `birth_due` 明确带有 `model_born: false`，不能将它作为已实例化后代的证据。后续协调器必须实际调用 `threemind.birth/1`，再原子记录父本来源和新脑状态。

上段说明 F4a 的交付边界。后续 F4b 已接通实际后代、数据库与界面，使用方法和当前限制见[生态训练](v2-ecology.md)；本页继续解释基础组件的公式和契约。

## 资源、损伤与繁殖

`threemind.ecology-rules/1` 默认共享资源，支持独立栖息方式。区域配置位置、范围、容量、初值、再生和最低到场个体数。各身体的需求受采样周期内获取速率和剩余容量限制；不足资源使用局部均分、按需求比例或按距离顺序分配。最低到场数使用实际物理位置计数，不根据“合作”标签认定意图。

一个周期内，先按容量补充区域资源，再转移到身体，最后结算维持、控制努力和损伤。控制努力为执行器控制量绝对值之和，成本明确属于模拟规则，不能称为机械功。所有身体储备、区域储备和已支出资源满足：

\[
R_{\mathrm{initial}} + R_{\mathrm{regenerated}}
= R_{\mathrm{body}} + R_{\mathrm{patch}} + C_{\mathrm{maintenance}} + C_{\mathrm{effort}} + C_{\mathrm{birth}}.
\]

新生身体储备从父本转移，繁殖另有支出和最低父本留存。共享环境没有因出生新建资源；独立栖息中新建区域的初始储备属于新增外部供给，会单独记账。失效身体中未花掉的资源保留在账目内，不能凭空消失或自动转移给后代。数值账本校验使用明确的浮点容差，不宣称任意精度守恒。

损伤来自声明区域以及采样区间的平均接触力。物理组件逐求解步累积接触冲量并保存峰值，避免撞击结束后末端接触力为零而完全漏掉它；损伤门槛作用于区间平均力，尚不是逐步峰值损伤模型。身体失效、Core 死亡和后台异常是不同状态。

繁殖还受年龄、冷却、人口和总出生预算限制。同一边界的机会顺序由种子、边界时间及个体编号确定，不能由线程先后决定。人口上限只暂缓繁殖，不删除个体。默认要求父本身体有效且 Core 尚未死亡，也提供明确的仅身体条件对照。底层账本可先结算资源，等待意识完成当前递送边界，再接收实际父本状态完成繁殖；未结算的出生边界阻止继续步进。

## 共同时钟与身体实例

`PopulationWorld` 的共享模式使用一个 MuJoCo 模型与一次统一步进；独立模式维护各自物理状态，明确没有个体间接触。每个个体提交当前匿名活动投影，物理执行声明区间后才递送测量。后出生的独立世界记录全球时间与自身物理起始时间；不能把两者当成同一年龄。

选中的根身体及其完整子树被实例化，原始感官和执行器端口继续由同一 `WorldPorts` 实现处理。物理实例前缀只用于定位对象，不参与通道编号或活动投影。属于其他身体的感官或执行器会报错，不能静默遗漏已经配置的器官。背景几何与外力保留在环境中。

共享模型预分配明确数量的身体槽位，空闲槽位关闭碰撞、透明度为零、运动状态复位；新生身体不继承父本的位置或速度。失效身体移出物理场景，复用槽位前重置状态。此处是声明的模拟器规则，不模拟遗体。透明度为零也用于排除射线感官中的空闲几何；这与仅关闭观察界面的几何显示不同，见 [MuJoCo rangefinder 定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#sensor-rangefinder)。实际验收另外检查移除身体后射线不再命中它。

物理恢复保存完整积分状态、求解器 warm start、端口测量与控制、成员槽位、接触冲量／峰值及时间。世界物理哈希、布局、种子、引擎版本、渲染校准不匹配时拒绝精确继续。渲染校准是本机证据，不保证跨 GPU 或驱动逐位一致。世界名称、观察标签、编辑器数组顺序和观察查询不改变物理结果。

## 默认接入的身体状态感官

2026-09-07 用户确认：`threemind.body-state-senses/1` 默认接入，储备、损伤和附近资源强度可分别关闭、配置。端口默认 4092、4093、4094，与已声明的世界端口冲突时拒绝启动。编码使用原有命名空间和感官种子，不加入“有益”“有害”或奖励标签。

储备与损伤按明确尺度归一化；空尺度分别使用身体容量和致命损伤阈值。资源场采用公开的径向线性公式：

\[
s_{\mathrm{resource}}(x)=\sum_p\max(0,1-\|x-x_p\|/r_{p,\mathrm{sense}})\,R_p/C_p.
\]

这是定义的虚拟资源场，没有模拟真实扩散、风向或遮挡，不能作相应物理效果的研究结论。最终感官值乘增益、限幅并应用声明强度；三个感官和原物理量作为同一次完整身体样本发送。记录保存原始储备、损伤、各区域实际库存与距离、归一值及编码值，零值也保留。关闭感官保留原物理刺激，不偷偷关闭观察账目。

这些感官不直接操作 Core 能量账本、连接或内部状态。普通刺激引发的活动及其能量消耗仍由已有 Core 动力学决定。界面和解说器只消费外部观察，不能据研究者的解释剪裁这些刺激或读出。

## 范围与工程预算

每个共享物理模型最多 256 个身体槽位；展开后上限为 8192 个身体、32768 个几何体、16384 个关节，RGB 为每采样区间 16777216 个标量。它们是明确的实现预算，不随显示性能档位自动缩减。独立栖息可在不同物理实例中使用同样协议；本阶段没有建立多进程分布式物理求解器。

当前验收覆盖资源收支、规则与状态拒绝、共处碰撞和独立隔离、已出生身体的物理恢复、自由关节复位、真实离屏眼睛、空槽不可见／不被射线命中，以及观察编号和解释不进入参考／原生 Core。它们是工程验收，不证明意识、适应性演化或合作形成。完整生态训练器、GUI、群体存储、所有个体的报告来源及导出继续实施。
