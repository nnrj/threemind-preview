# 具身差异与功能分化：待检验推论

2026-09-08。来自项目讨论，记录为研究预测 `body-differentiation/1`，不是新增的意识公理，也不是已经完成的实验结论。基础假设仍以[意识假设纲要](consciousness-hypothesis.md)为准；实际方程见[第二代内核](v2-kernel.md)。

## 推论的内容与强度

同一套不读取语义的映射、传导和塑形规则，作用于具有不同物理条件与刺激历史的感官和躯体接点，可能逐步产生不同的连接、响应、抑制和稳定性。在具有可遗传差异的种群中，环境选择还可能保留其中有利于该环境下生存、繁殖的结构。研究者之后可能观察到局部聚集或分布式的功能分化。

位置、传导和采样时延、响应范围、带宽、身体运动及接触历史属于候选差异来源；不预先命名“走路脑区”，不挑选内部节点赋予器官功能，不把正确动作、善恶或语义答案写进适配器。来源信封编号只记录采集与递送证据，不能变成脑内因果连接。

这是**附带条件的可检验预测**，尚不是从现有公理必然推出的数学定理。差异能提供塑形条件，不保证一定形成稳定功能区、独立动作控制或意识。若所有执行器在相同初始状态下以完全相同的转换响应同一活动，它们会获得相同控制信号；内部全局抑制不会自动创造各自独立的输出自由度。若各个体初态、输入和确定性规则完全相同，单纯淘汰也不会产生新的可遗传差异。

## “一视同仁”和“全部广播”的准确含义

- **输入规则中立**：各接点使用声明的同类编码规则；保留实际位置、时间、幅度、匿名接点身份等可用差异，不读取“这是眼睛／这是左腿”等观察标签来决定连接。中立不意味着把所有刺激合成同一个通道，也不意味着对每个节点施加同样的输入。
- **运输可以广播**：总线允许多个消费者读取同一活动。广播本身不证明全部接点以相同增益、相同时延产生相同物理作用，也不替代对实际转换规律的说明。
- **物理响应不作价值判断**：设备的响应范围、延迟、饱和、失效和资源消耗是明确的设备或环境条件；不能根据动作是否“聪明”或是否符合研究目标偷偷替模型纠错。
- **观察不筛掉无法解释的活动**：执行器作用范围与忠实读出是不同契约。没有被某个执行器采用的激活依然是真实状态；外部解释、AI 注释或相关性分析不能回写、删改这些状态。

不因本次推论自动增设一个有监督输出解码器、随机神经投影矩阵或新的可塑连接层。若进一步验证显示已有表示能力不足，应单独提出机制变更、假设、版本和对照，不能将新机制伪称为已有公理的必然实现。

## 当前内核确实保留了哪些机制

下表核对 Python 参考实现和 Rust 原生实现，不仅依据参数名称。短期抑制势、长期结构减弱、输入数量竞争和空间竞争不是同一种机制。

| 机制 | 实际作用 | 默认状态 |
| --- | --- | --- |
| 局部抑制势 | 实际触达量在正延迟后增加局部抑制势；响应因子为 `1 / (1 + inhibition_response_gain * inhibition)` | `inhibition=true` |
| 拓扑抑制扩散 | 只沿任一方向已存在的邻接边转移，按导通率分配；发送端扣除，接收端延迟递送 | 随局部抑制开启，扩散率 `3.5 / s` |
| 遗忘与稳定保护 | 连接权重随时间衰减，稳定度提供保护；低于阈值才剪除 | `plasticity=true`、`forgetting_rate=0.025 / s` |
| 输入数量竞争 | 按单个感官帧的幅度与预算选择通道，属于显式实验门控 | 默认关闭 |
| 空间竞争 | 在明确启用的因果空间内，已有较强邻接对较弱目标施加衰减 | 空间默认关闭，竞争率为 0 |
| 全局活动钳制 | 超过配置的总活动目标时同比缩放活动 | 默认关闭 |

局部抑制势是随活动变化的状态，不等于已实现可独立学习的负权突触、专门的抑制细胞谱系或特定器官门控。现有抑制沿刺激形成的拓扑传播，其作用范围可以随结构改变；这足以否定“新版已经没有抑制”的担心，但不证明它足以学会任意动作。

`tests_v2/test_inhibition_fidelity.py` 从空模型递送刺激形成全部被测连接，检查真实延迟、自抑制后的响应减弱、连接邻居与未连接通道的差异、遗忘保护、关闭可塑性、模型交换及不规则分段恢复。测试不直接写入节点势或边来制造预期结果，不把机制回归当作功能分区实验。

## 当前工具中需要揭示的先验

1. **感官身份**：网络感官使用稳定匿名接线；世界感官用端口块与掩码编码。身份只区分接点，并不按 ID 的数值远近组织认知。更改显示名称不应改线。
2. **感官分帧**：当前世界将同一次躯体采样的感官合成 `whole-body-sample`。默认 `co-stimulus` 会在同帧实际共同触达之间形成边。因此，分帧本身可能强烈影响结构，不能忽略后再把所有聚集都归因于身体差异。
3. **因果空间**：可选空间坐标由声明的种子规则产生，不是身体距离自动映射进内核，也不是已证明的自然脑区。普通三维显示坐标更不参与动力学。
4. **现有电机输出**：`PlanarBody` 和 `WorldPorts` 使用固定哈希符号投影，将全部节点激活转换为各执行器的控制量。没有动作目标或语义筛选，但确实存在人工给定的投影规则。它应作为**工程接入基线**，不能当作输出选择性从身体性质中自然形成的证据。

这些功能保留供工程接入与明确对照；本次不为假装符合预测而改写既有模型、世界版本或历史结果。人体／机器人接口可以采用多类信号契约，但必须公开实际转换，不能只用“符合统一协议”掩盖外部智能或固定投影。

## 验证顺序与证据标准

完成正在补齐的观察、预警、评估和适配器工具后，再开展正式研究。先用少量接点和简单躯体，验证选择性，再扩展到行走等复杂行为；不以开展新实验替代功能补全。

至少分别报告三个层次：

1. **内部功能分化**：在未参与训练的探针下比较完整响应、抑制、结构和时间特征；区分直接输入造成的瞬时差异与可保持的结构差异。不强制聚类器一定分出指定数量的脑区。
2. **身体控制**：测量执行器动作和环境结果。单有网络聚集、不同电机运动，或漂亮的三维布局，不足以说明学会了控制。
3. **遗传与选择**：采用独立出生的评估副本，评估学习不写回父本；与无选择、固定继承和不同环境条件比较。出生清空短期状态，不能据此研究父本的短期记忆；需要该问题时另设隔离的状态复制实验。

必要对照包括：无／有身体差异、固定／变化的接点身份、相同的原始输入重放、关闭可塑性、关闭局部抑制、声明的分帧和时间窗对照，以及工程固定投影对照。对照应单独改变一个条件并记录真实递送输入；不能拿闭环中已经分化的输入声称“只有内核参数不同”。训练／评估种子、有效样本量、效应大小、不确定性和负结果均保留。

如果聚集只由编码或分帧产生、关闭可塑性仍得到同样控制、换用固定解码器就能复现全部表现，或者差异只存在于训练数据中，应缩小或否定对应结论。支持预测的结果只能增强对具体机制与条件的信心，不能直接证明全部意识假设、主观体验或 AGI。

## 神经科学的辅助参照

- [Meirovitch 等，2026，神经肌肉网络的发育连接重组](https://www.nature.com/articles/s41593-026-02344-7)：特定肌肉内存在早期冗余支配及活动相关的连接修整，为“广泛作用机会随后分化”提供启发；不是整个神经系统全连接，也不是 ThreeMind 已经得到相同结果。
- [Xu 等，2009，运动学习与突触形成、稳定](https://www.nature.com/articles/nature08389)：运动训练伴随连接重组，为持久结构与学习的关系提供参照；不规定 ThreeMind 必须采用生物的全部机制。
- [Glasser 等，2016，多模态人类皮层分区](https://pmc.ncbi.nlm.nih.gov/articles/PMC4990127/)：区域可依据结构、功能和连接等变化识别。ThreeMind 不预设分区数量、边界形状或人脑同源关系。
