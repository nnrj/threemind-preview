# 实验记录与研究报告

本页说明 E2a 的实际实现：固定数据采集、图形／JSON 内容配置、版本保存与引用。E2b 已提供[四种格式导出与证据包](v2-research-exports.md)，E2c 已提供[AI 草案与来源审计](v2-research-ai.md)，E2d 增加[输入、干预与事件来源](v2-research-events.md)。固定修订分享继续实施。

## 从真实数据开始

生态训练已增加[整组种群轨迹与全部个体来源](v2-ecology-reports.md)。它们固定世界与种群共同恢复点，保留未繁殖和已死亡个体，分别标明物理结算时间与 Core 时间；可从生态详情直接创建记录。

进入“记录与报告”，选择“实验记录”或“实验报告”，点击新建。左侧“添加数据来源”可以按实验选择意识，固定具体恢复点，选择时间范围和指标，也可以复用已经采集的来源。时间范围使用精确的非负整数微秒，留空表示从零到提交请求时的最新恢复点。时间序列区间两端包含；阶段统计仍使用原分析服务定义的半开区间，两者不能混为同一种统计设计。

采集是显式请求的 PostgreSQL 后台任务。它只复制所选标量及必要的来源信息，不生成模型文件，不改变运行时意识。采集请求提交时已经固定恢复点；队列等待期间意识继续运行也不会扩大范围。

| 来源 | 实际数据 | 默认展示 |
| --- | --- | --- |
| 时间序列 | 所选时间区间内且提交版本不晚于恢复点的全部已记录观测 | 节点平均激活、连接数量、平均权重；能量有有效值时加入能量曲线 |
| 节点分布 | 完整恢复点经 Core 只读解析投影得到的节点属性 | 激活、抑制等实际节点分布 |
| 连接分布 | 完整恢复点的实际连接属性，经 Core 只读解析投影 | 权重、稳定度分布 |
| 统计分析 | 已完成配对分析的固定 JSON 产物 | 配对数量、缺失、均值差、区间、效应和校正 p 值表 |

没有用 AI 解读接口的最近 32 条摘要代替完整时间序列。没有将“随时间变化的平均权重”误标为“网络中所有连接的权重分布”。未记录、版本未知或能量账本未启用的值不会被补零。旧数据不迁移、不扫描。

## 组织图表和解释

首次选择来源时提供可以修改的默认内容：目的说明、适用曲线或分布、数据表和限制说明。完全没有有效值的曲线不会默认加入。此后可以添加多个来源和内容块，并调整顺序、标题、指标、图形类型、直方图组数及说明。

支持五种内容块：

- **研究说明**：目的、方法、结果、讨论、限制、假说等 Markdown 正文及 LaTeX 公式。正文明确标为作者解释。
- **图表**：时间序列折线／散点、完整所选数据的直方图、固定分析中某个终点的柱状图。不同单位的统计终点不能被混成一项均值或同一柱形量纲。
- **数据表格**：选择列，按 100 行分页查看完整采集数据。表中显示质量，数值保留原值，悬停可查看完整数值字符串；很小的非零数用科学计数法显示。
- **数值摘要**：首末样本、最小／最大、样本算术均值、有效／缺失数量。首末样本若缺失，仍显示缺失，不偷偷寻找另一条样本替代。
- **引用实验记录**：报告可以选择记录的修订号与内容块。原记录后来的编辑不会改变报告的固定引用。

图形配置和 JSON 配置双向同步。JSON 编辑器有行号、语法高亮、格式化和校验。保存始终执行服务端校验，不要求用户先点校验。JSON 只能声明指标、来源和展示意图，不能填入测量数组、SQL、JavaScript、文件路径或伪造数值字段。手工说明不能被结构校验证明为科学事实，这一边界同样适用于后续 AI 生成。

## 图表的统计含义

预览默认最多展示 500 个时间序列点；保存修订的查看接口允许明确选择 10–1000 个显示点。短序列显示全部原始样本。长序列按样本次序划分显示组，返回各组实际起止时间、算术均值、最小／最大、有效和总样本数。图中标注有缺失值的组，完整数据仍可分页查询。

显示组的极值范围**不是置信区间**，样本算术均值也不是时间加权均值。时间坐标先对精确整数微秒做差再转秒，避免直接将巨大的绝对模拟时间转成 JavaScript 浮点数。空组／空值保留断点，不连接成伪造观测。

直方图使用完整所选来源的有效行，缺失数单独保留，固定宽度分组包含最大值。统计分析直接保留原服务的独立配对单位、分析方法、随机种子、重采样次数、CI、Holm、多重比较、逐终点缺失以及阶段删失信息，不在报告层再计算一套显著性。

预览来源摘要省去体积较大的逐配对和回放正文，并标明完整内容保存在原采集清单。省略只影响页面负载，原清单与数据哈希不变。

## 数据库、版本和资源边界

schema 26 在同一 PostgreSQL 中加入采集请求、完成清单、标量行、文档头、不可变修订、来源引用与记录引用。它们不是多套数据库，采用相同项目权限和强制 RLS。笔记仍是作者私有；记录与报告是项目共享的研究材料，研究者可编辑，查看者只读。

完成采集前，标量行分批写入，并流式计算 SHA-256。最终清单和行在同一事务、有效 worker 租约下提交；失败或超过预算不会留下看似完整的部分来源。新的工作能力 `worker.research_documents` 防止旧 worker 领取自己不理解的任务。采集不占 AI 队列，不引入 MQ。

单次采集当前预算为 **200 万行、512 MiB 规范标量投影**，统计分析原件上限 32 MiB；超出时明确失败，需要缩小所选区间或指标，不静默截断。网络分布需要恢复完整模型，仍有与模型规模成比例的内存成本；时间序列的读取、写入采用有界批次。以上是工具资源预算，不改变模型的科学参数或运行性能档位。

每个保存请求携带操作编号和预期修订。重复提交相同操作返回原结果；同一操作编号换内容被拒绝；并发版本冲突保留当前草案，可另存副本。历史修订不可覆盖或删除；载入旧修订后保存产生新版本。内容哈希还包括来源和引用记录的哈希。

页面提供归档／恢复和标题检索分页。归档不删除证据。尚未被任何保存修订引用的完整采集可以显式释放；已引用来源和恢复点受到外键及预检查保护，不能因清理意识档案使研究文档断链。数据库所有者仍属于受信任运维边界，哈希不等于对抗数据库所有者的电子签名。

未保存草案可缓存在当前浏览器标签页，按账号、项目和文档隔离，退出登录清理。它只是可选恢复缓冲；数据库修订仍是权威状态，另一个作者更新后不会因为恢复本地草案而被自动覆盖。当前记录／报告采用明确保存，个人笔记的自动保存机制保持不变。

## 验证与接续

专项验证涵盖超过 32 条的完整时间边界、恢复点解析投影、精确内容哈希、缺失与未知提交版本、重复提交、并发修订、跨记录固定引用、租约过期、超额回滚、项目／角色／CSRF、不可变记录及未引用采集释放。浏览器验证图形／JSON 双向配置、默认图表、原始数值字段拒绝、真实分页、公式、丢失确认后重试、并发另存、草案恢复、中英文和手机深色布局。

全部样例属于工程验收数据，不构成 ThreeMind 意识或 AGI 的实证结论。研究图和四种文件格式已在 E2b 交付，AI 草案在 E2c 交付；E2 后续继续接入固定修订的显式分享、输入与干预事件等来源。先天演化训练器与容器内完整应用验收也仍在总计划中。

完整回归 337 项通过，最终专项 6 项通过，最终 Edge 三条流程通过。详见[验证清单](../benchmarks/2026-09-07-research-documents-validation.json)、[图形编辑](../images/v2/records-editor.png)、[研究预览](../images/v2/records-preview.png)和[手机深色布局](../images/v2/reports-mobile-dark.png)。
