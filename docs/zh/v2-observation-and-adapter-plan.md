# 演化观察、预警评估与适配器实施方案

2026-09-07 用户补充需求，2026-09-08 已同意按讨论后的边界继续实施。本文区分已确认设计与已实现范围，不把设计确认写成已经交付。

2026-09-08 当前状态：F5a～f 已完成，最新全量和 schema 46 容器整合验收通过，见[当前交付与验证](v2-integration-acceptance.md)。下方方案及分阶段说明保留实现次序；后续阶段已交付的功能，不再以前段的“继续交付”作为待办。

## 演化观察与播报

暂用「演化观察与播报」区分已有的意识读出／解读器。订阅版本化的演化事件和固定检查点，解释当前阶段、资源、存活、繁殖、失败与统计结果。基础规则可以把确定事件转为人类可读文本；可选 AI 在明确的证据范围内补充解释和总结。实时和结束后总结使用同一证据契约。不得把不完整的流式片段或选取的个体冒充整个种群。

观察服务可以关闭，上层按需输出到命令行、网页或三维场景；不让底层依赖这些显示形式。语音是上层的可选播报，默认关闭。关闭播报不能改变模拟时钟、刺激、选择或实验结果。AI 不代替原始日志，须保留引用、时间范围和不确定性。

## 运行预警与目标评估

建议分成两个可选组件，复用固定证据、任务和 AI 调用机制。运行预警识别资源、延迟、数值异常、任务失败，以及用户明确配置的行为条件；目标评估按独立实验协议检查行为与训练目标的关系，提供结果和下一步建议。

「危险倾向」需要可观察的行为定义、测试条件和误报边界，不能从网络形状或几个激活指标直接断言意识的意图，也不能据此裁剪原始读出。AI 结论属于外部解释，不等于经验证事实。是否允许告警触发暂停等操作，需要另外声明干预规则和权限；初步方案只观察、记录和提示。评估副本不写回训练父本，沿用已确认的隔离边界。

## 统一适配器契约

用户希望像外设接口一样接入更多感官与执行器。应先审计现有 Runtime 输入／输出总线、能力注册、时间戳、源策略、匿名通道身份及设备接入契约，再决定需要补齐的统一部分，不另造重复总线。

待核对内容包括：协议版本与能力协商、设备及端口身份、采样与递送时钟、输入／输出格式、原始载体与编码证据、背压与丢弃声明、生命周期、断开与重连、错误和恢复状态。接口可以统一，物理设备和虚拟环境不必使用完全相同的传输。硬件重连不能偷偷重新分配模型已学习的感官身份，也不能把外部标签写入 Core 形成预制连接。

物理输入断开、暂时无数据、明确关闭来源和 Core 意识死亡是不同事实。是否支持运行中热插拔、跨进程隔离和第三方适配器发布，需要结合现有实现提出具体方案后，与用户讨论。

## 安排

先完成当前可配置世界、躯体和演化策略；适当阶段提交复用分析、接口草案、代价与需要决策的问题。本文不授权隐式干预、外部 AI 调用或自动改变研究假设。

审计时发现 `network.receptor()` 以感官种子、`wiring_id`、通道和极性计算匿名接收节点，但 Lab 传入设备绑定 UUID。轮换同一绑定的凭据不会换线，在新运行或机器重新建立绑定则可能改变学过的感官身份。这一 network/2 部署复用缺口现已由下述 B13 修复。注册目录已有统一描述能力，不需要用另一条总线取代它。

### 建议的观察边界

1. **演化观察**：规则式文字由真实事件与恢复点产生，含时间、范围、原始引用；可供无界面 JSONL／控制台与网页复用。实时以已提交边界为准，显示实际延迟。观察暂停或读取消费失败不回滚训练，也不把“缺少观察”写成“没有事件”。
2. **运行预警**：独立启停和规则版本，阈值、持续窗口、解除及冷却均可图形／JSON 配置。首版只记录和提示，不自动暂停、淘汰、加刺激或修改连接。性能测量使用宿主时间，生态条件使用对应模拟／物理时间，不能混用。
3. **目标评估**：独立配置标准、环境、种子和观察区间；需要新实验时由用户显式启动独立出生副本。复用已有评估和研究执行器，结果及说明进入记录与报告。数据不足、条件不可测或未覆盖保留为“未判定”，不补出成功／失败。
4. **AI**：三类工具均可独立选择供应商、频率、发送范围和预算；默认关闭。先显示确定事实，AI 解释另列并保留调用与证据引用。只有用户在项目中实际启用后才自动请求 AI；当前开发验证仍使用本地模拟服务。
5. **语音**：作为网页的单独开关，默认关闭；需用户操作后启动。积压时停止追赶旧播报并标示跳过数量，原始观察记录保留。浏览器语音能力和语音包不可用时明确反馈，不能让它成为训练依赖。

“危险倾向”不设置一个来自网络形状的通用分数。可评估的是被明确测量的行为，例如碰撞次数、身体损伤、资源转移或某个测试任务的动作；这些都不能独立证明意图、痛苦、善恶或意识。规则、研究者说明和 AI 解释保持不同来源。

### 建议的接线与部署边界

- 一个逻辑端口标识某组已经确定的信号编码与匿名接线；部署绑定只保存地址、设备权限、凭据和会话。凭据、机器、显示名称的改变不重新计算逻辑接线。
- 接线清单记录协议、稳定 UUID、感官种子及必要编码配置，可与模型一起导出、导入或独立读取。它不包含密码／令牌，也不凭空建立任何连接。原始脑状态仍可由 Core 单独运行；感官重接需要对应的清单与适配器。
- 兼容既有设备：迁移时用原绑定 UUID 作为逻辑 UUID，保持旧公式和已经排队的刺激。新接入由用户显式选择复用已有端口或建立新端口，不按“眼睛”“麦克风”等名称猜测映射。
- 支持当前已有的运行中设备接入，但每次绑定变更要记录边界及接线版本；已接收的输入按接收时冻结的映射递送。更换编码必须显式作为新端口或实验干预，不能伪装为硬件重连。
- 第三方适配器先通过进程外 network/2 或纯 Runtime 接口接入。首版不实现把网页上传代码直接装进服务进程的插件市场；统一的是契约与证据要求，具体传输仍可以是函数、HTTP、WebSocket 或机器人侧驱动。

验收必须覆盖**固定递送输入、同一协议与后端**下观察启停前后的所有脑状态哈希一致、慢观察不丢承诺保留的原始事实、规则缺失／恢复／重复命中、评估副本不污染父本，以及导出后更换凭据／部署仍得到相同匿名映射。实时物理感官和 CPU 遥测可能受观察负载影响，必须记录输入和时延差异，不承诺实时系统无条件逐位相等。界面与说明和底层一起交付，避免只增加协议却没有可操作入口。

### 已确认的实施次序

稳定接线复用已经完成，接下来交付规则式演化观察与可配置预警，再接入独立目标评估、AI 与可选语音。首版采用“只读事实与建议、执行新评估必须显式启动”的边界；自动干预仍需另行明确规则和权限，默认不存在。优先补齐工具和界面，不以开展新的功能分区实验替代交付。

### 2026-09-08 讨论后的具体约束

- 统一身份、版本、能力、时间、单位、生命周期、错误和证据等公共契约；输入、执行器、被动观察、显式控制分别使用合适的数据契约。允许函数、共享内存、HTTP／WebSocket、硬件驱动等传输，不强迫全部适配器使用 JSON、network/2、同步请求或精确重放。
- 「适配器」为总称；设备适配器可调用底层驱动，也可以直接通信。机器人部署不依赖 Lab、网页或云数据库。连接设备不等于已经学会控制设备。
- B13 的一次性 UUID 回填已经完成且成本很小；不维护两套 Core 或编码分支，不据此给开发期测试数据增加长期兼容承诺。
- 默认不手工给内部节点分配器官功能；现有固定电机投影如实标记为工程对照。具身差异在统一规则下产生分化的预测、已有抑制机制及对照边界单列于[具身差异与功能分化](embodied-functional-differentiation.md)。这次讨论不自动引入新的可塑输出层或预制连接。
- 事实、规则判断、研究者说明和 AI 解释分开。图表读取真实证据；AI 关闭或失败不影响基础事实。选择指标不会由评估建议偷偷写回生态筛选。
- 分析已有证据无需新建意识；执行新实验时使用显式启动的独立出生副本。若未来研究当前短期记忆，需要独立的状态复制选项，不能把清空短期状态的出生当作精确复制。
- 复用已有事件、恢复点、任务、供应商和记录／报告。观察、预警、评估不为形式对称增加三套数据库、MQ、微服务或顶层菜单。生态训练详情提供观察与预警，评估结果接入记录／报告。
- AI 以关键事件、可配置间隔和结束总结为主，不逐物理步调用。语音默认关闭，可跳过积压播报并显示计数；科学证据的保留策略不随之变化。

### 已完成的独立修复：network/2 稳定接线

B13 已交付不可变接线 UUID、原映射升级、独立凭据与控制来源、校验清单下载／复用，以及相应图形入口。`threemind.network-wiring/1` 可以由纯 Runtime 读取，模型和清单分别保存；不向严格的 profile/5 擅自增加字段，也不让 Core 依赖部署文件。学过刺激的模型跨项目导入、换凭据后继续输入，与原匿名接线得到相同完整状态；详见[实现和验收](v2-network-devices.md)。

B13 只覆盖已有 network/2 数值协议。把所有相机、模拟世界、身体和第三方驱动纳入部署清单，仍需对应能力声明、校准与验证，不能把单个网络端口清单包装成全部适配器已经可互换。演化观察、预警、评估、AI 与语音已获准按上述边界推进；各部分交付后另记验收，未因为 B13 修复而默认启用。

### F5a：规则式生态观察与预警

2026-09-08，已接通独立 Runtime 规则函数、Lab 持久化观察游标、配置版本、事件解释、种群小结、阈值与采样持续窗口、冷却、覆盖缺失及恢复。页面提供默认图形和高级折叠配置、JSON 双向编辑／校验、历史规则、条目筛选、原始引用、重试和固定范围 JSONL 导出。整体默认关闭，说明与预警可分别停用，旧条目仍可查询。

观察从已经提交的证据取数，分批处理后让出已有 Runtime 任务名额。没有新恢复点时休眠，提交恢复点才唤醒，不不断生成空执行记录。它仍需要空闲 worker 和执行额度；单节点长训练时可能等待，页面如实展示进度。已实现的预警指标是生态计数，不把它们包装为性能监控或意识意图识别。

详情与限制见[生态观察与规则预警](v2-ecology-observer.md)。独立目标评估、性能与故障规则、AI 及更广泛适配器验收仍需继续交付；当前没有为了验证功能分区而提前开展新的科学实验。

### F5b：独立观察输出与可选语音

2026-09-08，已提供 `threemind-observe` 命令行入口，复用同一规则函数，只读打开明确指定的独立种群库，支持固定范围、跟随新恢复点、文字及 JSONL 输出。慢控制台不会长期占住 SQLite 读事务；不加载模型数据块。无法从清单确认的内核生命计数保持缺失，不把读到最新恢复点解释为训练完成。

网页语音默认关闭，优先本机语音，使用独立呈现游标和有界积压队列。跳过播报不删除原始记录；更换配置、语音报错或离开页面停止播报。模拟语音浏览器验收、固定证据不变、独立安装入口和桌面／窄屏检查已通过；未调用真实外部语音或 AI 服务。此阶段复用 schema 42，没有改动 Core 或训练协议。

### F5c：独立出生评估与固定判定

2026-09-08，已提供独立评估批次、完整图形／JSON 配置、来源身份与已知谱系种子隔离、全部试验的控制、只读终点评估和固定来源。父本不受评估学习影响；缺失、失败、取消和未完成保留在分母，按明确阈值与比例规则判定，不包装成意识质量或危险意图分数。

记录／报告新增只能引用固定来源的规则判定块，复用已有图表、完整数据与四种格式导出。已有 AI 草案工具保留全部规则判定，不能填写或覆盖结果；仍需显式发起。schema 43 使用现有 PostgreSQL 和 Runtime 队列，没有新的协调微服务。详情、公式、范围和验收见[独立评估](v2-assessments.md)。观察 AI、性能／故障预警与更多适配器验收继续交付。

### F5d：可选 AI 观察解释与调度

2026-09-08，已提供独立开关、供应商和关注点、图形／JSON 配置、发送预览、同一范围多次解释、版本与调用历史。自动调度按关键事件、间隔和结束总结触发；单个训练只允许一个请求处理中，失败停止自动请求，工具次数上限与供应商预算同时生效。

解释保留全人口提交摘要、完整范围事件计数、规则覆盖及来源。AI 只能生成待复核解释，不能修改事实或执行建议；模拟 AI 和浏览器回归均验证脑哈希不变。schema 44～45 复用原有 AI 队列与项目权限。详见[AI 生态观察说明](v2-ecology-ai.md)。

### F5e：执行资源、进度与故障预警

2026-09-08，schema 46 复用独立 notification worker，提供默认关闭的资源／进度规则、版本、图形／JSON 配置、宿主采样、缺失／无执行对象区分、通知和当前观测导出。当前预警不变成遥测刺激或 Core 命令；人口和研究任务失败使用原事务通知，不伪装为模型死亡。

后端和浏览器覆盖默认关闭、严格校验、重复缓存不累计时长、无外发邮件、固定刺激前后脑哈希一致。手机表格改为自适应卡片。详见[执行预警说明](v2-execution-health.md)。

### F5f：公共适配器契约与独立 SDK
