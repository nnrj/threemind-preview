## 结论与本次边界

**新版不是旧内核的等价加速实现。时间架构改造之外，学习、巩固、遗忘、抑制、结构损伤、生命周期及默认环境均发生了实质变化。此前“55 个字段都有对应项，因此功能补全完成”的验收结论不成立。** 字段覆盖、测试通过、科学机制保留、操作便利性是不同的验收条件。

本次仅修复普通意识的强制时长：默认 `duration_s: null`，图形配置留空表示持续运行；显式填写正数才设置模拟时间终点。暂停、恢复、研究单步、历史分叉、配置修改及生态 worker 均能保存并处理空终点。不使用极大数字冒充无限，不以宿主时间到期判死。已有明确时长及项目保存的默认值不会被追溯改写；已有意识暂停后可以清空时长。已经标记 `completed` 的有限任务当前仍不能直接编辑／继续，需要从恢复点分叉；这是原有管理层限制，本次记录，不额外修改。

配对比较、分代筛选的每个阶段、终点评估和显式分阶段协议仍须选择有限观察窗口，因为这些操作需要一个统计或筛选终点；它们不会给普通意识重新设置默认寿命。独立发育入口默认持续；生态协议可设空时长，但当前生态表单仍显式预填 30 秒。独立 `threemind-runtime` CLI 的 `--until-us` 仍默认 1 秒，属于有限批处理入口，尚不是持续设备服务入口。这两处不同入口的默认策略列为待讨论项。

**除时长修复外，下列内核差异和 UI 问题均未在本次擅自修改。** “可解释的选择”不等于“已获用户同意”，也不等于“已证明更好”。不迁移、不扫描 `data/`，不重新训练模型，不开展新的 AGI 效果研究。

## 核查对象、证据与局限

- 旧基线：仓库 `95a6db5` 中保留的 `core/threemind/runtime.py`、`model.py`、`frames.py`、`attention.py`，结合 `adapters/`、旧 API 与 `legacy/ui/src/`。这是最后保留的统一旧实现，不是所有历史提交的穷举。旧 UI 的 V1／V2／V3 在这份源码中是同一个 `ConsciousnessRuntime` 的模型／编码／空间预设，`kernel_id` 本身不选择另一套动力学代码。
- 新基线：`src/threemind_core/` Python 参考实现、`crates/threemind-core/src/` Rust 实现、Runtime 与 Lab 接入代码；新建状态是 `state/5`、动力学 `causal/7`。新版本号 1～7 属于**新事件内核家族**，不能当作已保留旧帧内核的七个对照。
- 规范依据：[意识假设](consciousness-hypothesis.md)、[抑制与能量](local-inhibition-energy-and-dynamics.md)、[架构边界](architecture-boundaries.md)、[时序传输](temporal-frame-transport.md)、[空间决策](spatial-embedding-decision.md)、[术语](terminology.md)，以及本轮用户对持续意识、刺激塑形和被动读出的要求。以代码行为核对文档，不把旧／新文档的“已完成”当作证据。
- 可重跑证据：[脚本](../../scripts/audit-kernel-behaviors.py)、[源码哈希、全部默认参数与八组微型探针](../benchmarks/2026-09-08-kernel-behavior-audit.json)。命令：`.venv/Scripts/python.exe -X utf8 scripts/audit-kernel-behaviors.py`。脚本仅创建内存模型并写这份小型证据文件，没有数据库和环境连接。
- 核查覆盖：旧 `RuntimeConfig` **55 项**、新 `Config` **60 项**，并补充配置类以外的公式、硬编码常数、Manifest、来源、读出和宿主行为。下表每个编号是一个差异／保留事项；参数全量表在文末。八组探针用于揭示差异，**不是**全状态空间等价证明、时间尺度标定或研究价值判断。

以下“保留”只表示该机制仍存在；“时间改造”指已接受的模拟时间方向；“实质改变”需要单独审议；“缺失／回退”指旧能力或约定没有等价覆盖；“新增工具”不构成内核正确性的证明。

旧规范和旧实现本身也有冲突：[空间决策](spatial-embedding-decision.md)要求主线因果空间关闭，但保留的旧创建页面默认 V3 且空间开启。新版空间默认关闭符合该文档方向，仍须记录它与旧 UI 实际默认行为的差异；不能一概认定为回退。旧 `Manifest.weighted_edges` 虽可填写，但保留的 Runtime 没有读取这个开关，始终执行加权边公式；不能把该声明字段当作已经实现的无权图分支。`package_schema_version` 是文件格式版本，不是内核选择。

## 公式差异：不能只靠字段改名解释

令 `c=a_i*a_j`，`B` 为双方巩固总量，`N` 为局部新颖项。省略所有 `[0,1]` 封顶时：

| 项 | 旧 | 新 |
| --- | --- | --- |
| 新生边初值 | `w0=β(.5+c)+.18B+N`；`s0=B+N`；`e0=B`，随后同 tick 遗忘 | `w0=βc+Bi+Bj+N`；随后立刻 `w+=ηc`、`s+=gs*c+Bi+Bj`、`e+=c` |
| 既有共刺激边 | `Δw=ηc*k*(1-w)+.08B`，k 为经过 1／否则 .45 | `Δw=ηc`；联想发射另有 `associative_gain*amount` |
| 节点局部塑性 | `p=max(.12,1-.72*s)`，p 进入巩固 | 无 p |
| 边稳定度无输入衰减 | `s←max(0,s-δs*(1-e))` | `s←s*exp(-dt/τs)` |
| 权重无输入衰减 | 未经过：`w←w*(1-.0025*(1-(.08+.92*s)))` | 对 `dw/dt=-.025*w/(1+4*s(t))` 做解析区间积分 |
| 抑制封顶 | `q←cap*tanh(q/cap)`，多处执行 | `q←min(cap,q)`，显式延迟事件 |

时间常数 `-.1/log(.72)≈.3044` 可近似对齐**纯激活衰减**；它不能同时对齐学习、边稳定度、遗忘保护和抑制非线性。旧传播增益除以 .1 得到 4.2，也只是候选速率，不能证明新传播及延迟网络等价。直接学习率缩小十倍尤其需要重新给出理由：外部感官事件的数量没有因为数值步缩小就必然增大十倍。

单个默认孤立节点在旧版的删除还受约 80 秒无触达保护；新版的支持指数尾部和更低阈值可能把该例保留时间推至约 85 分钟。这是对无边、无后续触达条件的数量级估算，不是通用记忆寿命或性能基准。

## 接下来应由审阅决定的事项

1. 先决定哪些旧科学机制必须恢复：节点局部可塑性、学习／巩固公式、稳定度与资格迹关系、默认新颖性、节点删除保护，以及真正的节点结构损伤。对每项保留或替换都明确理由和验收例，而不是合并成一个“优化内核”决定。
2. 单独明确生命周期：真实断流如何区别于暂时静默；waiting 是否例外；停止计算、取消任务、意识死亡如何区分。默认持续已修，不代表其余生命判据已与假设完全一致。
3. 再决定默认实验对象与仪器：空间是否默认开启、个体身份种子、输入分帧节奏、旧带标签基线、工程执行器接线的用途。不能靠观感选择更“活跃”的默认值。
4. 获得这些决定后才修内核，先做局部数值／行为对照与输入、输出不变性验证，再补用户指定的意识命名、创建预设、图像旁即时读出、明文聊天、发送清空和菜单层级。
