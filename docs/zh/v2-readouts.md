# 截面结构与时序响应读出

2026-09-10：界面入口现名“时序与截面读出”，时序／截面使用并列标签。时序结果同时进入连续聊天、[时序观察实验与记录／报告](v2-temporal-research.md)。窗口分类、完整节点聚合、原有采样曲线成为独立数据来源；本轮未改变以下测量、候选、排序及收敛公式。

读出器是围绕 ThreeMind 的只读研究工具。它观察匿名节点和连接，不向内核写入概念、词义、目标、奖励或连接。页面中的“符合有限窗收敛判据”描述一组有限采样规则，不能单独证明意识、语义或 AGI。

## 使用入口与配置

意识详情新增“读出与响应”：时序响应、截面结构、分类／复现筛选、在观测窗口、结果详情、分页指标与完整导出。新建、暂停编辑、项目默认配置均提供“截面结构读出”和“时序响应读出”分组；高级分组默认折叠，支持图形／JSON 双向编辑。全部 38 个读出参数进入统一目录。

默认两类读出器均启用，100 ms 模拟时间采样。人工、文件与记录重放打开时序窗口；AI 和背景设备默认不打开窗口。这只控制分析触发，不关闭相应刺激。未触发窗口的实际背景递送仍列入已有窗口的重叠记录。

读出协议在运行配置、数据库检查点恢复上下文、证据包中保存。它不是模型本体的一部分；`.tmind` 的内核与 runtime profile 继续保存可塑模型及感官接线，独立 Runtime 可以自行订阅读出器。只导出模型不能代替导出研究证据。

## 完整输入与时间边界

内核通过 `observation_nodes` 公开全部匿名节点在指定观察时刻的解析投影；通过 `induced_edges` 读取显式选中节点间的有向连接。它们不推进数值格点、不执行额外学习、不修剪节点，也不改变核心状态散列。Python 参考实现和原生 Rust 都实现此契约。

Lab 在固定采样时刻和实际刺激递送时刻取样。同一时间的所有已递送事件仍按 Core 顺序执行，之后读取该时刻的状态；不同载体的来源保持分开。引入只读采样不得改变固定刺激下的最终模型。

窗口从载体首个**实际递送**帧开始。协议过滤掉的末帧不延长输入；记录冻结的 `first_scheduled_index` / `last_scheduled_index` 定义真实递送范围。导入或配置变更后从载体中途开始的窗口标记 `partial_start`。最后实际帧递送后开始尾段观察；最长窗口仍从首帧起算，避免长载体造成无限窗口。

`envelope_id` 是 Runtime 的来源编号，不进入 Core 的 `Stimulus`，不选择传播路径、连接、节点或学习对象。它把观察窗口与实际输入记录对应起来，**不证明窗口中的激活都由该输入造成**。内部历史塑形、持续活动及并行刺激仍可共同参与动力学。没有编号的被动截面无需补造关联；外部解读者认为“无关”的共同激活也必须保留。来源启停和注意绕过是另行公开配置的输入策略，确实会改变实际刺激，不能与中性的编号混为一谈。

暂停保存尚未完成的窗口、基线、累计指标、复现历史和下次采样时间；恢复继续积累，不重复暂停边界。修改时序参数会在配置事务中结束旧窗口并记录 `configuration_changed`。分叉意识不会冒用父实例的读出窗口。结束、终止、预算耗尽均显式记录中断或删失。

## 截面结构

阈值以上节点按激活、联想痕迹、稳定性、匿名 ID 排序，选择最多 `max_nodes`（默认 7）个，读取其诱导子图。满足最少节点（默认 3）和最少内部边（默认 2）才生成结构候选。这是公开的科学选择规则，不宣称选中图等于模型全图。

默认启用“记录完整活动截面”（配置键沿用 `read_touched_activity`）。每次截面采样在 `raw_nodes` 保存该时刻的**全部源节点**及未量化的节点测量，包括弱活动、零活动、无直接／联想痕迹及未入选候选的节点。`raw_observation` 标记 `threemind.raw-node-observation/1`、完整性、源节点范围与“未建立因果归属”。节点不会因外部标签、阈值、排序或解读器假设而从这份原始截面中删除。即使没有结构候选，也保存原始截面；零源节点的完整空截面与未记录有区别。

`activity_nodes` 继续作为“阈值与痕迹筛选结果”保存，候选子图另有 `structure`。这些是派生数据，不能冒充全部活动。页面和详情 API 默认展示原始截面；默认显示 20 条只是分页，可以遍历或导出所有已保存节点。候选边依然仅为显式选中子图的边，`raw_nodes` 不表示保存了完整连接图。

2026-09-07 补强之前的历史截面没有 `raw_observation` 和 `raw_nodes`；页面会明确提示缺失，不能从筛选结果猜回弱活动。显式关闭完整记录时标为 `recording-disabled`，CSV 标明 `derived-nodes-only`。不改写历史研究记录，不扫描或迁移旧 `data/`。

schema 33 为要求完整截面的运行、研究计划和配对实验增加 `worker.raw_readout_v1` 能力条件，并更新等待中的任务。旧 worker 不会领取这些新任务；已经在旧 worker 上执行的任务保留其原执行回执，实际完整性仍以每条记录为准。它没有新增数据库或修改 Core、模型本体格式。

结构身份散列包含实际节点 ID 和有向边端点。状态签名再加入节点激活／稳定性、边权重／稳定性的 0.2 步长量化（`round(5x)`）。在滚动模拟时间窗内统计相同签名出现的采样数与跨度，达到默认 4 次、0.8 秒后触发复现提示；默认 120 秒冷却仅控制再次提示。连续驻留也会计入复现采样数，不能解释成独立重复实验。

另保存有限轮邻域着色的拓扑分组指纹，便于外部归组；它不是严格图同构证明。实际 ID 不同的结构不会因为分组指纹相同就合并为同一条复现证据。外部标签作为注释保留，不参与候选、签名或核心传播。

## 时序积分与基线

每个窗口保留从第一次观测起出现的所有节点，包括尚低于阈值的节点。这样，节点后来成为候选时不会丢失此前的弱活动积分。完整采样中未出现的已记录节点以 0 参与后续区间；不能把有界三维图当成完整样本。

采样时刻为 $t_j$，全部时长计算使用模拟微秒，积分换算成秒。区间采用明确的左值保持估计：

$$
I_i=\sum_j a_i(t_j)(t_{j+1}-t_j),\qquad D_i=\sum_j\mathbf{1}_{i,j}(t_{j+1}-t_j)
$$

这里的 $t$ 在公式中以秒表示，$a_i$ 是归一化激活。积分不是“每 tick 相加”，也不是精确连续时间积分。事件之间的实际变化仍可能未被采样捕获；已保存的聚合序列和覆盖时段随结果导出。时序记录保存逐节点累计指标及聚合采样曲线，并未保存各节点在每个时序采样点的完整波形；需要逐节点截面时应同时启用完整截面记录，并按其独立采样间隔解释覆盖。

刺激前默认 1.2 秒内的完整样本按区间实际时长计算均值和标准差：

$$
\mu_i=\frac{\sum_j a_i(t_j)\Delta t_j}{T},\quad
\sigma_i=\sqrt{\max\left(0,\frac{\sum_j a_i(t_j)^2\Delta t_j}{T}-\mu_i^2\right)}
$$

区间裁剪至请求的基线窗口。缺失的早期历史不补造；实际覆盖 $T$、请求时长及是否完整均可查看。完全无历史时均值／波动为 0，同时明确标记覆盖不足。

超基线激活与活动条件为：

$$
x_i=\max(0,a_i-\mu_i-g\sigma_i),\quad
\mathbf{1}_{i}=\mathbf{1}\{a_i>0,\ x_i>0,\ a_i\geq\theta_a,\ x_i\geq\theta_x\}
$$

默认 $g=1$、$\theta_a=0.055$、$\theta_x=0.005$。结果保存激活／超基线积分、活动时长、最长连续活动、尾段活动比例、再次进入次数、峰值、直接／联想痕迹积分、抑制势积分、基线均值与波动。`direct` 和 `associative` 是衰减痕迹，绝不能将它们的积分标成“直接触达次数”。

## 候选、排序与有限窗分类

候选范围可选“有联想痕迹或尾段持续”“仅有联想痕迹”“全部超基线活动”。候选为空时不会悄悄回退成全部节点。非候选也保留其测量结果，排序分数为空。

时序详情默认显示所有已记录节点统计，“只看候选节点”由用户显式打开。窗口编号、分类、候选与排序均属于外部分析，不能认定某个共同激活“没有内在关联”。发送给外部 AI 的输入受用户设置的幅度区间、数量预算约束，但明确标为分析子集并记录选择范围；底层原始记录保持不变。AI 摘要不得把未提供的节点当成无活动，也不能据此排除内部关联。

默认综合排序以活动占比 $r$、最长连续活动占比 $c$、尾段活动占比 $q$、候选间最大超基线积分归一化值 $s$ 计算：

$$
S=0.30r+0.20c+0.20q+0.30s
$$

关闭强度项时使用 $S=0.43r+0.29c+0.28q$。也可按活动时长或超基线积分排序。这些权重沿用研究工具的解释性排序，不是内核机制或客观语义评分。

集合比较使用单独的科学参数 `comparison_top_k`（默认 7），按当前超基线激活从配置范围内选取。显示数不会进入分类。相邻样本计算：

$$
J(A,B)=\frac{|A\cap B|}{|A\cup B|},\qquad
V(p,q)=\frac12\sum_i|p_i-q_i|
$$

空集合对的 Jaccard 定义为 1，但仅有空集合不能得到收敛结论。$p,q$ 是候选激活归一化分布；相邻值按实际区间时长加权。尾段覆盖裁剪至配置窗口，非整齐时间戳也使用实际时长。

同时计算全部超基线活动总量的幅度范围：

$$
R=\frac{\max_j X_j-\min_j X_j}{\max_j X_j},\quad X_j=\sum_i\mathbf{1}_{i,j}x_{i,j}
$$

零总量时幅度范围记为 0。该条件避免固定比例的指数衰减被误标为收敛。默认至少在输入结束后观察 1.2 秒、尾段覆盖 0.8 秒且至少三次采样，然后按以下顺序判定：

| 结果 | 有限采样条件 |
| --- | --- |
| 候选集合周期重复 | 至少三个相同、非恒定的候选集合循环，周期 2–8 个等间隔样本；不宣称幅度也周期重复 |
| 尾段衰减 | 判定尾段总幅度不回升，终值 ≤ 已观察尾段峰值的 35% |
| 无持续尾段 | 判定尾段没有超基线活动 |
| 符合有限窗收敛判据 | 存在候选；平均 Jaccard ≥ 0.8、分布漂移 ≤ 0.12、总幅度变化 ≤ 0.12 |
| 窗内未定 | 最长窗口已到但以上条件未满足，且输入已经结束 |
| 删失／中断／未观察 | 输入未结束即达时长上限，预算不足，运行结束、取消或参数改变等 |

所有配置阈值、原始集合轨迹、完整聚合轨迹、具体结束原因均进入结果。背景刺激或其他载体重叠时，图表不能隔离因果归属，应通过配对实验和消融进一步检验。

## 资源、数据库与导出

默认最多同时 64 个窗口、每窗累计 100,000 个节点、每窗 10,000 个轨迹点。预算只限制观察工具：超出时生成明确的未观察或删失记录，绝不剪掉模型节点。基线也受节点条目预算限制；过多时缩短保留历史并显示实际覆盖，不能以零填充来假装完整。

节点扫描成本随全部节点数增长；诱导边查询只访问选中节点的邻接关系。开启很多重叠窗口仍然昂贵，可在科学配置中调整采样间隔、触发来源与预算。设备显示性能档位独立于这些参数。

完整截面存储量约随“源节点数 × 截面采样次数”增长。可显式增大采样间隔或关闭完整截面记录以减少开销，并在研究协议中保留该选择；显示档位、分页、候选数量不会偷偷减少原始节点。实时外部感知中，额外记录开销可能影响宿主机吞吐和采样到达时间；编号中性与读出不改 Core 的保证针对**实际递送的时间戳刺激序列相同**的情况，不承诺不同负载下物理世界输入也相同。

截面事件的唯一键由观察时刻、Core 序号、读出配置及格式版本决定，避免为事件编号再次编码完整节点数组；实际节点内容仍完整写入不可变事件。2026-09-07 本机合成节点探针中，10 万节点约 15.58 MB 未压缩 JSON，一次读出、键计算和编码的中位时间约 606 ms。该探针不包含 Core、数据库与页面，不是容量承诺，也不能据此把默认 100 ms 采样视为大网络的实时保证。

读出事件和可恢复观察状态与内核检查点、输入递送一同提交到 PostgreSQL。约 8 MiB 读出缓冲会触发提交和背压；失败不能先确认读出再丢失状态。数据库 007 只增加读出查询索引，不扫描旧 data、不建立第二套数据库。

历史列表在数据库侧去除大数组；节点、连接和轨迹分别分页。默认因果事件列表排除读出大载荷，防止普通事件页加载整段研究数据。完整导出是用户显式动作：

| 导出 | 内容 |
| --- | --- |
| 单条 JSON | 完整节点、候选、有向连接、轨迹、参数、外部注释、来源、覆盖与提交版本 |
| 单条 CSV | 全部已保存节点指标表，`observation_scope` 区分原始截面、时序聚合与仅派生节点；连接和配置以完整 JSON 为准 |
| JSONL | 指定类型／分类的全部读出记录，通过数据库游标输出 |
| SVG / PNG / PDF | 时序记录全部已保存聚合轨迹，注明结果、结束原因、基线覆盖与模拟秒 |
| 研究证据 ZIP | 新增 `structural-readouts.jsonl`、`temporal-readouts.jsonl`，并保留原始输入和恢复上下文；受选定检查点版本约束 |

这些文件是数据库研究记录的按需导出，不是在运行过程中反复覆写模型。读出模块不会自动往词典写入所谓“理解结果”，未来实验记录与报告可引用这些不可变数据生成自己的图表和解释。
