# 空间基底：基线与实验分支决策

[中文](spatial-embedding-decision.md) | [English](../en/spatial-embedding-decision.md)

## 决策

ThreeMind 的主线基线模型应当保持**因果空间基底关闭**。空间基底仍是有价值的、明确独立的实验分支，而不是核心意识假设的默认条件。

## 为什么必须区分

当前运行时中，空间基底并非纯粹的可视化设置。当它与空间邻域规则一起启用时，会直接改变因果动力学：

- 两个节点的距离超过 `spatial_radius` 时，候选新连接会被拒绝；
- 联想传播会随边距离衰减，并在超过半径时被阻断；
- 可选的 `spatial_competition` 会降低较弱空间邻居的激活。

因此，它不是把既有拓扑显示为二维或三维，而是为“哪些节点可以相连、活动如何传播”加入了结构先验。

## 当前实现的注意点

当前节点位置由 `sensory_seed` 与节点 ID 确定性生成，因此可复现，但并不是由刺激历史自然生长而来。当因果空间规则启用时，这些指定位置相当于预先铺设的发育几何。它作为空间实验的模型选择是合法的，但不能被误认为自发的空间组织。

## 主线基线

对于检验原始假设的实验，图组织应当可归因于外界直接触达、联想传播、遗忘、巩固、局部连接历史、感官适配器与外部刺激历史。关闭因果空间基底，可以避免一个未被明确承认的邻域先验预先决定哪些通路可能出现。

界面仍可提供用于观察的二维或三维**非因果投影**。这种投影必须明确标注为纯可视化，且不得反向影响节点生成、边形成、传播或竞争。

## 空间实验分支

可用独立模型包开启空间基底，研究另一个问题：

> 维数、局部空间邻域、传播距离与竞争，会如何改变联想、局部聚类和持续组织？

每个这类实验都应归档空间维数、位置生成规则、半径、邻域开关、竞争强度、种子，以及匹配的无空间基线。结果必须被解释为空间先验的效应，而不是原始无空间模型必然需要空间的证据。

## 后续方向

若未来令位置本身随刺激依赖的活动、生长或具身反馈而变化，应将其作为新的、明确的模型假设引入，并同时与无空间基线和当前固定坐标的空间分支进行对照。
