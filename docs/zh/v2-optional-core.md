为保留旧模型的规范表示，模型状态省略本表中等于默认值的字段，由明确的动力学契约提供默认值；表单和运行协议始终显示完整值。Python、Rust 和独立 SQLite Runtime 使用相同规则。实现指纹表示当前程序支持的版本，某个模型实际使用的版本以其状态 `dynamics` 为准。

## 连接形成与时窗

默认策略保持一条外部刺激一个共同触达集合。相同时间戳的两条独立外部刺激不会因此自动合并。时窗对照 `temporal-association` 则在实际外部刺激或内部兴奋信号递送时形成候选：

$$S(t)=\{i:a_i(t)>0,\;0\le t-t_i^{touch}\le W\},\qquad T(t)=\{j:\delta a_j(t)>0\}.$$

源必须实际被触达过，且没有被实验干预静默；目标必须在当前事件中真正获得正激活。仅允许 $S(t)\times T(t)$ 中不同节点的候选，受既有静默边约束。窗口包含两个边界；没有触达的新节点不会被空间坐标、标签或文档内容凭空建立。源到目标有方向，后来的目标不会自动反向连接过去的源。

候选分数仍为 $c_{ij}=a_i a_j$。`edge_birth_activation_product_min` 仅用于新边，低于门槛不生边；既有边仍能学习。这一点是对旧同名门槛的语义澄清。时窗使用最后实际触达时刻，而 `trace_tau` 只决定资格痕迹衰减，两者独立。

## 巩固和局部新颖

单节点直接冲量改为可配置的

$$b_i=\min(B,v_i(g_{first}\mathbf1_{first}+g_{repeat}+g_I\max(0,I-1))).$$

$B$ 是 `consolidation_cap`。内部递送没有直接冲量，不能借用上一条外部刺激的强度。新边的可选新颖加成为

$$r_{ij}=\max(a_i^{assoc},a_j^{assoc}),\qquad N_{ij}=g_N\max(0,1-r_{ij}/r_0).$$

该式只在 $r_{ij}>0$ 且至少一个端点在这批边形成之前已连接到邻域时使用，否则 $N_{ij}=0$。批内新产生的边不能反过来制造本批自己的“已有邻域”前提。联想分量按激活时间常数连续衰减，不把旧单 tick 的量冒充固定物理窗口。

新边初始权重为 $\min(1,g_{birth}c_{ij}+b_i+b_j+N_{ij})$，初始稳定度增加 $N_{ij}$，随后仍执行既有局部学习。加成只发生在出生时；没有联想传播或只有独立首次刺激，不算局部新颖。这里没有词义新颖度、全局新奇奖励或语义评分。

## 传播、抑制与全局钳制

`propagation_activation_min` 在发出信号前比较源激活；已排队信号照常递送。抑制扩散额外门槛 $m_q$ 按模拟秒定义，每个步长 $h$ 使用 $\max(\epsilon,m_q)h$，分别检查发送量与目标累计量。它只影响沿既有邻接的扩散，不拦截直接活动生成的延迟自抑制。

抑制递送时采用 $q_i\leftarrow\min(Q,q_i+\delta q_i)$。提高 $Q$ 可保存大于 1 的抑制势；Python/Rust 状态、JSON、Arrow 和 SQLite 往返都按该配置验证。暂停调低 $Q$ 会在当前模拟时间对已有势限幅，队列原值和时间戳保留。这个限幅是显式参数干预。

全局钳制默认关闭。开启后，在同一时间的已排队事件全部递送后、该时刻传播发出前，若 $A=\sum_i a_i>A_*$，使用

$$a_i\leftarrow a_i A_*/A.$$

直接和联想分量按同一比例缩放以保留有效状态分解，资格痕迹与已形成结构不按显示量重写。总激活不足时不放大，不注入外部能量。暂停开启或降低目标也在参数干预时应用钳制。这是全局约束的研究对照，不宣称它是局部涌现机制或默认意识假设。

## 证据、验收与尚缺范围

冻结旧 Rust 内核生成的起点、终点、在途队列和哈希作为控制样本，验证旧版继续和新增机制关闭时的等价行为。专项同时覆盖窗口边界、内部实际递送、零联想／无邻域的新颖对照、已有边不受生边门槛影响、抑制势大于 1、参数变更的队列保留、Python/Rust 数值对照和双格式模型往返。具体结果见[验证页](v2-validation.md)。

配置版本、输入事件、完整恢复状态和查询结果进入现有证据链；默认采样不是每次生边原因的完整逐事件日志，若要精确检查中间结构，应显式启用详细记录。科研参数不随显示性能档位变化。

C 的计算／拓扑预算、注意选择、能量供给与饥饿机制、因果空间仍在恢复中。本批不以参数数量增加代替完整 C 阶段，也不产生新的意识或 AGI 结论。
