# 多模态感官与输出器官

[中文](multimodal-sensory-and-output-adapters.md) | [English](../en/multimodal-sensory-and-output-adapters.md)

## 边界与目的

ThreeMind 已实现听觉、视觉、声音输出和图像投影四个可插拔适配器。它们位于 Core 之外：

```text
音频 / 图像 / 视频 / 麦克风 / 摄像头
  → 非语义编解码与感官采样
  → 匿名 SensoryFrame 序列
  → InputBus
  → ThreeMind Core
  → 匿名 OutputFrame
  → 声音输出器官 / 激活图像投影器
```

Core 不知道 WAV、像素、摄像头、频带、字符或“物体”是什么。适配器不使用语音识别、OCR、物体识别、预训练 embedding 或大模型。不同意识以自己的 `sensory_seed` 将相同物理特征映射为不同匿名通道；因此适配器定义的是感受能力和分辨率，不是意义。

四个设备在宿主注册表中默认可用，但新模型包中的绑定默认关闭。用户上传载体或主动开启麦克风、摄像头、嘴巴、图像读出时，UI 会显式启用对应宿主设备和当前模型绑定，并把最终配置写回模型包。

## 听觉感官 `auditory-sensor`

上传的音频由宿主解码为单声道物理采样，实时麦克风直接发送 `float32` PCM。听觉适配器按真实采样率重采样和分帧，然后采用以下可选编码：

- `band-energy`：默认模式。使用小型、确定性的频带能量组；它不是语音识别；
- `waveform`：把每个时间窗分成若干波形区间，以独立的正、负匿名通道保留较少变换的物理轮廓；零振幅不会被平移成持续刺激。

每个特征可产生 `level`、`rise`、`fall` 三类匿名通道。下降量使用独立的非负 `fall` 通道，因为 Core 不把负数解释为另一种兴奋。零驱动不排入输入帧，但从正值降到零仍由 `fall` 保留。首帧只建立变化基线，不制造虚假变化；浏览器 AudioWorklet 的短块先在适配器中保留，凑满一个感官时间窗后才编码，不用补零伪造静音。

可配置项包括目标采样率、每秒感官帧数、频带数和范围、波形区间数、水平/变化开关、增益、帧间输入 epoch 以及上传上限。麦克风实时监听默认关闭，必须显式开启。

## 视觉感官 `visual-sensor`

图像和视频由宿主解码为像素；实时摄像头在浏览器端按配置节奏产生低分辨率灰度帧。视觉感官可选：

- `luminance`：默认灰度亮度；
- `edges`：Sobel 局部边缘强度；
- `threshold`：按显式阈值形成二值物理采样。

这些都是确定性的信号过滤，不做目标分类，也不生成字符画语义。图像被缩放到可配置的视网膜尺寸后，按局部 patch 依次送入 InputBus。这样保留空间邻近与时间顺序，并避免把整张图的所有像素放进一次共同触达，进而错误地产生全图二次密集连接。每个像素同样可产生 `level/rise/fall` 匿名通道。

可配置项包括视网膜宽高、最高帧率、patch 宽高、过滤模式、阈值、水平/变化、增益、patch 间 input epoch 与上传上限。摄像头实时监听默认关闭。

## 输出器官

`acoustic-output-organ`（界面称“嘴巴”）直接订阅匿名 OutputBus，把节点 ID 与激活强度确定性映射为有限个振荡器的频率和响度。它不读取节点标签，也不执行 TTS；因此最初发出的可能只是噪声或音型。若未来形成稳定的刺激—活动—声音关系，应通过可重复实验与外部解码器验证，而不能由器官预先写入语义。

`activation-image-projector` 把匿名节点身份和激活强度投影为固定尺寸灰度图。它同样不读取标签，不宣称自己是生物器官；它是一个用于研究输出映射的外部实验器件。

输出端使用有界的最新帧缓冲和可配置推送间隔。浏览器跟不上时只跳过旧的显示帧，不阻塞 Core，也不修改意识网络。

## UI、协议与审计

右侧“刺激”面板的文本框上方提供 `＋`、耳朵、眼睛、嘴巴和图像读出按钮：

- `＋` 上传音频、图像或视频；
- 耳朵/眼睛分别启停浏览器麦克风和摄像头；
- 嘴巴/图像读出分别订阅匿名声音控制或灰度图像；
- 浏览器权限、上传/编码进度、失败原因和活动状态都有即时反馈。

实时二进制协议为 `threemind-media/1`。包头显式携带序号、采样时间和物理格式；服务端拒绝乱序、错误尺寸或类型不匹配的包，并对视觉帧再次执行最高帧率约束。暂停、关闭或断线会清空变化基线，不把中断期间伪造成巨大变化。

上传载体按 SHA-256 内容寻址保存在 `data/media/`，重复内容只存一份。写入采用流式限额，不把大文件整体载入内存。实时麦克风和摄像头的原始内容不落盘，只保存会话、匿名帧数量、InputBus `envelope_id` 和投递审计。审计数据库为 `data/media-audit.sqlite3`，可通过 API 和适配器管理页查询，并导出 CSV 或 JSONL：

- `GET /api/media/capabilities`
- `POST /api/media/uploads`
- `GET /api/media/sessions`
- `GET /api/media/deliveries`
- `GET /api/media/export?format=csv|jsonl`
- `WS /api/media/input/{consciousness_id}/{adapter_id}`
- `WS /api/media/output/{consciousness_id}/{adapter_id}`

## 依赖与降级

标准库始终支持 PCM WAV，浏览器实时 PCM/灰度像素也不依赖媒体解码包。完整的压缩音频、视频和常见图片上传使用可选依赖：

```powershell
python -m pip install -e ".[media]"
```

缺少依赖不会阻止服务启动；适配器管理页会显示“部分可用”及具体不可用能力，绝不把不可用信号伪造为零。

## 实验解释边界

当前没有“强制脑区”。听觉频带与视觉视网膜具有不同且不重叠的匿名通道命名空间，功能区是否出现，应由反复感官耦合、局部连接、遗忘、巩固、空间条件和抑制共同决定。`receptor_topology` 只是审计元数据，Core 不读取它。若以后为了对照实验加入强制分区，也必须默认关闭、明确记录，并与自然形成组分开报告。

同一载体在不同 seed 下映射到不同匿名通道；不同参数也会改变可感知信息。比较实验必须保存模型包、感官配置、载体校验和、投递顺序、背景条件和输出适配器设置。声音像语言、图像像物体或活动区域分化，都只能作为候选现象，不能单凭观感赋予理解或主观体验。
