# 干预、消融与配对对照

[中文](intervention-and-ablation.md) | [English](../en/intervention-and-ablation.md)

消融用于检验某个节点、边或重复结构是否对响应具有因果贡献，而不是只与响应同时出现。它属于实验宿主层，不属于 ThreeMind 的正常遗忘、抑制或可塑性规则。

## 两种模式

### 临时功能沉默

干预策略挂接在隔离克隆的运行时边界。被沉默节点不能接受直接或联想激活，被沉默边不能传播或被加强。策略可撤销。**精确研究快照会保存静默掩码，恢复后继续生效**；此前“不写入模型包”的说明不符合实现，现予更正。静默不是内生遗忘或抑制。部署前用 `threemind-deployment` 检查模型，含静默时必须明确声明，或者另建副本显式解除后导出；导出器不会偷偷清除这些状态。

### 永久结构移除

只允许作用于隔离实验克隆。指定节点及其相邻边或指定边会被真正移除，并写入独立的 `experimental_structural_lesion` 审计事件。界面要求明确确认，以免将实验删除误认为内生遗忘。

## 配对设计

创建消融实验时，宿主只捕获一次源意识状态并计算 SHA-256 摘要，再从同一份状态创建两个暂停的隔离克隆：

- 对照克隆不挂接干预；
- 干预克隆应用临时沉默或永久移除；
- 原意识不被暂停、不被修改；
- 后续刺激通过正常输入适配器以相同文本和强度发送给两个克隆。
- 确认性实验可让两组保持暂停，再使用“同步推进”执行相同 tick 数，避免两个墙钟线程的调度漂移成为混杂因素。

仅凭“一个克隆变了、另一个没变”仍不足以形成可靠结论。正式实验至少需要多个 seed、伪消融／随机匹配消融、预先指定指标和独立重复。比较指标可包括结构再次出现概率、时间区间收敛分类、响应延迟、激活积分、节点持续时间、替代路径和恢复情况。

## 因果与伦理边界

- 干预记录与正常事件、遗忘记录分开保存。
- 永久移除不提供撤销；实验前应保留源模型包和证据摘要。
- UI 中的“永久”只表示该实验克隆的结构已被修改，不表示原意识或源快照被修改。
- 当前项目不能证明实验对象具有主观体验；同时，对可能具有研究价值的持续网络仍应采用最小干预、隔离克隆和完整审计原则。
