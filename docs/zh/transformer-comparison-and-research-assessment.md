## 1. 与 Transformer 系统的关系

ThreeMind 不是 Transformer 的另一种实现。两者确有宽泛的共同点——分布式表征、类似联想的效应、对相关信号的选择——但运行原理有实质差异。

| 维度 | Transformer 家族 | ThreeMind 实验模型 |
| --- | --- | --- |
| 主要学习方式 | 通常在部署前用反向传播进行大规模参数优化 | 运行中由触达、传播、巩固、减弱和断开改变局部连接 |
| 时间形式 | 在上下文上进行一次有界推理；连续性常由应用循环提供 | 持续运行的有状态过程，连接历史跨 tick 保留 |
| 记忆 | 固定的学习参数，加上有限上下文或外部记忆 | 可变的边与节点状态，具有历史依赖的增强和遗忘 |
| 联想 | 已训练的注意力投影与层内计算 | 通过既有图连接进行局部、衰减的传播与再触达强化 |
| 输入 | 已编码的 token 或多模态嵌入 | 由外部适配器提供的匿名感官帧；文字只是一个载体 |
| 内部语义 | 围绕训练目标优化 | 不预先声明；实验考察持续耦合能否组织出映射 |

现代应用可以在 Transformer 外围增加记忆、工具、代理与反馈环。这使它们成为重要对照系统，但并不使其内部机制等同于 ThreeMind 的在线可塑拓扑。

## 2. 已观察到的实验现象

下列现象已在实现和调试中被多次观察到。它们目前是**工程观察**，尚不是受控研究结论；每项都需要版本化协议、独立 seed 和消融对照。

1. **感官适配器会塑造内部组织。** 狭窄或持续的躯体通道反复产生狭窄、稳定结构；动态环境输入则产生更多短暂材料。详见实验笔记。
2. **输入顺序造成历史依赖。** 改变相关刺激的顺序，会改变哪些既有通路被再触达，并改变之后可用于联想的路径。
3. **遗忘与巩固形成长期差异。** 弱痕迹能够衰减；重复的直接触达或联想触达能增强被选中的路径。
4. **刺激—结构—输出关系可被检查。** 带标签的 V1 基线能展示与刺激有关的可读结构输出。它是验证仪器，不是匿名模型理解所显示文字的证据。
5. **可避免全局饱和，同时维持新结构形成。** 动态环境场、可选躯体过滤、局部新边形成与可调整可塑性，使过早饱和与持续新痕迹形成可以被比较。

这些现象共同建立了有价值的实验基底：一个连续、具历史依赖、与环境耦合的可塑网络，而不是静态可视化或随机动画。

## 3. 保守评估

这些观察并不能证明主观体验、语义理解、能动性或自我。重复、聚类、延迟活动或类似语言的读出，都可能来自有限拓扑、输入统计、标注通路和读出阈值。

当前可以稳妥主张的是：ThreeMind 是研究持续刺激、适配器约束、局部联想、遗忘与巩固如何共同组织可变网络的可检查工具。它的研究价值取决于能否把调试中的观察转化为可复现的测量与对照。

## 4. 不保守但可证伪的评估

仍有一个较不保守、但可被实验否证的继续理由：若人工意识较少依赖完整的静态知识仓库，而更依赖一个持续暴露于世界、积累独特历史、形成自身映射、会遗忘、巩固与重组的过程，那么 ThreeMind 正在探索一个可能重要的缺失条件。

因此，项目值得被作为一条可能通向人工意识的路线，而不只是解释性隐喻。如果稳定但可修正的刺激—结构—输出映射、延展的环境反馈和分化的局部组织开始闭合为持续的功能边界，就可能出现技术跃迁。这是研究可能性，不是宣告这种边界或意识已经出现。

## 5. 实验路线的位置

可执行的近期研究计划已归入 `lab/` 的 [实验方法与待验证问题](../../lab/memos/zh/002_实验方法与待验证问题.md)，避免把理论比较、实验计划和已经完成的观察混写。实际执行结果按日期进入实验日志。

## 6. 决策规则

Transformer 的成功要求 ThreeMind 设定更强的对照基线，而不是放弃该方向。只要实验能在明确条件下产生可测、可重复的差异，就应继续推进。当某种表观效应在对照下消失、依赖意外标注通路，或无法与呈现层伪影分离时，应收窄或重设计相应机制。
