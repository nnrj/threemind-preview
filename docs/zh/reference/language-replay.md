## 可复用工具

`threemind.language-replay/1`保存章节、原文事件、采样、匿名通道、物体示意定义及证据路径。JSON上限32MiB，最多15分钟、100章、10000次采样；它是派生的可视化文件，不替代完整实验数据。原始大文件不随页面全部加载。保存为项目产物并标记同名schema后，可在回放菜单查看；当前列表沿用平台最近200个产物的范围，更早文件可本地打开。页面仅GET读取，不提交刺激或运行命令。

界面与离线MP4使用同一个`LanguageReplayRenderer`。导出按指定时间逐帧求值，不把机器编码速度当成实验速度；不实例化或推进Core。命令使用项目Node依赖、已安装Edge和FFmpeg，自行启动并关闭独立Vite预览；不接管用户服务。

```powershell
node tools/export_language_replay.mjs --input .work/language-replay-20261005/language-replay.json --output .work/language-replay-20261005/reexport.mp4 --fps 15 --ffmpeg D:/DevTools/ffmpeg/bin/ffmpeg.exe
```

加`--preview-only`只产生检查图；已有MP4拒绝覆盖。导出限制20分钟墙钟、512MiB视频，FFmpeg使用2个编码线程，不保存成千上万的临时图片。本次编码约139秒、MP4约5.4MiB；无需CUDA、Docker、在线模型或付费供应商。视频、JSON及封面使用现有Lab产物服务追加保存到E52项目，另增演示记录，不改原研究报告。
