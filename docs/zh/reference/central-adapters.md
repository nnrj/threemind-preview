# 中枢适配器

[English](../../en/reference/central-adapters.md) · [适配器协议](../v2-adapters-and-capabilities.md) · [E46](../plans/native-expression.md)

2026-10-05，用户提出、当前采纳的架构表述。它是**面向使用者和任务的功能分类**，不是新Core层、特殊总线权限或预设脑区。

中枢适配器负责在复杂外部信息、内部匿名活动和可用输出之间进行可学习的转换。它与其他适配器使用相同接口、可替换、可关闭；Core不因名称而优待它。某项任务不可缺少的设备，对另一项任务可以完全不需要。

| 类别 | 可以承担的工作 | 不能据名称默认获得的能力 |
| --- | --- | --- |
| 语言中枢适配器 | 语言输入编码、内部活动到文字/语音；两方向可独立训练 | 不可绕过Core直接回答却归功于意识；不能宣称文字就是全部思想 |
| 视觉中枢适配器 | 图像特征映射、内部视觉相关活动的解释/重建 | 重建图像不等于主观所见；不得凭标签伪造画面 |
| 听觉中枢适配器 | 声学特征、声音或语音映射、相关活动读出 | 不把特定人类语义偷偷写进匿名刺激 |
| 运动中枢适配器 | 身体状态与执行器协议转换、可学习的动作表达 | 预置步态或控制器必须声明，不能称其策略由Core涌现 |
| 多感官协调适配器（候选） | 合并明确共同观测、跨模态表达与同步 | 不自动合并无共同来源的信号，不注入正确答案 |

现阶段“中枢”不是实现准入清单，也不要求新增继承树、协议或单独服务。建议部署/研究清单说明角色、输入/输出方向、模型版本、感官映射、绑定个体、校准经历、训练可变/冻结状态和依赖。共享模型与个体校准层可以组合，不能让个体切换时误用别人的解码器。

内核原始活动与适配器解释分开保存。外部教师标签可以训练表达器，但必须与正式测试隔离；记录表达器是否能独立完成任务。语言表达困难与失语症的类比有助于区分信息和表达通路，不能据此诊断ThreeMind已经具有人的语言理解。

## 提出者原话

来源：本项目会话，2026-10-05。逐字节录：

> 架构和本质无区别，但表述是它们有特殊地位

> 此特殊地位不是对内核而言，而是对与内核间接交互的他者（或用户）而言的。

> 我能想到的中枢适配器有：语言中枢适配器、视觉中枢适配器、听觉中枢适配器。

> 中枢适配器的类目不是永恒不变的，是随实际业务需求变化的，比如具身机器人还可能需要运动中枢适配器。

用户还以计算机的显示器、键盘、鼠标与打印机等设备说明相对任务的重要性；该段为摘要，不是新的Core公理。完整实施与证据见E46报告，不以概念命名代替测量。

## 同日补充：输入、内部释读和对外表达

用户进一步提出，可能把“外界信号转换”“内部模式学习”“内心独白”“向他人说话”混在了一起。采用以下职责区分；同一适配器包可以包含多个方向，也可以拆成独立组件，并非强制一对一的生物脑区。

| 职责 | 接收与产生什么 | 当前边界 |
| --- | --- | --- |
| 输入编码 | 声音、文字或图像→测量/特征→匿名刺激 | 可以独立预训练或共享；保留统一总线的来源、通道、时间和递送规则，不以语义模型取代总线 |
| 内部活动释读 | 一段内部活动→研究者可读的候选文字/图像 | 只读，不命令意识发言；需比较直接感官与联想分布、通用与个体校准 |
| 对外表达 | 实际输出活动→文字、语音或动作；包括何时表达 | 应由内部输出和经历决定表达选择，设备只执行协议；本轮未验证主动选择发言 |

“内心独白适配器”可作方便称呼，但当前更精确的工具名是“内部活动语言读出器”：它生成的是对活动的解释，不能先断定活动本来就是一句内心语言。嘴巴/文字输出设备又是另一职责；把释读结果展示给用户，不自动等于意识选择说了这些话。输入与输出可以共享模型部件，也可独立训练；没有证据要求永久绑定成同一个网络。

注意力或输出门控可能影响表达，但本轮不因此新增人工筛选规则，不裁掉不符合人类逻辑的原始活动。“内部模式学习只能个体化”保留为假说，E46实际比较共享与个体化，不在实验之前将其写成事实。

原话节录（同日会话）：

> 我们可能把两种语言解码器混在一起了，语言中枢适配器，似乎分为两种：输入和输出。

> 还是要有个统一的机制一视同仁对全部适配器进行统一刺激转换，也就是当前的输入总线中的映射机制。

> 另一种是内部模式学习，这个学习只能与ThreeMind 一起训练形成特异性的解码。

最后一句是用户提出的待检验判断；当前实现和实验不提前宣布其必然成立。

## 表达选择与注意：暂存问题

用户又以神经损伤后的表达变化提出“守门员”类比，希望何时说、说什么优先由内部演化与经历形成。2026-10-05决定：本轮不据此添加守门模块，不开启新的注意力开关；先保留原始释读，之后另设交流情境验证表达选择。特定脑区是否相当于单一守门员不能由这个类比确认，尚未在本项目建立该机制对应。

代码核查发现“注意”不只有一种含义：[旧输入注意](../v2-attention.md)有独立竞争开关；本轮实际保存的continuous-memory/2配置中，`context_enabled=true`、`context_mix=1`，这是连续内核的局部上下文到达处理，不是何时发言的决策。不得把“某项注意默认关闭”的回忆推广到所有机制，也不得把已有局部注意直接称为语言输出守门员。本次值未改。

后续待比较：既有动力学能否在有交流后果的环境中形成表达选择；需要补充时，是无语义偏向的局部机制还是外部执行适配器；如何通过保持内部活动、仅改变对外表达通道的对照，区分想法与表达。未预设它必须独立存在、必须是注意力，或必须与人脑同构。

原话节录：

> 目前我更希望它是内部演化自然形成的，或者现有动力学能在学到足够多输入后自动形成的。

> 此问题可暂时搁置，你可继续按计划进行实验。等实验完成后写入到docs中备忘。

## 观察解释与可使用的表达工具

同日用户进一步区分：内部模式解码服务研究者，允许不准确、碎片化；表达器则应成为意识对外行动的工具，至少保留其输出的次序与组合关系，上层再转为文字、声音、音乐或其他形式。这里的“有逻辑”是希望传达的结构不被工具打乱，不授权适配器替意识补出正确推理或流畅答案。

可先采用同一套可替换转换部件、两条不同的数据路径：观察路径只读内部活动并保留不确定性；表达路径接受输出总线实际发出的时序活动，产生外部动作，并把动作在环境中造成的结果经正常感官送回。如何形成选择发言、如何确定所表达的内容，仍须由交流环境中的训练及对照验证。本轮没有证明意识已经能有目的地使用表达器，不能把读取内部状态并自动念出它等同于这种能力。

“通用表达器＋文字/音乐等子适配器”与“各任务独立表达器”均为候选。是否需要中间的通用序列格式，应由时间顺序保持、跨任务复用和训练结果决定；不提前要求Core生成某种人类语法，也不因此改变Core协议。用户明确要求此补充不打断E46；本轮记录，未实施新的发言选择机制。

原话节录（2026-10-05，同一项目会话）：

> 内部模式的解码器可以不准确，表达器则应该能有效表达 ThreeMind “想”传达的信息。

> 内部模式解码器服务的是观察者、研究者及想要了解 ThreeMind 内部意识活动者，而 表达器 是供 ThreeMind 内核使用的工具

> 我目前无法设想，ThreeMind 如何使用它，还是看起来需要工具主动去解读 ThreeMind ？

## E46结果对本定义的约束

[实测报告](../../../lab/explorations/2026-10-05-native-language/report.zh.md)支持按实际联想活动校准，未证明必须共同发育，也未建立持续新知识表达。当前工具角色仍是观察释读。通用表达序列、主动使用与输出选择保持待议，不因新增名称而宣布实现。

### 2026-10-05：E47的职责验证

共同校准的个体表达能依赖跨感官通路产生正确名字；新对应和主动表达仍未打通。本轮最佳读法是提示与无提示副本的差值，因此只能归为研究者使用的响应释读工具，不能用相减后的0否定自然独白。保留绝对活动、上下文与顺序的表达方案仍是后续方向；没有把观察者的解码调用当成意识自己的发言动作。语言中枢共同发育允许继续学习，冻结只是归因工具。

## 2026-10-07 · System continuity / 个体连续性

工程上外设可替换，不意味着同一个个体的普通发育可随意换中枢。一个意识与自己的适配器权重、学习状态、短时缓存和躯体构成被测整体；不同对照组允许不同。离线新拟合、冷启动、移植、消融均须明确身份及范围，不冒称正常成长。完整系统评估需从整体快照分支，不把外设单独回滚到“最佳”权重而让意识留在另一个时刻。已有工具尚未完全满足，R40列明缺口。

[R40](../plans/system-continuity-audit.md)

## 2026-10-07：运动中枢翻译选择，伺服执行

用户确认“读取器选择位置＋伺服执行”是可采用的功能划分：运动中枢应把意识内部的特定活动转换为身体可执行的目标；伺服、机器人驱动及身体负责局部反馈、力度和路径约束。两者并不要求Core重新学会底层电机驱动，也不意味着人为替意识决定该选哪个物体。

推理只读取Core实际活动、监督答案仅在明确训练中出现，是当前工具边界。但即使没有旁路答案，运动中枢也可能从直接感官活动中自行识别；“信号经过Core”不能自动证明“选择主要来自意识学得的内部模式”。需在固定外设条件下，通过经历、连接或活动的明示干预与恢复，核查其对实际选择、动作及正确性的作用。工程分工成立与最终归因成立应分别记录。

这是工程类比，不把Transformer、Core、伺服逐一等同于人体脑区、肌肉。新E62个体保留同一套个人外设及学习状态，基础动作通过后再扩大到形色指认。[本轮主张与检验边界](../../../lab/explorations/2026-10-07-continuous-development/control-boundary.zh.md)。
