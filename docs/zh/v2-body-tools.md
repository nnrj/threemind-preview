# 环境场、躯体过滤与模拟内感受

这些是 ThreeMind 内核之外的运行时工具。默认环境仍是 MuJoCo 物理模拟，躯体过滤和模拟内感受默认关闭。旧环境场现在明确命名为“合成环境场”：它是用于通道、适配器与刺激撤除实验的数值载体，不宣称真实生理来源或完整物理世界。默认感官来源的原则不变。

## 使用入口与参数

新建／暂停编辑中的高级参数分为“合成环境场”“环境躯体过滤”“模拟内感受”三组，20 个字段都有默认值及图形／JSON 双向编辑。运行详情的“感官与输入 → 环境与躯体”提供固定检查点、时间／来源筛选、图表、原始和编码值以及完整 CSV／JSONL 导出。读者可以查看更早检查点和载体，但没有参数写入权限。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `ambient_field.sample_us` | 100000 μs | 合成环境采样间隔 |
| `transient_rate_per_s` | 0.4 /s | 扰动出现的离散采样危险率 |
| `transient_amplitude` | 0.12 | 扰动通道幅度 |
| `lifetime_min_us` / `lifetime_max_us` | 200000 / 1400000 μs | 外部扰动寿命范围 |
| `maximum_transients` | 512 | 同时存在的扰动上限；记录未创建数量 |
| `ambient_field.intensity` | 1 | 该工具载体的输入强度 |
| `body_filter.enabled` | false | 显式开启环境载体过滤 |
| `body_filter.sample_us` | 100000 μs | 躯体感知采样间隔 |
| `threshold` / `adaptation` / `noise` | 0.035 / 0.55 / 0.02 | 幅度阈值、适应比例、均匀测量噪声 |
| `body_filter.channel_count` | 3 | 单个环境帧的感知容量 |
| `baseline_tau_s` | 1.2 s | 感官基线时间常数 |
| `baseline_capacity` | 4096 | 基线记忆最多包含的感官通道数 |
| `interoception.enabled` | false | 显式开启模拟内感受载体 |
| `interoception.sample_us` | 100000 μs | 内感受采样间隔 |
| `interoception.channel_count` | 2 | 感官接线通道数 |
| `interoception.amplitude` / `intensity` | 0.08 / 1 | 模拟信号幅度与输入强度 |

环境／感官种子 `RunSpec.seed` 创建后固定；模型身份种子 `Config.seed` 是另一项配置。上述 20 项可在普通意识暂停并提交检查点后修改。参数修改不追溯重写已经排队的刺激；基线、随机发生器、计数与已有扰动可以继续，后续新采样使用新参数。基线容量缩小时会在工具恢复后记录实际淘汰数量。

## 边界与时间

躯体过滤只作用于 MuJoCo 及显式合成环境场，不再次处理文字、音视频、遥测或远程器官自己的编码。内感受拥有独立开关，不经过环境躯体过滤，也不向能量账本供给。实验阶段可以关闭输入而让外部场继续变化；永久关闭全部来源时，这些工具停止新采样，已承诺的未来刺激仍按原时间递送。

采样起点为 $t$ 时，工具生成的结果位于 $t+\Delta t$；MuJoCo 仍按实际模拟区间结尾递送。观察频率、网页刷新率和宿主速度不会改变外部工具的采样期限。周期载体和测量噪声属于明确披露的外部实验假设，不是核心中的隐藏维持活动脚本。

## 躯体编码

同一感知时刻的独立帧分别处理，保持载体边界。未到下一感知时刻的帧被记为 `body_sampling`，原始载体保留，不更新基线或消耗测量噪声。对实际采样的通道：

$$
x'=\operatorname{clip}(x+\eta,0,1),\qquad \eta\sim U(-n,n)
$$

$$
y=\operatorname{clip}((1-a)x'+a|x'-b|,0,1),\qquad
b_{new}=b+(1-e^{-\Delta t/\tau_b})(x'-b)
$$

新通道的基线初始化为本次测量值。`Δt` 是这个通道上两次实际测量的模拟间隔；不是 UI 帧数。只保留正值且达到阈值的通道，再按当前编码幅度取容量内的最大值，并列使用通道编号。此选择是公开的感官限制，不解读环境意义；它与 Core 的输入注意门控是独立阶段。

超过基线容量时，按最久未观测时间、再按通道编号淘汰基线；计数进入证据。淘汰不修改模型中的节点、连接或记忆。噪声使用固定感官种子及可恢复的随机发生器状态；和旧 `SystemRandom` 路径相比，同源实验可以明确重复。这里不承诺跨 Python／数学库版本逐位一致。

## 合成场与内感受

合成场保留旧工具的缓慢周期、快速循环、随机漂移和有限寿命扰动。采样间隔为 $\Delta t$、出现率为 $\lambda$ 时，每个间隔最多新增一个扰动，概率为：

$$p=1-e^{-\lambda\Delta t}$$

它是离散采样载体规则，不是完整连续 Poisson 过程。提高采样间隔会改变载体分辨率，不能当作透明的性能档位。扰动在寿命到期后的首个采样时刻消失；达到容量上限的尝试被计数。已有扰动不因修改寿命参数而提前重写期限。基底与扰动是不同帧，感官通道由种子与来源命名空间确定；没有语义标签传入 Core。

第 $i$ 个模拟内感受通道在模拟秒 $t$ 的幅度为：

$$v_i(t)=A\left[0.35+0.65\frac{\sin(t/(0.9+0.7i))+1}{2}\right]$$

这恢复了旧版可选周期身体源的用途，并将 tick 转换为显式秒制。它不代表模拟了心脏或某种真实器官；真实机器／机器人应接入相应传感器，而不是把该公式当作真实感受。

## 证据、恢复与模型复用

原始 `payload.frames` 与躯体 `transduction` 结果按同一载体保存；`input_frames.stimulus` 记录感官编码后的输入，Core 注意选择另见 `input_gate`。未感知帧明确标记过滤原因，不能把其原始值冒充有效输入。检查点事务一起提交模型、原始载体、实际递送和外部工具状态。早期检查点查询不暴露未来的递送或门控结果。

`GET /api/v2/projects/{project}/runs/{run}/body-tools` 支持检查点、时间、来源和翻页；`/body-tools/export` 导出符合条件的完整 CSV／JSONL，使用数据库游标逐批读取。CSV 内嵌 JSON 列保存完整多通道数组；JSONL 首行说明检查点、状态哈希、筛选和工具配置。图表仅汇总当前页，导出不受页面 30 行限制。

Python SDK 的 `EnvironmentHost`、`BodyFilter` 和 `AmbientField` 可以在没有 Lab 数据库的独立宿主使用；通过 `capture()` 保存外部状态。Lab 把这些状态放在检查点 `context.body_tools`，MuJoCo 的原环境状态仍单独保留。普通分叉和配对共同培养继承同源外部状态；新的继承出生重新建立身体与环境，保留继承的 Core 结构。调整实验臂的躯体配置保留共同培养的未来输入承诺。

导出的 Core 模型继续是 state/5、causal/6、profile/4，不自动附带正在运行的合成环境或周期源。独立部署由宿主明确安装适配器并保存相应外部上下文；导入模型不等于重新播放旧实验环境。这与已经采用的显式外部能量供给边界一致。数据库仍为 schema 10，没有新增数据库或自动反复覆写模型文件。
