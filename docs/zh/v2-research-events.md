# 输入、干预与事件证据

记录与报告的“添加数据来源”现在可选择“输入、干预与事件”。这类来源固定已提交的 Lab 事件记录，供人工编写、AI 草案和四种格式导出使用。它不会推进意识、执行命令或修改原始事件。

## 选择范围

选择意识、具体恢复点和模拟时间区间，留空恢复点表示在提交采集请求时固定最新恢复点。采集同时要求事件时间不超过截止时间、提交版本不超过该恢复点版本。以后继续运行、修改参数或产生新事件，不会更新已经固定的来源。

| 范围 | 包含内容 |
| --- | --- |
| 全部已记录事件 | 所有匹配时间与提交边界的 Lab 事件，包括以后新增的类型 |
| 输入接收、调度与递送 | 感官输入命令、排队、拒绝、递送、能量／标量调制及遥测会话 |
| 人工干预与参数变更 | 干预与 `configuration_changed`，原始内容保留当时记录的参数和修改前后值 |
| 阶段与运行控制 | 阶段、暂停、终止、关闭输入、检查点及研究推进 |
| 结构、时序与器官读出 | 截面读出、时序读出及器官输出事件 |

“指定事件类型”可进一步按类型键筛选，以逗号分隔，与上表范围同时生效。精确成员列表来自 `/report-catalog` 的 `event_groups`，不是模糊匹配事件名称。没有匹配项时保存明确的空来源，不自动扩大范围。

## 时间、顺序与事实

默认模板包含日志条目总数、按类型与阶段分组的计数图、事件表格，以及研究目的和局限说明。计数图基于全部已采集行；图上同一类型的拒绝与成功调度分别计数。

表格显示模拟时间、事件类型与阶段、提交版本、事件 ID、事件键及可关联命令的受理时间。时间使用整数微秒字符串，保留精度；相同模拟时刻按原始事件 ID 排列。ID 是稳定展示顺序，不能证明同一时间戳内部的因果先后。

- `processed_command` 表示 worker 已处理命令。它不保证载体随后递送，也不保证通过注意／来源筛选。
- `scheduled_input` 表示已排队，`delivered_input` 表示观察到了递送事件；原始内容仍需结合通道与筛选证据解读。
- `rejected_input` 包含独立拒绝事件及能量／调制调度结果中的拒绝。不会仅因类型名带有 `_scheduled` 就标为成功。
- `configuration_commit` 表示参数修改与相应检查点已提交。

命令受理时间统一显示为宿主机 UTC；事件时间是模拟时间。二者不能直接相减计算延迟。尚未被 worker 处理的命令没有对应的提交事件，不会被编造成已执行干预。

计数单位是**日志条目**。同一输入可能形成接收、调度、递送等多条记录，不能把条目数解释为独立输入数或独立实验次数。事件来源只允许计数事实和分类计数图，不允许对每行固定为 1 的计数指标作“均值曲线”等没有解释意义的图表。

## 原始内容和性能

每个固定数据行保留完整事件 payload、原始 provenance、事件身份、提交版本和关联命令信息。载体和 provenance 另有 SHA-256，整个来源的哈希还包括选择条件、恢复点、所有完整行和覆盖说明。

表格默认每页 100 行，数据库查询先去掉大 payload 和原始 provenance，再返回页面。点击“查看原始内容”才读取该固定行的完整内容；这不是重新读取运行中的当前事件。移动页面可横向滚动查看全部字段。

采集通过数据库游标读取，事件游标一次取 16 行；写入达到 1000 行或 8 MiB 即提交给当前事务中的批次，整个来源仍在事务末尾原子生效。单个来源沿用 200 万行／512 MiB 上限；超限会失败并回滚，不保存截断来源。一个很大的单事件仍需要相应内存，缩小时间区间不能拆分它。

## 缺失与覆盖

来源显式记录省略的“提交版本未知”旧行数、首末时间、最大事件间隔、质量计数和选取范围。最大间隔是日志条目间隔，不是采样频率。没有匹配事件只能说明该范围内没有匹配的已提交 Lab 记录，不能据此证明内核没有活动。

这里不是每一次内核传播的完整轨迹，也不是当前待处理命令队列。读出器关闭或记录预算限制产生的未记录过程，不会被补造。需要判断连续性、因果响应或内部结构变化时，应同时引用轨迹、检查点、协议及相应专用测量。

## AI、导出与版本

AI 获得所选范围、来源哈希、覆盖说明，以及按类型／阶段聚合的全部事件数量和首末时间。不会自动发送原始载体、参数值或每行 payload；因此 AI 不能据此知道某次参数修改的具体内容。生成模板更新为 `threemind.research-authoring/2`，原生成调用保持原提示与证据。结构校验仍无法证明解释文字正确。

Markdown、HTML、Word、PDF 中包含事件表格、身份、时间、阶段和原始内容哈希。正文不展开大载体和完整参数；选择“证据包附带全部固定来源数据行”后，ZIP 内 JSONL 包含全部固定原始行，可重算来源哈希。未勾选时，清单明确说明未附带原始行。

数据库迁移 029 增加来源类型与 worker 能力匹配，新文档采集、导出和 AI 作业要求 `worker.research_events_v1`。旧节点不能误领它不理解的任务；已排队旧任务保留原来的要求。Core、Runtime 模型格式、科学参数和原始事件记录方式均未改变。
