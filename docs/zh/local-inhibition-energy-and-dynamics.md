# 局部抑制、可选能量记账与动力学追踪

[中文](local-inhibition-energy-and-dynamics.md) | [English](../en/local-inhibition-energy-and-dynamics.md)

## 研究动机

在关联实验中，网络可能出现过度联想：一个刺激唤起的局部结构继续激活不相关的既有结构，最终造成大范围震荡。ThreeMind 不把预期答案或“正确概念”写进抑制规则，而是提供一个默认开启且可显式关闭的局部抑制机制，检验竞争、注意切换和短时不应期能否由相邻节点之间的简单作用涌现。

该机制与旧式全局稳态钳制、空间竞争、注意／竞争门彼此独立。旧式全局稳态钳制默认关闭；只有模型包明确设置 `homeostasis_enabled: true` 时，才会按 `target_total_activation` 缩放总激活量。关闭局部抑制时，已有兴奋、联想、固化和遗忘行为不受影响。

## 拓扑局部抑制

- 兴奋连接继续保持有向，`A → B` 不会因为抑制功能而产生 `B → A` 的兴奋传播。
- 抑制把任一方向的既有连接视为物理邻接，因此可在 `A` 与 `B` 之间扩散；这只是由兴奋边派生的运行时索引，不增加新的模型拓扑。
- 节点因本 tick 的激活上升产生局部抑制势。抑制在下一 tick 生效，形成延迟反馈，而不是事先判断哪个节点“应该”获胜。
- 抑制势会衰减、饱和，并按相邻连接的导通强度分配。一个节点向所有分支送出的抑制总量不会超过它本次可转移的量，分支不会凭空复制抑制势。
- 抑制以分流方式降低节点对直接刺激和联想传播的响应，并降低其继续传播的能力。节点自身保留的抑制可形成短时适应／不应期。
- 系统没有因果波 ID、全局赢家扫描或语义规则。全局抑制若出现，应来自许多局部抑制的传播叠加。

主要参数包括抑制生成增益、衰减、扩散比例、响应衰减增益、饱和值和最小传播量。所有参数都能在创建意识时或运行中调整；功能默认开启，仍可显式关闭以作对照。

## 可选能量记账

能量模拟与抑制相互独立，并且默认关闭。关闭时，能量变量完全不参与动力学；计算机提供的电力和算力已经足以维持人造网络运行，Core 不会暗中引入一个生物式资源上限。

开启后：

1. 模型从显式初始储备开始；
2. 直接激活、联想传播和抑制扩散按各自配置消耗储备；
3. Core 内部不会自动恢复或凭空产生能量；
4. 可选的 `energy-budget` 适配器从外部按有限速率供应能量；它不排序、不筛选刺激，也不改变注意预算；
5. 关闭供应适配器时，储备可以耗尽，活动也可以衰弱；
6. 缺能结构损伤是另一个默认关闭的实验项。与能量记账同时开启后，结构维护成本和缺能侵蚀才参与运行。causal/9 已撤去独立饥饿判死，所有死亡按连续无激活宽限期判定，详见[确认记录](plans/energy-lifecycle.md)。

这个标量仍是实验性记账量，尚不能宣称等同于现实物理能量。未来可研究更客观的约束候选，例如真实功耗、可用计算时间、内存带宽、温度或机器人电池，但这些量也必须通过明确边界进入，不能被包装成内核的隐藏目的。

`host-telemetry-field` 是独立且默认开启的宿主物理遥测感官：它把 CPU、内存、磁盘、网络汇总计数和供电状态等可用实测量编码为普通匿名刺激。可选的 `process-telemetry-field` 表示整个 ThreeMind 服务进程，`runtime-telemetry-field` 表示单意识实例的真实执行代价，二者默认关闭。三者都绝不是能量补给，也不会直接修改节点；完整边界见[物理遥测感官](physical-telemetry-sensory-adapters.md)。

## 动力学追踪

详细记录开启时，Core 先写入一个完整的非因果观测关键帧，随后逐 tick 保存稀疏变化：

- 节点激活、抑制和支持度的前后值；
- 直接触达、联想触达与待生效抑制；
- 节点和连接的创建、删除、增强与减弱；
- 本 tick 的抑制生成／传播及可选能量余量。

追踪数据只经输出和历史接口供调试器读取，绝不会反馈进网络。UI 在 **意识管理 → 详情 → 动力学追踪** 中提供分页浏览和原始稀疏增量详情。详细记录仍由“开始／停止详细记录”显式控制，以避免无意生成大量数据。

## 尚未实现的生物学对照

生物神经系统存在专门的抑制性神经元及多种递质、受体和局部回路。当前实现是抽象的节点状态与拓扑扩散，不声称复刻这些结构。未来可以把“显式抑制节点／抑制边类型”作为独立模型能力，与当前均质节点方案做可证伪的对照实验；不应在没有对照的情况下把它偷偷变成默认规则。
