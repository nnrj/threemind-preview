# 因果空间基底与观察投影

当前版本说明（2026-09-08）：新建意识使用 causal/8、state/6；旧版本只读导出，不再原版本续跑。下文版本引入与升级说明属于历史记录，当前默认值和局部公式以[V3 恢复记录](plans/v3-restoration.md)为准。 可选空间竞争保持原数值格点执行；兴奋发送和旧拓扑抑制使用独立传播周期。

空间基底是独立、默认关闭的实验机制。它恢复旧版空间维数、邻域半径、距离传播与空间竞争能力，不把普通三维显示当作因果空间的替代。基本立场继续遵守[原空间决策](spatial-embedding-decision.md)：人为给定的发育几何必须公开，不称其为刺激自行生成的空间组织。

## 配置与入口

| 参数 | 默认 | 范围及含义 |
| --- | --- | --- |
| `spatial_embedding` | false | 是否启用因果空间基底 |
| `spatial_dimensions` | 3 | 1～64 维 |
| `neighborhood_enabled` | true | 空间启用时，约束连接适应和兴奋传播 |
| `spatial_radius` | 2.5 | 正数，最多 10⁶，单位为基底坐标单位 |
| `spatial_competition_rate` | 0 | 0～10⁶，每模拟秒；0 关闭竞争 |
| `seed` | 20260724 | 既有内核身份种子，创建后固定；同时用于此显式发育几何 |

五个新增参数进入新建、暂停编辑、项目默认配置的高级分类“因果空间实验”，与 JSON 编辑双向同步。它们是模型参数，不受设备显示档位控制。半径、维数、开关和竞争速率可在暂停后显式修改，修改按旧参数结算至当前模拟时间后生效；已经排队的信号保持其旧时间戳和数值，不被新几何追溯改写。

“动力学 → 空间基底”提供检查点时间筛选、完整分页选择、因果坐标投影、坐标／分组／距离表和完整导出。选定检查点后，图像、表格和导出固定为同一状态及其参数；列表不会默默跟随正在变化的运行。刷新当前组可载入新检查点。

## 坐标不是连接

对节点身份 $i$、坐标轴 $j$ 和种子 $s$，使用固定 ASCII 字符串：

```text
threemind.sha256-id-axis/1:{seed}:{node_id}:{axis}
```

取 SHA-256 的前 4 字节，按大端无符号 32 位整数 $u$ 解释，坐标为：

$$x_{ij}=\frac{u}{2^{31}}-1$$

每维位于 $[-1,1)$。这是可复现的发育位置先验，不是随机造边。节点仍必须经实际刺激产生；距离再近也不会单独建立连接。节点身份与种子随模型保留，导入、普通恢复和继承同一结构时保留对应几何；新增节点按自己的新身份定位。

维数增加时保留已有坐标轴，增加新的轴；减少时去掉后面的轴。显式修改维数会改变距离，因此必须作为配置干预解释，不能当作调节视觉效果。旧版使用的 BLAKE2b 位置规则没有直接沿用；新版规则随 `causal/6` 明确定义，不宣称复现旧模型数值，也不迁移旧测试 data。

坐标是内存缓存，可由模型身份、种子、维数和规则版本精确重建，无需在模型文件或数据库中重复保存另一份坐标主副本。缓存不参与状态哈希，读取几何不会改变连接、活动、事件编号或模型状态。

## 邻域与兴奋传播

全部维度参与欧氏距离：

$$d_{ij}=\sqrt{\sum_{k=1}^{D}(x_{ik}-x_{jk})^2}$$

当空间与邻域开关同时开启时，共同触达／时间窗候选只有在 $d_{ij}\le R$ 时才参与连接适应，包括新生与既有边的该次强化。这对应旧候选邻域检查。调小半径不会删除原有边；原有边仍可按正常遗忘规则消退。

兴奋传播在原本的源活动、权重和秒制传播增益基础上乘：

$$g_{ij}=\max\left(0,1-\frac{d_{ij}}{R}\right)$$

半径外和刚好位于半径边界的兴奋通量为 0。实际发出的正通量才参与后续传播／适应预算及能量收费。已经发出的信号在未来抵达时不重新按距离计算。

距离规则不自动套用到拓扑抑制扩散：此处恢复的是旧空间分支的兴奋规则，抑制仍按其已有拓扑和能量规则传递。开启邻域不应该悄悄改成另一种抑制模型。

## 空间竞争的秒制定义

空间竞争与邻域开关独立：只要空间开启且竞争速率 $r>0$，每个固定数值边界检查已有的半径内有向边。对目标节点 $i$，计算较强、未被干预静默的源通过这些边指向它的数量 $m_i$，然后：

$$a_i' = a_i\exp(-r\,\Delta t\,m_i)$$

直接和联想活动分量使用同一比例，痕迹与结构不会由此自动删除。关闭竞争或没有较强邻居时不抬高或压低激活。源、目标或边被干预静默时不参与竞争。

所有强弱比较来自同一边界快照，随后统一施加比例，避免旧版逐边原地修改造成遍历顺序偏差。旧 `spatial_competition` 的 tick 比例不能直接作为此处每秒速率；这是显式规则替换。竞争作为固定数值边界上的算子，不是连续解析积分，也不会因为多读取一次图像、增加一次检查点而多执行一次。

## 完整几何与分组解释

“半径内有向连接”只计已存在的边。分组是这些边忽略方向后的弱连通分量，包含孤立节点，每组使用最小节点身份作标识；不是潜在空间邻居集合，也不是自动识别出的语义类别。普通显示布局仍保持非因果，与此处的实际坐标查询分开。

画面可选择 X／Y／Z 对应哪三个坐标轴，隐藏轴用 0 投影；距离和邻域仍使用全部 $D$ 维。屏幕上重合或接近，不证明高维距离小。显示节点上限与形状沿用设备偏好，完整导出不受显示数量截断。连线代表已有结构，超出当前半径的旧边仍可能显示；是否位于半径内在距离表中单独列出。

坐标和结构对应选定检查点。激活等原始数值取该检查点的已结算状态，导出同时给出 `time_us`（观察时界）和 `state_time_us`（最近状态结算时间），二者不一定相同，不能把原始状态行冒充另一时刻的采样。

## API、导出与版本

* `GET .../checkpoint-history`：按 `after_us`／`until_us` 包含端点筛选；`before` 为不包含的版本上界，按版本倒序分页。没有旧接口最近 200 条的查看限制。
* `GET .../spatial?checkpoint_id=...`：完整分组统计及坐标、连接距离的独立分页。`node_after` 按节点身份，`edge_after` 按排序后连接偏移。
* `GET .../spatial/graph?checkpoint_id=...&axes=2,0,-1`：同一检查点的有界显示数据。轴从 0 开始，-1 表示隐藏；不得重复、越界或全部隐藏。
* `GET .../spatial/export?checkpoint_id=...&records=nodes|edges|all&format=csv|jsonl`：节点 CSV、连接 CSV、或完整混合 JSONL。导出包括原始节点／边数值、坐标／距离、参数、规则、种子、检查点及哈希；CSV 混合类型请求会明确拒绝。

只读项目成员可查看和导出；空间配置写入仍需研究者权限及暂停检查点。项目隔离由相同数据库访问边界执行。旧内核版本没有空间契约时明确返回 `supported=false`，不制造旧几何历史。

新建为 `causal/6`，状态结构保持 `state/5`，profile/4 不变。无需数据库迁移，也不引入新数据库。旧 1～5 版本可按原动力学继续，冻结 causal/5 控制保留原生终点哈希。显式启用新空间配置才升级旧模型，并保留已有能量、注意账本、有效调制和在途队列；缺失的旧账本从明确升级边界建立。

独立 Python／Rust Runtime、JSON／`.tmind` 和 SQLite 恢复均保存空间参数与身份；Core 的 `spatial_geometry()` 支持无 Lab 数据库查询完整派生几何。同时补强独立能量／调制端口的输入关闭检查，已经排队的承诺仍保留。

此页交付空间实验功能和证据链。高维几何和弱连通分组仍需遍历相关结构；完整检查点查询／导出不是每帧显示路径，不据此宣称大模型实时吞吐已达标。远端设备、旧环境身体、研究工具及笔记／报告继续按[恢复清单](v2-capability-restoration.md)推进。
