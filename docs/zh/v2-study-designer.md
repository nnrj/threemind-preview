# 图形研究协议与条件编辑

“实验与训练”及“比较与消融”的“设计新实验”提供图形协议。共同基础使用与意识创建相同的 419 项科学参数目录，基本参数有默认值，高级参数按内核、感官、来源、躯体、读出、记录等分类。条件组可以添加、复制、改名、删除，逐组编辑核心参数、Runtime 参数、已有结构干预和阶段门控。

右上角链接切换整个协议的 JSON；行号、高亮、格式化、重复键检测和校验使用现有 CodeMirror 编辑器。基础配置与各条件也保留图形／JSON 双模式。切回图形前校验，冻结时无论是否点击过校验都重新检查；服务器保存入口执行相同规则。失败保留草案，不创建半个实验。

## 共同基础与显式覆盖

基础协议确定出生与共同培养。每个独立环境种子培养出一个起点，同一种子的各条件从这个真实恢复点分叉。条件只保存相对基础协议的覆盖，未覆盖字段随基础协议变化。界面保留已有显式覆盖，即使该值恰好等于新的基础值；可以主动清除一组覆盖，重新继承基础。

每组 `config_patch` 配置 Core，`runtime_patch` 配置真实 Runtime 组件。支持感官、来源准入／竞争、身体过滤、内感受、外部能量供给、环境场、读出、器官及记录设置。后端 `resolve_arm` 是预检和 worker 执行共用的解析函数，不再各自维护不同的组件清单。旧的 `body_filter`、`interoception`、`energy_supply` 等顶层条件写法仍可执行；同一个根不能同时用旧字段和新覆盖，以免覆盖顺序含糊。

以下参数在条件表单中只读，JSON 改动也会拒绝：

- 环境类型、环境种子、模拟时钟策略、速度、条件总时长、重放区组与实验归属。
- Core 身份种子、数值格点间隔、出生时的初始能量储备。
- 已建立感官身份的编码方式、规范化、通道数量及各感官自身的不可变身份字段。
- 阶段名称、顺序、数量与时长。各条件可改变阶段是否接收刺激，以及是否永久关闭输入。

这些设置应在共同基础编辑；跨身份或数值步长收敛比较使用独立实例，不能伪称同一起点的配对延续。配对实验拒绝各分支自行采集物理遥测；真实测量应先记录再重放。设置允许调整并不代表当前实验必然触发该组件，例如没有文件载体时改变听觉参数不会凭空产生声音刺激。

基础中的共同结构干预没有定义执行时点，新的协议拒绝它；各条件中的结构干预在分叉后执行，只针对已经形成的结构。没有用人工配置生成本不应存在的连接。

## 模板与阶段

提供局部机制消融、刺激撤除／恢复、感官带宽／动作反馈、任意可变参数扫描和自定义条件。模板是可继续编辑的起点，不是意识存在或某种效应成立的证明。

扫描字段来自真实参数目录，数值、布尔与枚举值按实际类型校验，限制为 2～12 个不同值。模板只有点击“应用模板到草案”后才替换条件，保留其他基础参数，并提供一次撤销；撤除模板同时设置基础阶段与总时长。阶段门控维持原半开模拟时间区间。

这次同时修正阶段／带宽过滤重建 `Stimulus` 时丢失 `bypass_attention` 的问题。已有在途帧的竞争决定现在保持不变；过滤不撤销已冻结的标记，也不绕过增益或其他内核约束。

## 重放区组

选择重放环境后，按种子编号分别编辑刺激记录。每帧有微秒时间、强度及匿名节点／幅值表格，帧与通道均分页；可切到 JSON 导入较长序列。保存区组经过实际 `Stimulus` 契约检查，不排序或删除用户提供的数据来掩盖错误。

时间从共同培养开始计量，条件起点是共同培养结束时刻。每个区组必须有明确记录，不能缺一组便自动套用另一组。相同记录换种子编号不构成独立重复；完全相同的区组给出提示，采集独立性仍须由研究者根据来源判断。空记录允许作为显式无外界刺激的设计。

旧协议可能在 `base.replay` 和 `replay_blocks` 同时放帧；旧配对执行实际上选用后者。新的保存入口拒绝这类未使用参数。已冻结的旧 worker 协议保留原选择行为；重新设计时可明确移除基础中未使用的帧，原区组和原实验不变。非重放环境携带重放区组也会被拒绝。

## 查询、复用与边界

实验库支持名称检索和分页，列表只读取标识、名称与哈希，选中后单独读取冻结协议。意识列表刷新使用摘要，不重复传输每个实例的完整科学参数和重放数组。详情、执行、导出仍使用完整原协议；这不是减少科研数据。

“以此协议再设计”打开独立草案，冻结后创建新的实验编号；旧实验的协议及校验哈希不会改变。与档案注释、模型本体和 E 的笔记／结构化报告各有职责。

接口新增 `GET /api/v2/study-configuration`、项目内 `POST studies/validate`、`GET study-library` 和 `GET studies/{id}`。`GET runs?summary=true` 提供轻量运行列表。现有完整查询继续可用。数据库保持 schema 15，Core／state／profile 版本不变，没有读取旧 data。

本批完成配对协议编辑。人工逐步命令、同源沙箱、等待／读出／注记、输入顺序／重复／遗忘模板、AI 计划桥以及 E 的写作与报告仍按[恢复计划](v2-capability-restoration.md)继续，不能把这些尚未完成的模块算作本编辑器的功能。
