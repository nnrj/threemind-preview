# continuous-memory/4：执行与状态契约

[English](../en/local-events-v4.md) · [实施计划](plans/local-events-v4.md)

`threemind.continuous-memory/4`、状态 `threemind.continuous-memory-state/4.1`。Python 与 Rust 分别独立执行。`/3` 继续可创建、恢复和运行；共享代码可以修改，但不能改变其既定行为。本期不自动升级个体，也未把新建默认从 `/3` 改成 `/4`。

## 对象自己的时钟

节点拥有激活、迹、抑制、支持度 S、H、疲劳/显著性及各自时间锚点；连接拥有权重、资格迹、稳定度、H、短时突触资源、快迹及各自锚点。实际触达、发出、局部失效时才写回这些量。节点安排自己的下一发出时刻、激活失效、回收及可选能量维护事件，连接安排自己的失效、新颖性结算或旧稳定度对照事件。索引队列只递送已安排的事件，不扫描图决定谁更新。

激活/迹/抑制和资格迹保留指数消退。默认H及权重、支持度沿 `/3.1` 的解析积分；稳定度损失按本连接资格迹的时间积分结算。后者取代原全图离散更新，是 `/4` 明示的数值语义变化。`legacy-stability` 对照保留原离散遗忘算式，但由每条连接自己的周期事件执行；不能等同完整 `/3`。

传播仍默认每100ms，首次发出默认对齐这一模拟格点；异步选项从该节点实际开始工作时安排下次发出。10ms `step_us` 仅保留为旧配置元数据，`/4` 不使用全图10ms求解。非默认 `step_us`、`association_window_us`、`attention_budget`、`target_total_activation` 明确拒绝。全局稳态、空间竞争、输入排名、时间窗全图生边及传播/学习配额不支持。模拟时钟仍是单调微秒，宿主速度不改变它的事件顺序或传播周期。

观察、保存、加载校验、明确的暂停配置变更及结构继承可以遍历全图；这些不是普通运行时的更新。默认传播仅遍历有关节点的邻接，`scan-control` 显式枚举全体节点后运行同一局部发出算子。对象按需结算不停止闲置遗忘，提前计算的到期事件保证无输入时也会失效。前一讨论把 `/3` 的回收归入旧全图扫描并不准确：`/3.1` 已使用局部到期回收，不能用未执行的旧全图裁剪解释其文字保持退化。

## 接收到什么就处理什么

默认 `reception_mode=unified`：激活、迹、抑制生成、S/H、疲劳和普通学习不按外部/内部标签选动力学分支。源标签仅记录 direct/associative。信号可以携带发送者自身特征用于原局部上下文，外部没有发送者特征时使用零键；“统一处理”不等于强行制造相同的输入特征。`legacy-source` 保留外部直接强化、内部到达参加上下文与新颖性的区别，作为显式对照。

接收端先处理已递到本节点的同刻消息；`coincident` 默认本地整合，`sequential` 逐条处理。此选择会影响饱和、疲劳和局部上下文，不能仅因时间主观而视为数值等价。同刻先接收，再发出，再判定到期。它不要求所有节点同步刷新，也不查询其他节点实时激活。

一个外部输入包或一个节点发出的局部多目标包携带实际接触通知。只在该包真正到达的节点间按其接受量建立/强化接触；没有全体活跃节点两两查找。普通权重与稳定度奖励保持直接增加，新颖性不转为D。统一模式的出生窗口记录真实本地再到达，历史来源模式只计内部到达；立即结算对照分别使用本包接受量与旧 associative 判据。奖励增益公式不变，算子身份明确区别于旧核。

节点H剂量来自自身接受量，连接H剂量只来自通过本连接资源/幅度/能量门控后的真实发出量，参考量0.1模拟秒。节点H不赠给连接，也不读取两个端点激活相乘以延长H。短时突触仍可能先释放而在发送下限被拒，拒绝不获得H剂量；本期没有悄悄改掉这一既有机制或把H增益0.2调大。

## 局部资源场

`energy_model=local-field` 是默认模型；`energy_simulation_enabled=false` 仍是默认总开关。不是模拟液体。固定区域由独立能量种子与节点出生ID决定，供给位置不依赖图大小、学习随机数或显示坐标。区域相当于显式资源接触范围，并不宣称是生物脑脊液空间。关闭能量时没有供给/支出/维护动力学。

`counter-random` 用独立计数哈希；`stream-random` 用独立、完整保存的64位随机流。两者都可重放；熵不取自宿主时间。一个供给事件把资源放入一个区域，区域内按各节点自身容量缺额比例摄取，没有先遍历到谁就先给谁。固定区域数默认16，节点容量默认1。初始资源总额按区域均分并受初始容量裁限；后续 `energy_capacity` 是每个区域池的上限，`energy_node_capacity` 是每节点上限。不同于共享账本的全体单池容量，比较时必须声明此区别。

维护只结算节点自身和其拥有的出边，开启缺能损伤时节点自行安排维护事件。能量支出及匮乏侵蚀影响有关对象，不取全图规模计算损伤，也不对图统一磨损。区域摄取访问该区域成员，是局部竞争成本；不能宣称与区域人数无关。能量报表全局汇总是只读工具。`global-ledger` 作为共享资源对照，使用同样局部工作/维护算子，只把消费对象换成共享池，不偷用旧全图饥饿侵蚀。

## 回收、唤醒与恢复

自动/手动回收、留点开关沿既定决策。休眠、唤醒默认关闭；休眠关闭联动关闭唤醒，不自动重新开启。只有残余接触传递两端真实信号，同刻在连接上相加；节点/连接各判自己的正阈值。唤醒不赋固定权，不批量恢复其他连接，弱残余可立即再次消退。删除和静默不会被唤醒抵消；关闭唤醒后在途唤醒包也不能生效。

状态完整保存局部锚点、待发出/失效事件、在途消息、短时资源/快迹、抑制待量、孤立计时、局部储量与随机流。恢复拒绝身份/定义哈希不匹配、缺失必要到期和无效对象。完全旧版通过自身身份运行，不允许把 `/3` 状态标成 `/4`。显式结构继承是新个体出生，继承投影后的结构、S/H、稳定度及既有经历计数，重置动态活动、资源历史、消息和时钟；它不是连续恢复。

模型选项、种子、区域划分与传播周期出生固定。数值调整通过已有暂停/检查点/配置审计流程，先按旧参数结算，再启用新参数；H边界和资源容量缩小时明确裁限，观察工具不修改参数。API/CLI同一注册目录可选 `/4`；UI展示该目录及选项，失效旧参数不展示为可操作设置。
