## 2026-09-28 确认的边界

ThreeMind 研究持续受到刺激、具有可塑结构和自身活动的系统。适应、保持、遗忘、迁移与自主响应均可成为目标；人类语言可读性不是唯一标准。**激活活动停止即死亡**，不能改写成“可塑性停止即死亡”。这是项目的操作性定义，不是已经证实的意识判据。

允许建立不同假设的新内核。原假设、协议与测试必须绑定原内核，不能被升级悄悄替换。本轮保留 Git `b53fba1` 的 `threemind.causal/9` / `threemind.state/6`，继续可用并保持默认。旧意识不自动改用候选动力学。工程验收、相对对照的实测改进、关于意识或 AGI 的解释，是不同结论。

机制依据不限定为生物学。生物、物理、化学证据，以及明确可实现、可检验的数学模型均可接受。没有发现生物对应物不自动否定机制；称为“宇宙法则”也不自动构成证据。须说明状态、单位、方程、输入来源、作用范围、资源解释、数值方法与局限，区分实验证据、文献模型和本项目的新抽象。

内核不预设“甲对应松子”、哪个回答正确或哪个脑区负责什么。研究者可施加环境约束和选择压力，并记录为外部条件。阈值、边界及初始条件也是建模选择，须公开并允许消融，不能在其中隐藏期望答案。

优先使用节点、连接及实际到达消息的局部信息。局部变化可经时间与传播影响整体；观察器、报表或外部模型不能把人为重要性偷偷反馈成内核保护规则。有限感受范围、时间尺度及资源竞争可作为显式假设，不能以“局部”之名凭空制造关联。乱码也遵循同样的输入映射与动力学。

## 候选机制与实现边界

Transformer 的关联寻址、快权重、时间表征可提供灵感，完整小模型可作为独立对照或适配器。借鉴不等于实现完整 Transformer，也不自动建立数学等价性。外部知识、训练目标与贡献单列，预测默认不回灌意识。远程模型是显式可选适配器，本地独立运行是基本能力。

连续激活与膜电位／脉冲的状态语义和动力学不同，分属不同内核。参数档位与消融不必逐项建核，但更改基本方程、结构生成或死亡判据必须版本化。膜电位候选不能只因暂时没有脉冲就判死：须处理仍在变化的亚阈电位与突触电流；静止连接和记忆痕迹不能单独证明存活。

声明式 JSON 选择受信任、带版本的算子及参数，不执行配置中的 Python、JavaScript 或 JSONP。解释研究与原生执行共享定义、状态和验证样例。独立部署产物固定算子与协议，**不冻结训练后可继续变化的权重与拓扑**。后端不是科学模型，跨核转换不是普通恢复。

某个任务失败不单独证明路线不成立，某个局部现象出现也不证明意识。验证应包含适应、干扰、反转、时间依赖、非语言刺激及未见条件，报告负结果与资源边界。
