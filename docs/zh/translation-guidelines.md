# ThreeMind 中英翻译规范

[中文](translation-guidelines.md) · [English](../en/translation-guidelines.md) · [文档与科研写作规范](writing-guidelines.md)

制定日期：2026-11-21。依据作者在中文校订、英文翻译和术语讨论中提出的要求整理，与写作规范配套使用。适用于论文、报告、技术文档、补充方法、术语表及图表文字的翻译和同步修订。

翻译要做到信、达、雅：**信**，忠实保留事实、定义、研究主张、论证关系和结论力度；**达**，让英文读者清楚理解对象、步骤和理由；**雅**，用自然、准确、流畅的学术英语表达。三者应同时满足。准确不等于逐字硬译，流畅也不授权改写作者的科学主张。

## 1. 先确定底稿，按本次修改范围同步

以作者本次指定、已经校订的中文版本为翻译依据。旧英文稿用于查找已有表述和对应位置，不能反过来覆盖新中文。对整篇文档工作时，记录所用的中英文文件及版本；对单句或单段请求，以用户给出的文字为准即可。

中文只改了一句，英文就按该句及必要的衔接调整，不顺手重写整段、删改相邻结论。作者指定保留的段落继续保留。摘要字数、标题长度和格式按当前任务处理，不能把某一次投稿的限制套到所有后续版本。

**反例：**作者补入“并应用于新情境”，译文继续沿用旧段落，漏掉新增内容。

**正例：**把新增含义译入相应句子，再检查相邻句的指代和衔接；其余准确的内容保留。

## 2. 忠实翻译命题，保留结论的力度和范围

先理解一句话在断言什么：谁在什么条件下做了什么，证据支持哪项判断，哪些词表示假设、可能性、因果或比较。译文保留这些关系。不能为了显得谨慎，将“实验表明”习惯性改成“可能与……相容”；也不能把待检验假设译成已证实事实。

| 中文 | 不合适的译法 | 合适的译法 |
| --- | --- | --- |
| 这些结果表明，经历形成的连接参与组织响应。 | These results may be compatible with a possible role for experience. | These results show that connections formed through experience help organize responses. |
| 我们假设，持续经历能够塑造自主活动。 | We demonstrate that ongoing experience shapes autonomous activity. | We hypothesize that ongoing experience can shape autonomous activity. |

`show`、`demonstrate`、`support`、`suggest`等词按上下文和证据选用，不机械规定中文某词只能对应一个英文词。关键是译后主张的确定程度、适用范围和因果关系没有变化。

“自主活动”“人造意识模型”“自我意识”等概念按原文的定义分别翻译。不能为了谨慎把模型的研究定位删掉，也不能把通过自主活动判据译成已经验证了另一个概念。

## 3. 保留作者定义，不在译文里另立定义

定义的对象、范围、构成和例外都属于正文内容。应完整翻译，并在后文依照同一定义使用。发现定义有技术问题时，应指出问题及依据，按照已有授权处理；不能只在英文里悄悄修正。

**反例：**原文讨论“意义由外部观察者赋予”，译文自行补出“本文中的意义仅指任务答案”，从而缩小原命题。

**正例：**忠实翻译原命题。如需限定“意义”的含义，另列建议供作者决定，并在获准后同步修改两版。

同样，“不预置语义”与“任何状态都没有意义”，“内核不接收答案”与“包括教师监督的适配器在内的整个系统都不接收答案”，分别是不同命题。翻译不能扩大或缩小约束的对象。

## 4. 先辨认概念，再选词；术语表随已确认的定义更新

优先采用专业读者熟悉、符合具体机制的词。作者已经确认的定义和译名优先于旧稿中未经确认的表述。若旧术语表落后，应记录并在获准范围内更新，不能为迁就旧表删去“中枢”等有实际含义的部分。

术语查核可从[项目术语表](terminology.md)起步，同时核对作者当前底稿中的定义。若不能确认某个词是否为通行术语，应查原始论文、正式教材或权威技术文档；仍无依据，就把它作为描述性用语解释，不声称它是行业公认的名称。中文译名不自然时，应改进中文表达，而不是顺便改变英文原词所指的量或机制。

下表说明应核对的区别，供当前文稿选词时使用；它不替代文稿的完整术语表，也不授权全局改名。

| 中文概念或表述 | 英文处理方式 | 需要保留的区别 |
| --- | --- | --- |
| 刺激 | stimulus；复数 stimuli | 接口上的 input 可以译为输入，但不能把已定义的刺激一律改称 input；图内也一致。 |
| 响应 | response | 按正文区分响应、响应差异和行为，不为避免重复而交替替换。 |
| 激活、激活信号 | activation、activation signal | 状态或过程与传导的信号分别表述；若采用其他已确认的专业译名，应统一说明。 |
| 抑制、抑制信号 | inhibition、inhibitory signal | 与短时压抑所指的机制区分。 |
| 读出器、输出适配器 | readout、output adapter | 按正文定义的职责翻译，不因二者都可训练就混称。 |
| 按固定规则读出 | read out responses using a fixed rule | 说明读取规则固定，不能自动改成参数冻结实验。 |
| 参数冻结的读出器 | a readout with frozen parameters | 说明停止更新的是哪个组件及其参数。 |
| 参数冻结的输出适配器 | an output adapter with frozen parameters | 不能省略组件身份，只写成 fixed readout。 |
| 运动中枢适配器 | motor-center adapter（采用该已定义名称时） | 保留中枢的职责含义，不能仅为缩短名称改成 motor adapter。 |
| 内核 | Core（作为本文正式组件名时） | 正文统一大小写；代码标识、版本字符串、文件名及他人文献中的 kernel 保留原样。 |

同一概念统一名称，不等于同一个中文词在所有语境里只能用一个英文词。例如，“独立来源”若已定义为原始个体及其派生副本的共同统计起点，可按确认的译名使用 `independent origin`；“数据来源”仍按数据出处翻译。不能把来源、实例、个体、配置和配对比较组全部替换为 `instance` 或 `source`。

还要检查中文是否误译了本来恰当的英文术语。例如，`exposure`在刺激实验中可指接受刺激，不宜照摄影语境写成“曝光”；`learned response`若采用“习得响应”，应与全文的“响应”一致，并说明它指学习形成的响应方式。名称自然以后，方法仍需交代清楚；一个英文短语并不会自动成为无需解释的专业术语。

选词应依据实际含义。例如，公式中的信号幅度若对应 `amplitude`，不能仅因中文读着别扭就改成“传导的难易程度”，因为后者换了讨论的量。中文的“传导”“传递”也不要求与 `conduction`、`transmission`逐字配对；应核对具体过程及领域用法，再沿用确认的译名。

## 5. 保留数量、统计单位和逻辑条件

逐项核对来源数、个体数、副本数、题目数、世界数、重复次数、分母、效应量和区间。保留“全部”“至少”“仅”“两种条件均”等词的作用范围。尤其注意联合判据：未同时成功，不等于每个组成条件都失败。

**中文：**“八个提示中，没有一个在两种配对关系相反的教学条件下都得到正确的新目标回答。”

**错误：**“None of the eight questions was answered correctly.”

**正确：**“None of the eight prompts yielded correct new-target answers under both teaching conditions with opposite stimulus pairings.”

这里的0/8表示八个提示均未满足两种条件联合成功的要求，不能译成八次单独作答全错。同理，64组比较、每组五种系统，应保留组与系统的层次，不能合并成320个独立比较。

百分比与百分点、响应大小与响应差异、持续时长与观察窗口也应分别核对。不能因为英文更短就省去影响数量含义的定语。

## 6. 保留实验步骤、动作主体和连续性

译文要让读者分清谁接受教学，谁产生响应，谁读取活动，谁更新参数，谁执行动作。保留保存、复制、教学、测试、干预和恢复的实际次序。快照副本与繁殖子代、完整个体与仅内核状态，按原文区分。

**中文：**“适配器读取节点激活，再按运动系数计算指令。”

**错误：**“The coefficients read node activation and generate commands.”

**正确：**“The adapter reads node activation and uses the motor coefficients to calculate commands.”

“有提示记录减去无提示记录”若指逐项数值相减，应写成 `subtract the uncued activity values from the corresponding cued values`，而不是 `take the set difference`。是否读取一段时间的过程，也不能译成只取某个时刻的状态。

内部时间与程序在现实中运行的时间分别表述。“从300内部秒运行至600内部秒”可译为 `advanced from 300 to 600 internal seconds`；若文稿选择 `seconds of simulated time`，首次说明后保持一致。

## 7. 用自然英文重组句子，保留解释的次序

可以调整语序、拆分长句、补出英文语法需要的主语、将名词结构改成动词。先说明目的，再描述操作和结果，让专业读者不必反复回读。避免堆叠抽象名词、连续被动句和没有定义的缩写。

**生硬：**“The implementation of the verification of the effect of connection blockade was conducted.”

**自然：**“We tested how blocking the connections affected the response.”

主动语态通常便于交代谁做了什么；关注干预对象时，`The target connections were blocked`也很自然。不要求所有句子都以 `we` 开头，不为“学术腔”堆积名词，也不为避免重复而改换已经定义的术语。

原文如果缺少关键主语、比较对象或步骤，先查同段上下文和所引方法。仍无法确定时，指出缺项，必要时提出一个具体问题。不要替作者编出一个看似顺畅的实验流程。授权的语言调整可以直接完成；涉及科学含义的新增解释单独标明。

## 8. 时态反映叙述对象，保留必要的时间信息

通常用过去时叙述本批已经完成的操作和结果，用现在时说明定义、规则及文章中的图表内容；未来工作按其计划或可能性表达。按语境选时态，不机械地把中文每个“了”译成某种固定时态，也不为简洁删去所有表示完成或先后的信息。

- “实验采用了两套外设。”可译为 `The experiment used two peripheral configurations.`
- “输出适配器将响应转换为指令。”作为一般职责可译为 `The output adapter converts responses into commands.`
- “固定参数后，我们继续教学。”可译为 `After freezing the parameters, we continued teaching.`

原文没有强调的先后、必然性或因果关系，不因时态和连接词的选择而凭空增加。例如，先后发生不能仅靠一个 `therefore`改写成因果结论。

## 9. 正文、图表和补充材料一起核对

同一个刺激、组件、条件和统计指标，在正文、图中文字、图注、表头、术语表和补充方法中使用同一已确认名称。不能正文用 `stimulus`，图中却未经说明改成 `input`；也不能正文说读出器参数冻结，图中只写成容易混淆的 `fixed mapping`。

英文图注应交代分图、组别、测量内容和必要统计信息。方法细节可由明确的节号或实验编号引向补充材料，不在图末突然加入“另行保存”“分别记录”等操作旁白。

保留公式、参数符号、代码字段、版本标识、图表编号和引文对应关系。参考文献的作者、题名及出处按真实来源核对，不能把自行翻译的题名当作正式英文题名。研究中实际提供启发并被论述使用的文献，应在相应论点或方法处引用。

英文列表通常可用 `1.`、`2.`，段内列举可用 `(i)`、`(ii)`；按目标文档的格式保持一致。具体期刊或平台要求在投稿时核对，不将某次模板的限制固化为所有文档的要求。

## 10. 区分翻译、技术修正和压缩改写

翻译保持内容对应；技术修正解决原文与实现或证据不一致的问题；压缩改写为了特定篇幅删减信息。三者可以在获准的任务中一同完成，但应让作者知道哪些属于含义变化。

作者要求翻译时，不自行删去理论主张、重要条件或实验结论。作者明确要求缩写时，先保留研究问题、主要方法、关键结果及结论，再删重复和次要细节。字数上限是上限，不必凑到恰好相等，也不能为少几个词制造歧义。需要同时提供完整译文与压缩版时，清楚区分版本。

发现事实冲突时，说明原句、依据和建议修改，不在英文中无声解决。已获准的修正直接实施并列出；作者限定不改的内容，继续按限定处理。已发表报告的科学解释更正沿用[结论契约](plans/experiment-conclusion-contract.md)的追加修订规则。

## 翻译和交付前的复核

先通读中文及相关定义，再逐段翻译。初稿完成后，先对照两版核验含义，再暂时放下中文，单独阅读英文，检查它是否像一篇自然、连贯的英文论文；最后核对图表、术语和交叉引用。

逐段至少核对：

- 主语、动作、对象、比较关系和因果关系是否一致？
- 定义、研究问题、结论力度和必要条件是否保留？
- “全部”“仅”“同时”“至少”等逻辑条件是否译对？
- 数据、单位、分母、时间、版本号和引用是否一致？
- 新增的英文解释是否确有原文或已获准依据？
- 英文读者能否知道为什么这样做、怎样做、得到了什么？
- 同一术语是否在正文、图片、表格和补充材料中保持一致？
- 本次中文修改是否完整同步，未涉及的已确认内容是否保留？

关键定义、容易歧义的统计句和重要结论，可额外用中文复述译文含义再与原文比较；这种检查不能代替源文和证据核对。整篇文档交付时，说明实际同步的版本，并列出涉及含义的修正、术语调整和仍待决定的问题。只请求一句译文时，直接给出译文，不附上一套检查报告。
