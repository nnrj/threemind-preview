# 人工实验控制台与同源沙箱

意识详情的“人工实验”用于在明确恢复点上操作、观察和留下研究注记。它复用真实 Runtime、感官输入和结构干预，不生成另一套模拟内核。配对研究的冻结条件保持只读；可从其恢复点创建独立沙箱，再开展人工探索。

## 推进与暂停

已暂停且未死亡的普通意识，可以推进指定模拟秒数，或推进当前 Core 的一个数值步长。默认值为 0.01 模拟秒，单次范围为 1 微秒至 24 模拟小时。操作接受时锁定科学修订号和绝对目标：

$$t_{目标}=t_{接受时恢复点}+\Delta t$$

worker 继续原有时间戳队列、数值格点、环境状态和读出窗口，在该目标提交恢复点并暂停。这个停止点不替换运行协议的总终点；目标超出总终点会拒绝，可先在暂停配置中明确延长总时长。实时模式仍受宿主单调时钟约束；不把“一个数值步长”解释为一个渲染帧或固定 CPU 耗时。

每次操作有请求 UUID。相同请求重试返回原操作，相同编号携带不同参数会拒绝。接收确认丢失时，界面提供“重试同一操作”；重试不会在最新时间上再加一次时长。租约重试也继续到已经记录的绝对目标。模型状态、最终操作回执、输入与事件在同一个受租约保护的数据库事务提交；失败不留下假成功回执。

提前手动暂停或正常关闭 worker 会记录中断及实际停止时间。死亡、终点与失败保留真实状态，不能把未达到目标记作完成。结构干预和关闭输入通过已有命令队列提交，在下一次推进生效；不以按钮点击时的浏览器时间伪造生效时间。

## 被动观察与注记

默认选择最新已提交恢复点，也可选择历史点。状态摘要保存该点的实际指标与哈希；图谱操作保存恢复点和查询引用；输出操作保存截至该点已提交的截面、时序、声音及图像事件引用。没有记录的输出保持缺失，未来事件即使模拟时间相同也不会越过科学修订边界混入。

图谱、输出引用和注记只读取必要的元数据，不为写一句注记展开完整模型。摘要需要实际状态，计算前后检查 Core 哈希不变。注记是研究者文字，不写入模型激活或连接。原始输出是数字证据，不自动声称有语义理解。

操作列表按稳定游标分页，查看旧页时新记录不会挤动当前成员；主动刷新回到最新。每条记录可以打开固定恢复点图谱、节点／连接查询或对应输出证据。JSONL 导出使用数据库游标，包含全部筛选意识的操作、参数、操作者、初始与结果恢复点、状态及错误，不局限于当前页。

写入观察记录和注记也属于项目写操作，只读成员可以查看与导出已有记录。所有读取和写入经过同一项目授权和数据库行权限。

## 同源沙箱

“从此恢复点创建暂停沙箱”创建独立意识，保存精确来源恢复点，初始 Core 状态与选中点一致，并继承可恢复外部状态。新沙箱保持暂停，直到用户明确推进。原意识、原始证据和协议不变；真实设备会话不随模型时间倒流或自动复制。

沙箱可以使用原有图形／JSON 参数编辑、普通感官输入、干预与恢复工具。克隆仅保证明确起点相同；后续输入、参数或物理环境不同会产生不同轨迹，不能因此自动宣称满足配对因果推断条件。

## 接口与部署

项目内意识路径下新增 `research/actions`（提交及分页查询）、`research/export`（完整 JSONL）、`research/evidence/{id}`（原始事件）。`forks` 支持 `paused: true`；图谱查询支持 `checkpoint_id`。数据库迁移 016 增加同库 `research_operations`、项目隔离及恢复点引用，没有引入 MQ 或额外存储服务。

升级先停旧 worker，执行 `threemind migrate` 后再启动。迁移显式设置 schema 搜索路径，并分别验证从已有版本升级和全新初始化。Core causal/7、state/5、模型 profile/5 与 419 项科学参数不变，没有读取旧 data。
