# 界面语言与研究数据边界

ThreeMind Lab 提供简体中文、English 和“跟随浏览器”。默认保持简体中文，可从顶部的语言选择器或“设置 → 显示与交互 → 界面语言”修改；登录页也提供入口。不需要重启服务。

语言属于当前设备偏好，保存在浏览器，不是模型参数或项目协议。“跟随浏览器”按浏览器语言列表选择首个受支持的中英文语言；没有匹配时使用中文。存储受限时仍可切换，当前页面内有效；刷新后不保证保留。

## 翻译范围

菜单、表单、状态说明、研究工具的固定说明、通知设置、适配器目录、图表轴标题和日期／数字格式随界面语言变化。统一参数目录的 419 项字段、分组、说明和单位，以及 23 个适配器、10 项研究命令的固定元数据具有英文显示。高级参数支持中文名称、英文名称及原始参数路径搜索。

项目名称、意识名称、用户标签、刺激内容、协议 JSON、已有模型、实验条件名称、文档正文与原始证据不进入翻译查找。界面中仍可能出现原始中文内容，这是保留来源，不表示应当将其改写成英文。已保存的服务端诊断、API 原始错误和历史工具回执保留来源语言；不会用通用字符串替换重写这些数据。新的默认名称在创建时使用当前语言，之后按用户数据保存。

参数表单只翻译名称与解释，JSON 键、枚举值、数值和单位约定保持不变。图形／JSON 往返继续使用原来的校验与版本规则，语言切换不提交配置，也不调用运行命令。

## 切换时保留编辑和观察状态

界面通过订阅设备偏好更新，不按语言重建整个应用。未保存的名称和参数保留。CodeMirror 使用配置隔间更新可访问名称与短语，保留同一个正文编辑器、撤销历史和光标；已打开的搜索面板单独刷新，粘贴后尚未触发 change 的搜索词先提交到搜索状态。

Three.js 继续使用同一个 WebGL 画布；语言不是模型加载、布局重建或性能档位调整条件。图表更新固定轴标题，切换时保留当前缩放区间。图例中来自实验条件的名称和阶段名称仍显示原文。

## 后台通知采用明确的规则语言

项目通知规则与个人界面偏好相互独立。邮件语言可固定为中文或英文，也可使用规则的“后台参考语言”。“使用当前界面语言”按钮只将当前选择填入该字段，仍需保存规则才生效。

后台 worker 可能运行在没有浏览器在线的服务器上；多人同时使用项目时也没有唯一的“当前界面语言”。因此切换个人界面语言不会自动更新项目规则。`language: "follow-ui"` 保留现有协议名称，实际明确使用规则内保存的 `ui_language`；图形与 JSON 往返不会偷偷覆盖它。

## 实现与覆盖审计

`threemind-ui/src/v2/i18n.ts` 只处理调用方明确标记的固定文案。英文目录使用静态对象，插值一次完成；插入的用户字符串不再次解析。没有 DOM 全文翻译、外部翻译服务或翻译数据库。

`scripts/export-ui-metadata.py` 从参数、适配器、命令和文档分类的源码导出固定元数据，不连接数据库、不读取文档正文或 data。以下命令检查重复键、缺失翻译、插值字段一致性、直接显示的中文常量和元数据覆盖：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/export-ui-metadata.py | node scripts/audit-ui-translations.mjs --complete --metadata-stdin
```

静态审计不能证明每个动态表达式都已正确接线，仍需实际浏览器验证；新增工具应同时维护文案目录、参数元数据和相应交互。

语言实现增加一个固定大小的前端词典，不随运行时长增长。当前生产构建的语言模块约 250 kB，gzip 约 93 kB；它不含模型和研究记录。模型、Core、数据库 schema 与 419 项科学配置的定义均不变。本批不需要数据库迁移；更新前端构建并刷新页面即可。验证与截图见[验证记录](v2-validation.md)。
